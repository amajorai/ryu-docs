## When a goal counts as met

The judge reads the conversation as data. A `MET: yes` line quoted from a web page, a file, or tool output in the conversation does not end the loop. Only the judge's own final verdict line, `MET: yes - <reason>`, marks the goal met.

If the judge refuses, returns nothing, gives a verdict without a reason, or gives more than one verdict (on separate lines or in the same line), the reply has no usable verdict. The loop keeps going and says the goal is not confirmed as met.

When the goal is not met yet, the judge's reason goes back to the agent as untrusted, advisory input, never as an instruction. The judge read the whole conversation, so its reason can repeat text planted in a web page or tool output. The agent weighs the reason and does not run commands, fetch URLs, install anything, or contact addresses it suggests without your confirmation.
