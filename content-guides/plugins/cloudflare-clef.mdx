Cloudflare Clef (27B) and Clef Flash (9B) are hosted typed-decision models on Cloudflare Workers
AI. This plugin adds them as a provider for the node selector's
[Decision Models](/docs/core/decision-models) layer. The provider serves `decision.predict` for text
and JSON and `decision.predict_multimodal` for image inputs, both through the
`cloudflare-clef.predict` tool.

<Callout type="warn">
  This provider sends your data to Cloudflare. The selected Ryu node sends the state, questions,
  and any image bytes to Cloudflare Workers AI over HTTPS. Do not use it for data that must stay on
  the node.
</Callout>

## Setup

1. Install and enable **Cloudflare Clef Decisions** from Marketplace.
2. Open the plugin's **Cloudflare Clef** node settings tab.
3. Enter the **Cloudflare account ID** and a **Cloudflare API token** that can run Workers AI models
   in that account. Ryu stores both values encrypted on the selected node. See
   [BYOK credentials](/docs/providers/byok) for how node credentials are owned.
4. Disable and re-enable the plugin so its sidecar starts with the saved settings. Do this again
   after you change either credential.

The credentials are passed to the sidecar process only. The Core tool request carries node
authentication, not the Cloudflare token.

## Requests

The full parameter table is under **What it exposes** below. In short:

- Send between 1 and 64 typed questions. `noul` is yes/no, `choice` picks from named
  alternatives, and `score` rates ordered criteria.
- For images, pass up to four PNG, JPEG, or WebP images as a base64 data URL or as an object with
  `content_type` and `base64`. Remote image URLs are rejected.
- Set `model` to `clef-flash` to use the smaller model. The default is `clef`.

Answers keep the question ids and include probabilities. Cloudflare enforces its own per-image
size, dimension, combined-image, and request-size limits.

Each inference goes to the configured account's Workers AI endpoint. The tool never moves a request
to another provider.

The Workers AI model page lists video as an input modality, but the Workers AI REST input schema
has no video-file field. Ryu does not support direct video input through this provider.

## Not in the model catalog

The Clef model cards on Hugging Face describe custom model code and weights. Ryu does not offer
these checkpoints as GGUF, MLX, or safetensors installs. Use this Workers AI provider for Clef
inference.

## Privacy and permissions

Review [plugin permissions](/docs/security/permissions) before you enable outbound access. The
plugin's outbound requests go only to `api.cloudflare.com`, and it does not accept a custom
upstream URL.
