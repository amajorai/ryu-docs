This plugin provides Composio's tools to agents. Composio event triggers that start an agent or a
workflow are bound and consumed through Connect instead. Core checks every saved target against
your permissions and the presented credential's restrictions before it runs a delivery; see
[Connect trigger events](/docs/standalone/connect-api-trigger-events#core-target-bindings-and-consumption).
