This provider connects Ryu to [Ollaya](https://ollaya.dev/), an open-source local decision-model
service. Ollaya answers typed `choice`, `score`, and yes/no questions about text or JSON and returns
structured answers. It does not generate chat prose.

The plugin calls Ollaya's TypeSafe-compatible `POST /v1/systemone` and `GET /v1/models` endpoints
on the selected Ryu node. Ollaya remains a separate process that you install and start yourself.

## Setup

1. Install Ollaya using its [platform instructions](https://ollaya.dev/docs/quickstart).
2. Start it with a model, for example `ollaya run laya`.
3. Enable **Ollaya Decision Models** in Ryu and select it under **Decision Models** in the node
   selector.

The plugin uses Ollaya's default loopback address, `http://127.0.0.1:11435`. The model list shows
only checkpoints already available on that machine.

<Callout type="warn">
  The plugin supports only a keyless local Ollaya service. Core does not send provider credentials
  over plaintext HTTP, so an Ollaya server configured with `OLLAYA_API_KEY` is not supported.
</Callout>

## How agents use it

Agents call the stable `decision.predict` tool whichever decision provider is selected, so
switching between Laya and Ollaya does not change what agents call. The provider reports an error
when Ollaya is not running or the requested model is not installed. See
[Decision Models](/docs/core/decision-models) for the common request shape and a provider
comparison.
