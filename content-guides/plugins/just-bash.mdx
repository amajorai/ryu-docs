## What it does

A simulated bash shell for agents, powered by Vercel Labs' [just-bash](https://github.com/vercel-labs/just-bash) CLI and exposed as one command tool, `just-bash.run`. The agent writes an ordinary bash script (pipes, redirection, loops, `grep`, `sed`, `awk`, `jq`, `find`, `sqlite3` and other common commands) and gets back `stdout`, `stderr` and `exitCode` as JSON. It needs no Docker, container or VM runtime.

Each call mounts a folder from the active workspace read-only as the shell's working directory. The script may write files, but writes stay in memory and are discarded when the call ends. The real workspace is never modified. There is no network access, no Python or JavaScript runtime, and no host binaries such as `git` or `node`.

## Install the just-bash CLI

just-bash is a Node.js CLI (Node.js 20.19 or newer) that you install yourself; Ryu does not bundle or download it. Install it, then add the binary to Core's command-tool allowlist:

```bash
npm install -g just-bash@3.6.0
export RYU_COMMAND_TOOL_ALLOWLIST="just-bash=$(command -v just-bash)"
```

Set `RYU_COMMAND_TOOL_ALLOWLIST` in the environment Core starts with, then restart Core. Each entry is `name=absolute-path`, and entries are separated by `,` or `;`. The plugin refers only to the `just-bash` key, never to a filesystem path. The CLI always reports version `1.0.0`, so Core cannot check which release is installed. Pin the npm version yourself.

## Limits

| Limit | Value |
| --- | --- |
| Working directory inside the shell | `/home/user/project` (the mounted folder) |
| Script size | 8192 bytes of UTF-8 |
| Timeout | 60 seconds per call |
| Output | About 1 MiB in total. Longer output is cut and returned as raw text with `truncated` set to `true`. |
| State between calls | None. Variables, functions, the current directory, and written files are discarded. |

<Callout type="warn">
  just-bash is beta software, and a simulated shell is not a hardened isolation boundary like a
  container or microVM. A script can read every file in the folder it is given, including hidden
  files such as `.env`. Run untrusted code in a real sandbox instead.
</Callout>

See [plugin runtime](/docs/extend/develop/extensions/plugin-runtime) for how command tools run.
