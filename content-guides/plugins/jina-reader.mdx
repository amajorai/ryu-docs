## What the Extract capability accepts

The **Extract** capability (`web.extract`) sends the page URL to Jina Reader and returns the page
content. Set `format` to `markdown` (the default, main-content Markdown), `html`, or `text`.

The target must be a public HTTP or HTTPS URL without embedded credentials. Extract rejects these
before it calls Reader:

- `localhost`, `*.localhost`, `*.local`, and `*.internal` hostnames, including absolute names
  with a trailing dot such as `localhost.`
- Private, loopback, link-local, `0.0.0.0/8`, multicast, and reserved IPv4 addresses
- IPv6 unspecified, loopback, unique-local, link-local, IPv4-mapped, and multicast addresses

Reader resolves hostnames and follows redirects, so these checks apply to the URL you pass, not to
where it redirects.

## Errors

A provider denial, rate limit, malformed response, or target error (an HTTP 4xx or 5xx from the
page) returns the raw Reader response instead of results. Retry after you correct the target or
resolve the provider restriction.
