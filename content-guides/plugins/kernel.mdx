## What it does

Kernel adds [Kernel](https://www.kernel.sh) cloud browsers to Ryu's Browser layer. When you select **Kernel** in the Browser provider picker, the standard `browser.*` tools that agents call drive a Kernel browser. Ryu connects to Kernel's hosted MCP server and manages the OAuth sign-in for you.

## Setup

1. Ask an operator to allow the reserved `mcp:server` permission for this plugin in the [Gateway grant policy](/docs/gateway/governance). Kernel's MCP server needs it, and enabling the plugin is refused without it.
2. Install **Kernel** from Marketplace and approve its permissions.
3. Connect your Kernel account when Ryu asks. You can limit the authorization to one Kernel project.
4. Select **Kernel** in the Browser provider picker. See [swappable layers](/docs/core/swappable-layers) for how providers are chosen.

## How tabs map to Kernel sessions

Each Kernel browser session is one Ryu tab. Kernel controls a browser by screen coordinates, so Ryu binds the coordinate verbs and leaves the element-reference verbs unbound:

| Ryu verb | Kernel behavior |
| --- | --- |
| `browser.navigate` | Creates a new Kernel browser on the URL and returns its session as the tab id |
| `browser.tabs` | Lists your live Kernel sessions |
| `browser.screenshot` | Captures the session's screen |
| `browser.click_at` | Clicks a viewport coordinate |
| `browser.key` | Presses a key or chord; `cmd` becomes `Ctrl` because Kernel browsers run on Linux |
| `browser.scroll` | Scrolls at the viewport centre; pixel amounts are converted to wheel steps of about 100 px |
| `browser.drag` | Drags between two viewport coordinates |

Every `browser.navigate` creates a new Kernel browser, with no cookies or sign-in state shared with earlier sessions. `browser.snapshot`, `browser.click`, and `browser.type` are not available through Kernel. `browser.tabs` shows each session's start URL because Kernel does not report the page a session is currently on.

<Callout type="warn">
  Kernel bills each browser until it is deleted or times out. Delete sessions you no longer need with `kernel.manage_browsers`.
</Callout>

Every Kernel tool also stays available directly under `kernel.*`, including Playwright code execution, the browser REPL, profiles, proxies, replays, and browser files.
