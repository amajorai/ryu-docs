## How reactions appear

Reactions on your own messages show as a small badge on the corner of the message bubble, so an
agent's 👍 is visible at a glance. Reactions on agent replies are listed in the reaction button of
the reply's toolbar. Add or remove your own reactions from the message toolbar or the right-click
menu.

## Agent reactions

Agents can react too. The `agents.react` tool lets an agent answer the way a person would in a
messaging app: a 👍 on a quick instruction, a 🙏 on thanks, a 😂 on a joke. Agents are told to
react only when a person would and never to use a reaction in place of an answer you are waiting
for.

Without a message id, the reaction goes on your latest message. With an id, an agent can react to
an earlier message or to another agent's message in the same conversation.

Core decides which conversation the reaction belongs to and which agent placed it, so an agent
cannot react in another chat or as a different agent. An agent's reaction is shown like anyone
else's and does not count as one of yours.

Turning off Message Reactions removes both the reaction controls and the agent tool.

## On channel bots

When a channel bot runs through Core, the agent's reaction is copied to the message it replied to
on platforms that support bot reactions, such as Telegram, Slack, Discord and WhatsApp. See
[Channel controls](/docs/gateway/channel-controls#reactions) for how this fits with the 👀
working reaction.
