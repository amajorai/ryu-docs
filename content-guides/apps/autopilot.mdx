Autopilot is a positioning-first launch companion. Choose one job, define the
market position and target customer, then derive outreach from that strategy
before running bounded Ryu work.

## Save and preview

**Save brief** stores the current strategy draft and marks it saved for the next
strategy pass; it does not start a pass. In Activation, the landing-page
call-to-action is a static preview. Editing the field updates the preview, but
the preview does not navigate or send a message.

## State and preview boundary

The standalone browser preview may show illustrative strategy content. A
connected Companion starts from node-owned state. If a saved record is
malformed or from an unsupported shape, Autopilot keeps valid user-authored
fields such as the brief and company name, fills missing fields from an empty
draft, and never substitutes the illustrative workspace, activity, or run
history.

Strategy passes require an available Ryu agent. If the agent or its host
capability is unavailable, the pass stays in an error state and is not reported
as completed.
