In the Companion editor:

- **Write** and **Preview** keep the raw Markdown body in view. The toolbar inserts common Markdown formatting.
- If a source read fails, **Try again** retries it.
- A failed autosave shows **Save failed**. The next edit retries the write.
- Version history can save a snapshot, show its diff against the current source, and restore it.
