The Learning settings tab has two independent opt-ins, both off by default:

- **Learn skills from my chats** distills reusable skills on this device. New skills go to the
  approval Inbox before they can be used.
- **Train my local model** opts into stronger-model ratings and fine-tuning on a device with capable
  graphics hardware. Rating sends conversation text to that model, which may run in the cloud.

Each choice is saved to the selected node, so you can leave either activity off while using the
other. These consent settings remain available when the Learning app is turned off, and are saved
separately from the app's enable switch. Switching nodes reloads that node's saved consent.

The controls wait for the saved choices to load and for each change to finish saving. If a read
fails, choose **Retry**. If a save fails, the switch returns to its saved value so you can try
again.
