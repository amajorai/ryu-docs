Other payment providers in Ryu's Marketplace are separate from this app:

- **Stripe Link Agent Wallet** is the recommended default for standard checkouts and Stripe MPP
  payments, for supported U.S. Link accounts.
- The **x402 MCP** server is a separate stablecoin payment option.

These providers keep their own credentials, approval behavior, and budgets. They do not use this
app's Tempo wallet or receipt ledger. See [Machine payments](/docs/surfaces/desktop/user-guide/payments)
for the provider comparison.

## Data at rest

The receipt ledger encrypts who was paid, the requesting site, and the settlement reference on disk with a key only this app receives from Ryu. Amounts, currencies, networks, statuses, and times stay unencrypted so daily budgets and the receipt list keep working.

Receipts saved by an earlier version are encrypted the first time the updated app starts. If the app is updated before Ryu itself, new receipts stay unencrypted until Ryu delivers its key, and the app's status reports that it is waiting for a Ryu update.

A Payments service run without Ryu creates its own key file in its data folder. Keep that file with the data.
