When a revision includes an HTML artifact, the Artifact pane previews it with scripts disabled and can save it as `artifact.html` through the browser's normal download flow.

If a review is refused, Blueprint shows the error and keeps your reviewer note so you can retry.
If a change is saved but the refreshed plan cannot load, Blueprint tells you that the save succeeded
and pauses further edits and decisions. Choose **Retry loading plan** to reload the plan and agent
feedback. This retries the read without submitting the approval or other saved change again.

## Data at rest

Blueprint encrypts every plan file (the plan, each revision, annotations and verdicts) with a key only this app receives from Ryu. Plans saved by an earlier version are encrypted when the updated app starts.

If the app is updated before Ryu itself, it keeps working unencrypted until Ryu delivers its key. Its health status says it is waiting for a Ryu update.

Agent tools run inside the running app, which holds the key. When the app is stopped, opening Blueprint in Ryu starts it again.
