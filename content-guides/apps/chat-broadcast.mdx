The running view selects active chats by default. Switch to **Selected** to choose specific conversations.

Before delivery, review the exact message and recipient list in a confirmation step. That reviewed snapshot is what gets sent, even if the conversation list refreshes or background controls change before you confirm. Repeated confirmation clicks do not duplicate delivery.

The latest delivery summary reports each chat separately. If any send fails, the message stays in the composer so you can revise or retry it. A chat-list refresh error can be dismissed while the refresh control remains available to try again.

Each message is app-authored, so Core treats it like any other app send. It must pass the Gateway firewall's secret and prompt-injection checks, and by default each chat's message waits in the Approvals inbox until you approve it. A delivery the inbox is holding is reported as accepted.
