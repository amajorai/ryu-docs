## Scans

Scanning is read-only. A scan never edits repository files, and stopping it does not either.

- **Stop scan** keeps findings already saved from the run and marks the scan canceled. The workbench refreshes that saved state, shows how many findings were retained, and reports when a scan completed before the stop took effect.
- Running scans refresh while the app is visible. A slow status response finishes before another automatic refresh starts, and returning to the app refreshes the latest state.
- The saved scan list can be searched by scan name, repository name, or scan kind. The detail pane follows the first visible result and clears when no scans match.

### Changes scans

Changes scans treat repository metadata as review input. It cannot authorize running repository-provided commands.

- Executable Git configuration is disabled, including filesystem-monitor hooks and external diff commands.
- Git index metadata is limited to 64 MiB and copied into a private review snapshot.
