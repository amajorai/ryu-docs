**Stop scan** keeps findings already saved from the run and marks the scan canceled. The workbench refreshes that saved state, shows how many findings were retained, and reports when a scan completed before the stop took effect. Scanning remains read-only; stopping it does not edit repository files.

The saved scan list can be searched by scan name, repository name, or scan kind. The
detail pane follows the first visible result and clears when no scans match.

Running scans refresh while the app is visible. A slow status response finishes before
another automatic refresh starts, and returning to the app refreshes the latest state.

Changes scans disable executable Git configuration, including filesystem-monitor
hooks and external diff commands. Repository metadata is review input and cannot
authorize execution of repository-provided commands.
Git index metadata is limited to 64 MiB and copied into a private review snapshot.
