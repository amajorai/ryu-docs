The Dashboards app powers Home, the desktop's live, customizable dashboard for data from your Ryu node. Add stat, chart (line, bar, area, or pie), table, list, text (Markdown), or map widgets fed by Composio actions, HTTPS endpoints, or inline data.

{/* catalog:insert {"before":["## Permissions"]} */}

The dashboard builder and hardware device displays reach dashboards only through these capabilities, so any enabled app that provides them can serve both. When no enabled app provides them, the builder's tools return an error naming the missing capability, and paired hardware devices stay paired and connected: their dashboard display requests return an error and live re-poll nudges pause until a provider is enabled again, with no restart needed.

## Use Home

- On a new node, Home creates a starter board with a welcome note, plus any built-in presets whose data source the node supports. You can remove any of those widgets or add your own.
- Use the dashboard selector in the title bar to switch boards, create a board, rename the current board, or delete it. Deleting asks for confirmation and opens another remaining board. The only board cannot be deleted.
- Choose **Grid** for a compact tiled layout or **Canvas** for a freeform board. The selected view is saved per dashboard. In Canvas, pan and zoom the board, fit all widgets, use the minimap, and drag or resize cards; their positions and sizes are saved. New widgets are placed near the viewport center in a free area.
- Choose **Add widget** for a built-in preset or **Custom widget** to select a widget kind, data source, refresh interval, and display configuration. Cancel, Escape, or the dialog's corner close button dismisses without creating a widget.
- The source picker, the **Add widget** presets, and the assistant builder all follow the connected node’s catalog. HTTPS sources use a guarded fetch that refuses private addresses, redirects, and oversized responses.
- Built-in Core metrics (such as system status, connected clients, or open quests), website monitor results, and workflow outputs are not available as widget sources, because the Dashboards app has no supported way to read that node data. Agent sources are also unavailable, because widget refreshes cannot run an agent on your behalf. These sources cannot be saved. A widget that already uses one stays on the board and shows a message that its source is not available instead of data. Edit its source or remove it.
- Creating or editing a widget accepts only the sources the catalog lists, and only plain Composio action identifiers. An invalid source is refused without replacing the widget's last saved source.
- A widget an agent adds or changes through the Dashboards app's own tools keeps running for that agent. Each time it refreshes, including when you refresh it, Ryu applies that agent's [account access](/docs/surfaces/desktop/user-guide/agent-account-access#choose-which-accounts-an-agent-can-use), so a Composio action must use an account the agent may use. Changing the title or layout keeps this; choosing a new source makes the widget yours. Widgets the dashboard builder adds or changes run as yours, whichever agent built them.
- Choose **Build a work view** to open the **Ask Ryu** assistant docked beside the board as this dashboard's builder: describe what you want to see and it adds and arranges widgets. On an empty board, **Build a work view for me** sends a starter request to the assistant; you can also add widgets yourself. Closing the assistant leaves build mode. Home has no separate chat pane.
- Open a widget's actions to refresh it or remove it. If Home cannot load a board, use **Try again** after restoring the connection.
