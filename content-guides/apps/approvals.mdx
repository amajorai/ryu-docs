## Using the inbox

- **Approve** or **Reject** a pending request to move it into approval history. While the decision is being acknowledged, both controls on that row stay disabled. If a decision fails, retry it from the still-pending row.
- For a task the agent thinks is complete, **Mark done** completes it; **Not yet** clears the suggestion so the task stays open for later.
- Notification filters show all, unread, archived, and severity-specific rows. Opening an unread notification marks it read. **Ack** acknowledges a workflow notification gate; **Archive** moves a row into Archived and marks it read, and **Restore to inbox** returns it to the live feed.
- **Open in chat** starts a new chat with a proactive suggestion prefilled. **Dismiss** hides the suggestion and records dismissal feedback.

Approved tool actions retain their original calling agent, selected scope, and
permissions when dispatched through an app alias. Approving an inbox item does
not grant a missing configuration permission. If the action itself is refused,
the approval records that error rather than reporting a successful edit.

When an agent asks in chat to configure itself, the permission card offers three
choices. **Allow once** authorizes the current call and asks again next time.
**Allow for session** reuses the grant only within that conversation's
permission scope. **Deny** leaves the agent configuration unchanged.
