Create, edit, organize, preview, import, and export carousel frames locally with
Ryu's media tools.

Add a local starter visual, upload an image, or generate an image. New image
layers start in the lower-left so they keep the headline and body copy visible;
you can move and resize each visual as an editable layer.

## State and preview boundary

The standalone browser preview uses illustrative local content. A connected
Companion starts with an empty node-owned gallery. A malformed saved value is
kept empty or shown as unavailable instead of being replaced with the sample
project.

The browser-only gallery displays a **Preview data** banner so sample projects
cannot be mistaken for node-owned work.

Media and model work uses the configured Ryu bridges. If a bridge fails or
returns no usable output, Slides shows the error and keeps the action available
for another attempt. It does not present a generated result until the bridge
returns usable output.

Generated and imported carousels never invent missing copy. A slide without a
headline is skipped, and a slide missing its body or visual prompt is kept with
that field empty. The status message after generation or import says how many
slides were skipped and how many frames still need a body or visual prompt.
