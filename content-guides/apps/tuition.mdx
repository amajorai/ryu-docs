## Saving and retries

- If adding a material or subject fails, Tuition keeps the entered values so you
  can retry. A successful retry clears the earlier error and refreshes the saved
  item in the list.
- While a study, skill, material, review, subject, or settings write is pending,
  its action is disabled, so a repeated click cannot submit the same change twice.
- A failed settings save keeps the edited values for an exact retry.

## Data at rest

Tuition encrypts your study material and answers with a key only this app receives from Ryu.

| Encrypted | Stays readable |
|---|---|
| Subject and skill descriptions | Subject and skill names |
| The text of your materials, and their titles and links | Mastery numbers |
| Each question's prompt, choices and answer key | Schedule numbers |
| Your answers and their feedback | |
| Session summaries and suggested review cards | |

The readable fields let the planner and reminders run. When you accept a suggested review card, the skill it names becomes a skill name, which stays readable like every other skill name.

- Data saved by an earlier version is encrypted when the updated app starts.
- If the app is updated before Ryu itself, it keeps working unencrypted until Ryu delivers its key. Its health status says it is waiting for a Ryu update.
- Agent tools run inside the running app, which holds the key. When the app is stopped, opening Tuition in Ryu starts it again.
