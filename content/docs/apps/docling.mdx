## What it does

Docling is IBM's MIT-licensed, high-fidelity `document.parse` backend. It analyzes page layout to find reading order, rebuild merged cells and spanning headers, and export markdown that preserves headings, lists, and tables. That keeps multi-column papers and financial statements intact during chunking.

The first parse downloads Docling's models, which can take minutes and use hundreds of megabytes. Later parses run as CPU-bound inference. Everything runs locally, including air-gapped operation after the models are cached, and documents stay on the node. Parses run as jobs: submit returns `202` and a `job_id`, then the caller polls.
