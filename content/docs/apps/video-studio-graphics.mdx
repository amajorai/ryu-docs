This guide covers the title and graphic layers you add to a
[Video Studio](/docs/apps/video-studio) project. Prepare the edit first with
[timeline editing](/docs/apps/video-studio-editing), then review the project
with [production review](/docs/apps/video-studio-finishing).

## Titles

Use **Titles** to add title cards or lower thirds. Set the text, position, size,
color, timing, and fades, then style it: 12 bundled open-license fonts (Inter,
Roboto, Montserrat, Poppins, Oswald, Anton, Bebas Neue, Merriweather, Playfair
Display, Lobster, Permanent Marker, and Source Code Pro) or the system sans,
weight, italic, underline, strikethrough, alignment, letter spacing, line
height, outline, a hard or blurred shadow, and a square or rounded background
box with its own opacity and padding. **Fill** can be a solid color or a
left-to-right gradient from the title color to **Gradient end color** (each
letter takes its color along the gradient, in the preview and the export), and
**Text blur** softens the whole text, outline included.

With a **Box color** set, **Box padding** pads the box evenly, and **Box
horizontal padding** and **Box vertical padding** override it for the left and
right or top and bottom edges (all are fractions of the video height). **Box
offset X** and **Box offset Y** move the box away from the text, as fractions
of the video width and height from -0.1 to 0.1, for a knocked-out or
drop-block look; the text stays where it is. Keyframes on **Background
padding** animate the even padding, so a set horizontal or vertical padding
holds its value.

To use your own typeface, open **Style and motion** on a title and choose
**Import font…** under **Imported or system font**. Video Studio accepts
TrueType (`.ttf`) and OpenType (`.otf`) files up to 24 MB, so large CJK
families import too; files over 1.4 MB upload in chunks and the status line
shows the progress. Web fonts (`.woff`, `.woff2`) and font collections (`.ttc`)
are not supported. The font is added to
this node's font library under its own family name, and the preview and the
export both draw the title with that file. The title's **Font** stays as the
fallback, so if an imported font is deleted or missing on another node, the
title uses that font instead. A font cannot be deleted while a title or caption
style uses it. Imported fonts count toward the node's media storage allowance but not its
media file limit. An export loads only the imported fonts its project uses.

**Online fonts** in the same picker searches the
[Fontsource](https://fontsource.org) catalog by family name. Only fonts under
the SIL Open Font License 1.1, the Apache License 2.0 or the Ubuntu Font
Licence 1.0 are listed, and **Add** downloads one TrueType file (the regular
weight of the font's default character subset, such as Latin) into the font
library, checks it like an imported file, and selects it. Each added font keeps
its source and license, which the **Credits** panel, the downloaded credits
document, and the exported project package and archive list for every project
that uses it.
Video Studio contacts only the Fontsource catalog and its jsDelivr file host
for this, and says why when either is unreachable.

The same picker lists the fonts installed on the computer running Video Studio
under **System fonts**. The export asks for a system font by its family name,
so it renders when that font is installed where the export runs; otherwise the
**Font** is used. Use an imported font when a project moves between computers,
because project archives carry imported fonts but not system fonts.

Imported and system fonts work everywhere you style text: titles, caption
styles (see [Style captions](/docs/apps/video-studio-transcription#style-captions)),
and text templates, where the font you pick applies to every title the
template adds.

Titles animate in with slide, pop, bounce, typewriter, word reveal, word
highlight, **word slide** (each word rises into place in turn), **word
highlight block** (a box in the highlight color moves behind the word being
read, and the text keeps its color), blur, zoom, or wave, animate out, and can
loop (pulse, wobble, float, or wave). Titles also take rotation and keyframes.
Double-click a title in the preview to edit its text in place, and drag it on
its timeline lane to move or trim it.

### Title keyframes

Each title in the Titles area has a **Keyframes** field. Pick a property and
choose **Add keyframe at playhead** to record its current value, then set each
keyframe's value, easing (Linear, Ease in, Ease out, Ease in and out, or Hold),
or remove it. Titles animate position, scale, rotation, and opacity, and also
text size, letter spacing, line height, background padding, background corner
radius, text color, and background color. Colors blend smoothly between
keyframes. A title without a background color gets its box from its first
background color keyframe.

On the timeline, select a title and click the diamond at the end of its lane
item to open its keyframe lanes: one lane per animated property. Drag a
diamond to retime it (it snaps to the title's edges, the playhead, markers,
and its other keyframes), use **Graph** to drag values up and down, and use
**Curve** to shape the easing to the next keyframe. Arrow keys nudge the
selected keyframe by a frame (Shift for 10), and Delete removes it. **Add**
records the chosen property at the playhead.

In the export, text size, letter spacing, line height, text color, background
color, and the padding of a square-cornered box change on every frame, as in
the preview. The size, padding, and corner radius of a rounded box change in small steps
(about two frames apart on short titles, wider on long ones), because the box
is drawn as one shape.

The Titles area also holds 23 original text templates in six categories: lower
thirds, title cards, callouts, quotes, calls to action, and social. Apply one at
the playhead and replace its text, and optionally pick an imported or system
font for all of its titles.

Exported titles use only the Regular and Bold faces of a font, and are drawn
slightly smaller than in the preview. Rounded boxes are sized by estimate, and
very long per-letter animations move in groups of letters in the export. The
bundled fonts ship inside the Video Studio sidecar, so no extra download is
needed. If an install is missing them, the title **Font** picker says so and
exports use a system font instead.

### Speak a title

Choose **Text to speech** on a title in the Titles area, or right-click the
title on its timeline lane and choose **Text to speech**, to narrate its text
with Ryu's text-to-speech. Each line is read as a sentence, and a lower third's
"Name · Role" separator is read as a pause. The audio is saved to the media
library and generation history, then placed as a clip that starts with the
title on the lowest free audio track. **Text to speech voice** in the Titles
area sets the voice, language, and speaking rate that both actions use; it
lists the voices of the speech engines installed on your Ryu node, grouped by
engine and language. Review the pronunciation and timing after it is placed.
If the title changed meanwhile, the narration stays in the library for you to
place by hand.

## Vector graphics

Open **Vector graphics** to add rectangle, ellipse, triangle, line, polygon (3
to 12 sides), star (3 to 12 points with an inner radius), heart, and arrow
layers above the timeline. Set a shape's timing, position, size, opacity, fill,
stroke, stroke width, and entrance. Rectangles take a corner radius (0.5 makes a
pill), strokes can sit inside, centered on, or outside the edge, and shapes
rotate from -180° to 180° and take blend modes. **Add keyframe at playhead**
records the left, top, rotation, opacity, scale, stroke width, corner radius,
inner radius, fill color, or stroke color, and each keyframe row sets its value
and easing (Linear, Ease in, Ease out, Ease in and out, or Hold). Scale grows or
shrinks the shape around its center.

Selected shapes open the same keyframe
lanes on the timeline as titles. A shape whose size, stroke, corners, or colors
are keyframed exports with one drawing for every frame of its animation, however
long it runs; frames that do not change are stored once. A plain ellipse or
triangle, with no stroke alignment, rotation, keyframes, or blend mode, exports
without its outline; choose a stroke alignment to export the outline.

Each shape also takes up to four **masks**, edited like clip masks: every mask
shape except text, with position, size, rotation, feather, opacity, invert,
and an outline stroke. A shape's masks sit in its own box and turn, move, and
scale with it, so `x` and `y` run from -1 to 1 across the box and the stroke
width is a fraction of the box height. Masks hide everything outside the box,
including an outside stroke, and they do not animate.

The same area holds **Stickers**, **Adjustments**, the canvas background, and
**Motion tracking** (see
[color, effects, and motion](/docs/apps/video-studio-color-and-effects) and
[assisted editing](/docs/apps/video-studio-assisted-editing#motion-tracking)).

## Stickers

**Stickers** searches 304 emoji, 210 country flags, and 30 original shapes by
name or keyword, filters by set, and offers eight animation presets. A sticker
is added as a 1024-pixel image in a **Stickers** library folder and placed at
the playhead on the lowest free track above the picture, at 35% scale for four
seconds; adding it again reuses the image. Flags with very detailed coats of
arms are not included.

Agents can search the same library and place a sticker with a preset (see
[agent tools](/docs/apps/video-studio-agents#timeline-operations)). When the
editor cannot draw a sticker itself, Video Studio draws it on your node
instead, which needs an FFmpeg build with SVG support (librsvg).

Emoji are Twemoji graphics by Twitter, Inc and other contributors, licensed
under CC-BY 4.0; flags come from the flag-icons project under the MIT license.
Sticker credits appear in **Credits**, and published videos that use an emoji
sticker must keep its attribution.

## Avatars

Open **Avatars** to add a procedural 2.5D character layer. Set its timing,
position, size, depth, skin, outfit, and accent colors, then choose a neutral,
wave, or point pose. Idle bob and slide entrances use the same saved timing in
the preview and FFmpeg export. The character is built from local shape layers, so it renders without a
provider or external asset.

To pose the rig, choose a limb, head, or mouth property, set
its value, and choose **Add rig keyframe at playhead**. Rig values
interpolate between saved keyframes and use the same pose timing in the preview
and rendered export. Add a **Rotation limit** or **Translation limit** for the
selected joint and axis to keep keyed local poses inside a bounded range. The
same limits clamp the evaluated pose in preview and export; saving a second
limit for the same joint and axis replaces the previous one.

**Lip-sync audio** animates the mouth from speech in an audible timeline clip
(following its trim and speed) or from library media. **Lip-sync sensitivity**
(0.5 by default) and **Lip-sync smoothing** (0.4 by default) tune the motion,
and transcript words widen vowels and close the mouth on m, b, and p. The result
is ordinary mouth keyframes, so run it again after changing the audio. This is
vector-rig lip-sync; Video Studio does not produce photoreal talking heads.

## 3D stage

Open **3D stage** to add local depth blocks. Set the stage camera's offsets,
zoom, orbit, and tilt, then set each block's center offsets, depth position,
width, height, extrusion, timing, and color. Float and orbit motions update the
projected camera position in the preview and export. Each block renders with
front, top, and side faces through the local FFmpeg graph, without an external
renderer. Add camera path keyframes for x, y, zoom, orbit, or tilt at
explicit timeline times; the same linear interpolation drives preview and export.

Enter a **World direction** and choose **Generate local world** to replace the
stage with a bounded local world layout: terrain, water, mountains, structures,
a landmark, and a saved 12-second camera path. The result is ordinary editable
stage blocks and camera keyframes, saved with the project. The generator makes
only this fixed set of local stage elements, not arbitrary 3D assets.

Open **Meshes** to import bounded Wavefront OBJ or glTF/GLB geometry. Video
Studio keeps validated triangle vertices and faces in the project, applies glTF
node transforms, projects the result through the saved stage camera, and
rasterizes the same geometry into the local export. Rotation, scale, position,
timing, and color remain editable.

Add mesh keyframes for position or Euler
rotation to animate a short stage motion; the same interpolation is used in
preview and export. The first bounded glTF rotation and translation animation
channels are projected into mesh rotation and position keyframes. Embedded
buffers and embedded PNG base-color textures are accepted.

Bounded linear glTF skin animations are baked into validated vertex poses for
preview and export. Importing a file does not keep static glTF skin rig data, so joint,
parent, rig-keyframe, and joint-limit controls appear only on a saved mesh that
already carries rig data. External buffers, image URLs, and other
unsupported animation channels remain outside this importer.
