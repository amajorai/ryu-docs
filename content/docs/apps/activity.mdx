## What it does

The unified activity feed: everything happening on this node - monitor alerts, finished tasks, runs, approvals, meetings, and notes - newest first, grouped by day.

This page is part of the [Apps catalog](/docs/apps), [app manifest lifecycle](/docs/core/app-manifest-lifecycle), [Plugins vs Apps](/docs/extend/develop/extensions/plugins-vs-apps), [Marketplace](/docs/extend/develop/extensions/marketplace), [Gateway governance](/docs/gateway/governance) documentation path. In the same category, compare [Agent Status](/docs/apps/agent-status), [Calendar](/docs/apps/calendar).

|---|---|---|
