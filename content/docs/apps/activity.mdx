## What it does

The unified activity feed: everything happening on this node - monitor alerts, finished tasks, runs, approvals, meetings, and notes - newest first, grouped by day.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | none |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | none |
| web | full |
| cli | list |

### Companion surfaces

- **Activity** (html)

## Permissions

**Grants:** `activity:read`, `shell:integrate`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See the node's activity feed: every monitor alert, finished run, approval, meeting, and note. |  |

## Engine requirement

Requires Ryu >=0.1.0.
