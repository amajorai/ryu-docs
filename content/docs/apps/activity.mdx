## What it does

The node's unified activity feed lists monitor alerts, finished tasks, runs, approvals, meetings, and notes. It shows the newest entries first and groups them by day.

The companion receives changes through Ryu's generic host event stream, so the feed
updates without opening a socket or polling from the app frame. Core owns the stream
and the Activity app only renders the feed and opens the selected chat session.
