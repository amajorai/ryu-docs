The [Ryu Apps showcase](https://ryuhq.com/products/apps) is a public web page
that shows the official Ryu app surfaces. Each app has a skeleton preview and
its own detail page.

The showcase lists these apps:

| App | What it is for |
| --- | --- |
| [Sites](https://ryuhq.com/products/apps/sites) | Create, refine, and publish websites. |
| [Dashboards](https://ryuhq.com/products/apps/dashboards) | Live widget boards over a Ryu node. |
| [Video Studio](https://ryuhq.com/products/apps/video-studio) | Layered timelines, captions, and rendering. |
| [Slides](https://ryuhq.com/products/apps/slides) | Create and export carousel frames. |
| [Spaces](https://ryuhq.com/products/apps/spaces) | Notes, documents, files, and retrieval context. |
| [Calendar](https://ryuhq.com/products/apps/calendar) | Scheduled agent and workflow runs. |
| [Canvas](https://ryuhq.com/products/apps/canvas) | Media and agent graphs saved in Spaces. |

<Callout type="warn">
The Sites listing is behind a staged rollout. Until it opens, the showcase
does not list Sites and its detail page returns "not found". The rollout
gates only this web listing and the cloud Marketplace listing, not the app on
a node.
</Callout>

The previews illustrate each surface. They are not live account data. To
install an app, use the [Marketplace](/docs/extend/develop/extensions/marketplace).

For the runtime contract behind each app, see the [Apps catalog](/docs/apps),
the [app manifest lifecycle](/docs/core/app-manifest-lifecycle), and the
[app reuse standard](/docs/extend/develop/extensions/app-reuse-standard).
