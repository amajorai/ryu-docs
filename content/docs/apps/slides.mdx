Create, edit, organize, preview, import, and export carousel frames locally with
Ryu's media tools.

## State and preview boundary

The standalone browser preview uses illustrative local content. A connected
Companion starts with an empty node-owned gallery. A malformed saved value is
kept empty or shown as unavailable instead of being replaced with the sample
project.

The browser-only gallery displays a **Preview data** banner so sample projects
cannot be mistaken for node-owned work.

Media and model work uses the configured Ryu bridges. If a requested capability
is unavailable or returns no usable output, Slides keeps the action in an error
state rather than presenting a generated result.

## Permissions

**Grants:** `storage:kv`, `media:generate`, `hook:side-model`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Open Slides projects and browse the local gallery. |  |

| **Can generate** | Use Ryu's configured model and media engines to create visuals or carousel layouts. | `slides.edit` |
