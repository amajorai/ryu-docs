## What it does

Create, edit, organize, and export visual slides and thumbnails locally with Ryu's media tools.

## Permissions

**Grants:** `storage:kv`, `media:generate`, `hook:side-model`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Open Slides projects and browse the local gallery. |  |
| **Can edit** | Create projects, change layers, capture video frames, and save edits. | `slides.view` |
| **Can generate** | Use Ryu's configured model and media engines to create visuals or carousel layouts. | `slides.edit` |

## UI it contributes

### Apps shelf

When enabled, this app appears as one icon tile in the desktop sidebar's Apps shelf. Use sidebar sections for the app's record lists; feature navigation stays inside the Companion.

### chat widget templates

- **Slides widget** - Slides chat widget metadata is coming soon; no render tool is available yet.
