## What it does

Slides is a local-first Ryu Companion for visual slide and thumbnail work. It
keeps project state in its own storage namespace and uses Ryu's host bridges for
uploads, model-assisted carousel drafts, and image or video generation.

## Shipped workflow

- **Gallery** - Create, open, search, sort, select, archive, restore, and empty
  local projects.
- **Layer editor** - Work with text, image, and shape layers. Drag, resize,
  rotate, duplicate, reorder, hide, lock, and undo or redo edits.
- **Media tools** - Upload an image or video, scrub and capture a video frame,
  clean up near-white backgrounds, request a visual from the configured Ryu image
  engine, or draft a carousel from the configured model.
- **Export** - Render a project to PNG, JPEG, or WebP. Animated GIF/APNG export
  is not available in this build and is labelled as such in the UI.

## Permissions and boundaries

Slides requests `storage:kv`, `media:generate`, and `hook:side-model`. The app
has no sidecar and does not call a media provider directly. Missing host bridges
fall back to the browser picker or local editor state and remain visible as
capability status rather than becoming a silent failure.
