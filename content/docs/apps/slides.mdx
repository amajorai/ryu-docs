## What it does

Create, edit, organize, preview, import, and export carousel frames locally with
Ryu's media tools.

Add a local starter visual, upload an image, or generate an image. New image
layers start in the lower-left so they keep the headline and body copy visible.
You can move and resize each visual as an editable layer.

## State and preview boundary

- **Browser preview.** The standalone browser preview uses illustrative local
  content. Its gallery shows a **Preview data** banner so sample projects cannot
  be mistaken for node-owned work.
- **Connected Companion.** It starts with an empty node-owned gallery. A malformed
  saved value is kept empty or shown as unavailable instead of being replaced with
  the sample project.

## Generation and import

Media and model work uses the configured Ryu bridges. If a bridge fails or
returns no usable output, Slides shows the error and keeps the action available
for another attempt. It never presents a generated result before the bridge
returns usable output.

Generated and imported carousels never invent missing copy:

- A slide without a headline is skipped.
- A slide missing its body or visual prompt is kept with that field empty.
- The status message after generation or import says how many slides were
  skipped and how many frames still need a body or visual prompt.

## Permissions

**Grants:** `storage:kv`, `media:generate`, `hook:side-model`, `files:download`

`files:download` lets Slides deliver the PNG, JPEG, and editable JSON files that
you explicitly export. It does not grant access to files elsewhere on your device.

| Level | Description | Implies |
|---|---|---|
| **Can view** | Open Slides projects and browse the local gallery. |  |
| **Can edit** | Create projects, change layers, capture video frames, and save edits. | `slides.view` |
| **Can generate** | Use Ryu's configured model and media engines to create visuals or carousel layouts. | `slides.edit` |
