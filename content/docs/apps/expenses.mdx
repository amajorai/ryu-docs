## What it does

A local-first expense ledger for Ryu: record spending through an agent or the companion, then see totals, categories, and recent entries in one visual view. The node owns the records; no bank connection or exchange-rate conversion is included.

### Expense Tracker

The bundled agent uses the `expenses` tools for record lookups and mutations. It asks for missing
fields instead of guessing, preserves the user's wording, stores amounts in integer minor units,
and does not provide financial, tax, or investment advice.

## Data at rest

Expense Tracker encrypts each expense's merchant, amount, account and note with a key only this app receives from Ryu. Dates, categories and currencies stay readable so the ledger can be filtered and sorted. Expenses saved by an earlier version are encrypted when the updated app starts. If the app is updated before Ryu itself, it keeps working unencrypted until Ryu delivers its key, and its health status says it is waiting for a Ryu update. The `expenses` agent tools reach encrypted records through the running app; if the app is not running, open it in Ryu and try again.

Tools: `expenses`

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`expenses`** - Expense Tracker tools for listing, summarizing, adding, correcting, and deleting local ledger records. Amounts remain integer minor units and unlike currencies are never added together.
