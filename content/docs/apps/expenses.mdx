## What it does

Expenses is a local-first ledger for personal spending. Ask the Expense Tracker
agent to record an entry, find a category total, summarize a month, or correct a
mistake. The companion app shows the same records as a visual ledger with month
and category filters, category distribution, and a quick Add expense form.

The node owns the records. Expenses does not connect to a bank, infer a balance,
convert exchange rates, or provide financial, tax, or investment advice. Amounts
are recorded values, stored as integer minor units, and unlike currencies are
never added together.

## Two install modes

### App bundle

Install the **Expenses** app to get the Expense Tracker agent and the visual
Expenses companion together. The agent is the conversational surface; the app
is the visual view over the same ledger.

### Standalone agent, then the visual app

Install the standalone **Expense Tracker** agent from Marketplace when you want
to start with conversation. It declares the Expenses app as its required data
provider. Install **Expenses** later when you want to inspect and edit the same
records in a visual view; it does not create a second ledger.

## Agent tools

The `expenses` MCP server exposes these tools to agents and workflows:

- `expenses.list` - list bounded records, optionally filtered by date, category,
  or currency.
- `expenses.summary` - return record counts and totals grouped by currency and
  category.
- `expenses.add` - record a confirmed expense using a calendar date and integer
  minor-unit amount.
- `expenses.update` - correct selected fields on an existing record.
- `expenses.delete` - permanently remove a record after the user explicitly
  asks for it.

Writes use the normal Ryu approval behavior. The agent must not claim a write
worked unless the ledger returns the saved record.

## Permissions

**Grants:** `app:http`, `mcp:expenses`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See records, totals, category breakdowns, and recent entries. |  |
| **Can manage** | Add, correct, and permanently delete expense records through the app or agent tools. | `expenses.view` |

## Companion

The **Expenses** companion is a self-contained app surface. It reaches the
ledger through Ryu's app bridge, so the frame does not receive a node token or
make a direct network request. Its controls and cards use Ryu's shared UI
primitives and semantic design tokens, and it follows the active light or dark
theme from the host.

## Engine requirement

Requires Ryu >=0.1.0.

## Local data

The ledger stays on the active Ryu node in the app's local data store. The app
does not send expense records to a third-party financial service.
