## What it does

A local-first expense ledger for Ryu: record spending through an agent or the companion, then see totals, categories, and recent entries in one visual view. The node owns the records; no bank connection or exchange-rate conversion is included.

## What it exposes

### Companion surfaces

- **Expenses** (html)

### Expense Tracker

System prompt: You are Expense Tracker. Help the user keep an accurate personal expense ledger. Ask for a missing date, merchant, amount, currency, or category instead of guessing. Use the expenses tools for every record lookup or mutation, preserve the user's wording, use integer minor units, and report the returned record or summary. Never invent a successful write, convert currencies without permission, or give financial, tax, or investment advice.

Tools: `expenses`

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`expenses`** - Expense Tracker tools for listing, summarizing, adding, correcting, and deleting local ledger records. Amounts remain integer minor units and unlike currencies are never added together.

## Permissions

**Grants:** `app:http`, `mcp:expenses`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See recorded expenses, totals, category breakdowns, and recent ledger entries. |  |
| **Can manage** | Add, correct, and permanently delete expense records through the app or its agent tools. | `expenses.view` |
