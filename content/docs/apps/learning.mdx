## What it does

Learning loop: turn chats and runs into reusable skills, gated by the approval Inbox, with an experience log of what was learned.

This page is part of the [Apps catalog](/docs/apps), [app manifest lifecycle](/docs/core/app-manifest-lifecycle), [Plugins vs Apps](/docs/extend/develop/extensions/plugins-vs-apps), [Marketplace](/docs/extend/develop/extensions/marketplace), [Gateway governance](/docs/gateway/governance) documentation path. ## What it exposes

### Companion surfaces

- **Learning** (html)

## Permissions

**Grants:** `learning:crud`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Read the experience log and the skills the learning loop has produced. |  |
| **Can teach** | Turn a chat or run into a proposed skill, which goes to the approval inbox before any agent can use it. | `learning.view` |

## UI it contributes

### Apps shelf

When enabled, this app appears as one icon tile in the desktop sidebar's Apps shelf. Use sidebar sections for the app's record lists; feature navigation stays inside the Companion.
