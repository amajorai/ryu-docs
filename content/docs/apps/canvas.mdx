## What it does

A node board for generative media: wire up image, video, chat, text-to-speech, speech-to-text, upload, and note nodes, search attributed Openverse or node-configured Unsplash images, then run the graph through Ryu's media and agent bridges. Each board persists as a Space document, so it stays editable, shareable, and searchable.

Image nodes expose full aspect-ratio labels in the size menu: `1:1` (1024 × 1024), `16:9` (1024 × 576), `9:16` (576 × 1024), and `4:3` (1024 × 768). The selected dimensions are sent with the image-generation request.

New nodes start in a two-column layout around the current viewport so they remain reachable as you add more. Drag nodes to arrange the board, connect compatible source and target handles, and delete a node to remove its attached edges.

The board name, nodes, edges, and viewport are saved together in the backing Space document.

In the same category, compare [Backstage](/docs/apps/backstage), [Content](/docs/apps/content), [Drawesome](/docs/apps/drawesome).

Speech-to-text nodes transcribe with the engine you choose in Ryu's Voice Recognition settings, the same one chat voice input uses. With Parakeet, Whisper, or audio.cpp, the audio is transcribed on your node and stays there. With Gateway, your node sends the audio to the speech-to-text provider configured for your Gateway.

Icons and brand logos inserted through **Assets** are converted to PNG images before saving. Existing SVG asset nodes are also displayed as raster previews. Unsupported SVG content reports an error rather than loading scripts or external resources.
