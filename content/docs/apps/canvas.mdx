## What it does

Canvas is a node board for generative media. Connect image, video, chat, Audio, Voice Recognition, upload, and note nodes, then run the graph through Ryu's media and agent bridges. Each board persists as a Space document, so it remains editable, shareable, and searchable.

Chat nodes use Ryu's shared model/agent/provider picker. A model selection carries
its provider lane through the host bridge into Ryu's Gateway router; BYOK keys,
subscription passthrough, and entitlements remain Core/Gateway-owned.

## Permissions

**Grants:** `spaces:docs`, `core:list_agents`, `media:generate`, `media:transcribe`, `hook:run-agent`, `hook:side-model`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Open canvases and read their contents. |  |
| **Can edit** | Create and change canvases, including the documents they store in Spaces. | `canvas.view` |
| **Can generate media** | Produce images and transcriptions inside a canvas, which spends model credits on every generation. | `canvas.edit` |
