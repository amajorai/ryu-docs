## What it does

A node board for generative media: wire up image, video, chat, text-to-speech, speech-to-text, upload, and note nodes, then run the graph through Ryu's media and agent bridges. Each board persists as a Space document, so it stays editable, shareable, and searchable.

## Permissions

**Grants:** `spaces:docs`, `core:list_agents`, `media:generate`, `media:transcribe`, `hook:run-agent`, `hook:side-model`, `app:realtime`, `ui:declarative-http`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Open canvases and read their contents. |  |
| **Can edit** | Create and change canvases, including the documents they store in Spaces. | `canvas.view` |
| **Can generate media** | Produce images and transcriptions inside a canvas, which spends model credits on every generation. | `canvas.edit` |
