## What it does

An Excalidraw whiteboard shipped as a Ryu app: draw, diagram, and rearrange freely, with Mermaid-to-Excalidraw bundled so a diagram can be imported straight from text. Each board persists as a Space document, so it stays editable, shareable, and searchable.
