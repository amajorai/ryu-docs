## What it does

Whiteboard is an Excalidraw surface for drawing, diagramming, and rearranging freely.
Mermaid-to-Excalidraw import is bundled, so a diagram can start from text. Each board persists as a Space
document and remains editable, shareable, and searchable.

AI diagram generation uses Ryu's shared model/provider picker. The selected provider lane and model
are sent through the host bridge; discovery, BYOK credentials, subscription entitlements, and
Gateway routing stay in Core.
