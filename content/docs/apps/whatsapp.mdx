## What it does

Connect WhatsApp Personal or WhatsApp Business (Cloud API) to a Ryu agent or team from a native workspace tab.

## UI it contributes

### Apps shelf

When enabled, this app appears as one icon tile in the desktop sidebar's Apps shelf. Use sidebar sections for the app's record lists; feature navigation stays inside the Companion.

### chat widget templates

- **WhatsApp widget** - WhatsApp chat widget metadata is coming soon; no render tool is available yet.

## Engine requirement

Requires Ryu >=0.1.0.
