## What it does

Connect WhatsApp Personal or WhatsApp Business (Cloud API) to a Ryu agent or team from a native workspace tab.

## Surfaces

| Surface | Support |
|---|---|
| gateway | full |
| core | none |
| desktop | full |
| island | none |
| mobile | limited |
| extension | none |
| web | full |
| cli | list |

## UI it contributes

### Sidebar buttons

- **WhatsApp**

### chat widget templates

- **WhatsApp widget** - WhatsApp chat widget metadata is coming soon; no render tool is available yet.

## Engine requirement

Requires Ryu >=0.1.0.
