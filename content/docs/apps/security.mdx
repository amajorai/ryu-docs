## What it does

A local-first security workbench for reviewing authorized repositories, validating static findings, and keeping scan evidence and safe remediation proposals together.

This page is part of the [Apps catalog](/docs/apps), [app manifest lifecycle](/docs/core/app-manifest-lifecycle), [Plugins vs Apps](/docs/extend/develop/extensions/plugins-vs-apps), [Marketplace](/docs/extend/develop/extensions/marketplace), [Gateway governance](/docs/gateway/governance) documentation path. In the same category, compare [Automated Reasoning](/docs/apps/reasoning), [Safe Actions](/docs/apps/safe-actions).

## Permissions

**Grants:** `app:http`

| Level | Description | Implies |
|---|---|---|
| **Can view security evidence** | Browse repositories, saved scans, findings, coverage, and retained evidence. |  |
| **Can run security scans** | Start read-only local static scans for repositories and scoped folders. | `security.view` |
| **Can triage findings** | Change finding status and prepare read-only remediation proposals; the app never applies a patch. | `security.view` |
