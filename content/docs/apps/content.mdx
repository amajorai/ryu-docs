## What it does

Content is a catalog preview for a planned Ryu-native, local-first
short-form content workspace. Its Companion payload is not shipped yet, so the
current package is list-only and cannot be installed as a working editor.

The planned workflow covers briefs, structured slideshow plans, frame editing,
scheduling, publishing, and local performance signals. This page describes that
direction without presenting an unavailable interface as a released feature.

## What it exposes

### Planned workflow views

- **Overview** - workspace summary, next post, and one-click generation.
- **Automations** - reusable niche, audience, voice, cadence, and target recipes.
- **Studio** - hook and caption editor, destination account selection, frame reorder/remove, visual regeneration, direct source-image download, optional video rendering, project export, and vertical preview.
- **Library** - saved drafts with draft, scheduled, published, and archived states.
- **Inspiration** - searchable local slideshow library with one-click editable remixes.
- **UGC Lab** - selfie, product, and talking-head prompts routed to the local image primitive, with offline previews.
- **Accounts** - local publishing destinations, optional Outpost sync, workspace plan/usage, and team invitations.
- **Calendar** - the local publishing queue and weekly rhythm.
- **Analytics** - local preview metrics for reach, likes, saves, shares, and completion.
- **Settings** - model mode, preferred model names, publishing handoff, bridge status, and reset.

## Permissions

The list-only package requests no grants. Permissions will be documented and
approved with the signed Companion payload when the working surface ships.

## Local state

The preview stores no drafts, credentials, or publishing state and adds no Core
route or sidecar. The eventual Companion is intended to keep project state local
and make Outpost an optional publishing handoff.

## Engine requirement

Requires Ryu >=0.1.0 for catalog compatibility. No runtime is active today.
