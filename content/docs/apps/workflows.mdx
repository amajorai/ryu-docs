## What it does

Workflows: petgraph DAG automation with triggers, durable execution, and a natural-language workflow builder.

## Permissions

**Grants:** `workflows:crud`, `workflows:runstate`, `workflows:catalogs`, `ghost:record`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See workflows and their run history, without changing or starting anything. |  |
| **Can run** | Start a workflow and watch it execute. Implies viewing. | `workflow.view` |
| **Can edit** | Create and change workflows, including their triggers and steps. Implies running. | `workflow.run` |
| **Can delete** | Permanently remove a workflow and its run history. Implies editing. | `workflow.edit` |
