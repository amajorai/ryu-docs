## What it does

Workflows automates petgraph DAGs with triggers, durable execution, and a natural-language workflow builder.

Agent nodes use the shared Ryu model/agent/provider picker and catalog. The app
does not maintain a second agent list or provider credential path; execution and
subscription/BYOK routing stay behind the host bridge.

## What it exposes

### Companion surfaces

- **Workflows** (html)

The desktop host owns the **Workflows** record picker through a `sidebar_sections`
contribution. Selecting a workflow opens `/workflows/<id>` in the canvas companion;
the companion no longer duplicates the workflow list in an internal left rail.

## Permissions

**Grants:** `workflows:crud`, `workflows:runstate`, `workflows:catalogs`, `ghost:record`, `core:list_agents`, `ui:toast`, `ui:declarative-http`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See workflows and their run history, without changing or starting anything. |  |
| **Can run** | Start a workflow and watch it execute. Implies viewing. | `workflow.view` |
| **Can edit** | Create and change workflows, including their triggers and steps. Implies running. | `workflow.run` |
| **Can delete** | Permanently remove a workflow and its run history. Implies editing. | `workflow.edit` |
