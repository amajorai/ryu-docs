## What it does

Inbound webhook endpoint registry: resolved public URLs, signing-secret configuration, last-delivery times, and the ingress backend status.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | none |
| web | full |
| cli | list |

## What it exposes

### Companion surfaces

- **Webhooks** (html)

## Permissions

**Grants:** `webhooks:crud`, `ui:toast`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See registered inbound endpoints, their public URLs, signing-secret status, and when each last received a delivery. |  |
| **Can manage** | Configure and rotate inbound signing secrets, which decides which outside systems may trigger work here. | `webhooks.view` |
