## What it does

Inbound webhook endpoint registry: resolved public URLs, secret presence, last-delivery times, and the ingress backend status.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | none |
| web | full |
| cli | list |

## What it exposes

### Companion surfaces

- **Webhooks** (html)

## Permissions

**Grants:** `webhooks:crud`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See registered inbound endpoints, their public URLs, and when each last received a delivery. |  |
| **Can manage** | Register, rotate, and delete inbound endpoints and their secrets, which decides what outside systems may trigger work here. | `webhooks.view` |

## Engine requirement

Requires Ryu >=0.1.0.
