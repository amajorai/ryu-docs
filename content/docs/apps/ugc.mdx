## What it does

UGC tracks creator-marketing campaigns. It stores briefs, a creator roster, reviewed post submissions, per-post metric snapshots from a curated Composio action map, and CPM or flat-rate payout accrual against a campaign budget.

Metric refreshes use Ryu's managed Composio provider through the Gateway. UGC never asks for or stores a Composio API key; provider credentials and any applicable provider-cost accounting remain in Ryu's managed provider path.

## Permissions

| Level | Description | Implies |
|---|---|---|
| **Can view** | See campaigns, the creator roster, submissions and their metric history, and what each payout is worth. |  |
| **Can manage** | Create and edit campaigns and creators, approve or reject submissions, and refresh post metrics - which decides what this node fetches and what each creator accrues. | `ugc.view` |
| **Can settle payouts** | Approve accrued payouts and mark them paid. Marking a payout paid freezes its amount - it is never re-priced afterwards, even if the post keeps gaining views - and is the record this campaign's spend is reconciled against. | `ugc.view` |

### Hook events

- **Submission received** - A creator's post was recorded against a campaign, once for each `submissions` row. The `(campaign_id, platform, external_post_id)` unique index rejects duplicates with 409, so a duplicate does not emit again. `external_post_id` is empty when the URL could not be parsed; that submission remains reviewable by hand but cannot auto-refresh.
- **Submission approved** - A submission passed review and its payout row was created or repriced. This event is transition-gated and fires once for each pending → approved move. Approving an already approved submission returns a 200 no-op and emits nothing.
- **Submission rejected** - A submission was turned down and any accrued, unpaid payout was removed. This event is transition-gated like approval. Rejecting an already rejected submission returns a 200 no-op and emits nothing. `reason` contains the reviewer's text for the creator.
- **Post metrics refreshed** - A metric snapshot from the curated Composio action was appended for the submission's platform. This event is not transition-gated and fires on every successful refresh, even when all counters are unchanged. The payload includes the new sample and its delta from the previous snapshot. A failed refresh emits no event; the API reports the failure per submission and one unavailable platform does not fail the batch.
- **Payout amount changed** - A payout row's `amount_cents` changed because the row was created on approval or repriced as views grew. Accrual is idempotent repricing, so each submission has one payout row. A refresh that leaves the amount unchanged emits no event. Paid rows are never repriced. `reason` contains the sentence written for the amount change.
- **Campaign budget reached** - Total accrued payouts first crossed `budget_cents`, so further accrual is clamped and new approvals pay nothing. This event is transition-gated and fires once at the crossing. It re-arms only when the budget is raised above the accrued total. A campaign with `budget_cents` set to 0 is uncapped and never emits this event.
