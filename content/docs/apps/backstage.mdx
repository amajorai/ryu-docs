## What it does

A local-first YouTube thumbnail studio that keeps its editor while using Ryu for governed model and image generation.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | none |
| desktop | full |
| island | limited |
| mobile | none |
| extension | none |
| web | limited |
| cli | none |

## What it exposes

### Companion surfaces

- **Backstage** (html)

## Permissions

**Grants:** `storage:kv`, `media:generate`, `hook:side-model`, `hook:run-agent`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Browse Backstage projects and open the thumbnail editor. |  |
| **Can edit** | Create projects and change thumbnail layers. | `backstage.view` |
| **Can generate** | Use Ryu's configured local, managed, or BYOK model and image lanes. | `backstage.edit` |

## Engine requirement

Requires Ryu >=0.2.0.
