## What it does

Drafts is a durable outbox for messages you have not sent. Text you leave in a composer is saved instead of disappearing with the tab. Each draft lives in a node-wide store, so it survives tab switches, closed conversations, app restarts, and project changes.

You can arm a draft with a condition so it sends itself when the condition becomes true. Ryu currently supports two conditions: fewer than N agents are running, or the agent's usage window has room again. The app evaluates both against readings from this node. A condition that never becomes true leaves the draft unsent.

## Composer drafts

The chat composer autosaves one row per conversation. Switching away from a tab keeps its
textarea in that tab, and remounting the tab or restarting the app restores the saved text. A
brand-new chat has no conversation id yet, so all unsent launchpad text shares one `latest` row:
the most recently edited new-chat prompt is the one restored after a restart. Sending or clearing
the composer removes that unsent row. Temporary chats never write to the Drafts outbox.

## Permissions

**Grants:** `drafts:crud`, `chat.sendFollowUp`, `core:readings`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See the drafts kept on this node and what each one is waiting for. |  |
| **Can edit** | Write, arm, and delete drafts. Arming a draft is what lets it send itself later, so this is the level that can cause a message to go out unattended. | `drafts.view` |
