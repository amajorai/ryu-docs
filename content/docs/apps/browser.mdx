## What it does

A real-Chromium browser (Electron) Ryu runs as a local sidecar and exposes as the grant-gated `browser.control` capability: list/open/navigate tabs, screenshot, read titles, take an accessibility snapshot with stable element refs, and drive the page with synthetic click/type/scroll input. Core spawns the sidecar lazily and idle-stops it; the desktop Browser panel drives it through the ext-proxy.

## What it exposes

### Tools

### `chromium__list_tabs` - List Browser Tabs

List the tabs currently open in the local Chromium browser sidecar. Returns `&#123;tabs:[&#123;id,url,title&#125;]&#125;`; the `id` is what every other browser tool takes. When the sidecar is not running the tool reports itself unavailable.

Backend: HTTP · Method: GET

_No parameters_ (empty schema).
### `chromium__open_tab` - Open Browser Tab

Open a NEW tab in the local Chromium browser at `url` and return `&#123;tab:&#123;id,url,title&#125;&#125;`. Use the returned `id` with the other browser tools. To move an EXISTING tab, use chromium__navigate_tab instead.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | URL to load in the new tab (the sidecar defaults to about:blank when omitted). |

### `chromium__tab_detail` - Browser Tab Detail

Fetch one tab's current `&#123;tab:&#123;id,url,title&#125;&#125;` by tab id. 404s once the tab has been closed.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | Tab id, as returned by chromium__list_tabs or chromium__open_tab. |

### `chromium__navigate_tab` - Navigate Browser Tab

Navigate an EXISTING tab to `url` and return `&#123;tab:&#123;id,url,title&#125;&#125;`. Requires a tab id from chromium__list_tabs or chromium__open_tab; 404s once the tab has been closed.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | Tab id to navigate. |
| `url` | string | yes | URL to load in that tab. |

### `chromium__screenshot_tab` - Screenshot Browser Tab

Capture a PNG screenshot of one tab. Returns `&#123;image,encoding:"base64",mime:"image/png"&#125;`. Requires a tab id from chromium__list_tabs or chromium__open_tab.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | Tab id to capture. |

### `chromium__tab_title` - Browser Tab Title

Read one tab's current document title as `&#123;title&#125;`. Cheaper than a screenshot for confirming a navigation landed.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | Tab id whose title to read. |

### `chromium__snapshot_tab` - Snapshot Browser Tab

Read one tab's accessibility tree. Returns `&#123;tab,snapshot_id,elements:[&#123;ref,role,name,value,depth,props&#125;],truncated&#125;`, where each `ref` (`@e1`, `@e2`, …) is the handle chromium__click and chromium__type take. Refs are minted fresh by every snapshot and are dropped when the tab navigates, so snapshot again after any action that changes the page. Content inside cross-origin iframes is not included.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | Tab id to snapshot, as returned by chromium__list_tabs or chromium__open_tab. |

### `chromium__click` - Click Browser Element

Click the element a chromium__snapshot_tab `ref` names, using a real mouse event at the element's centre. Returns `&#123;ok,tab,x,y&#125;`. A ref the current snapshot does not know, or whose element is hidden or gone, is a 400 telling you to snapshot again - it never falls back to another element.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `ref` | string | yes | Element reference from a prior chromium__snapshot_tab, e.g. "@e3". |
| `tab_id` | string | no | Tab to act on. Omit for the tab the browser is currently showing (a snapshot focuses the tab it reads). |

### `chromium__type` - Type Into Browser Element

Focus the element a chromium__snapshot_tab `ref` names and insert `text` at its caret, optionally pressing Enter. Text is APPENDED by default - set `replace` to overwrite a field that already has a value. A `ref` that is focusable but cannot accept text (a link, a read-only or disabled input, a checkbox) is a 400 rather than a silent no-op. Returns `&#123;ok,tab&#125;`.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `ref` | string | yes | Element reference from a prior chromium__snapshot_tab, e.g. "@e3". |
| `text` | string | yes | Text to insert at the element's caret. |
| `replace` | boolean | no | Overwrite the field's current value instead of appending to it. Use `replace` with an empty `text` to clear a field. |
| `submit` | boolean | no | Press Enter after typing (a real key event, so form/search handlers fire). |
| `tab_id` | string | no | Tab to act on. Omit for the tab the browser is currently showing. |

### `chromium__scroll` - Scroll Browser Tab

Scroll a tab's viewport with a real wheel event dispatched at its centre. `amount` is a distance in CSS pixels; omitted it travels 80% of the viewport. Returns `&#123;ok,tab,x,y&#125;`. Snapshot again afterwards - scrolling changes what is laid out.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `direction` | string (one of: up, down, left, right) | yes | Direction to scroll the page in. |
| `amount` | integer | no | Scroll distance in CSS pixels. Defaults to 80% of the viewport. |
| `tab_id` | string | no | Tab to act on. Omit for the tab the browser is currently showing. |

### `chromium__close_tab` - Close Browser Tab

Close one tab and return `&#123;ok:true&#125;`. 404s when the tab is already gone.

Backend: HTTP · Method: DELETE

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | Tab id to close. |

### Capabilities

- **Browser** - capability `browser.control`
  - Grant: `browser:control`
  - Target: local-machine
  - Verbs:
    - `browser__tabs` -> `chromium__list_tabs`
    - `browser__navigate` -> `chromium__open_tab`
    - `browser__screenshot` -> `chromium__screenshot_tab`
    - `browser__snapshot` -> `chromium__snapshot_tab`
    - `browser__click` -> `chromium__click`
    - `browser__type` -> `chromium__type`
    - `browser__scroll` -> `chromium__scroll`

## Permissions

**Grants:** `browser:control`, `tool:http-egress:127.0.0.1`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Read the browser's open tabs, their titles, screenshots, and accessibility snapshots. |  |
| **Can control** | Open, navigate, and close tabs and drive pages with synthetic clicks, typing, and scrolling, using whatever the browser is already signed in to. | `browser.view` |
