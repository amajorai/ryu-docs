## What it does

Tests is a Ryu-native verification workspace for turning a project change into an executable test plan and a reviewable result. It brings UI, API, and agent-action tests into one compact dashboard: configure a project, map its features, plan tests, generate a run, and inspect the evidence.

The companion is local-first. It does not connect to an external testing service or require a third-party account, API key, or remote runner. Project and run state stays in the Ryu surface until a future execution adapter is connected through Ryu's normal app seams.

## Workflow

- **Create Tests** walks through project configuration, feature exploration, test planning, and generation.
- **All Tests** filters projects by UI or API coverage and opens the project workspace.
- **Project detail** groups the use-case flow, site exploration, generated test cases, agent actions, and test report.
- **Test detail** pairs a run overview and conversation with a preview panel and generated Playwright-style code.
- **Test Lists** collects tests into named release or regression suites.
- **Monitoring** shows schedules, last results, next runs, and pause or run-now actions.
- **Settings** keeps the integration-shaped API key and GitHub sections ready for future Ryu-owned adapters without storing external credentials today. Subscription, entitlements, and provider billing remain Ryu-owned platform concerns rather than app credits.

## Permissions

Tests requests the read-only `core:list_agents` permission for Ryu's shared runtime catalog. It
uses the same model, agent, and provider-lane picker as other Companion apps, and stores the
resulting runtime choice with the project configuration. It does not make network requests to an
external testing service. Provider credentials, subscription entitlements, and model routing
remain behind the Ryu host bridge.

## Engine requirement

Requires Ryu >=0.1.0.
