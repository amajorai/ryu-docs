## What it does

The calendar projects every scheduled agent and workflow run onto Month, Week, Day, and Agenda views. It combines past runs from history with upcoming cron or interval runs, and includes a New automation dialog for scheduling an agent.

High-frequency interval markers are counted by local calendar day, including 23-hour spring-forward
and 25-hour fall-back days, so the marker stays at local noon and never reports an extra or missing
run because of daylight-saving time.

## Permissions

**Grants:** `calendar:crud`, `core:list_agents`

The New automation dialog uses Ryu's shared model/agent/provider catalog. Calendar
keeps scheduling mutations on its calendar bridge, while agent metadata and the
picker come from the same host-owned catalog used by the other apps; provider
credentials and subscription entitlements never enter the companion.

| Level | Description | Implies |
|---|---|---|
| **Can view** | See past and upcoming scheduled runs for every agent and workflow on this node. |  |
| **Can schedule** | Create, reschedule, and remove automations, which decides what runs unattended on this node and when. | `calendar.view` |
