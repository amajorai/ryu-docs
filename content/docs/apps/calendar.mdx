## What it does

The scheduled-runs calendar: every agent and workflow scheduled job projected onto Month, Week, Day, and Agenda views - past runs from history, upcoming runs from cron/interval - with a New automation dialog that schedules an agent.

## Permissions

**Grants:** `calendar:crud`, `core:list_agents`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See past and upcoming scheduled runs for every agent and workflow on this node. |  |
| **Can schedule** | Create, reschedule, and remove automations, which decides what runs unattended on this node and when. | `calendar.view` |

## UI it contributes
