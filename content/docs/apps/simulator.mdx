## What it does

Drive iOS Simulators (macOS + Xcode) and Android Emulators from a workspace tab. Ryu runs the device-control toolchain (`simctl`, `adb`) as a local sidecar and exposes the grant-gated `simulator.control` capability: list/boot devices, install & launch apps, open deep links, screenshot, and (Android) tap/swipe/type. The desktop Simulator panel shows whichever platform the connected node supports.

## What it exposes

### Capabilities

- **simulator.control** - capability `simulator.control`
  - Grant: `simulator:control`

## Permissions

**Grants:** `simulator:control`

| Level | Description | Implies |
|---|---|---|
| **Can view** | List the iOS Simulators and Android Emulators on this node and screenshot them. |  |
| **Can control** | Boot devices, install and launch apps, open deep links, and send taps, swipes, and typing to them. | `simulator.view` |
