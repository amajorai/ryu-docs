## What it does

Drive iOS Simulators on macOS with Xcode and Android Emulators from a workspace tab. Ryu runs the device-control tools (`simctl`, `adb`) in a local sidecar and exposes the grant-gated `simulator.control` capability. Agents can list and boot devices, install and launch apps, open deep links, take screenshots, and tap, swipe, or type on Android. The desktop Simulator panel shows the platform supported by the connected node.

## What it exposes

### Capabilities

- **simulator.control** - capability `simulator.control`
  - Grant: `simulator:control`

## Permissions

**Grants:** `simulator:control`

| Level | Description | Implies |
|---|---|---|
| **Can view** | List the iOS Simulators and Android Emulators on this node and screenshot them. |  |
| **Can control** | Boot devices, install and launch apps, open deep links, and send taps, swipes, and typing to them. | `simulator.view` |
