## What it does

A public feedback board and private Ryu product workspace: collect requests, votes, and comments, turn demand into a roadmap, and use configurable Ryu workflows to prepare or build what users ask for.

### Companion surfaces

## Permissions

**Grants:** `app:http`, `storage:kv`, `spaces:docs`, `shell:integrate`, `hook:side-model`, `hook:run-agent`, `core:list_agents`, `workflows:crud`, `workflows:runstate`, `workflows:catalogs`, `blueprint:review`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Browse the private feedback inbox, roadmap, changelog drafts, and automation history. |  |
| **Can manage** | Moderate public feedback, change requests and roadmap state, and publish changelog updates. | `feedback-board.view` |
| **Can run builds** | Start, resume, and inspect Ryu workflows that prepare or build a feature request. | `feedback-board.manage` |
