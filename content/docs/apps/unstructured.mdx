## What it does

Unstructured is an Apache-2.0 `document.parse` backend that reads roughly sixty formats, including
PDF, modern and legacy Office files, email, EPUB, HTML, spreadsheets, and scanned images through OCR.
Its output uses typed elements such as `Title`, `NarrativeText`, `ListItem`, `Table`, `CodeSnippet`,
and `PageBreak`, so the sidecar can preserve structure in generated Markdown.

The `unstructured[all-docs]` install uses 1–2 GB of Python packages. Native tools such as poppler, tesseract, LibreOffice, and pandoc must already be present on the host. The sidecar reports missing tools by name through the job's `error` and `missing_dependencies` fields. Parses run as jobs: submit returns `202` and a `job_id`, then the caller polls.
