## What it does

A self-organizing bookmark library with HTML/browser imports, notes, inferred collections, and semantic search through Ryu Spaces.

This page is part of the [Apps catalog](/docs/apps), [app manifest lifecycle](/docs/core/app-manifest-lifecycle), [Plugins vs Apps](/docs/extend/develop/extensions/plugins-vs-apps), [Marketplace](/docs/extend/develop/extensions/marketplace), [Gateway governance](/docs/gateway/governance) documentation path. ## What it exposes

### Companion surfaces

- **Bookmarks** (html)

## Permissions

**Grants:** `spaces:docs`, `storage:kv`

| Level | Description | Implies |
|---|---|---|
| **Can browse** | Read your saved bookmarks and use semantic search across their titles, notes, tags, and URLs. |  |
| **Can manage** | Add, import, edit, favorite, and delete bookmarks in the Bookmarks library. | `bookmarks.view` |
