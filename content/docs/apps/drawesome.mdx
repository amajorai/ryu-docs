## What it does

A lightweight sketching studio for Ryu with seven natural-feeling pens, area erasing, and SVG or PNG export. Sketches persist in app storage and stay local to the node.

## Permissions

**Grants:** `storage:kv`, `ui:toast`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Open the current Drawesome sketch and export a copy. |  |
| **Can edit** | Draw, erase, clear, and save changes to the current sketch. | `drawesome.view` |

## UI it contributes

### Apps shelf

When enabled, this app appears as one icon tile in the desktop sidebar's Apps shelf. Use sidebar sections for the app's record lists; feature navigation stays inside the Companion.

## Engine requirement

Requires Ryu >=0.1.0.
