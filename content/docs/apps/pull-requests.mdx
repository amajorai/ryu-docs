## What it does

A focused GitHub work inbox for Ryu. Browse pull requests and issues across repositories, inspect summaries and discussion, then review, manage stacked pull requests, merge changes, or close and comment on issues through the locally authenticated GitHub CLI.

## Surfaces

| Surface | Support |
|---|---|

| island | limited |
| mobile | limited |
| extension | none |
| web | limited |

## What it exposes

### Companion surfaces

- **Pull Requests** (html)

## Permissions

**Grants:** `app:http`, `shell:integrate`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Use your local GitHub CLI login to list pull requests and issues and read their summaries and discussion. |  |
| **Can review** | Post comments and reviews, mark drafts ready, manage stacked pull requests, merge pull requests, and comment on or close issues using your local GitHub CLI credentials. | `pull-requests.view` |
