## What it does

Token Table is a catalog preview for a planned six-seat Texas Hold'em table for
friendly, cosmetic play. Its Companion and authoritative game sidecar are not
shipped yet, so the current package is list-only rather than an installable game.

The planned balance is deliberately fictional. It will never change model quotas,
billing, credits, or the node's actual token accounting.

## What it exposes

### Planned table views

- **Lobby** - join the shared room, see active seats, and choose a cosmetic buy-in.
- **Table** - six-max Hold'em with private cards, community cards, pot, blinds, street, and action controls.
- **History** - review the latest actions and the current simulated balance for the room.

## Multiplayer model

The eventual sidecar is intended to be authoritative for seats, hands, card
dealing, legal actions, settlement, and the simulated ledger. No game process or
room is started by the current preview.

## Permissions

The list-only package requests no grants. Its future grants will ship with the
signed Companion and sidecar payloads.

## Cosmetic token disclosure

Token Table's “tokens” are an in-game score. They are not transferable, redeemable, purchasable, or usable for model inference. Any node usage that inspired the concept is intentionally not read, spent, or mutated by the game.

## Engine requirement

Requires Ryu >=0.1.0 for catalog compatibility. No runtime is active today.
