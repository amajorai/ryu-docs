## What it does

MinerU is OpenDataLab's high-fidelity `document.parse` backend for scientific and scanned PDFs. It reconstructs reading order across multi-column pages, converts formulas to LaTeX and tables to HTML, and runs OCR on scanned pages. The output is markdown that preserves the source structure.

MinerU requires Python 3.10–3.13, 16 GB of RAM (32 GB recommended), about 20 GB of disk for its models, and a GPU for fast parsing: 4 GB of VRAM for the pipeline backend or 8 GB for the VLM backends. A CPU-only host can use `pipeline`, but parsing takes minutes. Models download on first use.

MinerU runs as a CLI in a supervised subprocess with a hard wall-clock limit. A timed-out or cancelled parse terminates the whole process group instead of leaving an orphaned process. Parses run as jobs: submit returns `202` and a `job_id`, then the caller polls.
