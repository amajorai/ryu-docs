## What it does

Document parsing via MinerU (opendatalab) - the highest-fidelity `document.parse` backend, and the heaviest. Built for scientific and scanned PDFs: it runs layout detection to reconstruct true reading order across multi-column pages, converts formulas to LaTeX, converts tables to HTML, and OCRs scanned pages, so a physics paper comes back as markdown a model can actually follow instead of two columns interleaved line by line. The cost is real: MinerU wants Python 3.10-3.13, 16 GB of RAM (32 GB recommended), about 20 GB of disk for its model set, and a 4 GB-VRAM GPU for the pipeline backend (8 GB for the VLM backends) to be quick - a CPU-only host works through the `pipeline` backend but parses take minutes. Models download on first use. MinerU ships as a CLI, so each parse is a supervised subprocess with a hard wall-clock kill: a timed-out or cancelled parse takes its whole process group with it rather than leaving a multi-gigabyte orphan. Parses run as jobs: submit returns 202 + a job_id, the caller polls.
