## What it does

Sprout Studio is a Ryu-native local-first short-form content workspace. Describe a brief with a niche, audience, voice, format, cadence, and targets; ask the configured local model for a structured slideshow plan; refine each frame; then save, schedule, publish, and learn from the result in one Companion surface.

The workflow remains useful without a cloud account or social credential. If a local model or image model is not available, Sprout keeps the draft editable with deterministic local previews. When Outpost is installed and an account is connected, the optional social bridge can receive a caption and schedule.

## What it exposes

### Companion surfaces

- **Sprout Studio** (html)

### Workflow views

- **Overview** - workspace summary, next post, and one-click generation.
- **Automations** - reusable niche, audience, voice, cadence, and target recipes.
- **Studio** - hook and caption editor, destination account selection, frame reorder/remove, visual regeneration, direct source-image download, optional video rendering, project export, and vertical preview.
- **Library** - saved drafts with draft, scheduled, published, and archived states.
- **Inspiration** - searchable local slideshow library with one-click editable remixes.
- **UGC Lab** - selfie, product, and talking-head prompts routed to the local image primitive, with offline previews.
- **Accounts** - local TikTok destinations, optional Outpost sync, workspace plan/usage, and team invitations.
- **Calendar** - the local publishing queue and weekly rhythm.
- **Analytics** - local preview metrics for reach, likes, saves, shares, and completion.
- **Settings** - model mode, preferred model names, publishing handoff, bridge status, and reset.

## Permissions

**Grants:** `hook:side-model`, `media:generate`, `storage:kv`, `social:crud`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Read automations, drafts, schedules, and local performance summaries. |  |
| **Can create** | Ask the configured local models to draft slideshow concepts and visuals. | `reelfarm.view` |
| **Can publish** | Schedule or publish locally, or send content to connected Outpost accounts. | `reelfarm.view`, `reelfarm.create` |

## Local state

Drafts, source visuals, UGC assets, accounts, team members, and settings are stored under Sprout's namespaced `storage:kv` key. The app does not add a Core route or sidecar of its own. Outpost is an optional handoff; if it is absent or unavailable, the local queue stays authoritative and the failure is shown in the activity trail. Direct source-image downloads require a CORS-readable image URL; failed imports never overwrite the selected frame.

## Engine requirement

Requires Ryu >=0.1.0. Video rendering is available when the host exposes the generic `media.video` primitive; the editor and JSON project export work without it.
