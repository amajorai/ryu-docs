## What it does

Mission Control gives a project-level view across chats. It shows recent sessions and their outcomes, daily activity, files that recur across chats, and unfinished tasks in threads nobody reopened.

The out-of-process `ryu-mission-control` sidecar owns the digest store and cross-chat rollup. The desktop serves it through the generic ext-proxy `public_mount`. The desktop computes digests from each chat's message parts and sends them to the sidecar because a manifest sidecar cannot read conversations and the parts column is sealed at rest. The same digest feeds the in-chat Mission Control panel, so both views stay consistent.

## Permissions

**Grants:** `hook:side-model`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See the project dashboard: which chats ran, what each one changed and reasoned, which files they touched, and what is still outstanding across all of them. |  |
| **Can manage** | Re-index a chat's digest, ask the node's own side model to narrate a session, and remove a chat from the dashboard. Narrating a session sends that chat's digest - its turn headlines, the agent's reasoning and its to-do list - to whatever model the node is configured to use. | `mission-control.view` |
