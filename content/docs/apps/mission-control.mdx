## What it does

The project-level view over many chats: recent sessions and what each one accomplished, per-day activity, the files several chats keep returning to, and the to-dos left outstanding in threads nobody reopened. Declares the out-of-process ryu-mission-control sidecar (kind:local), which owns the digest store and the cross-chat rollup and is served to the desktop through the generic ext-proxy public_mount. The digests themselves are computed in the desktop from each chat's message parts and PUT here, because a manifest sidecar has no conversation read and the parts column is sealed at rest - the same function feeds the in-chat Mission Control panel, so a chat's summary is identical in both places.

## Permissions

**Grants:** `hook:side-model`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See the project dashboard: which chats ran, what each one changed and reasoned, which files they touched, and what is still outstanding across all of them. |  |
| **Can manage** | Re-index a chat's digest, ask the node's own side model to narrate a session, and remove a chat from the dashboard. Narrating a session sends that chat's digest - its turn headlines, the agent's reasoning and its to-do list - to whatever model the node is configured to use. | `mission-control.view` |
