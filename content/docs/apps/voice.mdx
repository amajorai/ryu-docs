## What it does

Voice provides Voice Recognition transcription through `whisper.cpp` and Audio generation through OuteTTS and the universal Ryu Audio sidecar. It also exposes the installable Audio model catalog and a governance shell over the in-crate voice module.

| Level | Description | Implies |
|---|---|---|
| **Can manage voices** | Install and remove Audio voice models, each of which downloads to this node and occupies disk. |  |

## Engine requirement

Requires Ryu >=0.1.0.
