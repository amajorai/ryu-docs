## What it does

Voice data path: speech-to-text transcription (whisper.cpp) and text-to-speech (OuteTTS + the universal Ryu TTS sidecar), plus the installable TTS model catalog. Governance shell over the in-crate voice module.

## Permissions

| Level | Description | Implies |
|---|---|---|
| **Can manage voices** | Install and remove text-to-speech voice models, each of which downloads to this node and occupies disk. |  |
