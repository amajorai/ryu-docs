## What it does

Voice data path: Voice Recognition transcription (whisper.cpp) and Audio generation (OuteTTS + the universal Ryu Audio sidecar), plus the installable Audio model catalog. Governance shell over the in-crate voice module.

## Permissions

| Level | Description | Implies |
|---|---|---|
| **Can manage voices** | Install and remove Audio voice models, each of which downloads to this node and occupies disk. |  |

## Engine requirement

Requires Ryu >=0.1.0.
