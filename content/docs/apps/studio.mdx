## What it does

A local-first content queue for short-form ideas, hooks, visual direction, and planned publish slots.
Studio records these stages locally; it has no social-platform publisher or automatic scheduler.

## Permissions

**Grants:** `storage:kv`, `hook:side-model`

| Level | Description | Implies |
|---|---|---|
| **Can view** | Browse the local short-form publishing queue. |  |
| **Can manage** | Create, edit, plan, favorite, import, and remove content ideas. | `studio.view` |
| **Can generate** | Use Ryu's configured model to draft short-form ideas from a brief. | `studio.manage` |

## UI it contributes

### Apps shelf

When enabled, this app appears as one icon tile in the desktop sidebar's Apps shelf. Use sidebar sections for the app's record lists; feature navigation stays inside the Companion.
