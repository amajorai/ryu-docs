## What it does

The Island companion provides system-wide dictation and agent-ask. Speak anywhere to type a transcript, or ask an agent and paste its answer into the focused app.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | full |
| cli | full |

## What it exposes

### Policies

- **dictation** - On/off switch for system-wide dictation + agent-ask hosted by the Island companion. Enabling this plugin is the single switch - there is no separate settings master toggle. Island registers the global shortcuts and drives capture → Core Voice Recognition → optional agent → ghost insert. Core-local - no gateway restart.

## Permissions

| Level | Description | Implies |
|---|---|---|
| **Can dictate** | Start system-wide dictation and agent-ask, which records the microphone and types the result into whichever app is focused. |  |
