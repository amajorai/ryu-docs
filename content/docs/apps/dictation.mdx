## What it does

System-wide dictation and agent-ask via the Island companion: speak anywhere to type a raw or locally cleaned transcript, or ask an agent and paste the answer into the focused app.

## What it exposes

### Policies

- **dictation** - On/off switch for system-wide dictation + agent-ask hosted by the Island companion. Enabling this plugin is the single switch - there is no separate settings master toggle. Island registers the global shortcuts and drives capture → Core Voice Recognition → optional Speech Processing → optional agent → ghost insert. Core-local - no gateway restart.

## Permissions

| Level | Description | Implies |
|---|---|---|
| **Can dictate** | Start system-wide dictation and agent-ask, which records the microphone and types the result into whichever app is focused. |  |
