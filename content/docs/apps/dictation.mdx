## What it does

System-wide dictation and agent-ask hosted by the Island companion: speak anywhere to type a raw or locally cleaned transcript, or ask an agent and paste the answer into the focused app. Requires the Island companion, which is not available in this release, so it is hidden from the store until Island ships.

## What it exposes

### Policies

- **dictation** - On/off switch for system-wide dictation + agent-ask hosted by the Island companion. Enabling this plugin is the single switch - there is no separate settings master toggle. Island registers the global shortcuts and drives capture → Core Voice Recognition → optional Speech Processing → optional agent → ghost insert. Core-local - no gateway restart.

## UI it contributes

### Settings tabs

- **Dictation**

On Desktop, open **Gateway settings → Plugins → Dictation** to choose:

- the dictation and agent-ask shortcuts;
- the recognition engine and insertion mode;
- optional Speech Processing cleanup;
- the ask model.

The tab stays available while Dictation is disabled. Settings are saved, then take effect when the plugin is enabled. If enabling is denied, the tab shows the error so you can retry after the permission or dependency is resolved.

Each setting row explains itself underneath, including the rows that only appear for some choices:

- With **Insertion** set to **Paste**, **Paste command** takes a `+`-joined key combo such as `ctrl+shift+v`. Leave it empty to use your platform's own paste shortcut. **Restore clipboard** puts your previous clipboard back after the paste.
- With **Agent ask** on, **Agent-ask shortcut** is a separate global key from the dictation shortcut, and its **Activation** row says whether you hold the key or press it to start and stop.
- When you pick an agent for agent-ask, or as a custom cleanup override, the tab shows that agent's cross-app access below the settings. There you choose which Spaces and app tools it may use. If both are set, the agent-ask agent is the one shown.
