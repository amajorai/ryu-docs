## What it does

Discover services that speak the Machine Payments Protocol, review exact Tempo testnet charges, enforce per-request and daily budgets, make explicitly approved paid requests, and keep a local receipt ledger. Signing keys use Ryu's per-app encrypted custody and never enter chat, app state, logs, or receipt records.

## What it exposes

### Tools

### `mpp.services_search` - Search MPP services

Search the official mpp.dev service catalog. This is read-only and returns service names, descriptions, HTTPS URLs, categories, endpoints, and advertised prices when present.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | no | Optional text to match across service names, descriptions, URLs, and categories. |

### `mpp.wallet_status` - Check MPP wallet and budget

Read the safe wallet projection, active payment policy, and today's spent, pending, and available pathUSD budget. Private keys are never returned.

Backend: HTTP · Method: POST

_No parameters_ (empty schema).
### `mpp.payment_prepare` - Prepare an MPP request

Probe an allowlisted HTTPS endpoint for an MPP challenge and return an approval-safe summary. This does not sign or send a payment. If payment is required, pass the one-time approval token to mpp.pay only after the user reviews the exact amount, network, currency, recipient, expiry, and budget delta.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `method` | string (one of: GET, POST, PUT, PATCH, DELETE, HEAD) | yes |  |
| `url` | string | yes | Allowlisted HTTPS resource URL. |
| `headers` | object | no | Optional safe request headers. Authorization and payment credential headers are forbidden. |
| `body` | string | no | Optional request body, up to 256 KiB. |
| `idempotencyKey` | string | no | Optional stable idempotency key for this exact purchase. |

### `mpp.pay` - Approve and pay an MPP request

Spend funds for a previously prepared MPP challenge. This is a financial action: obtain explicit approval immediately before calling it. The one-time token is challenge-bound and expires after five minutes or sooner when the server challenge expires.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `approvalToken` | string | yes | One-time token returned by mpp.payment_prepare after the exact charge was reviewed. |

### `mpp.mcp_payment_prepare` - Prepare a paid MCP tool call

Call an allowlisted remote MCP tool without a payment credential and capture a standard MPP payment-required error or result metadata. This never signs a payment. Review the returned exact charge, then pass its one-time approval token to mpp.pay.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | Allowlisted HTTPS Streamable HTTP MCP server URL. |
| `tool` | string | yes | MCP tool name. |
| `arguments` | object | no | JSON object passed to the MCP tool. |
| `idempotencyKey` | string | no | Optional stable idempotency key for this exact purchase. |

### `mpp.receipts_list` - List MPP receipts

List safe local receipt projections in newest-first order. Credentials, proofs, request bodies, and signing keys are never stored or returned.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `limit` | integer | no |  |

### `mpp.receipt_get` - Get an MPP receipt

Read one safe local receipt projection by id.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `receiptId` | string | yes |  |
