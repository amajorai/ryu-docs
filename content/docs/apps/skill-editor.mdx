## What it does

Skill Editor authors a user-owned Agent Skill (`SKILL.md`). It edits front-matter fields such as name, description, allowed tools, and always-on, and provides a Markdown body editor, debounced autosave, and server-backed undoable version history.

Skills do support versioning: Core checkpoints the raw `SKILL.md` into the node's local
`source-history` Git repository, not only in browser storage. You can compare a saved file with the
current source and restore it; restoring records the current file as a named undo point, so the
action remains undoable. Unlabeled identical saves are coalesced, while named checkpoints remain
visible in Git history. Older JSON snapshots remain readable during migration.

## Editing

The Markdown body uses the same floating nested overflow toolbar as the desktop
page editor. The compact rail stays fixed near the bottom of the window; open it
to choose a category, then use the back button to return to the category list.
Formatting actions cover inline Markdown, headings, quotes, lists, links, and code
blocks, while Write and Preview remain available from the rail's primary actions.

## Permissions

**Grants:** `skills:crud`, `shell:integrate`

| Level | Description | Implies |
|---|---|---|
| **Can edit skills** | Create and rewrite a skill's `SKILL.md`, including its instructions, allowed tools, and always-on flag. These changes affect every agent that loads the skill. |  |

## Engine requirement

Requires Ryu >=0.1.0.
