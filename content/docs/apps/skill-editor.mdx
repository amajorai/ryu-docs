## What it does

Author a user-owned Agent Skill (SKILL.md): front-matter fields (name / description / allowed tools / always-on), a markdown body editor, debounced autosave, and server-backed undoable version history.

## Permissions

**Grants:** `skills:crud`, `shell:integrate`, `ui:toast`

| Level | Description | Implies |
|---|---|---|
| **Can edit skills** | Create and rewrite a skill's SKILL.md - its instructions, allowed tools, and always-on flag - which changes what every agent loading that skill does. |  |
