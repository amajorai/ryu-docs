## What it does

Splits your agent runs across three sidebar sections - Working, Needs input and Done - each row showing the project it belongs to. It also contributes the same live state to the desktop's [Live Activities dock](/docs/surfaces/desktop/live-activities), so a running agent or a pending approval shows up as a live card on the empty shell page and in the sidebar.

## UI it contributes

### Sidebar sections

- **Working**
- **Needs input**
- **Done**

### Live activities

- **Working** — cards for running agent runs, opening the owning chat
- **Needs input** — cards for pending approvals, opening the inbox

## Engine requirement

Requires Ryu >=0.1.0.
