## What it does

Agent runs appear in three sidebar sections: Working, Needs input, and Done. Each row names the project it belongs to. The same live state appears in the desktop's [Live Activities dock](/docs/surfaces/desktop/live-activities), so running agents and pending approvals show up as live cards on the empty shell page and in the sidebar.

## UI it contributes

### Sidebar sections

- **Working**
- **Needs input**
- **Done**

### Live activities

- **Working** — cards for running agent runs, opening the owning chat
- **Needs input** — cards for pending approvals, opening the inbox

## Engine requirement

Requires Ryu >=0.1.0.
