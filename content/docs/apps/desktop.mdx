## What it does

Virtual Desktop provides an interactive desktop for cloud-managed, self-hosted, and local Ryu nodes.
The sidecar starts a headless Linux desktop with Xvfb, a window manager, and a VNC server on
loopback. Core exposes it through the generic WebSocket ext-proxy, and the desktop panel streams it
with mouse and keyboard input. Ghost can drive the same display, so agents see and control what you
watch.

## Permissions

**Grants:** `desktop:view`, `desktop:control`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See the node's virtual desktop as a live stream. |  |
| **Can control** | Drive the virtual desktop with mouse and keyboard input. | `desktop.view` |
