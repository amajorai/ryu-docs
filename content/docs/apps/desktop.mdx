## What it does

An interactive Linux virtual desktop for Ryu nodes. The app sidecar owns stable per-Bot screens on the shared node device and exposes them through Core's authenticated WebSocket proxy with mouse and keyboard input. Files and installed applications remain shared.

## Permissions

**Grants:** `desktop:view`, `desktop:control`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See the node's virtual desktop as a live stream. |  |
| **Can control** | Drive the virtual desktop with mouse and keyboard input. | `desktop.view` |
| **Can view agent devices** | See the persistent virtual desktop assigned to an allowed agent. |  |
| **Can control agent devices** | Drive the persistent virtual desktop assigned to an allowed agent. | `agent.view` |
