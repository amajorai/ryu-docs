## What it does

An interactive virtual desktop for any Ryu node - cloud-managed, self-hosted, or local. The sidecar brings up a full headless Linux desktop (Xvfb + window manager + apps) with a VNC server on loopback, exposes it through Core's generic WebSocket ext-proxy, and the desktop Virtual Desktop panel streams it live with mouse/keyboard input. Ghost can drive the same display, so agents see and control exactly what you watch.

## Permissions

**Grants:** `desktop:view`, `desktop:control`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See the node's virtual desktop as a live stream. |  |
| **Can control** | Drive the virtual desktop with mouse and keyboard input. | `desktop.view` |
