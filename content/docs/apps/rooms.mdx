## What it does

Rooms lets a host start a model session on the active Ryu node and invite phones or browsers with a QR code. Everyone sees the same bounded transcript and can submit prompts through the room session.

The host node runs the model. A joined phone is a client: it does not download model weights, run WebGPU, or contribute compute.

## Start a room

1. Open **Rooms** from the Ryu sidebar.
2. Choose a model exposed by the active Mesh LLM engine.
3. Confirm that Ryu shows a reachable LAN, private-network, or public node origin.
4. Select **Start room**, then scan the QR code on another device.
5. The invited device enters a display name and joins the transcript.

Rooms cannot create a link for a loopback-only node. Enable a reachable node address first. The link carries the invite in the URL fragment; the server exchanges it for an HttpOnly guest session and does not put the invite in a query string.

## Room behavior

- One model generation runs at a time for each room. A second prompt receives a busy response until the current run finishes or is stopped.
- The transcript and run state are stored by the Rooms sidecar on the active node.
- Generation deltas are delivered to the host companion and guest page as named room events.
- Closing a room revokes its invite and guest sessions. A host can also rotate or revoke an invite independently.
- A node restart marks an interrupted generation as failed instead of presenting partial output as a completed response.

The desktop Companion uses Ryu’s shared App UI primitives and chat composer. The
public guest route is a separate single-file page so an invited browser can join
without loading the desktop shell or receiving a node credential; it follows the
same semantic theme tokens and interaction states.

## Permissions

**Grants:** `app:http`, `app:realtime`, `hook:side-model`, `core:list_agents`, `shell:integrate`

| Level | Description | Implies |
|---|---|---|
| **Can view rooms** | See rooms hosted by the active node and their synchronized transcripts. |  |
| **Can create rooms** | Start a room and issue an invite to selected devices. |  |
| **Can run rooms** | Submit prompts and stop an active generation. | `rooms.view` |
| **Can manage rooms** | Rotate or revoke invites and close rooms. | `rooms.view` |

## Public guest route

The host shares the active node's Rooms guest page:

```text
/api/rooms/guest#invite=<opaque-invite>
```

The guest page uses same-origin requests after exchange. It never asks the guest for a node token and never shows host controls.

## Engine requirement

Requires Ryu >=0.1.0 and a running Mesh LLM engine with at least one model available to the active node.

## Sidecar

Runs an out-of-process sidecar: `ryu-rooms`.
