## What it does

Shared model rooms hosted by your active Ryu node. Start a Mesh LLM session on the node, invite phones or browsers by QR, and keep the transcript synchronized without exposing node credentials.

## Permissions

**Grants:** `app:http`, `app:realtime`, `hook:side-model`, `core:list_agents`, `shell:integrate`

| Level | Description | Implies |
|---|---|---|
| **Can view rooms** | See rooms hosted by the active Ryu node and their synchronized transcripts. |  |
| **Can create rooms** | Start a room on the active node and issue an invite to selected devices. |  |
| **Can run rooms** | Submit prompts to a room's selected local model and stop its active generation. | `rooms.view` |
| **Can manage rooms** | Close a room or revoke its device invite. | `rooms.view` |

## UI it contributes

### Apps shelf

When enabled, this app appears as one icon tile in the desktop sidebar's Apps shelf. Use the app's sidebar sections for record lists; feature navigation stays inside the Companion.

## Engine requirement

Requires Ryu >=0.1.0.

## Sidecar

Runs an out-of-process sidecar: `ryu-rooms`.
