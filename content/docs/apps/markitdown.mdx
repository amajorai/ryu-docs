## What it does

MarkItDown is Microsoft's MIT-licensed, pure-Python `document.parse` backend and the default for machines without a native toolchain. Install it with `pip install 'markitdown[all]'`; the package uses a few tens of megabytes and does not require ONNX Runtime, a layout model download, a GPU, or `brew`/`apt` packages.

It parses PDF, DOCX, PPTX, XLSX/XLS, HTML, CSV, JSON, XML, EPUB, Outlook `.msg`, Jupyter notebooks,
and ZIP archives member by member. It emits Markdown, preserving headings and spreadsheet tables.
It does not perform OCR, parse legacy binary `.doc`/`.ppt`, or return element-level structure for
consumers that need structural chunking. A scanned PDF returns an empty result and a job error.
Parsing runs as a job: submit returns `202` and a `job_id`, then the caller polls.
