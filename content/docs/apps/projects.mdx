## What it does

A focused local project board for turning commitments into owned tasks. Keep projects, owners, due dates, and next actions together without replacing Ryu's CRM, Calendar, or Workflows.

## Permissions

**Grants:** `storage:kv`, `shell:integrate`, `ui:toast`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See projects, owners, due dates, and task progress. |  |
| **Can edit** | Create projects, add tasks, and update delivery status. | `projects.view` |

## UI it contributes

### Apps shelf

When enabled, this app appears as one icon tile in the desktop sidebar's Apps shelf. Use sidebar sections for the app's record lists; feature navigation stays inside the Companion.

## Engine requirement

Requires Ryu >=0.1.0.
