## What it does

Chat Broadcast lets you change direction across several chats without opening
them one by one. Use it for an announcement, a shared constraint, or a quick
instruction such as “stop linting; it is taking too long.”

## Choose chats

The **Running** view is selected by default and targets every visible chat that
is currently running. The **Selected** view lets you choose individual visible
chats, including idle conversations. Archived chats are not shown.

## Send safely

Write the message, review the recipient count and chat names, then choose **Send
now**. The message is added as a normal user turn in each destination chat, so it
appears in the transcript and has the same context as a message typed there.

Messages are delivered one at a time. A running chat queues the instruction
behind its current turn; an idle chat starts it normally. The app reports each
delivery so a failed destination does not hide the rest of the results.

## Permission

Chat Broadcast asks for the `chat.sendFollowUp` permission. It can see only the
chat summaries available to the signed-in user, and every destination is checked
again when the message is sent.
