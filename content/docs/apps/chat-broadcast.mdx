## What it does

Send one message to every running chat or a hand-picked set of visible chats, including idle conversations.

## What it exposes

### Companion surfaces

- **Chat Broadcast** (html)

## Permissions

**Grants:** `chat.sendFollowUp`

| Level | Description | Implies |
|---|---|---|
| **Can broadcast** | List the chats you can access and send a confirmed message into selected conversations, including idle chats. |  |
