This page lists the default keyboard map of the Video Studio editor. Start with
the [Video Studio overview](/docs/apps/video-studio); the actions themselves are
described in [timeline editing](/docs/apps/video-studio-editing),
[assisted editing](/docs/apps/video-studio-assisted-editing), and the
[workspace guide](/docs/apps/video-studio-workspace).

- **Cmd** means Command on macOS and Ctrl elsewhere; Video Studio treats them
  as the same modifier. On macOS the shortcuts list shows ⌘, ⌥, and ⇧ labels.
- Shortcuts never fire while you type in a text field or work in a dialog.
- Enter goes to the start only when no button, link, or menu has focus, so it
  still activates the focused control.

## Change a shortcut

1. Press `?` or choose **Keyboard shortcuts** in the workspace bar. The
   shortcuts list shows every action, including the ones without a default key.
2. Choose **Change** or **Add** on an action.
3. Press the new keys. Escape cancels, and Tab cannot be bound.
4. If the keys already belong to another action, Video Studio asks first and
   says what the other action keeps or loses.

You can reset one action or every action, and print a reference sheet.

- Bindings are stored per browser. When the browser blocks site storage,
  changes last for the current session only.
- Keys reserved by Ryu system-wide, such as the push-to-talk shortcut
  Cmd+Shift+A, cannot be bound.
- Option and Alt chords are recorded by physical key, so they work on any
  keyboard layout.

## Default keys

### Project and history

| Keys | Action |
| --- | --- |
| Cmd+S | Save the project (waits for an autosave that is already running) |
| Cmd+Z | Undo |
| Cmd+Shift+Z or Cmd+Y | Redo |

### Playback

| Keys | Action |
| --- | --- |
| Space | Play or pause |
| J | Play in reverse; press again for 2×, 4×, and 8× |
| K | Pause and reset the shuttle speed to 1× |
| L | Play forward; press again for 2×, 4×, and 8× |
| `/` | Play around the playhead: two seconds before to two seconds after, then return |
| Cmd+L | Cycle loop playback: off, the marked range, the whole timeline |

While a source tab is open in the preview, Space, J, K, and L play that
source instead of the timeline, and I and O mark its source range (see
[preview tabs](/docs/apps/video-studio-workspace#preview-tabs)).

### Navigation

| Keys | Action |
| --- | --- |
| Left / Right | Step one frame |
| Shift+Left / Shift+Right | Step one second |
| Cmd/Ctrl+Shift+Left / Cmd/Ctrl+Shift+Right | Jump five seconds |
| Up / Down | Previous or next edit point (hidden tracks are skipped) |
| Shift+Up / Shift+Down | Previous or next marker |
| `[` / `]` | Previous or next marker |
| Home or Enter / End | Go to the start or the end |
| I / O | Mark the range start or end at the playhead |
| Alt+X | Clear the marked range |
| Shift+drag on the ruler | Mark a range |

### Editing

| Keys | Action |
| --- | --- |
| S or Cmd+K | Split the selected clips at the playhead, or every unlocked clip under it when nothing is selected |
| Q / W | Ripple-trim the start or end of those clips to the playhead |
| Alt+Q / Alt+W | Trim the start or end to the playhead and leave a gap |
| Alt+[ / Alt+] | Trim the selected clip's start or end to the playhead |
| Delete or Backspace | Delete the selection |
| Shift+Delete or Shift+Backspace | Ripple delete the selection |
| Alt+Left / Alt+Right | Move the selected clip one frame |
| Alt+J / Alt+L | J-cut or L-cut at the selected clip's cut, or the cut nearest the playhead |
| Shift+Alt+J | Open **J/L cuts** (automatic split edits) |
| Cmd+Alt+G | Nest the selection into a sequence |
| Cmd+Alt+Shift+G | Decompose the selected sequence clip |
| Shift+M | Mute or unmute the selected clip |
| Shift+H | Hide or show the selected clip |

### Actions without a default key

These actions are reached from toolbars, menus, or the inspector. Give any of
them a key in the shortcuts list.

- Detach clip audio
- Export video
- Export range
- Insert the selected clip at the playhead
- Add marker
- Preview guides
- Ripple delete range
- Ripple mode
- Select all on track

## Pointer and focus modifiers

These work with the pointer or a focused control rather than the keyboard map,
so they are not listed in the shortcuts dialog:

- **Razor:** click a clip to cut it; Shift-click cuts every unlocked track.
- **Dragging clips:** Shift turns snapping off for one drag. Alt while trimming
  leaves the linked partner alone. Alt-dragging a clip body drops a copy.
- **Dropping media:** hold Cmd to ripple-insert instead of overwriting.
- **Timeline:** Ctrl+wheel, Alt+wheel, or a pinch zooms around the pointer;
  Shift+wheel or Cmd+wheel pans.
- **Selection:** Shift-click adds a clip; drag on empty lane space for a
  marquee, holding Shift or Ctrl to add to the selection.
- **Clip menu:** right-click, long-press, or Shift+F10 on a focused clip.
- **Markers:** double-click, right-click, or Shift+Enter on a ruler marker
  opens its editor.
- **Overlay lanes:** Alt+Left/Right nudges a title, graphic, caption, or
  adjustment layer by a frame (Shift for one second); Cmd+D duplicates it.
- **Preview:** arrows nudge the selected item 1 pixel (Shift for 10); Cmd
  suspends canvas snapping for one drag; Enter on a clip box opens crop mode
  and on a title box edits its text.
- **Keyframe lanes:** Delete removes a keyframe, arrows nudge it one frame
  (Shift for 10), and Enter opens its curve editor.
- **Number fields:** drag a field's label to scrub (Shift finer, Alt coarser);
  Up and Down step the value.
