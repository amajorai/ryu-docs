## What it does

Customer API keys submit uploaded or inline document bytes. Filesystem paths are
reserved for the Core-managed provider credential, even on the mounted API.
Customer keys cannot select another user's files from the service's local roots.

Document extraction through Firecrawl's MIT-licensed AnyDoc Rust library. It converts Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV, and text-based PDF files into GitHub-Flavored Markdown through the swappable `document.parse` capability. The local backend is fast and has no model or native-tool download, but it does not OCR scanned pages or fetch URLs. The same out-of-process backend also exposes an API-key-authenticated `/v1/extract` service for direct deployments.
