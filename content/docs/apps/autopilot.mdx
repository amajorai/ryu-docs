## What it does

A positioning-first launch companion. Choose one job, define the market position and narrow ICP, then derive outreach and copy from the same strategy before running bounded Ryu work.

## Permissions

**Grants:** `hook:run-agent`, `storage:kv`, `core:list_agents`, `shell:integrate`, `ui:toast`

| Level | Description | Implies |
|---|---|---|
| **Can view** | See the one-job strategy, market position, ICP, activation pack, and guardrails. |  |
| **Can edit** | Edit the one-job strategy, selected agent lane, and Autopilot guardrails. | `autopilot.view` |
| **Can run** | Run a bounded strategy pass through the selected Ryu agent. The agent still follows each enabled tool's own grants and approval gates. | `autopilot.edit` |
