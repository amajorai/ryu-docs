## What it is

The Spaces primitive: **named document collections** — the durable, queryable knowledge
layers you assemble from files, docs, and web pages. Each space owns:

- a **sqlite-vec (`vec0`) vector store**,
- a **content-addressed blob store** for the underlying documents,
- a **per-space embedder**, and
- a **GraphRAG** (entity/relation) retrieval strategy alongside plain vector search.

Spaces are where retrieval becomes composable: one space can hold a project wiki, another
an ingested corpus, and an agent can be pointed at either without code changes.

## Swap seam

Embedders and rerankers are injected as [rag](/docs/primitives/rag) instances, so the crate
has zero dependency on `apps/core`. The model-registry-driven embedder choice, default
`~/.ryu` paths, tenancy (`Tenancy`/`ResourceTenancy`) mapping, and preferences stay
Core-side (`apps/core/src/server/spaces.rs` shim). Consumed in-process as a non-optional
path dependency.

## Where it lives

`crates/core/spaces`

## API surface

- `/api/spaces/*` — create, ingest, search, graph, and version documents (see the
