## What it is

The Core-side code evaluators — the scoring engine for evals. Given a case
`(input, output, expected, vars)`, it runs the user's `(…) -> {score}` function in an
isolated runtime:

- **JS** via the deny-all [Deno sandbox](/docs/primitives/tool-exec),
- **Python** via the swappable [sandbox backend](/docs/primitives/sandbox).

The result scores one eval case, which feeds the Gateway's eval loop and the agent-quality
signals downstream.

## Swap seam

A leaf capability crate with zero dependency on `apps/core`.

## Where it lives

`crates/core/eval-code`
