## What it is

The durable-execution primitive — what makes a long-running workflow survive a crash. It is
the swap-seam `DurableEngine` trait (**checkpoint / resume / replay** a run to completion)
plus `FileCheckpointStore`, an atomically-durable (temp + fsync + rename) directory-backed
run-state store that makes crash-recoverable resume real rather than best-effort.

Because the trait is generic over the run/workflow types, the same seam re-admits an
external Temporal, Restate, or DBOS sidecar backend later — the in-tree
checkpoint store is the default, not the only option.

## Swap seam

In-process by default, consumed as a non-optional path dependency (the workflow store
checkpoints every node through it). The petgraph workflow executor (the `execute`
implementation) and the concrete `WorkflowRun` type stay Core-side
(`apps/core/src/workflow/durable.rs` host shim). Zero dependency on `apps/core`.

## Where it lives

`crates/core/durable`
