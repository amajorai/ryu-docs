## What it is

The Ryu developer SDK core — the shared Rust kernel that every language binding builds on.
It owns:

- the **manifest model** (via [kernel-contracts](/docs/primitives/kernel-contracts)),
- **gateway egress rules**, and
- the **gateway-mandatory model client** — the client that refuses to bypass the Gateway,
  so SDK-built agents are governed by construction.

This is the "works with any language" seam: one kernel, many bindings
([C](/docs/primitives/sdk-ffi), [Node](/docs/primitives/sdk-napi),
[Python/Swift/Kotlin](/docs/primitives/sdk-uniffi)).

## Where it lives

`crates/sdk/core`
