## What it is

The engine-agnostic inference-configuration primitive. Every model call ends up as a
request to *some* engine — llama.cpp, Ollama, vLLM, SGLang, MLX, or a cloud OpenAI-compatible
provider — and each engine speaks a different dialect. This primitive owns the translation:

- **`SamplingConfig`** — the per-request knobs (temperature, top-p, top-k, min-p, penalties,
  mirostat, DRY, seed, …).
- **`LaunchConfig`** — the per-launch knobs (context size, GPU layers, MoE offload, chat
  template / Jinja, speculative draft, quantization, continuous-batching flags).
- **Translation** — per `Engine`, configs are lowered into OpenAI-compatible request bodies,
  `llama-server` CLI arguments, or Ollama `Modelfile` parameters.

## Scope

This crate owns engine *configuration and translation* — not the provider launch lifecycle
(that lives in Core's sidecar providers), not the runtime priority-admission queue, and not
the embedding surface (`Embedder`/`Reranker` live in [rag](/docs/primitives/rag)).

## Swap seam

In-process by default, consumed as a non-optional path dependency (providers and adapters
build launch/sampling args unconditionally). Zero dependency on `apps/core`.

## Where it lives

`crates/core/engines`
