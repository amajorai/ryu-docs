## What it is

The system-wide predictive-typing brain — the completion engine behind inline "what you're
about to type" suggestions. It owns the completion engine (config, **per-app allowlist**,
**secure-field denylist**, prompt assembly, reply cleanup) and the `/api/predict/*` HTTP
surface.

## Swap seam

In-process default; Core consumes it as a non-optional path dependency. Every cross-cutting
call it needs — preferences, the agent's bound model, the default model id, the Gateway
side-model call, and the plugin-owned enabled flag — inverts through the `PredictHost`
trait. The process-global on/off flag (`predict::set_enabled` / boot seeding) stays in the
kernel — it is the built-in Predict plugin's switch.

## Where it lives

`crates/core/predict`

## API surface

- `/api/predict/*` — complete and get/put config (see the
  [Predict API reference](/docs/develop/api-reference/core/predict)).
