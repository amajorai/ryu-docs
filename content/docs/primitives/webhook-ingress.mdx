## What it is

The webhook ingress primitive — the seam that lets a **loopback-bound** Core receive
third-party webhooks (Composio triggers, per-workflow webhooks) without punching a hole in
your firewall. It owns:

- **Four ingress backends** — managed RyuRelay outbound SSE push, Tailscale Funnel,
  cloudflared quick tunnel, and a BYO own-relay.
- **A path-routed inbound dispatcher** with fail-closed HMAC re-verification.
- **Replay-window + delivery dedup**, and an **ingress-URL registry**.

## Swap seam

In-process default (no IPC on any hot path). The kernel couplings — Composio verify/run,
workflow-secret lookup, mesh funnel, auth token, data dir — invert through the
`WebhookIngressHost` trait. Public webhook *routes* stay kernel-ingress in Core and forward
into this engine.

## Where it lives

`crates/core/webhook-ingress`

## API surface

- `/api/nodes/webhook-ingress/*` — status and backend selection (see the
