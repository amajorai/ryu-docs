## What it is

The retrieval-augmented-generation primitive — the layer that decides *what context to
retrieve* before a model call. It owns three pieces:

- **Embedder** — local hashing plus remote OpenAI-compatible `/v1/embeddings`.
- **Reranker** — local term-overlap plus remote cross-encoder `/rerank`.
- **`RetrievalStore`** — the sqlite-backed chunk index shared by memory, Spaces, and OKF,
  with cosine merge and top-K rerank.

All three sit behind the narrow `RagProvider` trait, so retrieval is a swappable
capability rather than a hardcoded stack.

## Swap seam

Model/provider selection stays Core-side (`apps/core/src/rag_host.rs`) — the single
resolver keyed by the bound provider id. A per-space embedder is a `RagProvider`/`Embedder`
**instance** minted by that resolver, not a process-global singleton. The OKF ingest/export
path references the extracted [knowledge](/docs/primitives/knowledge) types directly.
In-process by default; chat retrieval injection, agent auto-routing, and
tool/space/search embedding all reach it unconditionally.
