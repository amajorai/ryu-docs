## What it is

The `DownloadCenter` — a single process-wide registry that owns the lifecycle of **every**
artifact Ryu pulls over the network: chat and embedding GGUFs, engine and agent binaries,
tools, and skills. Downloading is one of those layers everyone re-implements; here it's a
primitive by *reuse*.

- **Resumable** — stream-to-`.part` with HTTP `Range` + `If-Range` resume, so a dropped
  connection continues where it left off.
- **Verified** — bounded retry, checksum verification, then atomic rename into place. A
  corrupt download never lands as a valid artifact.
- **Controllable** — pause, resume, and cancel, with live SSE progress over a broadcast
  channel and a durable history log.

## Swap seam

The three kernel couplings — the data dir, the version-store checksum-skip, and Hugging
Face bearer auth — invert through the narrow `DownloadsHost` trait. In-process by default.

## Where it lives

`crates/core/downloads`

## Uses it

The [model catalog](/docs/primitives/model-catalog), the
[sidecar manager](/docs/develop/extensions/sidecar-ports), engines, and the marketplace
install path all fetch through it.
