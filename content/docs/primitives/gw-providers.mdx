## What it is

The Gateway's concrete backend providers — the OpenAI, Anthropic, local, core, OpenRouter,
Modal, GenAI, Replicate, and Fal HTTP implementations behind the `Provider` trait. It also
owns the **shared provider HTTP helpers** (retry, rate-limit header parsing, media-output
normalization, model discovery), the **per-provider quota sink**, and the **video-job value
types**.

## Swap seam

The trait returns a crate-local `ProviderError` that the gateway maps to its `GatewayError`
at the pipeline boundary — **a new provider is a drop-in**. The `ProviderRegistry`,
config-driven registration, and key custody stay in `apps/gateway` (*"engine moves, wiring
stays"*).

## Where it lives

`crates/gateway/providers`
