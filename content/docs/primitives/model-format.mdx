## What it is

A tiny leaf primitive: the `ModelFormat` enum — **GGUF / Safetensors / MLX** — plus its
wire/serde mapping and the pure format→engine capability tables (`engines_for_format`,
`needs_engine_label`, `format_supported_on_node`, `pick_engine`).

Every layer that touches a model artifact needs to answer "what kind of file is this, and
which engines can run it?" Without a shared type for that answer, each crate would invent
its own — so this is the neutral home both the catalog and the provider layer reference.

## Swap seam

A leaf capability crate with zero dependency on `apps/core`. The model catalog, sidecar
providers, chat adapters, and catalog sources all reference these format types
unconditionally; Core re-exports it as `crate::model_format`.

## Where it lives

`crates/core/model-format`
