## What it is

The BYOK SMTP email sink — a swappable outbound-email transport for self-hosted Ryu. It
delivers policy/monitor alerts today and agent-inbox send later (the SES agent-inbox path
in `packages/mail` is the other transport).

- A rich **multi-recipient / cc-bcc / text+html multipart / threaded / attachment builder**.
- A **one-line alert helper**.
- Runs over a **BYO relay** resolved preferences-first, then `RYU_SMTP_*` env — there is
  **no default provider**, and it is a clean **no-op when unconfigured**.

## Swap seam

Secret custody stays kernel-side via an injected password resolver, so the crate has zero
dependency on `apps/core`.

## Where it lives

`crates/core/email-send`
