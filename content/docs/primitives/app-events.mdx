## What it is

The app-event emit client — the one dependency-light helper an **out-of-process sidecar**
needs to raise an event declared in its app manifest's `contributes.hook_events` through
Core's `events.emit` host capability. Every plugin hook and workflow subscribed to that
event fires as a result.

The dispatch, authorization, and fan-out all live Core-side; this crate holds only the
outbound half an out-of-process sidecar needs.

## Swap seam

Zero dependency on `apps/core` by construction — the whole crate exists so a sidecar
doesn't have to link Core.

## Where it lives

`crates/core/app-events`
