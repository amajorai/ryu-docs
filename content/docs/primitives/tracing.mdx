## What it is

The per-run observability trace primitive: the ordered-span store (`Span` v1 contract +
SQLite-backed `TraceStore`) that records **tool-call / model-call spans** keyed by
`conversation_id` (the run id). It owns open/close spans, args-hash privacy fingerprinting,
and newest-first per-run span reads that back the desktop per-run trace viewer.

Placement is deliberate: span ordering and tool-call sequencing are *what ran*
(orchestration, Core's side). **Token counts and cost** are *what is measured or paid for*
(Gateway's side) — this store deliberately holds **no** tokens/cost fields.

## Swap seam

`TraceStore::open` takes an explicit database path, so the crate has zero dependency on
`apps/core`; the default-path choice (`~/.ryu/traces.db`) stays Core-side wiring. In-process
by default, consumed as a non-optional path dependency (the store opens at boot and backs a
`ServerState` field).

## Where it lives

`crates/core/tracing`

## API surface

- `/api/conversations/{id}/run-trace` — per-run span reads (see
  [get_run_trace](/docs/develop/api-reference/core/conversations/get_run_trace_handler)).
