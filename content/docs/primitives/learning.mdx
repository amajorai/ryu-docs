## What it is

The continual-learning loop (MetaClaw-style) + experience buffer — the layer that lets an
agent get better from its own runs. It is the reward-filtered **SFT / skill-synthesis
engine**: sweep conversations → PRM-score → distill skills or assemble a fine-tune dataset,
plus its durable experience store (SQLite `experience.db`) and the `/api/learn/*` +
`/api/experience/list` surface.

## Swap seam

In-process default, consumed by Core as a path dependency. Every Core-owned callback —
conversation-store sweep, Gateway PRM/synth side-model, skill-synthesis approvals inbox,
skills-registry reload, fine-tune dispatch, preference store — inverts through the
`LearningHost` trait. The lone kernel coupling (the `~/.ryu` data directory) inverts
through `init_data_dir`.

## Where it lives

`crates/core/learning`

## API surface

- `/api/learn/*` and `/api/experience/list` (see the
  [Learning API reference](/docs/develop/api-reference/core/learning)).
