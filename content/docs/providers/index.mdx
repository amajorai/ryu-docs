Providers are the backends that answer a capability request, such as a chat completion, an
embedding, or a transcription. This section is for anyone choosing or configuring where those
requests go. Ryu keeps four concepts separate:

| Concept | Meaning |
|---|---|
| Capability | What the request needs: chat, embeddings, speech, media, document parsing, or a Toolkit layer |
| Provider | Who answers the request: OpenAI, OpenRouter, a local runtime, a parser, or a plugin provider |
| Engine | The runtime that serves local model weights, such as llama.cpp or MLX |
| Model | The model or weights selected inside a provider or engine |

For the architecture behind this split, see
[Providers and Models](/docs/start-here/architecture/providers).
