Local providers keep inference on the node or adopt a local OpenAI-compatible service. Core owns
the local lifecycle where it owns the process: install, model cache, start/stop, health, and
hardware fit. Adopted services remain owned by their own runtime.

## Local chat and vision runtimes

| Runtime | Model family or format | Platform or boundary | Role |
|---|---|---|---|
| llama.cpp | GGUF | Cross-platform local runtime | Default local Chat runtime |
| Ollama | Ollama model namespace | Cross-platform adopted or managed service | Local Chat |
| vLLM | Safetensors | GPU-oriented serving | Local or remote-style Chat |
| SGLang | Safetensors | GPU-oriented serving | Local or remote-style Chat |
| MLX | MLX | Apple Silicon | Text Chat |
| MLX-VLM | MLX | Apple Silicon | Vision and omni Chat |
| oMLX | MLX | Apple Silicon adopted server | Multi-model Chat |
| Docker Model Runner | Docker/Hugging Face model IDs | Docker-owned service | Adopted OpenAI-compatible Chat |
| Apple Intelligence | OS-provided model | Supported Apple Silicon systems | On-device Chat |
| Mesh LLM | Mesh LLM's configured models | Mesh-owned process/configuration | Distributed OpenAI-compatible Chat |

Only one local Chat engine is active at a time. The resident model is swappable and model-format
aware; an incompatible model is shown with the reason it needs another engine rather than silently
being selected.

## Supporting local tiers

| Tier | Provider or engine | Role |
|---|---|---|
| Embedding | llama.cpp embedding server | Vectors for Spaces, memory, and semantic routing |
| Reranking | llama.cpp reranker | Re-score retrieved candidates |
| Classification | Dedicated local classifier tier | Inspection and smart-routing decisions |
| Voice Recognition | whisper.cpp or optional Parakeet | Audio to raw transcript |
| Speech Processing | S1-mini by Superwhisper | Optional transcript cleanup |
| Audio | Ryu Audio or OuteTTS | Text to speech |
| Image and video | stable-diffusion.cpp | Local generative media |

These supporting tiers can run alongside the active Chat runtime. The embedding tier is not a
second Chat choice, and the speech cleanup tier is not a general model picker entry.

## Local model formats

| Format | Local engines |
|---|---|
| GGUF | llama.cpp, Ollama, Docker Model Runner |
| Safetensors | vLLM, SGLang |
| MLX | MLX, MLX-VLM, oMLX |

The node's detected RAM, VRAM, platform, and engine availability determine the fit result. A model
catalog entry is not a promise that the same model will fit on every node.

## Local does not mean one implementation

Ryu's local provider path can point at a Core-managed process, a local service you already run, or a
custom OpenAI-compatible endpoint on a controlled network. The provider boundary remains explicit:
Core owns filesystem and process state; Gateway owns policy and cloud egress; the adopted runtime
owns its model store and service lifecycle.
