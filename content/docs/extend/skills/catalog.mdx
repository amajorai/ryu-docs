The `apps/skills` directory is Ryu's maintained collection of agent skills. Each one is a `SKILL.md` instruction pack you can install to the universal skills directory and activate per agent. The collection is led by the [setup-ryu](/docs/extend/skills/setup-ryu) flagship and rounds out with packs for the parts of Ryu an agent most often needs to reason about.

<Callout type="info">
  The catalog grows over time. Treat this page as the curated set Ryu ships rather than an exhaustive registry. Run `skills.search` from an agent to see what is installed on your node right now.
</Callout>

## Built-in specialists

**ryu-creator**, **ryu-configurator**, **ryu-agent-creator**, and **pdf** are embedded in Ryu and installed locally on startup without a catalog download. They are enabled on first installation and load on demand through the normal skill discovery path. Existing copies, edits, and disabled states are preserved. Agent skill allowlists still apply; having a skill does not grant tools, administrator access, or permission to publish.

- Ask **ryu-creator** to create a plugin or app using Ryu's primitives, manifest contracts, architecture, and design system. It covers Companion surfaces, chat widgets, sidecars, hooks and their phase/directive rules, capability adapters, workflow composition, packaging, permission tests, and rendered verification.
- Ask **ryu-configurator** to inspect effective settings and configure nodes, agents, integrations, roles, resource access, grants, secrets, budgets, or privacy. It checks the owning configuration surface, hook flags and grants, capability bindings, agent lifecycle and routines, and verifies both allowed and denied access where applicable.
- Ask **ryu-agent-creator** to build a saved node agent or an SDK agent. It covers instructions, runtime/model choice, tools and skills, Space grounding, memory, Draft/Trial/Active lifecycle, safety profiles, hooks, groups, routines, durable runs, and behavioral evals. See [Agent Creator](/docs/extend/skills/ryu-agent-creator).
- Ask **pdf** to create, render, inspect, or transform a PDF. It uses pdfcn as the React-first path for designed documents and keeps pypdf, pdf-lib, ReportLab, extraction, OCR, form, and rendered-proof guidance together. See [PDF](/docs/extend/skills/pdf).

## Built-in pstack pack

Ryu also embeds the [MIT-licensed pstack skill pack](https://github.com/cursor/plugins/tree/main/pstack)
from Cursor's public plugin repository. It contributes 47 built-in skills,
including `poteto-mode`, engineering playbooks, and the principles that the
playbooks reference. The complete skill trees are installed with their
playbooks, references, and scripts, so progressive loading can use the same
relative resources as the upstream pack.

The pack is guidance only. Ryu still owns tool access, approvals, model
routing, filesystem boundaries, and the activation/per-agent allowlist. The
Cursor-specific agent definitions and Benny automation are not bundled because
they are not Agent Skills and require Cursor host contracts.

For example: “Use ryu-creator to build a Companion app for reviewing documents” or “Use ryu-configurator to let this team run an agent while keeping its Space private.” Inspect their instructions in the Skills source view and disable any of them through the usual activation control. They provide guidance; the host continues to enforce policy.

## Shipped skills

| Skill | What it teaches |
|---|---|
| **ryu-agent-creator** | Design, create, test, and package saved or SDK agents with scoped capabilities, lifecycle, hooks, orchestration, and evals. Built in. |
| **ryu-creator** | Build and package plugins and apps with Ryu architecture, primitives, shared UI, and verification. Built in. |
| **ryu-configurator** | Configure effective settings and scoped access with permission, secret, and recovery boundaries. Built in. |
| **pdf** | Create, render, inspect, and transform PDFs with pdfcn/Takumi/Forme and reliable local PDF tooling. Built in. |
| **pstack** | Rigorous engineering workflows, playbooks, parallel-review patterns, and 23 reusable principles. Built in; MIT licensed. |
| **ryu-app-ui** | Compose Companion surfaces using Ryu App UI v1, semantic tokens, shared controls, and host-owned navigation. |
| **setup-ryu** | The flagship. Teaches an agent how Ryu is structured so it can install, configure, and operate a node accurately. See [setup-ryu](/docs/extend/skills/setup-ryu). |
| **ryu-local-model** | How to browse, download, and run local GGUF/MLX models through the model catalog and llama.cpp sidecar. |
| **ryu-mcp** | How to register, configure, and use MCP servers through Core's MCP registry, and which tools read versus write. |
| **ryu-author-skill** | How to author a new Ryu agent skill: the SKILL.md format, progressive disclosure, and how to test and publish. |
| **ryu-build-agent** | Focused REST guide for creating and configuring saved agents on a node. For broader agent design, SDK authoring, lifecycle, and testing, use ryu-agent-creator. |

## How they relate

`setup-ryu` is the entry point. The rest are focused packs you load when an agent will work in that area. Under progressive disclosure you can keep all of them installed and let the model load only the ones a turn needs, so a large catalog costs almost nothing until a skill is actually relevant. See [Skills](/docs/extend/skills) for how disclosure works.

To write your own and add it to a collection, see [authoring](/docs/extend/skills/authoring) and [publishing](/docs/extend/skills/publishing).
