---
title: "Ryu Agent Creator"
description: "A built-in specialist for designing, creating, configuring, testing, and packaging Ryu agents."
---

`ryu-agent-creator` is installed locally with Ryu without a catalog download and enabled on first installation. It loads on demand and respects global activation and per-agent skill allowlists. It supplies instructions, not additional privileges.

## What it covers

| Task | Guidance |
| --- | --- |
| Create a saved assistant | Builder studio, Settings or the supported node API; instructions, model/runtime, tools, skills, Spaces and memory |
| Author an agent in code | SDK Runnables, typed tools/workflows, Gateway model access, optional primitives and cancellation |
| Choose when it may run | Draft, read-only Trial, tested promotion to Active, and the selected safety profile |
| Add hooks | Correct phase/directive selection, agent/conversation scope, grants, flags, redaction, retries and bounded continuations |
| Coordinate work | Agent groups, workflows, requested routines, channels and durable harness sessions/runs |
| Test behavior | Representative success and failure cases, access denial, tool traces, Prompt Studio/evals, and saved product evidence |
| Deliver it | Reopen the saved agent, verify its entry point, or validate a portable template/package |

Try “Use ryu-agent-creator to build a read-only researcher grounded in this Space” or “Use ryu-agent-creator to write an SDK agent with a resumable workflow.” The skill chooses the requested form rather than requiring every agent to become a new app.

## Related specialists

- **ryu-creator** owns plugin/app packaging, shared UI and architecture. Its hook guidance distinguishes blocking, transformation and observation phases, both context planes, host grants, and failure behavior.
- **ryu-configurator** owns effective settings and access diagnosis, including hook activation/flags, capability bindings, agent safety/lifecycle and routines.
- **ryu-build-agent** remains the focused saved-agent REST guide; it is not the SDK authoring guide.

Existing skill copies, edits and disabled states are preserved by default installation. Updated bundled text does not overwrite a local copy; inspect the skill's source before relying on guidance from an older installation. See the [catalog](/docs/extend/skills/catalog) for all maintained skills and [Agents](/docs/surfaces/desktop/user-guide/agents) for the product workflow.

Health checks and eval scores are evidence about specific checks. The skill also calls for a real run using the selected runtime and permitted tools; neither a skill nor a passing configuration score bypasses Core or Gateway policy.
