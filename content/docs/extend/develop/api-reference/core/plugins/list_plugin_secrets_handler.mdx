          **Metadata only, by construction.** The response carries the key name,
          a `set`

          flag and the last-write timestamp; the ciphertext columns are not even
          selected

          by the query behind it, so there is no code path from this handler to
          a

          plaintext or an encrypted value. A masked settings field renders
          "Set"/"Not set"

          from this and nothing else.


          Not manifest-gated: an id with no manifest (uninstalled, or renamed)
          yields an

          empty list rather than a 404, so the UI can always ask and cleanup can
          always

          proceed.
