          Stop the caller's retained cloud task workspace and remove its owned
          resource lease after successful cleanup. Requires GatewayRoute with
          current personal identity; revoked execution permission does not
          prevent stopping an owned task. Idempotent for already stopped or
          absent caller-owned tasks. A stopped conversation cannot rerun
          installation automatically; start a new conversation. Failed cleanup
          preserves the lease for retry.
