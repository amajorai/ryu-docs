          Read the caller's cloud task: environment, backend (docker,
          opensandbox, vpn or box), executor (ryu or a managed CLI agent),
          lifecycle state (preparing, ready, running, finishing, failed,
          stopped, expired or interrupted), expiry, the repository commit and
          branch setup checked out, the active managed run with a redacted
          output tail of at most 16384 characters, the last finished run, the
          last finish result, and for a box task its Box (state, placement,
          screen, running time, cost so far and hourly rate from the Gateway's
          sandbox ticks, low-credit warning, and why it stopped) and the
          caller's running-Box cap. Requires GatewayRoute and current personal
          identity. A task owned by another caller reads as not found.
