          Atomically replace this user's templates and vault metadata.
          schemaVersion must be 1; revision must equal the current revision.
          Omitted value preserves the sealed value for the same id/key/kind;
          removing an entry deletes its value. Values are write-only and sealed
          at rest. Maximum request 1 MiB, 100 templates/entries, 20 repositories
          per template, 64 KiB script/instructions/value. GatewayRoute and
          verified personal identity required; request retries must reload
          revision after 409. Optional runtime selects backend auto or box (a
          fresh disposable Ryu Box per conversation), executor ryu, claude-code,
          codex, opencode or cursor, and lifetimeMinutes 5-240 (honored only for
          box); omitted runtime reads as auto/ryu/30. Managed executors require
          the box backend and internet access; box rejects a Tailscale key and
          bound network secrets, and a restricted box allowlist must include
          archive.ubuntu.com, security.ubuntu.com and the agent's provider hosts
          (422 cloud_environment_policy_unavailable). This route does not start
          scripts or test VPN credentials.
