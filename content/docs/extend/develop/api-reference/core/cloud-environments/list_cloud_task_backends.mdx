          The backends a cloud task can run on: the Ryu Box (Ryu credits) and,
          for this node's owner, the Claude Code and Codex CLIs signed in on
          this node with the owner's own plan. Reports whether each CLI is
          installed and how it is signed in (read from the CLI's own status
          command; Ryu never holds the plan's credentials), any usage-limit
          cooldown, and which session features each backend supports. Other
          callers get the Ryu Box only.
