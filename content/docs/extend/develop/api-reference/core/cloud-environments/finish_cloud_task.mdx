          Finish a cloud task. Requires GatewayRoute, ToolsExec and current
          personal identity. Interrupts the Box, commits all changes, and with
          push set pushes them to a new branch of the primary GitHub repository
          without force, returning a GitHub compare link. With openPullRequest
          (requires push) Core itself, not the Box, then opens a GitHub pull
          request from the pushed branch into the starting branch using the same
          GitHub credential (pullRequestTitle 1-256 characters, defaulting to
          the commit message's first line; pullRequestBody at most 65536
          characters; draft optional) and returns pullRequest with its url and
          number; a failed pull request is not an HTTP error, never changes
          teardown, and returns pullRequest null with pullRequestError auth,
          already_exists, validation, network or unknown. The default branch is
          ryu/ followed by the first 8 characters of the conversation ID; a
          branch must start with a letter or digit, use only letters, digits,
          '.', '_', '/' and '-' (up to 100 characters), contain no '..', '@{' or
          '//', not end in '/' or '.lock', and differ from the starting branch.
          teardown destroy removes the Box after a successful push; a failed
          push is not an HTTP error and always keeps the Box (pushed false,
          pushError auth, non_fast_forward, network or unknown). An assistant
          message summarizing the result is appended. Unknown body fields are
          rejected.
