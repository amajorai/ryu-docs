          Read the caller's server-owned cloud conversation binding before
          reopening a chat. Requires current personal identity and GatewayRoute;
          execution permission is not required to inspect or stop a task.
          Returns cloudEnvironmentId, state, backend (docker, opensandbox, vpn
          or box) and executor (ryu, claude-code, codex, opencode or cursor) as
          nullable strings. A marker belonging to a different owner is denied.
          Interrupted or stopped bindings remain cloud bindings and must never
          reopen as local execution.
