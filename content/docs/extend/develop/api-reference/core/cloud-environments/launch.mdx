          Run a disposable setup check on the selected node. Requires
          GatewayRoute, ToolsExec, personal identity, explicit fail-closed
          Gateway execution-budget approval and explicit Gateway outbound grant
          approval. Disabled internet needs no outbound grant; unrestricted
          needs network:egress:unrestricted; restricted domains need
          tool:http-egress:host approval for every expanded host. Provider
          platform overlays do not substitute for Gateway approval. The
          configured OpenSandbox provider supports explicit
          all/package-manager/custom/disabled egress and HTTPS network-secret
          substitution; readiness requires status=ok, dns+nft packet
          enforcement, exact policy rules and acknowledged sanitized vault scope
          metadata before workload upload. Secrets travel to the authenticated
          sidecar vault over HTTPS or literal loopback HTTP; workload
          environment receives placeholders. GH_TOKEN or GITHUB_TOKEN scoped to
          github.com supplies Git clone authorization. Repositories use separate
          owner/repository directories; install scripts run in the first
          repository root or an empty workspace when no repository is selected.
          Without OpenSandbox, rootless Docker supports disabled or unrestricted
          internet with task-visible ordinary variables. Per-environment
          Tailscale VPN uses an explicitly configured isolated rootless Docker
          runtime with preloaded versioned workload, egress and Tailscale
          images. Gateway must additionally approve network:vpn:tailscale for
          trusted enrollment and relay traffic. The saved reusable auth key must
          be scoped to this environment and cannot also be a task variable, a
          network-secret binding, or appear in scripts/instructions. VPN helpers
          enroll with memory-only state and userspace networking; workload runs
          unprivileged behind exact packet-enforced egress with public CA
          delivery. Saving the key does not test connectivity; setup checks
          enroll and run. Expired credential-free resource leases are recovered
          at startup and periodically. Internet-disabled VPN fails closed.
          Scripts run with a 120-second execution timeout and cleanup follows
          completion/failure/disconnection. Output redacts saved values and is
          bounded to 65536 characters per stream. startInstructions are returned
          for the next task; no durable cloud task workspace is created. Each
          invocation is a new setup check; callers must not automatically retry.
