          Verify a GitHub.com token against fixed authenticated-account and
          repository endpoints before sealing it as GITHUB_TOKEN in the caller's
          personal vault. The encrypted network secret covers github.com and
          api.github.com; an existing GITHUB_TOKEN entry preserves its stable
          ID. Requires the current snapshot revision and exact api.github.com
          Gateway approval. Invalid credentials, redirects, oversized responses,
          or invalid repository metadata do not persist anything. Returns
          sanitized account/repository metadata and the updated redacted
          snapshot. Tasks must explicitly request the returned vaultKey.
