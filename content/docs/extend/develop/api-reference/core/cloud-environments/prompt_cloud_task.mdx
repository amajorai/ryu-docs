          Send a prompt to the managed CLI agent (Claude Code, Codex, OpenCode
          or Cursor) of a fresh cloud box environment. Requires GatewayRoute,
          ToolsExec and current personal identity. Binds and prepares the task
          exactly as chat does on first use, creates the conversation if
          missing, and appends the user message. Each prompt is a fresh CLI
          invocation in the same Box; the agent receives the environment's
          variables except the GitHub credential. On completion one assistant
          message with the redacted summary is appended. Unknown body fields are
          rejected.
