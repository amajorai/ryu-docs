          Link another Claude or ChatGPT account on this node. Ryu makes a new,
          owner-only CLI config folder for it and starts the CLI's own sign-in
          with that folder (`claude auth login` with `CLAUDE_CONFIG_DIR`, `codex
          login` with `CODEX_HOME`), which opens the provider's page in the
          browser. The CLI writes its sign-in into the folder itself; Ryu never
          reads, copies or stores it. Poll `GET
          /api/cloud-task-backends/accounts` for the result. Up to 8 accounts
          per provider. Node owner only.
