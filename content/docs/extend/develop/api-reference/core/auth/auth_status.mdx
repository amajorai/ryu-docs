          Returns device authorization state. The active account bearer is
          included only for a trusted local client; requests forwarded through a
          tunnel (Tailcat, Cloudflared, OpenTunnel, or a plugin tunnel) receive
          status flags without the bearer. `lastFlow` reports the most recently
          settled device flow as `{ userCode, result: "succeeded" | "failed",
          error }` (or null); a client that started a flow matches its
          `userCode` to learn whether that flow added an account, because a
          failed add-account flow leaves the previously active account
          authenticated.
