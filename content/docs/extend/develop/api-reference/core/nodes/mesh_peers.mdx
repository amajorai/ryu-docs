          caller who

          already holds THIS node's `RYU_TOKEN` reaches it — returning that same

          the peer bearer is not a disclosure. Fail-closed auth on the peer is
          NOT

          weakened: the peer still requires a valid token; we merely hand one
          over. The

          bearer is this node's `RYU_TOKEN` and is valid on a peer **only if
          that peer was

          provisioned with the same token** (the shared-fleet convention). That

          precondition is surfaced via `bearer_source`/`note` rather than faked
          — a peer

          running a distinct token 401s and the operator must supply its own
          token.
