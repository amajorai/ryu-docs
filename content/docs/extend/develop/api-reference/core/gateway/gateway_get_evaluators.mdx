          Forwards to the gateway's GET /v1/evaluators. Returns the full shared
          evaluator catalog (8 categories) with `capabilities` + `enforced`
          flags: the built-in seed table merged with any user-authored
          `custom_evaluators` (custom entries override a built-in by `id` and
          report `builtin: false`). Fail-closed: a 502 is returned when the
          gateway is unreachable.
