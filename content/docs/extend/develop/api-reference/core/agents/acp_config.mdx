      - content: >-
          Opens a throwaway ACP session (no prompt) and returns `{ modes,
          models,

          configOptions }` exactly as the agent reports them at `session/new`
          (each

          `null` when unsupported). This is the data the desktop's per-agent
          permission

          mode / reasoning effort / model pickers are built from — fully
          agent-driven,

          nothing hardcoded. Non-ACP agents return all-null. Cached per spawn
          command.


          `?selections={"model":"…"}` applies those picks to the probe session
          first, so

          the answer includes options the agent only offers for that selection
          (an

          agent's option set can depend on its model — see
          `probe_acp_config_with`).
