      - content: >-
          Channel bots (Telegram, Slack, WhatsApp, Discord) call this endpoint
          with a

          `(conversation_id, agent_id, text)` turn and receive `reply`, durable
          assistant

          message ids, and optional `interactiveMarkup` from a plugin or app
          turn hook.

          Markup supports plain-text quick replies and typed callback actions;
          the

          callback arrives on a later request as the untrusted `channelAction`
          field.

          Unsupported channel adapters can degrade markup to the reply text.
          Model calls

          still flow Core → Gateway so the governance layer (firewall, DLP,
          budgets,

          audit) governs every bot-initiated call. `idempotencyKey` is the
          provider

          delivery identity; when supplied, Core stores and replays the
          completed result,

          including markup, rather than running the model twice, so a retried
          delivery

          with the same key does not append another user message. The durable
          assistant

          ids let a channel bind a later provider reaction to this exact turn
          after it

          sends the reply.
