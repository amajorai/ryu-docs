          Channel bots (Telegram, Slack, WhatsApp, Discord) call this endpoint
          with a

          `(conversation_id, agent_id, text)` turn and receive the assembled
          reply as a

          plain JSON `{ "reply": "...", "assistantMessageId": "..." }`. Model
          calls

          still flow Core → Gateway so the governance layer (firewall, DLP,
          budgets,

          audit) governs every bot-initiated call. The durable assistant id lets
          a

          channel bind a provider reaction to this exact turn after it sends the
          reply.

          `idempotencyKey` is the provider delivery identity; when supplied,
          Core stores

          the completed result and replays it for a retried callback instead of
          running

          the model or appending another user message.
