  structuredData:

    contents:
      - content: >-
          Restores the checkpoint's folder (files changed or deleted since are
          written back, files created since are removed; ignored files are
          untouched) and/or moves the conversation's active thread to just
          before the checkpoint's user message. A folder snapshot of the current
          state is taken first and returned as `files.undoCheckpoint`. A path is
          changed only when its current bytes are in that snapshot; anything
          else (ignored, too large, unreadable, blocked by a folder, or below a
          symbolic link) is left untouched and listed in `files.skipped`.
          Refused with 409 `turn_in_progress` or `folder_busy` while this chat
          or another chat in the same folder is running.
