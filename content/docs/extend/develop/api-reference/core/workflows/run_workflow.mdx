          Execute a workflow durably, or set dryRun to true for a transient
          read-only projection. Normal runs use file-backed resumable
          checkpoints; dry runs create no run history, lifecycle hook, approval,
          timer checkpoint, or effectful node execution. Pure nodes and
          classified read-only MCP tools may run, while other effectful nodes
          are returned as skipped with reasons. A caller-provided runId is
          ignored in dry-run mode.
