---
title: Merge a learning adapter
description: Register a completed continual-learning adapter as a local model artifact.
---

`POST /api/learn/merge` forwards a completed learning adapter to the existing
fine-tuning merge path. Provide either `adapter_name` or `adapter_path`:

```json
{ "adapter_name": "learning-cycle-2026-08-16" }
```

The response contains `model_id`, the registered model stem. Merging does not
change the model currently serving chat. To make the result active, pass that
stem to Core's explicit `POST /api/models/active` route after reviewing it.
