      - content: >-
          This route is **public** (it sits outside `require_auth`) because an
          external

          Composio delivery cannot send Core's bearer token. It is instead
          authenticated

          **fail-closed** with Composio's HMAC-SHA256 signature over

          `{webhook-id}.{webhook-timestamp}.{rawBody}` (see

          [`crate::composio_triggers::verify_webhook_signature`]). The project
          secret

          is hydrated from the encrypted store, all signed headers are
          mandatory, and

          a stale timestamp or mismatch returns 401 before anything fires.
