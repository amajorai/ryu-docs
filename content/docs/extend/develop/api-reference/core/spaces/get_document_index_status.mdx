      - content: >-
          The client-visible half of the failure posture in
          [`crate::space_file_index`].

          A file whose text could not be extracted is still stored and still
          findable by

          its filename; without this route that degradation is invisible, and a
          user who

          believes their PDF is searchable when it is not is exactly the defect
          this

          program exists to remove. Gated on `space.read` + the per-document
          ACL, like

          every other read of a document's substance.


          `state` is one of `pending` / `indexed` / `skipped` / `failed`, plus

          `unattempted` for a document stored before extraction existed —
          deliberately

          distinct from `skipped`: nobody looked, as opposed to nobody could
          read it.
