          Requires the Gateway master key. Submits directly to the configured
          OpenRouter account; batch rows do not traverse the normal per-request
          Gateway routing, budget, firewall, or wallet settlement pipeline. The
          configured `data_collection: deny` and ZDR policies are enforced by
          refusing the submission because the Batch API does not document those
          request-level controls. A successful submission returns `202` while
          the provider validates and queues the job. `requests` must be last on
          the wire; the Gateway serializer preserves this ordering.
