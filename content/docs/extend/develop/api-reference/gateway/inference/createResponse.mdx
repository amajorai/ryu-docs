      - content: >
          Create a response through the governed Gateway inference pipeline.
          Supports text and

          image-URL input, function tools and namespaces, text custom tools,
          bounded regex

          constraints, JSON output formats, streaming, and

          `previous_response_id` continuation. Reasoning effort, text verbosity,
          service tier, and

          prompt-cache hints are mapped to the shared Chat Completions pipeline.
          Reasoning summary

          and encrypted-reasoning include hints are accepted for Pi client
          compatibility, but

          reasoning items are not returned. Hosted web search uses the Gateway
          web service and

          requires a separate web-search operation grant. Cached-only calls
          never use live

          search and report unavailable when no cached backend exists. Other
          hosted tools,

          Lark grammar constraints, file/audio/video input, conversations,

          background responses, non-text function outputs, and response
          retrieval/deletion are not

          supported; their 400 errors name the supported alternative.
          `max_tool_calls` caps hosted

          tool calls, and `top_logprobs` or `include:
          [message.output_text.logprobs]` returns

          provider token logprobs on `output_text` (and on streamed text
          deltas). Unknown top-level request fields are rejected.
