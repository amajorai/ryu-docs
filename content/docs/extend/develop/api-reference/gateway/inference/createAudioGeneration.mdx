          Job-based music and sound-effect generation (cloud runs can take
          minutes). Speech from text stays on `/v1/audio/speech`. Returns `202`
          with `{ id, status }`; poll `GET /v1/audio/generations/{id}` for the
          result. The body is `{ model, prompt, ... }` plus the model's own
          input fields, which queue-based providers (Fal, Replicate) receive
          unchanged; providers with a fixed video schema reject audio. Honors
          `x-ryu-slot-audio-provider` / `x-ryu-slot-audio-model` per-agent slot
          overrides. The body may be up to 64 MiB, and every non-`data:` text
          field passes the inbound DLP scan.
