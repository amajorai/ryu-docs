      - content: >
          For a supervisor that holds the master key: returns the Gateway's

          readiness (version, listener, auth mode, key fingerprints) signed with

          HMAC-SHA256 under the master key. The request must carry a
          64-hex-character

          `nonce` and an `x-ryu-readiness-proof` header. The request proof and
          the

          response signature use different MAC inputs, so a response cannot be

          replayed as a request proof. A malformed nonce, a wrong proof, or a

          Gateway without a master key answers 401 `invalid_api_key`; only a

          missing `nonce` parameter is a 400.
