          Core→Gateway control call (trusted-forwarder or master key only). Core

          asks what a Box or sandbox of a given shape would be billed per hour

          before it starts one, so its credit pre-flight and the Gateway's ticks

          read the same rate table: the per-size Box rates when those are

          configured, otherwise the per-resource sandbox rates plus the sandbox

          markup. Not part of the standard OpenAI-compatible client surface —
