          Admits the direct-message sender who was given `code` by a channel bot
          under the default `pairing`

          policy. Pending codes are never written to the Gateway log, so the
          owner relays the code the sender

          received. Requires the master key (or a loopback peer in no-auth
          mode). A code is single use and

          expires after 24 hours. The response names the platform only, never
          the sender id or number.
