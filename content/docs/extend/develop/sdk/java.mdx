---
title: "Java library"
description: "Call a running Ryu Core node from a Java 17 application with a normal Maven dependency."
---

`com.ryu:ryu-client` is the Java library for applications that call a running Ryu Core node. It
uses Java 17's HTTP client and normal Java types. It does not load a Rust library, run a UniFFI
generator, or receive a provider API key.

This is the application library. The generated UniFFI project under `bindings/kotlin` is a
lower-level Rust-kernel binding for applications that specifically need manifest validation,
Gateway egress checks, model calls, or embeddings.

## Install

The source library is in the public [SDK hub](https://github.com/amajorai/ryu-sdk). From a checkout,
install it into your local Maven repository:

```bash
cd bindings/java
mvn install
```

Add this dependency to a Java 17+ application's `pom.xml`:

```xml
<dependency>
  <groupId>com.ryu</groupId>
  <artifactId>ryu-client</artifactId>
  <version>0.2.5</version>
</dependency>
```

Maven Central publication is a separate release step; the commands above are the verified
checkout-based path.

## Connect and send a message

Core normally listens on `http://127.0.0.1:7980`. Pass the node token when authentication is
enabled. The token is a Core node credential, not a provider key.

```java
import com.ryu.sdk.RyuClient;
import java.net.URI;
import java.util.List;

try (var ryu = new RyuClient(
    URI.create("http://127.0.0.1:7980"),
    System.getenv("RYU_TOKEN"))) {
  var agents = ryu.listAgents();
  var agent = agents.get(0);
  var reply = ryu.run(
      agent.id(),
      List.of(RyuClient.Message.user("Summarize today's tasks.")));
  System.out.println(reply);
}
```

For a remote node, use its HTTPS URL and the token issued for that node:

```java
var ryu = new RyuClient("https://core.example.com", nodeToken);
```

## Stream a response

`stream` is blocking and calls your consumer for each text fragment, then once with a `DONE`
event. An error produces one `ERROR` event.

```java
ryu.stream(
    "pi",
    List.of(RyuClient.Message.user("Explain this deployment in three sentences.")),
    chunk -> {
      if (chunk.isText()) {
        System.out.print(chunk.content());
      }
    });
```

## Other Core data

The same library provides typed access to the small embedded-client surface:

```java
var conversations = ryu.listConversations();
var spaces = ryu.listSpaces();
var matches = ryu.searchSpace(spaces.get(0).id(), "deployment steps", 5);
```

The client is intentionally thin. Core remains responsible for agent execution, permissions,
model routing, approvals, and audit. The Java library only handles HTTP, JSON, and SSE mapping.

## Build and test the library

```bash
mvn test
```

Tests use a local in-memory HTTP server and do not call a model provider. See the [SDK hub guide](/docs/extend/develop/sdk/hub)
for the package/library choice and [Language bindings](/docs/extend/develop/sdk/language-bindings)
for the lower-level Rust adapters.
