---
title: "Java Library"
description: "Call a running Ryu Core node from a Java 17 application with a normal Maven dependency."
---

`com.ryu:ryu-client` is the Java library for applications that call a running Ryu Core node. It
uses Java 17's HTTP client and normal Java types. It does not load a Rust library, run a UniFFI
generator, or receive a provider API key.

The generated UniFFI project under `bindings/kotlin` is a lower-level Rust-kernel binding. Use it
only when an application needs manifest validation, Gateway egress checks, model calls, or
embeddings from the kernel. See [Libraries and bindings](/docs/extend/develop/sdk/language-bindings).

## Install

<Callout type="warn">
  `com.ryu:ryu-client` is not published to Maven Central yet. Until it is, install it from a
  checkout of the SDK hub as shown below. [SDK publishing](/docs/extend/develop/sdk/publishing)
  tracks the release state.
</Callout>

Once the library is on Maven Central, add this dependency to a Java 17+ application's `pom.xml`.

```xml
<dependency>
  <groupId>com.ryu</groupId>
  <artifactId>ryu-client</artifactId>
  <version>0.4.0</version>
</dependency>
```

To install it today, or to test an unreleased change, install the library from a checkout of the
public [SDK hub](https://github.com/amajorai/ryu-sdk) into your local Maven repository.

```bash
cd bindings/java
mvn install
```

## Connect and send a message

Core normally listens on `http://127.0.0.1:7980`. Pass the node token when authentication is
enabled. The token is a Core node credential, not a provider key.

```java
import com.ryu.sdk.RyuClient;
import java.net.URI;
import java.util.List;

try (var ryu = new RyuClient(
    URI.create("http://127.0.0.1:7980"),
    System.getenv("RYU_TOKEN"))) {
  var agents = ryu.listAgents();
  var agent = agents.get(0);
  var reply = ryu.run(
      agent.id(),
      List.of(RyuClient.Message.user("Summarize today's tasks.")));
  System.out.println(reply);
}
```

For a remote node, use its HTTPS URL and the token issued for that node:

```java
var ryu = new RyuClient("https://core.example.com", nodeToken);
```

## Stream a response

`stream` blocks and calls your consumer for each text fragment, then once with a `DONE` event. An
error in the stream produces one `ERROR` event instead. A non-2xx response throws `RyuException`.

```java
ryu.stream(
    "pi",
    List.of(RyuClient.Message.user("Explain this deployment in three sentences.")),
    chunk -> {
      if (chunk.isText()) {
        System.out.print(chunk.content());
      }
    });
```

## Other Core data

The library also covers conversations and Spaces search.

```java
var conversations = ryu.listConversations();
var spaces = ryu.listSpaces();
var matches = ryu.searchSpace(spaces.get(0).id(), "deployment steps", 5);
```

Core runs agents and owns permissions, model routing, approvals, and audit. The Java library maps
HTTP, JSON, and SSE to Java types and does nothing else.

## Build and test the library

From `bindings/java` in the SDK hub, run the tests.

```bash
mvn test
```

Tests use a local in-memory HTTP server and do not call a model provider. See the
[Public SDK hub](/docs/extend/develop/sdk/hub) for choosing a package.
