The [`amajorai/ryu-sdk`](https://github.com/amajorai/ryu-sdk) hub holds every Ryu SDK package,
library, and binding. Start with a library, not a generated binding. A library calls a running
Ryu Core node with normal types from your language. The authoring SDK creates things that Ryu
installs or runs. The lower-level bindings embed the shared Rust kernel.

## Choose your path

| You are building... | Use | What it does |
|---|---|---|
| A Ryu plugin, app, tool, workflow, or skill | [`@ryuhq/sdk`](/docs/extend/develop/sdk) | Author and package Ryu extensions in TypeScript |
| A TypeScript or React Native app with embedded chat | [`@ryuhq/client`](/docs/extend/develop/sdk/client) | List agents, stream chat, read conversations, and search Spaces |
| A product that publishes or consumes notifications | [`@ryuhq/client`](/docs/extend/develop/sdk/client) + [Ryu Notify](/docs/standalone/notify) | Rich events, topics, SSE, activities, responses, and delivery adapters |
| A TypeScript or React Native app that manages Core | [`@ryuhq/core-client`](/docs/extend/develop/sdk/core-client) | Use typed agents, models, plugins, skills, MCP, Spaces, workflows, and Gateway calls |
| A Java app that calls Core | [Java library](/docs/extend/develop/sdk/java) | Use `com.ryu:ryu-client` with Java 17 and Maven |
| A Rust app that embeds the kernel | [Rust SDK](/docs/extend/develop/sdk/rust) | Use manifest, egress, model, and embedding primitives directly |
| A Python, Swift, Kotlin, C#, C, or Go app that embeds the kernel | [Language bindings](/docs/extend/develop/sdk/language-bindings) | Use the generated or C-ABI kernel surface |

## Quick starts

- **Call an existing agent.** Install `@ryuhq/client` and call `client.agents.run()`. See
  [`@ryuhq/client`](/docs/extend/develop/sdk/client).
- **Build a Ryu extension.** Scaffold a project with `bunx create-ryu-app my-plugin` (the default
  template is `agent`; pass `--template` for `action`, `hook-plugin`, `ryu-app`, `app`, and others).
  Author with `defineAgent`, `defineWorkflow`, `defineTool`, `defineSkill`, or `defineAction`, then
  pack with `bunx ryu pack`. See [Ryu SDKs and Libraries](/docs/extend/develop/sdk).
- **Build a Java app.** Use `com.ryu:ryu-client`, not the generated UniFFI project. See
  [Java library](/docs/extend/develop/sdk/java).
- **Build a React Native or Expo app.** Use the same TypeScript libraries as a web app, with no
  Rust binding. Inject `expo/fetch` for response streaming. Use `@ryuhq/core-client` for the full
  Core API. Keep node and control-plane tokens in secure storage such as `expo-secure-store`, and
  never bundle a provider API key.

## What the generated bindings are

The generated bindings in the hub wrap the shared `ryu-sdk` Rust kernel. They expose manifest
validation, Gateway egress checks, model calls, and embeddings. They do not replace the Core client,
and they do not create a hosted node.

| Binding | Use it when... |
|---|---|
| `ryu-sdk` | Your Rust application needs the kernel directly |
| `ryu-sdk-ffi` | Your C or Go application needs the C ABI |
| `ryu-sdk-uniffi` | Your Python, Swift, Kotlin, or C# application needs the kernel surface |
| `@ryuhq/sdk-native` | You use `@ryuhq/sdk`. It is the Node-API addon behind the model client |

Each target's build creates its generated source files. Do not edit them by hand. For
the API contracts behind them, see [Language bindings](/docs/extend/develop/sdk/language-bindings)
and [Rust SDK](/docs/extend/develop/sdk/rust).

## Verify a hub checkout

Contributors who change the SDK hub run these commands:

```bash
bun install --frozen-lockfile --ignore-scripts
bun run build:native
bun run test:packages
cargo test --workspace --locked --all-targets
mvn --batch-mode test -f bindings/java/pom.xml

# Optional target-language smoke tests.
bash bindings/python/test.sh
bash bindings/swift/test.sh
bash bindings/java/test.sh
```

## Source and releases

The hub contains the libraries, examples, tests, and release workflows. It is generated from the
Ryu monorepo, which remains the canonical source. See [SDK publishing](/docs/extend/develop/sdk/publishing)
for the release train and registry boundaries.
