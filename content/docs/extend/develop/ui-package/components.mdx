`TabsList` keeps its tabs on one line. By default it manages responsive overflow through a `More`
trigger: the trigger opens a searchable list of every tab, with drag handles, visibility toggles,
and a reset action. Right-clicking any visible tab opens the same controls. Layout preferences are
stored in `localStorage`; pass a stable `storageKey` when a page renders more than one independently
managed tab list, or set `persistLayout={false}` to opt out. For a strip that should keep every tab
visible, set `manageLayout={false}`. The list then becomes a horizontally scrollable, hidden-scrollbar
strip with an edge fade; hovering the strip reveals a small popover with rounded back/forward buttons
for paging through the tabs.

## Website motion

The public website exposes a reduced-motion-safe Lenis wrapper modeled on the BeUI scroll animation
pattern:

```tsx
import {
  ScrollProgress,
  SmoothScroll,
} from "@ryu/blocks/web/smooth-scroll";

<SmoothScroll root>
  <ScrollProgress />
  {children}
</SmoothScroll>
```

Use `useSmoothScroll()` when a surface needs the current scroll position, progress, velocity, or a
smooth `scrollTo` action.
