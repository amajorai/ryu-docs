A plugin can add to agent avatars in two ways:

- **`contributes.avatar_accessories`** adds parts that dress one region of the Ryu ghost
  costume (hats, glasses, ears, patterns, and more) or one region of an avatar style.
- **`contributes.avatar_styles`** adds a whole avatar look, similar to a DiceBear style. A
  style has its own palettes and regions, and a seed picks a random look.

Both publish through the [Marketplace](/docs/extend/develop/extensions/marketplace) like
any plugin, and a plugin can ship accessories, styles, or both. They need no permissions.

## Parts are shapes, not markup

Every part is a list of SVG primitives: `path`, `circle`, `ellipse`, `rect`, `polygon`,
`polyline`, and `line`. Ryu draws them itself, so a part can only describe geometry and color.
SVG or HTML markup, scripts, event handlers, `<foreignObject>`, external images, and `url(...)`
paints are not accepted.

| Attribute | Accepted values |
| --- | --- |
| `d` (path), `points` (polygon, polyline) | Path commands or point lists with numbers only, up to 8 KiB |
| `cx` `cy` `x` `y` `x1` `y1` `x2` `y2` | Finite numbers between -10000 and 10000 |
| `r` `rx` `ry` `width` `height` | Finite numbers between 0 and 10000 |
| `fill`, `stroke` | `none`, `currentColor`, `ink`, `palette.base`, `palette.light`, `palette.deep`, or a `#rgb`, `#rgba`, `#rrggbb`, or `#rrggbbaa` color |
| `strokeWidth` | 0 to 100 |
| `strokeLinecap` | `butt`, `round`, `square` |
| `strokeLinejoin` | `miter`, `round`, `bevel` |
| `opacity` | 0 to 1 |
| `transform` | `translate`, `rotate`, `scale`, `skewX`, `skewY`, or `matrix` with numeric arguments |

The `palette.*` and `ink` tokens recolor a part with the avatar it is worn on. A hat filled with
`palette.deep` matches whatever ghost color the user picks.

## Ghost accessories

Set `target` to `ghost` and `region` to one of `eyes`, `brows`, `mouth`, `ears`, `headwear`,
`glasses`, `accessory`, or `pattern`.

```json
{
  "id": "@example/hats",
  "name": "Example Hats",
  "version": "1.0.0",
  "runnables": [],
  "contributes": {
    "avatar_accessories": [
      {
        "id": "@example/hats:beanie",
        "label": "Beanie",
        "target": "ghost",
        "region": "headwear",
        "shapes": [
          { "type": "path", "d": "M12 3 Q18 -4 25 3 Z", "fill": "palette.deep", "stroke": "ink", "strokeWidth": 0.55 },
          { "type": "circle", "cx": 18.5, "cy": -2.2, "r": 1.3, "fill": "#ffffff", "stroke": "ink", "strokeWidth": 0.4 }
        ]
      }
    ]
  }
}
```

Shapes use the ghost's own 24-unit drawing space. The eyes sit at y = 10 on either side of x = 17,
and the top of the head peaks near (18, 0.6). A part replaces the built-in choice for its region
and is drawn at that region's place in the layering. Patterns are clipped to the ghost's body. Set
`"layer": "behind"` to draw a part behind the body instead, as with a cape.

## Avatar styles

A style declares a `viewBox`, at least one palette, optional `base` shapes for the body, and
regions. Behind-layer regions are drawn first, then the base, then front regions, each in the
order you declare them.

```json
{
  "contributes": {
    "avatar_styles": [
      {
        "id": "@example/robots:robot",
        "label": "Robot",
        "description": "Boxy robots with swappable eyes and antennas.",
        "viewBox": [0, 0, 64, 64],
        "palettes": [
          { "id": "steel", "label": "Steel", "base": "#9aa5b1", "light": "#e4e7eb", "deep": "#3e4c59" },
          { "id": "rust", "label": "Rust", "base": "#c26a3d", "light": "#f2c4a5", "deep": "#6b2e12" }
        ],
        "base": [
          { "type": "rect", "x": 12, "y": 14, "width": 40, "height": 38, "rx": 8, "fill": "palette.base", "stroke": "palette.deep", "strokeWidth": 2 }
        ],
        "regions": [
          {
            "id": "eyes",
            "label": "Eyes",
            "options": [
              { "id": "dots", "label": "Dots", "shapes": [
                { "type": "circle", "cx": 24, "cy": 30, "r": 3, "fill": "ink" },
                { "type": "circle", "cx": 40, "cy": 30, "r": 3, "fill": "ink" }
              ] },
              { "id": "visor", "label": "Visor", "shapes": [
                { "type": "rect", "x": 18, "y": 26, "width": 28, "height": 7, "rx": 3, "fill": "ink" }
              ] }
            ]
          },
          {
            "id": "antenna",
            "label": "Antenna",
            "layer": "behind",
            "optional": true,
            "options": [
              { "id": "single", "label": "Single", "shapes": [
                { "type": "line", "x1": 32, "y1": 14, "x2": 32, "y2": 4, "stroke": "palette.deep", "strokeWidth": 2 },
                { "type": "circle", "cx": 32, "cy": 4, "r": 2.5, "fill": "palette.light" }
              ] }
            ]
          }
        ]
      }
    ]
  }
}
```

When a user picks the style, the seed chooses a palette and an option for every region, so the
same seed always gives the same look. The user can then set the color and each region by hand. An
`optional` region can also be left empty. Option ids must be unique within a region and cannot be
`none`.

### Accessories for a style

An accessory can dress a region of any style, including a style from another plugin. Set `target`
to the style id and `region` to one of that style's region ids:

```json
{
  "id": "@example/hats:spring-antenna",
  "label": "Spring antenna",
  "target": "@example/robots:robot",
  "region": "antenna",
  "shapes": [
    { "type": "polyline", "points": "32,14 29,10 35,8 29,5 32,2", "stroke": "palette.deep", "strokeWidth": 2 }
  ]
}
```

The accessory appears next to the style's own options for that region. It uses the style's palette
tokens and is drawn on the region's layer, or behind the body when the accessory sets
`"layer": "behind"`. If no installed style has that region, the accessory is not shown.

## Ids and limits

Every accessory and style `id` is the owning plugin id, a colon, and a stable local name of lowercase
letters, digits, `.`, `_`, or `-`. Agents save these ids, so keep them stable when you rename a
label. Region, option, and palette ids use the same lowercase alphabet, up to 48 characters.

| Limit | Value |
| --- | --- |
| Accessories per plugin | 64 |
| Styles per plugin | 16 |
| Shapes per accessory, style base, or option | 64 |
| Regions per style | 16 |
| Options per region | 64 |
| Palettes per style | 1 to 16 |
| Size of one accessory | 32 KiB |
| Size of one style | 256 KiB |

Ryu rejects a plugin whose avatar parts break these rules when it loads the manifest.

## Where it appears

After the plugin is installed and enabled:

- Ghost accessories appear under **From Marketplace** in the matching part list of the
  **Halloween costume** appearance on the agent avatar's **Expressive** tab.
- Styles appear on the avatar picker's **Styles** tab, which shows only when an enabled plugin
  provides a style.
- The plugin's Store listing shows **avatar accessories** or **avatar styles** among its features.

If the plugin is disabled or uninstalled, its parts leave the editor. Agents that use a missing part
keep the saved choice but display the built-in fallback: classic eyes, or nothing for the other
ghost regions. An avatar that uses a missing style displays the agent's default avatar. The part
appears again when the plugin is turned back on.

A published agent keeps its accessory and style ids. Someone who installs the agent without the
plugin sees the fallback until they install the plugin.

See [Contribution surfaces](/docs/extend/develop/extensions/contribution-surfaces) for the other
host-rendered surfaces and [Agents](/docs/surfaces/desktop/user-guide/agents) for the avatar picker.
