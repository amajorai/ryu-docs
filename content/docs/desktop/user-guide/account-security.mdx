title: "Account security"
description: "Two-factor authentication and backup codes — enabling 2FA, the save-confirmation step, and regenerating backup codes."

Ryu accounts can be protected with **two-factor authentication (2FA)** using any TOTP authenticator app
(Google Authenticator, 1Password, Authy, …). The same flow runs in the desktop app (**Settings →
Account → Enable 2FA**) and in the web app (**Settings → Setup 2FA**).

## Enabling 2FA

1. Enter your password.
2. Scan the QR code with your authenticator app.
3. Enter the 6-digit code from the app to verify the authenticator is set up.
4. You are shown a list of **backup codes**.
5. **Confirm you saved them** by typing one back — the flow does not finish until you do.

## The save-confirmation step

The final step exists because backup codes are only shown once. After they are displayed, you must
type one of them back (case- and hyphen-insensitive) to prove you saved them. A wrong or missing
entry bounces you back to the codes with a warning that they will not be shown again, so you can copy
them down before the flow completes.

> Without backup codes, a lost authenticator app locks you out of your account.

## Managing 2FA

Once enabled, the dialog offers:

- **Regenerate backup codes** — issues a fresh set (the old set stops working) and runs the same
  save-confirmation step before applying.
- **Disable 2FA** — turns two-factor authentication off for the account.

Enabling or disabling 2FA takes effect across surfaces: the same account works on the desktop, the
web app, and the CLI (`ryu whoami` reports the 2FA status).
