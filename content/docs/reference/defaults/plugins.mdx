Ryu ships plugins through the official marketplace. Each plugin has a tier, a pre-installed policy,
and an install policy. Plugins add tools, turn hooks, MCP (Model Context Protocol) servers, Pi
extensions, and skills. Apps are self-contained products with their own process or Companion UI.
Both share the same lifecycle; see [App lifecycle](/docs/core/app-manifest-lifecycle).

This page lists the default provider of each capability, the pre-installed plugins, and the
per-plugin settings that have defaults.

## Default capability providers

A capability (like `web.search` or `document.parse`) can have several providers. When more than one
is enabled, the provider that declares `default: true` in its manifest is used unless you pick
another (see [provider selection](/docs/providers/toolkits#provider-selection)):

| Capability | Default provider | Swappable for | Notes |
|---|---|---|---|
| `web.search` | **Exa** | Ryu Cloud Search (pre-installed), Tavily, Brave, Serper, Parallel, Firecrawl, [DeepSeek](/docs/plugins/deepseek) (BYOK API key) | Exa needs no key (public MCP endpoint fallback), so it is the default. Ryu Cloud Search is also pre-installed but bills your Ryu Cloud credits, so it serves searches only after you pick it |
| `web.extract` | **Spider** | Scrapling, Jina Reader, Firecrawl, Tavily, Serper, Parallel, [DeepSeek](/docs/plugins/deepseek) (BYOK API key) | Spider is a pre-installed `command` tool |
| `web.crawl` | **Spider** | Spider Cloud, Firecrawl | Crawl depth default 1, limit default 10 |
| `computer.control` | **Ghost** | Bytebot (remote), Codex Computer Use (local, macOS, opt-in) | Ghost targets the local machine; Bytebot a remote desktop; Codex Computer Use drives one target app through the ChatGPT app's Codex engine |
| `browser.control` | **Browser app** (`@ryu/browser`) | Agent Browser, Cloudflare Browser Run, Kernel | Both the Browser app and Agent Browser are pre-installed; the Browser app declares itself the default |
| `document.parse` | **MarkItDown** | AnyDoc, Docling, MinerU, Unstructured | MarkItDown is the only parser seeded pre-installed; AnyDoc is an opt-in Rust service and API |
| `memory` | **Built-in store** | Mem0, Honcho | Built-in stays default; the others augment |
| `rag` | **In-process** (engines embed sidecar) | - | Mandatory |
| `engines` | **llama.cpp** (`:8080`/`:8081`) | vLLM, SGLang, MLX, OMLX, Ollama | Load-bearing |

## Pre-installed plugins

Like apps, most official plugins ship **without a record**. They are in the catalog, one
Install → Enable away. Only a subset is seeded **enabled** on a fresh install (`CORE_PREINSTALLED`
in `apps/core/src/plugins/builtins.rs`).

The tables below list the pre-installed tool, hook, and extension plugins. The rest of that list
is Core system surfaces and apps, such as `@ryu/engines`, `@ryu/durable`, and the mandatory
plugins.

### Tool and capability plugins (pre-installed)

| Plugin | What it adds | Notes |
|---|---|---|
| `@ryu/ghost` | `computer.control` tools | Default provider; MCP stdio |
| `@ryu/shadow` | `memory.context`, timeline tools | Local sidecar `:3030` |
| `@ryu/spider` | `web.extract` / `web.crawl` tools | Default provider |
| `@ryu/agentbrowser` | Web browsing tools | npx MCP server |
| `@ryu/exa` | `web.search` tools | Default provider, no key needed |
| `@ryu/cloud-search` | `web.search` through [Ryu Cloud hosted search](/docs/gateway/web-services#hosted-web-search) | Not the default. Agents cannot call it until you pick it in **Toolkits → Search**. Each successful search is billed to your organization's Ryu Cloud credits; off Ryu Cloud it returns `available: false` |
| `@ryu/docs` | Docs search MCP (`docs.ryuhq.com/mcp`) | Remote, fail-open, no install |
| `@ryu/composio-connect` | Composio For You connected-app MCP | Remote OAuth; connect an account from Marketplace → Connections |

### Turn-hook plugins (pre-installed)

These chat features ship as plugins that can be disabled or replaced. Each one uses a `match`
pre-gate, so an idle hook does not start a sandbox:

| Plugin | What it does | Defaults |
|---|---|---|
| `@ryu/goal` | Persistent goals - a one-line transcript judge | Judge = side model; max 25 turns |
| `@ryu/proof` | Proof-of-work: spawns an independent verifier sub-agent | Verifier = sub-agent (`code_read` preset); max 12 rounds |
| `@ryu/receipts` | Visual sibling of proof - captures a screenshot/recording as evidence | Evidence `any`; max 8 rounds |
| `@ryu/double-check` | Reviews answers you flag | Gated by flag/toggle; side model |
| `@ryu/chat-title` | Progressive conversation titles | Renames on first turn, then every 5 turns |

### Pi extension plugins (pre-installed)

These add tools to the managed Pi agent (Pi reads its extensions at process start, so toggling one
takes effect in a new chat):

| Plugin | What it adds |
|---|---|
| `@ryu/pi-shell` | Background bash (`bash_background` / `bash_output` / `bash_kill`) |
| `@ryu/pi-subagent` | Sub-agent (`Task`) tool |
| `@ryu/pi-monitor` | `monitor` tool (a port of Claude Code's Monitor) |
| `@ryu/pi-copy` | `copy_paste` tool: copy or move a block of text between or within files byte-for-byte, without the model retyping it |

### Other pre-installed plugins

| Plugin | What it does |
|---|---|
| `@ryu/auto-expand` | Pre-turn prompt improver (composer toggle + `/expand`) |
| `@ryu/rules` | Discovers Cursor- and Claude-style project rules and applies them to agent context, with per-agent controls |
| `@ryu/output-styles` | Twelve reusable personality profiles assigned per agent (ELI5, I have ADHD, Concise, Explanatory, Learning, Proactive, Plain text, Plain Technical, No AI slop, No Hype, Bro, Gen Z) |

## Available in the Store (install-on-demand)

These ship **without a lifecycle record**. A fresh machine does not list them as installed, and the
Store shows them as available. Install → Enable from the Store. Each is opt-in for the reason in the
last column (a per-turn model call, a binary, or a capability you should switch on):

| Plugin | What it does | Defaults | Why it is install-on-demand |
|---|---|---|---|
| `@ryu/recap` | Summarizes the turn that just finished (`/recap`) | Auto, min chars 1200, detail `standard` | A side-model call per long turn |
| `@ryu/no-ai-slop` | Runs the no-ai-slop editing skill on finished answers | Passes 1 (0-12), mode `revise` | A sub-agent per reviewed answer |
| `@ryu/no-more-mistakes` | Turns a correction into a durable rule in a Space | Capture/brief on; Space `Mistakes`; max 12 rules | A sandbox spawn per user turn |
| `@ryu/polite-prompts` | Rewrites an abusive message into a polite prompt before it is sent (`/polite`) | Auto-rewrite on | A sandbox spawn per user turn, plus a side-model call per flagged message |
| `@ryu/agent-comms` | Agent-to-agent mailbox and reaction replies (`agents.directory/send/thread/react`) | - | Delivery hook cannot be match-gated |
| `@ryu/expect` | Browser QA through the Expect MCP server | Explicit install/enable | Downloads a third-party Node package when enabled |
| `@ryu/agentation` | Visual feedback through the Agentation MCP server | Explicit install/enable | Downloads a third-party Node package when enabled |
| `@ryu/advisor` | `/advisor` - a stronger model reviews your work | Side model; `fail_open: true` | A side-model call per turn |
| `@ryu/mem0` | Second `memory` provider | Search limit 10, min relevance 0.1 | Needs an API key |
| `@ryu/honcho` | Memory provider (`memory.context`) | `reasoning_level: minimal`, messages 10 | Needs an API key |
| `@ryu/bytebot` | `computer.control` provider for a **remote** desktop | `http://127.0.0.1:9990/computer-use` | A capability that drives another machine |
| `@ryu/codex-computer-use` | `computer.control` provider using OpenAI's Codex Computer Use engine (macOS) | Explicit install/enable; target app unset | Unofficial; needs the ChatGPT app and Node, downloads a pinned npm bridge |
| `@ryu/security-guidance` | `/security-review` on your code | Side model | A side-model call per turn |
| `@ryu/pxpipe` | Loopback token-saving proxy | `http://127.0.0.1:47821` | Needs Node + a hand-configured provider |
| `@ryu/headroom` | Context compression; savings depend on workload | `:8787`, `timeout_ms` 4000, `min_messages` 4 | Needs a configured transform |
| `@ryu/rtk` | Local `rtk` CLI wrapper | Mode `wrap`, timeout 120 s | Needs the `rtk` CLI |

Each search, parse, security, and LSP plugin has its own page with exact settings under
[Plugins](/docs/plugins).

## Mandatory and load-bearing

Two protection tiers sit on top of pre-installed (see the [App lifecycle](/docs/core/app-manifest-lifecycle)
page for the exact mechanics):

| Tier | Members | Behavior |
|---|---|---|
| **Mandatory** | `@ryu/spaces`, `@ryu/rag`, `@ryu/layers`, `@ryu/skills`, `@ryu/media`, `@ryu/hardware` | Never disableable, never uninstallable, no `force` override |
| **Load-bearing** | `@ryu/engines`, `@ryu/durable`, `@ryu/agents` | Disable refused without an explicit `force = true` |

Mandatory is a strict subset of pre-installed, so a fresh install always has them.
