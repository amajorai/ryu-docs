Ryu ships with a local chat model, embeddings, voice, a default agent, and a set of pre-installed
apps and plugins, so a fresh install works with zero API keys. Each default resolves through a
registry, a config store, or a manifest, and each one has a documented override.

## How a default is resolved

A default is the last step of a fallback chain. A preference set in Settings beats the matching
environment variable, and an explicit request argument beats both. The exact order is in
[Node preferences](/docs/start-here/configuration#node-preferences), and the environment
fallbacks are in [Model and recall defaults](/docs/start-here/environment-variables#model-and-recall-defaults).

## What installs and turns on

A fresh store holds lifecycle records only for the pre-installed set (`CORE_PREINSTALLED`). Every
other official app and plugin is install-on-demand from the Store. The tier, pre-install, and
protection rules are in [Two-tier registry](/docs/core/app-trust-tiers#two-tier-registry),
and the labels the catalog shows (Official, Built-in, System, Pre-installed, Stability, Hidden) are
defined in the [attribute legend](/docs/apps#attribute-legend).

## Replace a default

| Default | Where to replace it | Reference |
|---|---|---|
| Chat and utility model | A model picker in Settings, or `RYU_DEFAULT_LLM_MODEL` | [Default models](/docs/reference/defaults/models) |
| Local engine | Install a GGUF, safetensors, or MLX model from the model catalog | [Models](/docs/surfaces/desktop/models) |
| Embeddings | `RYU_EMBED_MODEL` | [Environment variables](/docs/start-here/environment-variables#model-and-recall-defaults) |
| Capability provider (for example `web.search` or `document.parse`) | Pick another enabled provider | [Default capability providers](/docs/reference/defaults/plugins#default-capability-providers) |
| Pre-installed app or plugin | Disable it in the Store, unless it is mandatory or load-bearing | [Mandatory and load-bearing](/docs/reference/defaults/plugins#mandatory-and-load-bearing) |
