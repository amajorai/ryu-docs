## What it is

The image-generation modality primitive: `generate(prompt) -> image` behind a swappable
engine seam. Local stable-diffusion.cpp is the default; OpenRouter, Replicate, and fal
cloud providers route through the Gateway like every other model call.

It owns the abstraction and routing: prompt validation, default-count, the local-vs-cloud
dispatch, and the media proxy / gateway-forward mechanics — so a caller just asks for an
image and the primitive decides where it runs.

## Swap seam

Kernel couplings the crate cannot own — the local sd-server base URL, the Gateway URL and
token, and lazy-starting the sd.cpp sidecar — inject through the narrow `ImageHost` trait.
In-process by default, consumed as a non-optional path dependency (the
`POST /api/images/generate` data path reaches it unconditionally).

## Where it lives

`crates/core/image`

## API surface

- `POST /api/images/generate` (see the
