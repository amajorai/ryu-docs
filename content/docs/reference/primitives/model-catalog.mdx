## What it is

The model catalog primitive: everything around *choosing a model that will actually run on
this machine*. It owns:

- **HF search and detail** — the Hugging Face catalog surface.
- **GGUF tree inspection** — read a repo's weight files without downloading them.
- **Per-node device detection and fit estimation** — the verdict "will this model fit and
  run on *this* device?"
- **Installed-model tracking** and capability overrides.
- **Metadata sources** — A Major (aa), models.dev, and OpenRouter, including unified
  hover-card insights.

Artifact downloads route through the [downloads](/docs/primitives/downloads) primitive; the
`ModelFormat` type comes from [model-format](/docs/primitives/model-format).

## Swap seam

Kernel couplings — the `~/.ryu` data dir, Hugging Face bearer auth, the active-model
preference, the per-node engine-support gate, and the bundled default-model repos — invert
through the narrow `ModelCatalogHost` trait, which Core installs at boot.

## Where it lives

`crates/core/model-catalog`
