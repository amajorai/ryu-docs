## What it is

The shared wire contract for the Ryu self-healing loop — the `HealVerdict` action enum that
the out-of-process `ryu-healing` sidecar returns to Core, plus the two constants both sides
must agree on **out-of-band**:

- the `healrun_` **never-heal-a-heal** prefix (a healing run must not trigger healing), and
- the **context-truncation policy**.

Dep-light (`serde` only) and with zero dependency on `apps/core`, so Core and the sidecar
can both link it without either linking the other.

## Where it lives

`crates/core/healing-contracts`
