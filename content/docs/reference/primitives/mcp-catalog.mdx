## What it is

The MCP server catalog primitive: browse and install MCP servers from the official Model
Context Protocol registry (plus sibling Smithery and Ryu-hosted sources). It owns:

- the **tolerant `server.json` wire parser**,
- **catalog card/detail shaping**,
- the **SSRF-safe pagination fetch**, and
- a **security-hardened install-plan builder** — package-identifier, version, and
  remote-URL validation with no shell-metacharacter or path-traversal smuggling.

Installing an MCP server is one of the most common ways to extend an agent; this primitive
makes it safe by default.

## Swap seam

The one cross-cutting kernel coupling — the SSRF-guarded registry fetch
(`server::guarded_get_bytes`) — inverts through the narrow `McpCatalogHost` trait that Core
installs at boot. Zero dependency on `apps/core`.

## Where it lives

`crates/core/mcp-catalog`

## API surface

- `/api/mcp/catalog/*` — browse, detail, and install MCP servers (see the
  [MCP API reference](/docs/develop/api-reference/core/mcp)).
