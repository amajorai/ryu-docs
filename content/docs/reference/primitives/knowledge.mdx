## What it is

The Open Knowledge Format (OKF) primitive — the model, parser, and serializer for
**git-shippable knowledge bundles**. OKF is a plain-markdown-with-frontmatter format
(`Concept` / `Bundle` / `IndexDoc` / `LogDoc`), designed so a knowledge base lives in a git
repo: diffable, reviewable, versioned, and portable across machines.

The permissive parser accepts the format as authored in the wild; the serializer writes it
back canonically. The retrieval ingest, catalog source, and HTTP export handlers all
reference the OKF types.

## Swap seam

A leaf crate consumed as a non-optional path dependency. Its one kernel coupling — the
Windows `NoWindow` console-suppression utility used by the git-clone `Bundle::from_git`
path — is vendored verbatim as a small std-`Command` util, so the crate has zero dependency
on `apps/core`.

## Where it lives
