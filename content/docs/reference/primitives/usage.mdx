## What it is

The per-agent subscription usage-metering primitive — the layer that answers *"how much of
my plan have I used?"* for the subscription CLIs already on the machine (Claude Code, Codex,
Copilot, Grok, Z.ai GLM). It reads the credential the CLI already stored, calls the
vendor's own usage endpoint, and returns **normalized rolling rate-limit windows** (5h
session, weekly, per-model) plus non-percent figures — credit balances, Codex's banked
rate-limit resets with per-credit expiry, extra-usage spend.

Two hard invariants:

- **Never refreshes the token** — single-use refresh tokens rotate; refreshing would log
  the real CLI out.
- **Never spends a banked reset** — that is irreversible.

## Swap seam

In-process by default, consumed as a non-optional path dependency. Zero dependency on
`apps/core`; the vendor credentials are read from the same stores the CLIs themselves use.

## Where it lives

`crates/core/usage`
