## What it is

The git-native workspace primitive — how agent work gets *done in a repo* without trashing
it. It shells `git`/`gh` for a caller-supplied cwd and owns:

- **Per-run worktrees** — create → isolated `ryu/run-<id>` branch → `Drop`-on-completion
  cleanup, so every agent run is a clean room.
- **The aggregate run diff** — committed + staged/untracked, numstat + name-status.
- **Whole-tree apply** — commit → merge-into-base, *or* commit → push → `gh pr create`.
- **Read-only git helpers** — status, branches, checkout, create-branch, commit-push.

## Swap seam

In-process by default, consumed as a non-optional path dependency (the ACP chat loop opens
a worktree per isolated run). The only kernel coupling — the Windows console-suppression
`NoWindow` util — is vendored verbatim. The chat-cwd threading stays kernel-side; only the
git engine moves here.
