## What it is

The kernel contracts crate — the single, pure-data definition of the **`manifest.json`
manifest model** (types + validation) shared by `apps/core` and the Ryu SDK. One definition,
no drift: a plugin authored against the SDK validates against exactly what Core loads.

- **No I/O, no runtime dependencies** — `serde` and `schemars` only.
- The manifest schema (also published as
  [`/schemas/plugin.json`](/schemas/plugin.json)) is the contract every plugin, app, and
  built-in manifest must satisfy.

## Where it lives

`crates/core/kernel-contracts`
