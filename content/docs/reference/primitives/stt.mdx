## What it is

The speech-to-text modality primitive: `transcribe(audio) -> text` with a swappable engine
seam.

- **In-process parakeet ONNX** — the default, and the genuinely in-process hot path
  (behind the `voice-parakeet` feature).
- **whisper.cpp** — an HTTP proxy engine.
- **Gateway-routed cloud Whisper** — the cloud path, through the Gateway like any other
  model call.

## Swap seam

Host couplings the crate cannot own — the whisper base URL, Gateway URL/bearer, and the
parakeet model dir — inject through the narrow `SttHost` trait. In-process by default and
consumed as a non-optional path dependency (the voice, meetings, and hardware data paths
reach it unconditionally).

## Where it lives

`crates/core/stt`

## API surface

- `/api/voice/transcribe` and `/api/voice/tts_models` (see the
  [Voice API reference](/docs/develop/api-reference/core/voice)).
