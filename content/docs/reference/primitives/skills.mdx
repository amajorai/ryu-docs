## What it is

The Agent Skills primitive — the registry that makes **skills a first-class, importable
unit**. It owns:

- the **SKILL.md registry** with a **dual-root scan** (`~/.claude` + `~/.agents`, plus the
  Ryu roots),
- the **progressive-disclosure injection block** that decides when a skill's full body is
  worth the context window,
- **authoring + version history**, and
- the `/api/skills/*` CRUD surface.

Because the registry is injected into every chat turn, skills are how an agent picks up
capabilities *without a code change* — the same SKILL.md format from the Claude/Cursor
ecosystem, importable into Ryu in one step.

## Swap seam

Kernel-required and in-process only. Core consumes it as a path dependency and injects the
data dir; Core implements `Runnable` for `SkillRecord` host-side. Zero dependency on
`apps/core` itself.

## Where it lives

`crates/core/skills`

## API surface

- `/api/skills/*` — list, activate, install from source, catalog, and version skills (see
  the [Skills API reference](/docs/develop/api-reference/core/skills)).
