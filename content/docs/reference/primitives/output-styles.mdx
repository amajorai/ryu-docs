## What it is

The output-styles registry — how the voice of an agent's replies becomes a swappable,
authorable unit. It owns the `<name>.md` registry (frontmatter + body), the **four-source
merge** (plugin / user / project / managed), the selection file, the system-prompt style
block, user-root authoring, and the `/api/output-styles` CRUD surface.

## Swap seam

In-process only. Core consumes it as a path dependency and injects the data dir, so the
crate has zero dependency on `apps/core`.

## Where it lives

`crates/core/output-styles`
