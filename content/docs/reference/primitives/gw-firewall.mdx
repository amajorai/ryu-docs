## What it is

The Gateway firewall scanning core — the pure regex detection engine behind PII/DLP and
prompt-injection protection. It owns:

- the **curated pattern builders** for PII / secrets / injection / code-injection /
  toxicity / bias,
- **Unicode-obfuscation normalization** (so `ｐassword` is still caught),
- the **Luhn / credit-card / public-IPv4 validators**,
- the `DetectionKind` / `FirewallMatch` scan types, and
- the **command-injection scanner**.

## Swap seam

No pipeline / `AppState` dependency — the `FirewallBackend` impl + `FirewallRegistry` that
wire this into the gateway pipeline stay in `apps/gateway`.

## Where it lives

`crates/gateway/firewall`
