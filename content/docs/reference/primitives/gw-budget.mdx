## What it is

The Gateway token-budget stage — how spend is bounded. It owns **per-user / per-agent /
per-session token budgets** plus the **per-window exec budget**, exposed as a swappable
`BudgetBackend` trait + registry with an in-memory built-in. It was the **first extracted
gateway stage crate**, and its shape is the pattern every later stage followed.

## Swap seam

`BudgetBackend` + id-keyed registry. The wiring (which budgets apply to which route) stays
in `apps/gateway`.

## Where it lives

`crates/gateway/budget`
