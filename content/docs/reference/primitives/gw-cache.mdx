## What it is

The Gateway response-cache stage — how repeated calls stop costing tokens. It owns two
caches:

- **`CacheBackend`** — the exact-match TTL cache.
- **`SemanticCacheBackend`** — the embedding-similarity semantic cache, so a rephrased
  question still hits.

Each is a swappable trait + id-keyed registry with an in-memory built-in.
