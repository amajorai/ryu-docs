## What it is

The conversation search primitive: a sqlite-vec (`vec0`) **semantic KNN index** plus a
contentless **FTS5 lexical index** over past chat messages. Both stores carry vectors,
inverted index, and metadata only — **never the message text**. The caller re-reads and
decrypts snippets from `conversations.db`, so search never becomes a second, unencrypted
copy of your chat history.

## Swap seam

In-process by default, consumed as a non-optional path dependency (the ConversationStore
reaches it unconditionally). The embedder injects via the narrow `SearchEmbedder` trait;
the registry-driven embedder choice and the default database paths stay Core-side
(`apps/core/src/search_host.rs`).

## Where it lives

`crates/core/search`

## API surface

- Conversation search over `/api/conversations/search` (see
