## What it is

The Gateway model-routing core (Plane A) — the pure **model → provider resolution** logic
behind smart routing. It owns:

- the full `route()` resolution order (**exact map → longest user prefix → builtin prefix
  table → default**),
- the **built-in zero-config prefix table**,
- **modality-slot resolution**,
- the **cost-tier fallback-chain sort**,
- the **eval-driven A/B explore/exploit picker** (with an `AtomicU64` counter), and
- the **classifier ("smart routing") text helpers** — prompt build, reply parse,
  last-user-message extraction, keyword match.

It is keyed on plain provider *strings* and value types, so it stays pure and testable.

## Swap seam

The `RouterRegistry` / `SmartRouterBackend` traits + registration, the `RouteDecision` +
config value-types, and SmartRouter's async provider/embedding orchestration stay in
`apps/gateway` — *"engine moves, wiring stays."*

## Where it lives

`crates/gateway/router`
