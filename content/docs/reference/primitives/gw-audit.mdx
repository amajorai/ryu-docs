## What it is

The Gateway audit stage — the append-only record of what every model call cost and what it
did. It owns the **SQLite-backed append-only request log + lifetime token totals** plus
query/summary, exposed as a swappable `AuditBackend` trait + id-keyed `AuditRegistry` with
the built-in `AuditLogger` active by default.

## Swap seam

`AuditBackend` + registry — an external audit sink (e.g. a managed SIEM) is a drop-in swap.
Mirrors the `ryu-gw-budget` / `ryu-gw-evals` shape.
