## What it is

The voice activity detection modality primitive: `detect(frame) -> speech_prob`, feeding an
**endpointing / barge-in** state machine — the signal that decides when a user is speaking,
when they stopped, and when the agent should yield mid-turn.

- An **energy speech-probability backend** is always compiled.
- The noise-robust **Silero VAD ONNX inference** is the genuinely in-process hot path,
  behind the `voice-vad` feature, falling back per-hop to energy so voice mode never breaks.

## Swap seam

In-process **forever** — a per-frame hot path that is *never* IPC-bound; latency matters
more than isolation here. The one host coupling the crate cannot own, the `~/.ryu` data dir
the Silero model resolves against, is injected via the narrow `VadHost` trait installed at
boot.

## Where it lives

`crates/core/vad`

## API surface

- `/api/voice/ws` — the realtime voice session that drives VAD per uplink hop (see the
  [Voice API reference](/docs/develop/api-reference/core/voice)).
