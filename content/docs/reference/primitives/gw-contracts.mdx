## What it is

The shared value-types exchanged between Ryu Gateway stages (for example `AlertTier`) — the
neutral home for cross-stage vocabulary so peer stage crates (budget, firewall, …) never
depend on each other.

## Where it lives

`crates/gateway/contracts`
