## What it is

The long-term memory primitive — the layer that lets agents *know what they did before*.
A SQLite-backed, encryption-at-rest `MemoryStore` holding durable cross-conversation facts,
organized by a multi-level scope model (**user / node / project**) with category,
importance, and tags metadata, and scoped recall/CRUD over those facts.

Rows are encrypted with the shared [crypto](/docs/primitives/crypto) master key. The chat
auto-recall loop reaches it unconditionally, so every turn starts from what this store
remembers.

## Swap seam

In-process by default, consumed as a non-optional path dependency. The two kernel
couplings — the default `~/.ryu` database path and the bind-time owner backfill's
org/account resolution — invert through plain constructor injection
(`open(path, node_bound, owner)`), so the crate has zero dependency on `apps/core`. The
Core wiring lives in `apps/core/src/memory_host.rs`.

## Where it lives

`crates/core/memory`

## API surface

- `/api/memory` — get, list, and update memory (see the
