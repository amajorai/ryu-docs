## What it is

The Gateway marketplace-governance core — the crypto + matching that makes plugin
installation *trustable*. It owns:

- **pure grant-allowlist matching**, and
- **ed25519 manifest sign/verify** over a canonicalized (recursively key-sorted) JSON
  encoding.

It takes explicit keys and allowlists — **no env, disk, or process-key custody**. The
`RYU_MARKETPLACE_SIGNING_KEY` resolution, dev-persisted-key disk custody, and the default
grant allowlist stay in `apps/gateway` (*"engine moves, key custody stays"* — the
marketplace trust root, behavior-identical).

## Where it lives

`crates/gateway/governance`
