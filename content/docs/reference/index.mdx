Ryu ships ready to use, and every default is replaceable. This section is the reference layer: the
map of what ships out of the box and the benchmark that measures how well a model or harness can
operate Ryu.

<Cards>
  <DocCard href="/docs/reference/defaults" />
  <DocCard href="/docs/reference/benchmark" />
</Cards>

## Defaults

Ryu installs ready to use: a local chat model, embeddings, voice, a default agent, and a set of
installed-and-enabled apps and plugins. None of it is hardcoded — every default resolves through a
registry, a config store, or a manifest, and each one has a documented override. See
[Defaults](/docs/reference/defaults) for the full map, the default model of every surface, and the
port map.

## RyuBench

Measure how well any model or harness can operate Ryu: execution-verified, cost-normalized, and hard
to game. See [RyuBench](/docs/reference/benchmark) for the tasks, scoring, and local-model setup.
