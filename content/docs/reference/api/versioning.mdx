This page is the versioning and deprecation policy of the hosted Ryu API at
`https://api.ryuhq.com`. Deprecated routes link to it with `rel="deprecation"`. For the other
API conventions, see the [hosted API overview](/docs/reference/api).

## Versions

The major version is part of the path: `https://api.ryuhq.com/api/v1`. The `info.version` of the
[OpenAPI document](https://ryuhq.com/openapi/v1.json) versions the document itself, not the API.

| Change | Ships in |
|---|---|
| A new route | The current major version |
| A new optional request field or a new response field | The current major version |
| A new error `code` | The current major version |
| Removing a route or field, or changing the meaning of a field | A new major path, such as `/api/v2` |

Clients should ignore response fields they do not know and handle unknown error codes by their
HTTP status. See [Errors](/docs/reference/api/errors).

Behavior changes that an existing integration can notice, such as new response headers or a
stricter replay rule, are listed with what to do on [API Changes](/docs/reference/api/changelog).

## Deprecation

A deprecated route keeps working until its sunset date. Each response from it carries:

| Field | Standard | Example | Meaning |
|---|---|---|---|
| `Deprecation` | RFC 9745 | `@1798761600` | When the route was or will be deprecated, as Unix seconds. |
| `Sunset` | RFC 8594 | `Sun, 01 Aug 2027 00:00:00 GMT` | After this date the route may stop responding. Sent only when a date is set. |
| `Link` | RFC 9745 | `<https://docs.ryuhq.com/docs/reference/api/versioning>; rel="deprecation"; type="text/html"` | This policy. |
| `Link` | RFC 5829 | `<https://api.ryuhq.com/api/v2/...>; rel="successor-version"` | The replacement route, when there is one. |

The OpenAPI document marks a deprecated operation with `deprecated: true`. Browsers can read these
header fields cross-origin.

<Callout type="info">
No route of the hosted API is deprecated today, so no response carries these fields yet. A route
that was already removed answers `410 Gone` instead.
</Callout>
