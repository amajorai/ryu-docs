## How to read this page

The linked documentation describes the current implementation boundary, not a promise that every
surface is production-ready. Check each page's notes for the parts that are verified, scaffolded,
or dependent on a device build, external provider, or deployment configuration.

## Where the finished surfaces live

When a surface becomes a stable part of the supported product, its primary documentation moves into
the normal product section: [Apps](/docs/apps), [Surfaces](/docs/surfaces), or the relevant [Core
API reference](/docs/extend/develop/api-reference/core).
