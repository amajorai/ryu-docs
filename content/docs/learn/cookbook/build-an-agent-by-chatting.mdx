---
title: "Build an agent just by chatting"
description: "Describe the agent you want in plain language and let the builder studio configure its model, tools, and persona for you."
---

Describe a new agent in plain language instead of filling in each setting by hand. The flow uses
the agent builder studio to configure the agent's model, tools, and persona from a builder chat. It
is a quick path to a tailored agent before you learn every field.

## What you'll use

- [Agents](/docs/surfaces/desktop/user-guide/agents): agent setup and the builder studio.
- [A tool the model can call](/docs/learn/cookbook/a-tool-the-model-can-call): for when you want a custom tool, not a built-in one.

## Steps

<Steps>

<Step>

### Open the Agents page and start one

Each agent has its own chat model, tools, memory, and persona. Open the **Agents** page and click
**+** to start a new one.

<TryInRyu page="agents" />

</Step>

<Step>

### Describe what you want in the builder chat

The agent edit page is a two-pane studio. The left pane is a builder chat that edits *this* agent;
the right pane is the organized config (model and provider, tools, connections, rules, instructions).

Tell the builder what you want in plain language:

> Make a formal research assistant that uses web search and answers with citations.

The builder applies the change for you. It uses Core's built-in `agent_builder` tools
(`get_agent`, `configure_agent`, and `create_agent`) to update the saved agent and refresh the
right-hand panel. For a brand-new agent, the first builder message creates a draft for you to edit.

<Callout type="info">
The builder conversation runs as the flagship **Ryu** agent runtime with `persist: false`, so these
builder turns never enter your chat history. The built-in, locked `ryu` agent itself is edited
through its own config, not this builder.
</Callout>

</Step>

<Step>

### Refine and review

Keep iterating: "add the spaces memory", "switch the model to a local one", "make the tone
concise". Each request is one tool call against the agent record, and the right pane shows the
current state, so you can always see exactly what the builder changed.

</Step>

<Step>

### Chat with it

Save, and the new agent appears in the chat picker. Select it and your messages route through that
agent's model, tools, and persona.

<TryInRyu page="chat" />

</Step>

</Steps>

## Check your work

- After each builder request, the right-hand config panel re-hydrates to show the change (model,
  tools, or persona), so you can see exactly what the builder set.
- The saved agent appears in the chat picker, and selecting it routes your messages through its
  configuration, not the flagship `ryu` agent.
- Because the builder runs with `persist: false`, your builder back-and-forth never shows up in your
  chat history.
