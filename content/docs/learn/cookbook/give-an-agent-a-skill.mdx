---
title: "Give an Agent a New Skill"
description: "Install an Agent Skill from skills.sh, enable it, and scope it to one agent's allowlist."
---

An Agent Skill is a reusable `SKILL.md` instruction set for one task, such as code review, a writing
style, or a domain workflow. This recipe installs a skill from the public catalog, activates it, and
scopes it to one agent.

## What you'll use

- [Skills](/docs/surfaces/desktop/skills): browse and install Agent Skills from skills.sh.
- [Skills catalog](/docs/core/skills-catalog): the registry, activation set, and per-agent allowlist.

## Steps

<Steps>

<Step>

### Browse and install a skill

The **Skills** tab browses the public [skills.sh](https://skills.sh) directory. Find a skill and
install it. Ryu writes it in the universal Agent Skills layout (`~/.claude/skills/<slug>/SKILL.md`).
Claude Code and the skills CLI read the same directory.

<TryInRyu page="skills" />

Over the API the same flow is:

```http
GET  /api/skills/catalog
POST /api/skills/catalog/install
```

</Step>

<Step>

### Know the difference between installed and active

Installed is not the same as active. The shared skills directory can hold dozens of skills, and
injecting every one would overflow a small model's context. Ryu injects only the skills in its
**activation set**. A skill you install *through Ryu* is active automatically. Skills discovered in
the shared directory are visible but inactive until you turn them on. Use the switch on the Skills
page, or the API:

```http
POST /api/skills/activate
{ "id": "owner/repo/slug", "active": true }
```

</Step>

<Step>

### Scope it to one agent

By default an agent gets every enabled skill. To give *one* agent a skill (and not the others), set
that agent's **skill allowlist** on its edit page. An empty allowlist means all enabled skills. A
non-empty allowlist is intersected with the globally enabled set, so it never re-activates a skill you
turned off globally.

Both the default `ryu` agent and other ACP agents receive the skill.

</Step>

<Step>

### Use it

Chat with the agent. With the skill active and allowlisted, the agent gets its instructions. They
are injected into the prompt, or loaded on demand through the `skills` tool when **Settings → Memory →
Load skills on demand** is on.

</Step>

</Steps>

## Check your work

- On the Skills page the skill reads as **active** after you toggle it, or
  automatically if you installed it through Ryu.
- Ask the agent to do the task the skill covers. Its reply follows the skill's instructions.
- Set a non-empty allowlist on one agent and the skill reaches *that* agent only. Other agents,
  asked the same thing, answer without it.
- The skill file exists at `~/.claude/skills/<slug>/SKILL.md`, so Claude Code and the skills CLI see
  the same skill.
