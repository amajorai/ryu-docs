An **engine** is a runtime that serves models. A **model** is the weights it loads. You choose both, and you can swap either one.

## Engines are runtimes

Engines run as managed sidecars with a start and stop lifecycle. Ryu can install and run several kinds:

- llama.cpp, Ollama, vLLM, and SGLang for text.
- MLX on Apple Silicon.
- stable-diffusion.cpp for images.
- whisper.cpp and parakeet for speech-to-text.
- Kokoro (the default) and OuteTTS (the fallback) for text-to-speech.

You manage these from **Engines** in the sidebar or **Services** in Settings. Text engines are mutually exclusive, so only one is resident at a time. Image, speech, and embedding engines run alongside the text engine, so you can start and stop them freely.

<Callout type="info">
  The MLX engines are Apple Silicon only. On other hardware their install and swap controls are disabled with a reason shown.
</Callout>

## Models are the weights

<TryInRyu page="models" />

Separate from engines, **Models** is the built-in model catalog. It browses Hugging Face and selectable mirror sources across GGUF, safetensors, and MLX weights, and each format maps to its engine family: GGUF to llama.cpp or Ollama, safetensors to vLLM or SGLang, and MLX to Apple Silicon. From it you can:

- Search and filter models by format and task.
- See a device-fit verdict for each file, computed from your detected RAM and VRAM: runs great on your GPU, runs on your GPU, partial GPU offload (slower), CPU only (slower), too large for your device, or can't check your device.
- Install a model.
- For a chat model, use **Run in chat**: Ryu picks a compatible engine, installs it if needed, and opens a chat with the model. For other models, **Use this model** selects the installed model for its local runtime.

The device-fit verdict is the fastest way to avoid downloading something your machine cannot run. Look for a verdict that runs on your GPU before committing to a large file.

Local onboarding tries to install the default Gemma GGUF. Local chat works only after the download finishes and its runtime starts. Check readiness before you rely on local inference.

## Nothing is hardcoded

Every model and every engine is a swappable default. Ryu is not locked to one model. You switch the active model in the Models browser, and the local engine restarts to serve your choice.

## Deep links from the web

Some web pages have `ryu://` links. A model link opens the desktop app and offers to install or switch to that model. Ryu then finishes the download and runtime setup before it runs the model.

<Callout type="warn">
  Switching the active text model restarts the resident local engine. Finish any in-flight chat before you swap.
</Callout>
