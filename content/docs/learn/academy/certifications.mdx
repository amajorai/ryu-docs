Certifications are a way to prove you can actually do something with Ryu, not just that you read
about it. There are four official credentials, each mapped to an Academy path, plus community
certifications that are reviewed before they appear in the public catalog.

<Callout type="info">
  **Current as of August 23, 2026.** The Academy is the free preparation. Each official exam draws 10 questions from a 30-question pool generated directly from the published lesson quizzes.
</Callout>

Search and filter the full credential catalog at [ryuhq.com/certifications](https://ryuhq.com/certifications).
You can browse without an account. Sign in when you are ready to start an exam, save progress, or
view an earned certificate.

The [learning progress guide](/docs/learn/academy/learning-progress) explains the difference
between finishing a path, earning a Ryu Academy completion badge, and passing an official exam.

## Certified User

**Prepares with** [Ryu Essentials](/docs/learn/academy/essentials).

For everyone who uses Ryu day to day. You can be productive without writing code.

You should be able to:

- Explain what Ryu is and why it sits above any engine
- Install Ryu and complete first-run onboarding
- Start a chat, use voice input, and branch a conversation
- Recognize a tool call in a conversation and explain the agent loop

## Certified Operator

**Prepares with** [Operating Ryu](/docs/learn/academy/operator).

For power users who set Ryu up for themselves or a team.

You should be able to:

- Create and edit an agent, treating each slot as swappable
- Browse and install models from the catalog and switch the active model
- Install and activate skills, and understand installed versus active
- Connect tools and reason about an agent's allowlist
- Use Spaces and memory for retrieval, and set up an automation or monitor

## Certified Gateway Admin

**Prepares with** [Governing Ryu](/docs/learn/academy/governing).

For the person who owns policy. This is the governance layer.

You should be able to:

- Explain the Core versus Gateway split and why Core never enforces policy inline
- Configure model routing, including smart classifier-driven routing
- Set up guardrails such as the firewall and PII or DLP controls
- Apply budgets and manage keys with a BYOK vault
- Run evals and read the audit trail

## Certified Builder

**Prepares with** [Building on Ryu](/docs/learn/academy/builder).

For developers who extend the platform.

You should be able to:

- Explain the Runnable contract and how Agent, Workflow, Tool, and Skill unify under it
- Scaffold a project with the SDK and define a Runnable
- Package an app with a manifest and understand install, enable, and disable
- Publish to the marketplace and explain how publishing is governed by the Gateway

## Taking the exam

Exams are hosted on [ryuhq.com](https://ryuhq.com/certifications). Sign in, pick your track, answer
10 questions, and get your result immediately. Each official pool is generated from its current
Academy knowledge checks, so a published lesson update and its exam source cannot drift apart.

</Callout>

## Community credentials

Community authors can package lessons and an exam, submit the credential for review, and publish it
to the same searchable catalog. A community credential shows its author, policy, skills, and course
lesson count separately from official Ryu Academy credentials. Published community content is
reviewed, and its issuer cannot be presented as Ryu Academy.

The **Ryu for Business** path currently has no standalone official certification. Use the role-based
credential that matches your work, then complete the Business lessons for deployment and multi-node
practice.
