This course takes you from install to your first chat. At the end, Ryu runs on your machine and you
have used an agent with tools. You do not need a service key or a terminal.

## Who this is for

Everyone. You do not need to be a developer or bring your own models or keys. Onboarding installs a
local model stack for you.

## What you will learn

- What Ryu is, and how it adds controls around an agent engine
- How to install Ryu and what happens on first run
- How agents work, and how to meet the default **Ryu** agent
- How to run your first chat, including tool use
