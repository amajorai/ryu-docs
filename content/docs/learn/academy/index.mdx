Agents are powerful. Learning to wield them should not be. **Ryu Academy** gives you five guided
paths, 21 focused lessons, and four official credentials. Start with the app, then learn to operate,
govern, or build on the platform. A separate Business path covers deployment and multi-node use.

Every course is made of short lessons. Each lesson opens with what you will learn, walks through
the feature with real steps, and closes with a **knowledge check** so you can confirm it stuck.
Work through a track end to end, or jump straight to the lesson you need.

The web Academy keeps four destinations together: **Overview** introduces the paths,
**Catalog** searches and filters every path and lesson, **My learning** saves the learner’s place,
and **Certifications** contains exam preparation, exam progress, and publicly verifiable
credentials. Each path also has a native detail view with outcomes, prerequisites, practice, and
an ordered completion sequence. The same section navigation appears on every view, including
narrow screens.

The number on each course is its **level**: `100` is the gentlest starting point, and
each `+100` step assumes a bit more of what came before.

## How the Academy works

- **Tracks by role** - Each course targets one kind of person. Start with Essentials, then follow
  the track that matches what you want to do.
- **Lessons, not walls of text** - A lesson is one idea, done well, in a few minutes.
- **Knowledge checks** - Every lesson ends with a short self-test. No grading, no login, just a
  way to be honest with yourself before moving on. Sign in separately when you want to save
  completion progress.
- **Applied practice** - Every path names a practice capstone, and lessons point at the real Ryu
  surface or a concrete action to try.
- **Saved learning** - Mark lessons complete from the native path view, continue from the next
  action, and reopen a lesson when you want to revisit it.
- **Completion before credentials** - A finished path shows a Ryu Academy completion badge. It
  prepares you for an official exam but does not replace the server-scored certification.
- **Clear about maturity** - Lessons say when a capability is available now, when configuration is
  still being surfaced, and when Ryu Cloud involves a managed service.
- **One source for exams** - Official question pools are generated from the published lesson quizzes,
  so preparation and assessment stay aligned.

## Get certified

When you have worked through a credential-bearing track, the [certifications guide](/docs/learn/academy/certifications)
lays out the four official certifications, the 30-question source pool behind each 10-question exam,
and the skills you should be ready to demonstrate.
