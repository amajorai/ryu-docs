This course is for the person who owns policy. In the Gateway you decide what an agent is allowed to do, what data is safe to send, which model serves a request, what it costs, and how you prove what happened.

The Gateway is already on the default chat path. This course teaches its surfaces, not how to turn it on.

## Who this is for

- Platform and developer teams who run agents for others and need a single control point.
- Anyone responsible for security, spend, model choice, or compliance across a team or organization.
- The owner who is responsible for configuring the control layer.

## What you will learn

- The main design rule: Core decides what runs, the Gateway decides what is allowed.
- How model routing works, including smart classifier-driven routing from plain-language rules.
- How the firewall and PII/DLP guardrails protect requests and egress.
- How budgets cap spend, how BYOK (bring your own key) stores keys, and how BYOA (bring your own agent) points a compatible agent at the Gateway.
- How evals measure output quality and audit proves what happened.
