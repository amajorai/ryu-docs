This track is for teams who run Ryu beyond a single laptop. You self-host it, put agents into chat platforms, and spread work across machines. The Rust Core and Gateway are open source and self-hostable. The desktop app, web app, and backend are closed source.

Ryu Cloud is a managed offer in which A Major audits, builds, deploys, and hosts agents for a business. Part of it is a product you run, and part of it is a service. Each lesson says which is which.

## Who this is for

- Teams and businesses of any size
- Anyone deciding whether to self-host or use managed Ryu Cloud
- People who want agents reachable from Telegram, Slack, WhatsApp, or Discord
- Operators running Ryu across more than one machine

## What you will learn

- What gets deployed and how a hosted server stays governed
- How channel bots turn a chat platform into another surface onto the same agent
- How multiple servers, mesh, and sync work together
- Where managed Cloud is a feature you can use today versus a service offering
