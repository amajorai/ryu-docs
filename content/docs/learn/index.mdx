Learn has two parts, one for learning Ryu in order and one for doing a single task.

<Figure name="learn" />

- **Academy** - ordered courses with knowledge checks. Four of its paths prepare you for a
  [certification](/docs/learn/academy/certifications). Start here if you are new to Ryu.
- **Cookbook** - task recipes you can follow end to end. Start here if you already know what you
  want to build.
