knowledge checks, and the **Cookbook** gives you copy-paste-ready task recipes.

## Academy

Learn Ryu the structured way, from first chat to certified builder. Course tracks:

- **Essentials** — what Ryu is, install, first chat, first agent
- **Operator** — agents, models and engines, skills and tools, spaces and memory, automations
- **Governing** — routing, guardrails, budgets, and audit
- **Builder** — build on Ryu and publish
- **Cloud** — the hosted offering

Each course ends with a certification you can earn. See [Academy](/docs/learn/academy).

## Cookbook

End-to-end task recipes, practical and copy-paste-ready: building agents, routing traffic, deploying
Ryu, running multi-node setups, and wiring channel bots. See [Cookbook](/docs/learn/cookbook).
