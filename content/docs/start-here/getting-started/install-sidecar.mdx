---
title: "Install Agent Runtimes"
description: "Install Claude Code, Codex, or another agent runtime from Services."
---

Ryu manages agent runtimes as **sidecars**. Core downloads, verifies, installs, starts, and
health-checks each runtime. Manage them from the Services page.

## What sidecars are

A sidecar is a separate process for an agent runtime. Core handles its lifecycle: download,
verification, install, start, stop, and health checks. When the runtime is running, its agent
appears in the chat agent picker.

## Open the Services page

Open **Services** from the command palette (**Ctrl+K**, then type "Services") or the navigation.
Services shows each runtime's install and run state, with controls to install, start, and stop it.

## Install Claude Code

1. Find **Claude Code** in the Services list and click **Install**. Core downloads and
   verifies the runtime.
2. Provide your **Anthropic API key** so the agent can reach Claude.
3. Start the runtime.

## Install Codex

1. Find **Codex** in the Services list and click **Install**.
2. Provide your **OpenAI API key**.
3. Start the runtime.

<Callout type="info">
  Claude Code and Codex run as ACP subprocesses and use the provider key you supply. Store API keys
  in runtime configuration, not in chat messages.
</Callout>

## Pi needs no key

**Pi** is the built-in default and runs locally through llama.cpp with a bundled Gemma model. There
is nothing to install and no key to provide. Pi works on first launch and offline.

## After install

Once a runtime is installed and running:

- Its agent appears in the **agent picker** in the chat sidebar.
- Select it to route your next message through that runtime.
- You can stop the runtime from the Services page at any time to free resources.

To browse and install **local models** instead of cloud runtimes, see
[The App Store](/docs/surfaces/desktop/user-guide/store).
