description: "Install and configure an agent runtime such as Claude Code or Codex from Store → Engines, then verify it with a short task."
---

Ryu manages agent runtimes as **sidecars**. An agent runtime is the engine that performs a task;
installation, authentication, model setup, and permissions depend on the selected engine.

## Choose an engine

Open **Store → Engines** to inspect supported runtimes and their installation state. Select an
engine, follow its installation instructions, and configure the account or provider it requires.
Claude Code and Codex can use supported subscription authentication; an API key is not the only
possible authentication method.

<DocCard href="/docs/surfaces/desktop/engines/agent-runtimes" />

## Configure the default Ryu agent

The built-in **Ryu** agent uses Pi. Its engine and model connection are separate: having the agent
installed does not establish that a model is downloaded and ready.

For local inference, install and select a supported local model and confirm that its model server
is ready. After the model and runtime are installed, local inference can work without a provider
API key. Cloud providers and connected tools can still use the network.

<DocCard href="/docs/surfaces/desktop/user-guide/store" />

## Verify a task

Select the configured agent in Chat and send a short request. Check that it produces a reply before
adding tools or an automated workflow. Review tool permissions and the provider destination before
using project files or other sensitive data.

Gateway rules apply to requests routed through Gateway. Some engines make direct provider
calls; check the [engine's documented traffic path](/docs/surfaces/desktop/engines/agent-runtimes).
