Ryu opens to Chat with the built-in **Ryu** agent selected. Ryu uses
[Pi](/docs/surfaces/desktop/engines/agent-runtimes) with the model connection configured for your
selected node. Confirm that the model and runtime are ready before you send your first message.

<TryInRyu page="chat" />

## Send your first message

<Steps>

### Open a conversation

Click **New chat** in the sidebar, or start typing on the empty chat screen. The active agent at the
top of the composer is **Ryu**.

### Enter a message

Enter a message in the composer. Try `Summarize what you can do.`

### Send it

Press **Enter** to send. Use **Shift+Enter** for a new line.

</Steps>

Replies stream as they are generated. The selected agent and model configuration decide where the
turn runs and which provider receives it. Gateway rules apply to model requests routed through
Gateway. Ryu saves the conversation on the selected node. See
[Conversations and sessions](/docs/core/conversations-sessions) for the storage model.

<Callout type="info">
  Local inference requires a downloaded model and a ready local model server. Setup can require
  network access; installing the app alone does not prove inference is ready. See
  [Batteries-included defaults](/docs/start-here/architecture/batteries-included) for the full
  stack.
</Callout>

Offline inference does not make a whole task offline. Connected tools, account services, and
cloud providers can still require network access. Review the selected node's connections and
[telemetry defaults](/docs/surfaces/desktop/transparency) before running a private task.

## Find the command palette

Press **Cmd+K** (macOS) or **Ctrl+K** (Windows and Linux) anywhere in the app to open the command
palette. Use it to open Chat, Agents, Models, Skills, Spaces, Memory, Tools, and Workflows.

## Add other agents

The agent picker in the sidebar lists the agents installed on the node. A fresh install has only
Ryu.

To add Claude Code, Codex, or Gemini CLI, install and configure its runtime from
**Store → Engines**. Core starts the runtime as a subprocess and adds the agent to the picker.
These agents can call tools, read the result, and continue within the same reply.
