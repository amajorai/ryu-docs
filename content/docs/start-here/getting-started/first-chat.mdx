Ryu opens to Chat with the built-in **Ryu** agent selected. Ryu uses
[Pi](/docs/surfaces/desktop/engines/agent-runtimes) and runs locally, so you can send a message
without an API key or terminal.

<TryInRyu page="chat" />

## Send your first message

<Steps>

### Open a conversation

Click **New chat** in the sidebar, or start typing on the empty chat screen. The active agent at the
top of the composer is **Ryu**.

### Enter a message

Enter a message in the composer. Try `Summarize what you can do.`

### Send it

Press **Enter** to send. Use **Shift+Enter** for a new line.

</Steps>

Replies stream as they are generated. Ryu routes the turn through the Gateway to the local Pi
engine and saves the conversation in local chat history. See [Conversations and
sessions](/docs/core/conversations-sessions) for the storage model.

<Callout type="info">
  The default local stack is llama.cpp serving Gemma. Core starts it during onboarding. See
  [Batteries-included defaults](/docs/start-here/architecture/batteries-included) for the full
  stack.
</Callout>

## Find the command palette

Press **Cmd+K** (macOS) or **Ctrl+K** (Windows and Linux) anywhere in the app to open the command
palette. Use it to open Chat, Agents, Models, Skills, Spaces, Memory, Tools, and Workflows.

## Add other agents

The agent picker in the sidebar lists the agents installed on the node. A fresh install has only
Ryu.

To add Claude Code, Codex, or Gemini CLI, install its runtime from Services. Core starts the runtime
as a subprocess and adds the agent to the picker. These agents can call tools, read the result, and
continue within the same reply.
