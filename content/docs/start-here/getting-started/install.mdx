This page shows how to install Ryu and what you get on first launch. Check the
[system requirements](/docs/start-here/getting-started#system-requirements) first.

## Install the desktop app

1. Download the Ryu desktop installer for your platform from [ryuhq.com/download](https://ryuhq.com/download).
   After the download starts, the page shows where your browser saved the file and the install
   steps for your system.
2. Run the installer and launch Ryu (see [Open the installer](#open-the-installer) below).
3. Sign in to use the desktop app. For a backend-free deployment, operate a self-hosted Ryu
   Node through the CLI or SDK.

### Open the installer

Your browser keeps finished downloads in its downloads list, usually behind the downloads icon in
the top-right corner of the toolbar. Press <kbd>Ctrl</kbd>+<kbd>J</kbd> in Chrome or Edge on
Windows and Linux, or <kbd>⌥</kbd><kbd>⌘</kbd><kbd>L</kbd> in Chrome or Safari on macOS.

| Platform | File | Install |
|---|---|---|
| macOS | `.dmg` | Open the disk image, drag **Ryu** onto **Applications**, then open Ryu from Applications. |
| Windows | `.exe` or `.msi` | Run the installer and follow the prompts, then open Ryu from the Start menu. |
| Linux | `.AppImage` | Run `chmod +x` on the file, then start it. Some distributions need FUSE 2 (`libfuse2`). |
| Linux | `.deb` | Run `sudo apt install ./<file>.deb` from the folder you saved it in. |
| Linux | `.rpm` | Run `sudo dnf install ./<file>.rpm` (or `sudo zypper install` on openSUSE). |

The desktop builds are not yet notarized by Apple or code-signed for Windows, so the first launch
needs one extra confirmation:

- **macOS:** if macOS says it can't verify Ryu, click **Done**, open **System Settings → Privacy &
  Security**, scroll down, click **Open Anyway** next to Ryu, and confirm.
- **Windows:** if SmartScreen shows **Windows protected your PC**, click **More info**, then
  **Run anyway**.

After the first launch, Ryu keeps itself up to date.

## Run from source

From a checkout of the monorepo, run the desktop app with Bun:

```bash
bun install
bun run dev:desktop
```

This starts the Tauri desktop app and its local Core runtime.

## Install Core on a headless machine

On macOS or Linux, run the Core bootstrap:

```bash
curl -fsSL https://raw.githubusercontent.com/amajorai/ryu/main/install.sh | sh
```

On Windows, run this in PowerShell:

```powershell
irm https://raw.githubusercontent.com/amajorai/ryu/main/install.ps1 | iex
```

The installer does the following:

- Puts `ryu-core`, `ryu-gateway`, and `ryu-cli` in `~/.ryu/bin` (override with `RYU_INSTALL_DIR`).
- Starts Core.
- Begins the bundled model, engine, skill, Shadow, Ghost, and Island setup in the background.
  Shadow and Ghost start with Core. Island is downloaded and kept current, but it stays stopped and
  hidden until you enable it.

Agent detection and preferences stay separate onboarding steps in the desktop app.

### Upgrade or pin a release

| To | Do this |
|---|---|
| Upgrade to the latest release | Run the same command again |
| Install a specific release | Set `RYU_VERSION` to its tag, for example `RYU_VERSION=v0.4.0` |
| Reinstall the same pinned tag | Set `RYU_FORCE_INSTALL=1`. Otherwise a re-run skips binaries already at that version |

If Ryu Core is already running when you upgrade, the installer replaces the binaries but leaves
that process on the previous version. Restart Ryu Core afterwards.

If the install or Core does not come up, run `ryu-cli troubleshoot`. It checks the install, applies
safe fixes with `--fix`, and prepares a bug report if you cannot fix it yourself. See
[Troubleshoot an install](/docs/surfaces/cli/troubleshoot).

To run Core and Gateway as a server or container, see
[Self-host a Ryu server](/docs/start-here/getting-started/self-host).

## What you get on first launch

- **Ryu**, the built-in agent powered by Pi. Configure its model connection; local inference
  requires an installed model and a ready model server.
- **The sidecar manager.** Core downloads, verifies, installs, and starts additional runtimes such
  as Claude Code, Codex, and Gemini CLI from **Store → Engines**. See
  [Install agent runtimes](/docs/start-here/getting-started/install-sidecar).
- **Local conversations and memory.** Chat history and long-term memory are stored on your machine.
