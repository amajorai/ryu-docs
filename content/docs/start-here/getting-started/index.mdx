Install Ryu and run an agent.
The desktop app includes a chat interface, a local agent, Core, and the default runtime. You can
start without a terminal, provider key, or MCP (Model Context Protocol) setup.

The desktop app talks to **Ryu Core**, the local backend that runs agents, sends requests to the
selected engine, and stores conversations and memory on your machine. Additional agent runtimes run
as sidecars, which are separate helper processes. The default setup runs locally.

## System requirements

- **Operating system** - macOS or Windows 10 and newer.
- **Memory** - 4 GB RAM minimum for the bundled local model. More RAM (and a GPU) lets you
  run larger models from the catalog.
- **Disk** - a few GB free for the local model and any agent runtimes you install.

<Callout type="info">
  A configured Self-hosted Ryu Node works fully offline with its installed local agent. You only
  need network access to install additional models, skills, or cloud-backed agent runtimes. The
  account-backed Desktop Console remains a separate client surface.
</Callout>

## Install the desktop app

Use the prebuilt desktop app:

1. Download the Ryu desktop installer for your platform from [ryuhq.com/download](https://ryuhq.com/download).
2. Run the installer and launch Ryu.
3. Sign in to use the Desktop Console. For a backend-free deployment, operate a self-hosted Ryu
   Node through the CLI or SDK.

### Run from source

If you have the monorepo checked out, you can run the desktop app directly with Bun:

```bash
bun install
bun run dev:desktop
```

This starts the Tauri desktop app, which spawns Ryu Core on `:7980` for you.

### Install Core on a headless machine

For a headless machine, use the Core bootstrap:

```bash
curl -fsSL https://raw.githubusercontent.com/amajorai/ryu/main/install.sh | sh
```

On Windows, run `irm https://raw.githubusercontent.com/amajorai/ryu/main/install.ps1 | iex`
in PowerShell. The installer installs Core, Gateway, and CLI, starts Core, and begins the
bundled model, engine, skill, Shadow, Ghost, and Island setup in the background. Island is
downloaded and kept current but stays stopped and hidden until the companion feature is enabled;
Shadow and Ghost start with Core. The desktop keeps its agent detection and preferences as
separate onboarding steps.

## Choose where work runs

Choose one runtime:

- **Ryu Cloud** - Ryu manages the runtime and node maintenance.
- **Run locally** - Work stays on your device and can work offline. You own downloads, disk space,
  updates, performance, and uptime.
- **Connect an existing node** - Use a Core node your team operates. You provide its URL and token;
  your team owns setup, upgrades, access, and uptime.

## What you get on first launch

- **Pi**, the built-in agent. It runs locally through llama.cpp with a bundled Gemma model, so you
  can chat without an API key.
- **The sidecar manager.** Core downloads, verifies, installs, and starts additional runtimes such
  as Claude Code, Codex, and Gemini CLI from the Services page.
- **Local conversations and memory.** Chat history and long-term memory are stored on your machine.
