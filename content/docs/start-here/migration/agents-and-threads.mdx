Ryu has separate paths for agent setup, native transcripts, and reusable agent definitions. Use the
setup importer for configuration and the thread importer for past conversations.

## What is supported

| Source data | Ryu action | Result |
|---|---|---|
| Claude Code, Cursor, or Codex setup | **Import agent setup** | Scans a selected folder for supported instructions, skills, MCP servers, plugins, memories, subagents, and slash commands |
| Claude Code or Codex native history | **Import a past agent thread** | Restores readable transcript messages as a normal Ryu conversation |
| A Ryu agent definition | `GET /api/agents/:id/export` then `POST /api/agents/import` | Creates a new unlocked Ryu-owned copy |
| An existing Ryu agent record | `POST /api/agents/:id/migrate-to-ryu` | Copies its persona, tools, and model onto the Ryu engine without changing the source agent |

Cursor setup import is supported. Cursor native conversation history is not currently a supported
thread format.

## Import setup and threads

1. Open **Import a past agent thread** from the Chats section, launchpad, or command palette.
2. Pick **Claude Code** or **Codex**, choose the threads, and import them.
3. Open **Import agent setup**, point it at a source folder, and select the scan results to import.
4. Attach an imported thread to the project folder that contains the source code when the recorded
   working directory still exists.
5. Run a small test turn after reviewing the imported setup.

Re-importing the same native thread adds only messages that were not imported before. The recorded
working directory and Git branch can be retained as conversation metadata, so a staged move does
not lose the connection between a transcript and its code.

The setup scan can find:

- Project instruction files such as `AGENTS.md` and `CLAUDE.md`.
- Agent Skills stored as `SKILL.md` directories.
- MCP servers declared by supported configuration files.
- Plugin bundles, Claude project memories, Codex subagents, and Codex slash commands.

Imported instructions register their containing folder as a project and are used on turns that run
in that folder. Auto-import in **Settings → General → Chats** keeps instructions synchronized; for
safety, skills, MCP servers, and plugins remain explicit import choices.

## Review access after import

- MCP servers with custom headers or environment variables may need a new sign-in.
- Imported plugins stay disabled until you review their grants and enable them.
- Imported skills and commands can contain instructions written for the source tool.
- A native transcript restores readable message text. It does not warm the source agent's private
  runtime context automatically.

For the sync ledger, conflict handling, and export bundle, see [Agent import and export
sync](/docs/gateway/agent-sync). For the generated request and response shapes, see the [Agents API
reference](/docs/extend/develop/api-reference/core/agents).
