Use this section when you are moving from another AI agent, workspace, app, or provider. Ryu keeps
setup, conversations, source content, project folders, app data, and credentials as separate
boundaries. Choose the smallest path that contains what you need.

<Callout type="info">
Migration is a copy and cutover process. Keep the source available until you have checked the
destination. Recreate access separately; do not copy API keys, OAuth sessions, signing secrets, or
provider credentials into a content export.
</Callout>

## Choose a path

| What you are moving | Start here | The destination receives |
|---|---|---|
| Agent setup and past threads | [Migrate agents and threads](/docs/start-here/migration/agents-and-threads) | Supported instructions, skills, MCP servers, plugins, memories, subagents, slash commands, and Claude Code or Codex transcripts |
| Code projects and knowledge | [Migrate projects and Spaces](/docs/start-here/migration/projects-and-spaces) | Existing folders and Git history, project context, Markdown Space source, or a complete Ryu node backup |
| A safe staged move | [Plan a safe migration](/docs/start-here/migration/plan-and-cutover) | A source-ID map, preview, repeatable import, canary, reconciliation, and rollback plan |
| Email or another provider service | [Migrate providers and services](/docs/start-here/migration/providers-and-services) | A provider adapter and an explicit mapping for domains, messages, templates, contacts, events, and credentials |
| A reusable Ryu definition | [Portable packages](/docs/extend/develop/extensions/portable-packages) | Versioned agents, workflows, plugins, skills, themes, Spaces, and declared artifacts |
| One reviewed conversation between Ryu nodes | [RNP conversation continuity](/docs/extend/integrate/rnp) | A bounded, user-approved transcript snapshot |

<Callout type="warn">
There is no universal importer for arbitrary third-party app databases. Export through the source
product or its API, map the data to a Ryu-owned contract, and keep the source export as a read-only
archive. Do not copy another product's SQLite files into Ryu.
</Callout>

## Know the boundary

- **Content** can be imported when Ryu has a matching contract, such as native agent setup, a
  transcript, a portable package, or Markdown Space source.
- **Access** must be recreated through the destination's sign-in, credential, webhook, billing, or
  domain setup flow.
- **Provider compatibility** can keep an application's request shape while changing its base URL.
  It does not move the provider account or its history.
- **App-owned data** needs the owning app's importer or export contract. A project folder is not the
  same thing as the Projects app board, and a Mail inbox is not a contacts database.

Start with [Plan a safe migration](/docs/start-here/migration/plan-and-cutover), then open the guide
for the data you are moving.
