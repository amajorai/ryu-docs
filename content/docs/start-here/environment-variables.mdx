This page is the reference for the environment variables of Ryu's open-source runtimes and the client
surfaces built on them: Core, Gateway, the CLI/TUI, desktop, and companion apps. It is assembled
from `packages/env` Zod schemas, per-app `.env.example` files, and code scans.

<Callout type="info">
  **Legend.** *Required* means the app fails to start or a feature is unusable without the var in that deployment mode. *Optional* means a built-in default exists or the feature is opt-in. *Required\** on `.env.example` rows means the example shows it uncommented for local dev - check the schema for production rules.
</Callout>

## How configuration is organized

| Layer | Mechanism | Apps |
|---|---|---|
| Env-only (no schema) | `process.env` / `import.meta.env` / `std::env` | `apps/core`, `apps/gateway`, desktop/webapp (Vite), `mcp`, `tui`, `island` |
| TOML + env overrides | `gateway.toml` + `GATEWAY_*` env | `apps/gateway` |
| User preferences | Raycast extension prefs (not env) | `apps/raycast` |

Copy the matching `.env.example` to `.env` (or `.env.local`) in each app directory. Core and Gateway have **no config file** beyond env vars (Gateway also reads `gateway.toml`).

### Address Core binds to

| Variable | Required | Default | Description |
|---|---|---|---|
| `RYU_BIND` | Required* | `127.0.0.1:7980` | Address Core binds to. Also the fail-closed gate: exposing beyond loopback is governed by this var. |
| `RYU_TOKEN` | Optional | - | Bearer token required on protected API routes. Unset = no node auth (local only). |
| `RYU_DIR` | Optional | - | Data directory root (db, models, plugins, spaces). Default: OS app-data dir. |
| `RYU_CORS_ORIGINS` | Optional | - | Extra CORS origins (comma-separated) added to the built-in desktop/web set. |
| `RYU_NODE_NAME` | Optional | - | Human-friendly node name (webhook relay, presence). Default: machine hostname. |
| `RYU_NODE_PUBLIC_URL` | Optional | - | Publicly reachable URL of this node (control-plane registration). |
| `RYU_BACKEND_URL` | Optional | - | Ryu backend / identity+content plane base URL. Default: `http://127.0.0.1:3000` |
| `RYU_SERVER_URL` | Optional | - | Alias/override for the backend base URL used by cloud sync + gateway seeding. |
| `RYU_CONTROL_PLANE_URL` | Optional | - | Managed-cloud control-plane base URL (credits, fleet). Falls back to `RYU_SERVER_URL`. |
| `RYU_AUTH_BASE_URL` | Optional | - | Better Auth base URL used to verify node-user JWTs. Default: `RYU_BACKEND_URL`. |
| `BETTER_AUTH_URL` | Optional | - | Better Auth base URL (alias). |
| `RYU_MASTER_KEY` | Optional | - | Master key (base64/hex) encrypting secrets at rest. Default: derived local key. |
| `RYU_TEAM_ID` | Optional | - | Multi-tenant scoping for a managed/cloud node. |
| `RYU_PROJECT_ID` | Optional | - | Multi-tenant project scoping for a managed/cloud node. |
| `RYU_MANAGED_NODE` | Optional | - | Marks this as a managed cloud node (routes model traffic to the hosted fleet). |
| `RYU_EXEC_APPROVAL_MODE` | Optional | - | Tool-exec approval mode for sandboxed/agent command execution (e.g. `off`/`prompt`). |
| `RYU_AGENT_EGRESS_SSRF_GUARD` | Optional | - | SSRF guard for agent HTTP egress (on by default); allowlist relaxes it. |
