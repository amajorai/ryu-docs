## Verify identity before account-security changes

Changing a password or email address, managing passkeys, and unlinking an account require a fresh
identity check before the protected change. The full-page **Verify your identity to continue**
screen offers the methods available to that account: a current password or emailed link when 2FA is
off, or an authenticator code, emailed code, or backup code when 2FA is enabled. A successful check
is bound to the current session and authorizes one protected change; it is not remembered for
future sign-ins. The sign-in device-memory choice never bypasses an account-security check.
This applies to every way of changing a password, including a direct request to the
authentication API's change-password endpoint: the current password it asks for is checked as
well, but it never replaces the identity check, and with 2FA enabled only an authenticator
code, emailed code, or backup code satisfies it.

An emailed code or confirmation link works once. If the same code or link is submitted twice at
the same moment, only one submission succeeds and only one protected change is unlocked.

Password confirmation waits for the password verifier to succeed before opening a security
window. A wrong password keeps account changes blocked and counts toward the verification
attempt limit; it cannot change the password or revoke other sessions.

## Set a password or change your email address

An account that signs in with emailed codes or links can set a password after confirming by
emailed link. A new password follows the sign-up rules: 8 to 128 characters, with an uppercase
letter, a number and a symbol. Ryu never trims or normalizes a password. A password those rules refuse is turned away before your identity
check is used, so you can correct it and try again without verifying again, within the few minutes
the check stays valid. Setting or changing a password signs out your other sessions but keeps the
one you used, and you can then sign in with the password.

The same rules apply wherever you choose a password: signing up, setting one, changing it and
recovering it. Each of them gives the same message for a password the rules refuse. The change-password
forms in the web app, the desktop app, the browser extension and the command line, and the web
password-recovery form, check a new password against the rules before they send it.

To change your email address, Ryu mails a link to your current address and one to the new
address. The change is made only when both are confirmed, in either order, within 24 hours, and
you can cancel it until then. An address that belongs to another account is refused, and so is
another spelling of it that sign-in treats as the same mailbox, such as a Gmail address with dots
or a plus tag added. The confirmation is sent even if Ryu emailed you an identity-check link a
moment earlier.

A request that is turned away does not use up your identity check. An address that isn't valid, is
your current one or belongs to another account, or a new request while one is still pending, can be
corrected or retried without verifying again, within the few minutes the check stays valid. Only
the request that goes ahead uses the check.

After the change you sign in with the new address only: the old address no longer signs in, and
a sign-in code requested with it doesn't reach your account. If the confirmation emails can't be
sent, your address is not changed and you can start again straight away. If someone else takes
the new address before you confirm the last link, the change is cancelled, your address stays as
it was, and you can start again with another address.
