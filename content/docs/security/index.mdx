---
title: "Security"
description: "How Ryu isolates execution, governs commands, scrubs secrets, redacts outbound data, and locks down its network surface."
---

Ryu is local-first. Core listens on `127.0.0.1:7980` and the Gateway on `127.0.0.1:7981`, both on
loopback by default. Ryu treats the model as untrusted: it does not receive raw credentials, and its
commands, subprocesses, and outbound responses each pass through a separate control. Start with the
[trust model](/docs/security/trust-model), then open the layer you need.

<Callout type="info">
Each layer covers one boundary. The warning callouts on each page say what that layer does not cover.
</Callout>
