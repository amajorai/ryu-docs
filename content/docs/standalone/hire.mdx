<Callout type="warn">
  Ryu Hire is in early access and **not yet available**. You can't start a
  specialist run, see a run estimate, pay for a run, or get a run receipt
  today. Hire has no published price or API.
</Callout>

Ryu Hire is a planned managed service for people who need a specialist agent
for one-off work. You would choose a specialist from the Ryu Apps catalog,
review what it needs, and run it once without installing the agent.

## Planned flow

None of these steps work yet.

1. **Choose a specialist.** Find an agent by the outcome you need, such as
   reviewing a release or triaging an inbox.
2. **Review the run.** See the context and connections the run asks for, and
   what it will cost, before the work starts.
3. **Approve and run once.** The specialist works in a managed execution
   context and returns the result.
4. **Keep the record.** The run's inputs, output, and final status stay
   together.

## Pricing and access today

Hire has no published price, run estimate, or way to settle a run, so nothing
is billed for Hire.

- Manual prepaid credit top-ups enable Ryu-managed Gateway usage without a
  plan. That balance doesn't give you Hire access.
- Hire's pricing and eligibility will be published when it opens. The public
  Ryu Hire product page and pricing card appear only then.
- Ryu hasn't published a self-hosted Hire service or a Hire API contract.

## What to use now

If you need a specialist agent today, install it from
[Ryu Apps](/docs/extend/develop/extensions/ryu-apps) and run it in
[OS](/docs/surfaces/desktop/ryu-os) or [Agent](/docs/surfaces/desktop/agent).
Installed apps run with a persistent workspace and the normal permission and
audit path.
