Ryu Hire is the managed, pay-per-run service for one-off work. It turns the
Ryu Apps catalog into an action: choose a specialist, review what it needs,
and run it without installing the agent or adding another subscription.

## The Hire flow

1. **Choose a specialist.** Find an agent by the outcome you need, such as
   reviewing a release or triaging an inbox.
2. **Review the run.** Check the requested context, connections, and credit
   estimate before the work starts.
3. **Approve and run once.** The specialist works in its managed execution
   context and returns the result.
4. **Keep the receipt.** The run keeps its credit charge, inputs, output, and
   final status together.

## Service boundary

Hire is a hosted service boundary for a single specialist run. It does not
require a local install, a provider setup, or a recurring product subscription
for the pay-per-run flow. The same permission and audit expectations still
apply to the context and connections a run is allowed to use.

If a specialist becomes part of your everyday work, move the workflow into
[Ryu OS](/docs/surfaces/desktop/ryu-os) or [Ryu Console](/docs/surfaces/desktop)
for a persistent workspace and operator controls.

## When to use Hire

Hire fits a task that has a clear outcome and an occasional cadence. Use the
[Ryu Hire product page](https://ryuhq.com/products/hire) to review the product
and its current entry path. This guide does not describe a self-hosted Hire
daemon or an unpublished API contract.
