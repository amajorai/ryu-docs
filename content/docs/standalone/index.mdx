Ryu has a few services that do not need the Desktop surface to be useful. A
standalone service has its own process, API credential, and data directory. You
can run it beside Ryu, call it from another backend, or place a hosted control
plane in front of the same kind of contract later.

These services are separate from Core's local notification and workflow feed.
Core still owns `/api/notifications/*`, user identity, workflow
acknowledgements, desktop notifications, and node-local delivery.

## The service set

| Service | Use it for | Local contract |
|---|---|---|
| [Ryu Gateway](/docs/gateway) | Governed model, tool, and Skill calls | OpenAI-compatible and Ryu APIs |
| [Ryu Box](/docs/core/boxes) | Persistent isolated workspaces | Box-compatible `/v1` API |
| [Ryu Mail](/docs/standalone/mail) | Agent inboxes and email transport | Authenticated Mail API plus HMAC inbound webhook |
| [Ryu Notify](/docs/standalone/notify) | Durable product events and live event streams | `/v1/events` REST and SSE |

The local service commands prove process behavior, storage, authentication, and
the documented API. They do not by themselves prove Ryu-hosted billing, TLS
termination, DNS/MX configuration, provider deliverability, high availability,
or a production deployment.

## Use them together

Box remains the source of truth for workspaces. Mail remains the source of truth
for inboxes and messages. A small adapter can publish safe metadata from either
service to Notify:

```text
Agent Mail ──message metadata──▶ Ryu Notify ──REST/SSE──▶ your dashboard or agent
Ryu Box    ──lifecycle metadata─▶ Ryu Notify ──REST/SSE──▶ your dashboard or agent
```

The repository includes [the notification examples](/docs/standalone/notify#box-and-agent-mail-examples)
for this composition. The examples keep Mail, Box, and Notify credentials
separate and do not copy message bodies, command output, provider credentials,
or Box driver references into the event payload.

## Choose the boundary

- Use Core's notification API when the recipient is a verified Ryu user or a
  workflow needs to wait for a human acknowledgement.
- Use Notify when an external product needs its own tenant-scoped event inbox,
  cursor reads, and a live stream.
- Use Mail or Box for the domain state they own, then publish a metadata event
  if another product needs to react.
