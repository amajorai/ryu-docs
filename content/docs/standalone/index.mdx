Ryu's standalone services are for developers and operators who call Ryu from
their own backend or agent, without the Desktop app. Most have their own
process, credential boundary, and versioned HTTP contract; Managed Agents and
Messaging are hosted APIs on the Ryu control plane.

## Standalone pricing and access

Standalone means the service has its own runtime or API boundary. It does not
mean every hosted service has its own public price or a checkout without a
subscription. Hosted Box is on for every organization. The other hosted
services are in early access, and Ryu opens each one to a single organization
at a time. Features your plan includes, such as Agent Inboxes and managed
Gateway, are not affected. A self-hosted service runs on your infrastructure
and provider accounts and is never billed by Ryu.

| Service | Self-hosted | Ryu-hosted |
|---|---|---|
| [Gateway](/docs/standalone/gateway) | Available | Available, with plan-pool or prepaid usage |
| [Passport](/docs/standalone/passport) | Not yet published | Early access |
| [Connect](/docs/standalone/connect) | Not yet published | Early access |
| [Box](/docs/standalone/box) | The self-hosted service is not yet published | On for every organization |
| [Mail](/docs/standalone/mail) | Early access | Free baseline, larger quotas on eligible paid plans |
| [Messaging](/docs/standalone/messaging) | No self-hosted service | Early access, enabled per organization, at the [AWS End User Messaging price](https://aws.amazon.com/end-user-messaging/pricing/) with no markup |
| [Notify](/docs/standalone/notify) | Not yet published | Early access |
| [Sites](/docs/standalone/sites) | Early access, built from source (needs a ryu-sites release newer than 0.4.0) | No hosted service |
| [Hire](/docs/standalone/hire) | No | Early access, not yet available |
| [Managed Agents](/docs/standalone/managed-agents) | No | Preview, off until an organization turns it on |

Each service page has its own pricing section. [Metering Rates](/docs/billing/metering)
is the complete list of hosted service rates, and
[Plans & Pricing](/docs/billing/plans) covers plan prices, credit pools, and top-up
fees.

## How the boundaries fit

The services own different kinds of state. Core still owns user identity,
workflow acknowledgements, desktop notifications, and the local
`/api/notifications/*` feed.

| Service | Owns | Main contract |
|---|---|---|
| [Ryu Gateway](/docs/standalone/gateway) | Governed model, tool, and Skill calls | OpenAI-compatible and Ryu APIs |
| [Ryu Passport](/docs/standalone/passport) | Encrypted, tenant-separated agent identity connections | Passport `/v1` API |
| [Ryu Connect](/docs/standalone/connect) | MCP hosting, Skills, governed tools, and Composio edge | Connect `/v1` + `/mcp` API |
| [Ryu Box](/docs/standalone/box) | Persistent isolated workspaces | Ryu Box `/v1` API |
| [Ryu Mail](/docs/standalone/mail) | Agent inboxes, messages, and inbound mail | Authenticated Mail API plus per-inbox HMAC |
| [Ryu Messaging](/docs/standalone/messaging) | Leased phone numbers, WhatsApp senders, SMS, MMS, WhatsApp, and voice messages, and opt-out lists | `/api/messaging` REST plus signed webhooks |
| [Ryu Notify](/docs/standalone/notify) | Durable events, live activities, and channel delivery | `/v1/events`, topics, activities, destinations, and SSE |
| [Ryu Sites](/docs/standalone/sites) | Website projects, saved versions, deployments, and visitor records | Sites `/api/sites/*` API plus a separate visitor listener |
| [Ryu Hire](/docs/standalone/hire) | Planned one-off managed specialist runs (early access, not yet available) | None published |
| [Ryu Managed Agents](/docs/standalone/managed-agents) | Hosted agent sessions and their event log | `/api/v1/managed-agents` REST and SSE |

## Use services together

Each service remains the source of truth for its own domain. An adapter can
publish safe metadata to Notify without copying message bodies, command
output, provider credentials, or inbound secrets.

```text
Ryu Mail   ──message metadata──▶ Ryu Notify ──REST/SSE──▶ your dashboard or agent
Ryu Box    ──lifecycle metadata─▶ Ryu Notify ──REST/SSE──▶ your dashboard or agent
```

See [Notify streams and composition](/docs/standalone/notify-streams) for the
working examples and reconnect behavior.

<Callout type="warn">
Running a standalone service locally covers its process, storage, authentication,
and documented API. It does not give you hosted billing, TLS termination, DNS/MX
setup, provider deliverability, high availability, or a production deployment.
</Callout>
