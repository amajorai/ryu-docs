          status, headers and body, plus `x-ryu-task-id` and
          `x-ryu-task-status`. A task that is still queued or running answers
          409 `task_pending` with Retry-After; one that was canceled or expired,
          or has no answer, answers 409 `task_canceled`, `task_expired` or the
          code of its state.
