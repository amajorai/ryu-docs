          Replays the log after `after` (or `Last-Event-ID`), then tails it.
          Each log event is one frame with `id: <seq>`; `: keepalive` comments
          keep the connection open; a final `event: end` frame (no `id`) carries
          `{sessionId, status, headSeq, reason}`. Resume a dropped connection
          with `Last-Event-ID` and deduplicate on `seq`.
