      - content: >-
          Appends 1 to 8 user events: `user.message` events, one
          `user.interrupt`, or answers (`user.custom_tool_result` and
          `user.tool_approval` events) with different `toolUseId` values. A
          `user.tool_approval` answers a pending `agent.tool_approval_request`
          (anthropic backend only). Without an `Idempotency-Key` a retried call
          can append a duplicate message.
