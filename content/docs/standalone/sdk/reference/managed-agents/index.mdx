Ryu Managed Agents is a preview on the Ryu control plane. It is off until an organization owner or feature manager turns on Managed Agents in Organization > Features, and the deployment must also offer it: otherwise routes answer `503 managed_agents_disabled` or `403 feature_disabled`. Authenticate with a `ryu_` API key in `x-api-key` (or `Authorization: Bearer`); API keys need the `agents:read` scope to read and `chat:write` to run agents. Every non-2xx response uses the `ManagedAgentsError` envelope with `X-Request-ID`.
