      - content: >-
          What Notify POSTs to a `webhook` destination's `url` for each new
          event it matches. With a `secret`, verify `webhook-signature`
          (Standard Webhooks; a library needs `whsec_` plus the base64 of the
          secret) or `X-Ryu-Notify-Signature`, which signs only the body and has
          no replay protection. Attempts are durable and retried with backoff;
          see `GET /v1/deliveries`. `ntfy` destinations receive the event body
          as text with ntfy headers instead.
