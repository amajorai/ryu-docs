Ryu Messaging is early access on the Ryu control plane. Ryu enables it for each organization, and the organization's Ryu Messaging feature must also be on: until both are, organization routes answer `404 not_found` or `403 feature_disabled`. There is no self-hosted Messaging service. Authenticate with a `ryu_` API key in `x-api-key`; it needs the `messaging:read` scope to read and `messaging:manage` to send, buy numbers or change settings, and a personal key also sends `X-Ryu-Organization`.

Every send and number purchase holds the quoted ceiling on the organization's credit first and settles at the AWS price, so those writes require an `Idempotency-Key`. Prices are AWS End User Messaging's own, with no Ryu markup; this document states no prices. Every refusal is `{error, message, ...}` (`MessagingError`).
