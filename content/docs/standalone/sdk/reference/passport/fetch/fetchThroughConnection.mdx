          Performs one HTTPS request on the connection's exact domain and port
          443, attaching the stored credential where `credentialHeaders` or
          `headerTemplates` ask for it, and returns the redacted answer.
          Administration bearers may only `GET`; a runtime grant may use its
          `allowedMethods`, and a connection outside its profiles answers `404`.
          Never retried by `@ryuhq/services` on a network error or 5xx.
