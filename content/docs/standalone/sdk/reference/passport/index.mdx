Ryu Passport stores per-domain login state for agents and never returns it. Administration routes take the tenant administration token; `/v1/runtime/*` takes a profile-scoped runtime grant, and the fetch route accepts either. Passport is in early access: Ryu provisions hosted keys, and its source is not yet published. A local process binds `http://127.0.0.1:8093` by default. A client address that keeps presenting unknown tokens gets `429` with `Retry-After`.

Every error is JSON with `error` and a stable `code` (`PassportError`); a request whose Accept names `application/problem+json` gets RFC 9457 problem details. `POST /v1/connections` honours an optional `Idempotency-Key` header (see that operation). The MCP OAuth custody routes are a separate contract and are not in this document.
