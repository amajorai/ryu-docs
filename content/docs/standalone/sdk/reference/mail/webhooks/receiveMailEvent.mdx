          What Mail POSTs to a webhook's `url` for each subscribed event. Verify
          `webhook-signature` with the `whsec_` secret the create (or rotate)
          call returned before trusting the body, and reject stale timestamps.
          Each delivery repeats the id, timestamp and signature as `svix-id`,
          `svix-timestamp` and `svix-signature`; a webhook created before
          Standard Webhooks signing (`signatureScheme: legacy`) keys only
          `svix-signature` with the UTF-8 bytes of the whole secret. Mail makes
          up to three attempts and records each in `GET
          /api/mail/webhooks/{id}/deliveries`.
