      - content: >-
          Creates an inbox. Hosted Mail builds the address from `localPart` (or
          the name) on the shared domain or a verified custom domain, and
          refuses an address it cannot issue with an `address_*` code and
          `suggestions`; plans limit how many inboxes an account holds.
          Self-hosted Mail takes the full `address`. A repeat with the same
          `clientId` returns the existing inbox.
