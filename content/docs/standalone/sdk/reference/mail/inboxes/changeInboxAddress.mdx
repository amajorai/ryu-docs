          Hosted Mail. Moves an inbox to a new local part (or custom domain).
          The previous address keeps forwarding to the inbox for a while and
          cannot be claimed by another owner. An address changes at most once
          per cooldown window (429 `address_change_cooldown`), and an
          unavailable address answers an `address_*` code with `suggestions`.
