      - content: >-
          Upgrade to a WebSocket. Offer both `ryu-mail.v1` and
          `ryu-bearer.<token>` in `Sec-WebSocket-Protocol` (on one header line
          or several); the server selects `ryu-mail.v1`, so the token is never
          echoed back. Then send a JSON `{ eventTypes?, inboxIds? }` filter. The
          token must be hex or URL-safe (base64url without padding), because
          subprotocol names allow no other characters. Offering only
          `ryu-bearer.<token>` (the server then echoes it) is deprecated. A
          token in the URL (`?token=`) is refused with 401.
