      - content: >-
          Hosted Mail. Exchanges a node gateway key, a Ryu API key with
          `mail:read`, or a console session for a ticket that opens one `GET
          /api/mail/realtime` socket. Tickets are random 256-bit values, single
          use, valid for 30 seconds, and bound to the organization, the
          credential that minted them and `mail:read`. `protocols` is the
          `Sec-WebSocket-Protocol` list to offer. A credential holds at most 16
          unredeemed tickets and an organization (or personal account) at most
          64 (429 after that).
