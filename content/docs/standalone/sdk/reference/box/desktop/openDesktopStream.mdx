          A WebSocket upgrade carrying the Box desktop as raw RFB bytes (binary
          frames only). It does not take the bearer key: mint a single-use,
          30-second token with `POST /v1/boxes/{boxId}/access-tokens` and
          `scope: desktop`, then offer the `ryu.box.v1` subprotocol and the
          token's `ryu.token.<token>` subprotocol; a token in the query string
          is refused with `401 unauthorized`. The page's `Origin` header must be
          the `origin` the token was minted for (`403 forbidden`). A token works
          once (`401 token_replayed`), a Box takes at most 4 viewers at a time
          (`429 quota_exceeded`), and a stream ends after 12 hours. A view-only
          token drops keyboard and pointer input. A request that is not a
          WebSocket upgrade gets `426 invalid_request`; `426 not_supported`
          means the service runs without its Bun server. The organization must
          have credit (`402 insufficient_credits` on Ryu-hosted Box) before the
          upgrade.
