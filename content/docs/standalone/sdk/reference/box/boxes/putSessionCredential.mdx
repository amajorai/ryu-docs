          Writes a `gwb1` Box inference key and its Gateway URL to a private
          file inside a live Box, never to argv, environment, the create body or
          Box state. `expiresAt` must be in the future and at most 21 minutes
          ahead. A driver that cannot hold private files (the host-isolation
          development driver) answers `409 not_supported`.
