      - content: >-
          Requires an `Idempotency-Key` (at most 128 characters). A repeat with
          the same key and body returns the first Box with `200`, type
          `box.existing` and `Idempotent-Replayed: true`; the same key with a
          different body gets `409 idempotency_conflict`; and once that Box has
          been deleted, a repeat gets `409 idempotency_key_resource_deleted`
          (send a new key to create another Box). With `setup` or `repo` the Box
          comes back `202` and `provisioning`; poll `GET /v1/boxes/{boxId}`
          until it is `ready`. An active-Box or resource quota gets `429
          quota_exceeded` with `retryable: false` and no `Retry-After`; retrying
          does not fix it.
