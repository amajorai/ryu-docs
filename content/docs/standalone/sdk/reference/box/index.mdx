Ryu Box runs persistent Linux workspaces whose filesystem survives commands, stop and resume, and forks. Every `/v1` route takes the tenant key as `Authorization: Bearer <key>`. Ryu-hosted Box (`https://box.ryuhq.com`) is early access and enabled per organization by Ryu, which provisions the tenant keys; you can also run the service yourself, where it binds `http://127.0.0.1:8090` by default. Every non-2xx response uses the `BoxError` envelope with `X-Request-ID`; a request whose Accept names `application/problem+json` gets the same error as RFC 9457 problem details (`BoxProblem`).

A replayed create or fork answers `200` with `Idempotent-Replayed: true`. `429 quota_exceeded` is a quota, not a rate limit: Box sends no `Retry-After` or `RateLimit` fields, and `retryable` says whether waiting can help. The terminal, tunnel and desktop-stream routes are WebSockets, marked `x-ryu-websocket`.
