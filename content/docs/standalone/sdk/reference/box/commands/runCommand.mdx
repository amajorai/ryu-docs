          Waits for the command and returns its output (`200`). With `stream:
          true` the output arrives as a `text/event-stream` of `stdout`,
          `stderr` and a final `exit` event. With `background: true` the process
          starts and `202` returns at once; follow it through its logs. Not
          idempotent: a retried request runs the command again.
