          A WebSocket upgrade. Authenticate with the bearer key or an
          `access_token` from `POST /v1/boxes/{boxId}/access-tokens`. Send
          keystrokes as text or binary frames and
          `{"type":"resize","cols":120,"rows":40}` to resize; output arrives as
          binary frames, and a final `{"type":"exit"}` text frame ends it. A
          request that is not a WebSocket upgrade gets `400 invalid_request`
          ("WebSocket upgrade failed."); `426 not_supported` means the service
          runs without its Bun server and cannot open WebSockets at all. The
          organization must have credit (`402 insufficient_credits` on
          Ryu-hosted Box) before the upgrade.
