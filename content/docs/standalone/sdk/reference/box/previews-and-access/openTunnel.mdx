          A WebSocket upgrade carrying a raw TCP stream to `port` inside the
          Box, as binary frames. Authenticate like the terminal. A request that
          is not a WebSocket upgrade gets `400 invalid_request`; `426
          not_supported` means the service runs without its Bun server. The
          organization must have credit (`402 insufficient_credits` on
          Ryu-hosted Box) before the upgrade.
