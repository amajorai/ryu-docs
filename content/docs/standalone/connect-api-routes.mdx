Connect serves these routes. For setup, bearers, and request shapes, see the
[Connect API](/docs/standalone/connect-api).

## Routes

Native routes run inside Connect. Routes marked compatibility mode forward to an
operator-configured upstream only when native registrations are absent.

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/` | Describe the service; redirect only when `RYU_PRODUCT_DASHBOARD_URL` is set |
| `GET` | `/health` | Public lane, readiness, and version report |
| `GET` | `/v1/skills` | List hosted Skill metadata |
| `GET` | `/v1/skills/:id` | Read one hosted Skill |
| `GET` | `/v1/tools/search` | Search granted native tools; Core catalog in compatibility mode |
| `GET` | `/v1/tools/describe` | Describe one granted native tool; Core catalog in compatibility mode |
| `POST` | `/v1/tools/requests` | Ask for a tool Connect does not serve yet |
| `GET` | `/v1/balance` | What the tenant can spend on metered calls now, and its [tag budgets](/docs/standalone/connect-api-tags#tag-budgets) |
| `POST`, `GET` | `/v1/media` | Upload a [reference file](/docs/standalone/connect-api-media#reference-media), or list yours |
| `DELETE` | `/v1/media/:id` | Delete a reference file early |
| `GET`, `HEAD` | `/v1/media/files/:token` | Fetch a reference file; no bearer, until it expires |
| `GET` | `/v1/resources`, `/v1/resources/:id` | Your [vendor resources](/docs/standalone/connect-api-media#vendor-resources-on-ryus-key) on Ryu's key |
| `GET`, `HEAD` | `/v1/free/:endpoint/*` | A catalog [free route](/docs/standalone/connect-api-catalog#free-routes); no bearer, rate limited |
| `POST` | `/v1/exec/tool` | Execute a granted native tool; Gateway in compatibility mode |
| `GET` | `/v1/tools/composio` | The tenant's granted Composio slugs; Gateway in compatibility mode |
| `GET` | `/v1/composio/tools` | The tenant's granted Composio slugs (native only) |
| `POST` | `/v1/composio` | Native Composio execution; Gateway operation proxy in compatibility mode |
| `POST` | `/v1/composio/execute` | Native Composio execution with an `expectedAccountId` constraint |
| `GET` | `/v1/composio/actions` | Browse granted Composio action metadata |
| `GET` | `/v1/composio/actions/:slug` | Describe one granted Composio action |
| `GET` | `/v1/composio/connection` | Poll the tenant's assigned account |
| `GET` | `/v1/composio/accounts` | List the tenant's assigned account |
| `GET` | `/v1/composio/toolkits` | The tenant's assigned integration |
| `GET` | `/v1/composio/trigger-types` | Granted trigger types and configuration schemas |
| `POST` | `/v1/composio/link`, `/complete`, `/cancel`, `/revoke` | Account linking lifecycle (management bearer) |
| `GET`, `POST`, `DELETE` | `/v1/composio/triggers` and `/v1/composio/triggers/:id` | Trigger management (management bearer) |
| `POST` | `/v1/composio/triggers/:id/reconcile` | Reconcile one trigger generation (management bearer) |
| `POST` | `/v1/events/claim`, `/v1/events/renew`, `/v1/events/ack` | Lease and acknowledge delivered events |
| `GET` | `/v1/usage` | The tenant's Composio billing receipts for a whole-hour window ([usage](/docs/standalone/connect-api-usage)) |
| `GET`, `POST` | `/v1/tasks`, `/v1/tasks/:id`, `/v1/tasks/:id/result`, `/v1/tasks/:id/cancel` | [Async tasks](/docs/standalone/connect-api-tasks#async-tasks) submitted with `Prefer: respond-async` |
| `GET` | `/v1/tasks/webhook-secret` | The task webhook signing secret (management bearer) |
| `GET`, `HEAD`, `DELETE` | `/v1/spool/:token` | Download a [spooled answer](/docs/standalone/connect-api-tasks#spooled-answers) (no bearer), or delete it early (the owning tenant's bearer) |
| any | `/v1/relay/*`, `/v1/vendors/*`, `/v1/credentials/vendors` | Relay tools, vendor calls and vendor keys ([routes](/docs/standalone/connect-api-relay#routes)) |
| `GET`, `POST` | `/v1/capabilities`, `/v1/capabilities/:id`, `/v1/capabilities/:id/plan`, `/v1/capabilities/:id/call` | Routed capability calls ([routing](/docs/standalone/connect-api-routing)) |
| `GET`, `POST` | `/v1/capabilities/:id/arena`, `/v1/capabilities/:id/arena/plan` | [Comparison arenas](/docs/standalone/connect-api-routing#comparison-arenas) and their leaderboard |
| `GET`, `POST`, `PUT`, `DELETE` | `/v1/composed`, `/v1/composed/:id`, `/v1/composed/:id/plan`, `/v1/composed/:id/call` | [Composed tools](/docs/standalone/connect-api-composed) |
| `GET`, `POST`, `DELETE` | `/v1/reviews`, `/v1/reviews/:callId`, `/v1/reviews/summary/:endpoint` | [Reviews](/docs/standalone/connect-api-reviews) of your calls |
| `POST` | `/v1/admin/health/sweep` | Re-check stored keys now (operator bearer `RYU_CONNECT_ADMIN_TOKEN`) |
| `GET` | `/v1/admin/demand` | Tool requests and searches that found nothing, across tenants (operator bearer `RYU_CONNECT_ADMIN_TOKEN`; `since`, `surface`, `limit`) |
| `POST` | `/v1/webhooks/composio/:id` | Signed Composio webhook ingress (no bearer) |
| `GET` | `/v1/oauth/callback/:toolkit` | Provider redirect that finishes a natively served toolkit's sign-in (no bearer) |
| `GET`, `PUT`, `DELETE` | `/v1/oauth/clients`, `/v1/oauth/clients/:toolkit` | A tenant's [own OAuth app](/docs/standalone/connect-api-native-toolkits#link-through-your-own-oauth-app) for a native toolkit (management bearer) |
| `POST` | `/mcp` | Native Connect MCP server: Skill resources and granted tools |
| `POST` | `/mcp/meta`, `/mcp/meta/read` | Native Connect MCP server with the five meta tools, or the three read-only ones |
| `POST` | `/mcp/*` | MCP forwarding to the configured upstream (compatibility mode) |
