---
title: "Usage review"
description: "On-demand, privacy-controlled conversation and activity review"
---

Ryu can produce a bounded usage review from the existing Core conversation and activity stores.
The review is generated only when requested; it does not add telemetry, background capture, or an
LLM call. The response includes structured input that another local or remote narrative step can
consume.

## Privacy

Usage review is disabled by default. Enable it explicitly through
`PUT /api/usage-review/settings`. The settings can also exclude conversation ids, activity kinds,
activity sources, and message excerpts. Exclusions are applied before aggregation. Settings are
stored in Core's existing preferences database.

```json
{
  "enabled": true,
  "excluded_conversation_ids": ["conversation-to-leave-out"],
  "excluded_activity_kinds": ["meeting"],
  "excluded_activity_sources": [],
  "include_message_excerpts": false
}
```

Message excerpts are off by default. Topic labels may still use an existing conversation title or
the first user turn, but the review does not return full transcripts.

## Review endpoint

`GET /api/usage-review` accepts optional Unix epoch millisecond bounds:

- `from`: inclusive start; defaults to seven days before `to`
- `to`: exclusive end; defaults to now
- periods are limited to 90 days

The response contains period metrics, UTC daily buckets, topic summaries, workflow summaries,
activity counts, and non-scoring AI-fluency observations such as iterative refinement, tool
orchestration, workflow continuity, and multi-agent collaboration. These are evidence-based
signals, not productivity, identity, or emotional judgments.

The `narrative_input` field repeats the bounded structured data with a grounding instruction for a
later narrative model. Core does not invoke that model as part of this endpoint.
