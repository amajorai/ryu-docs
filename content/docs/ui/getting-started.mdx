## Installation

`@ryu/ui` is a workspace package inside the Ryu monorepo. Add it to the app that renders the
components:

```json title="package.json"
{
  "dependencies": {
    "@ryu/ui": "workspace:*"
  }
}
```

## Load the tokens

Import the global stylesheet once at the root of the app:

```tsx title="app/layout.tsx"
import "@ryu/ui/globals.css";
```

The stylesheet provides semantic color tokens, typography, radius, animation keyframes, and the
Tailwind theme extensions used by the components.

## Use a component

Components are tree-shakable and import from their own package path:

```tsx
import { Badge } from "@ryu/ui/components/badge";
import { Button } from "@ryu/ui/components/button";

export function Example() {
  return (
    <div className="flex items-center gap-2">
      <Badge variant="secondary">Ready</Badge>
      <Button>Continue</Button>
    </div>
  );
}
```

Open the [component catalog](/docs/ui/components) for each module's named exports and import path.

## Merge classes

Use `cn()` when a component or surface needs conditional Tailwind classes:

```tsx
import { cn } from "@ryu/ui/lib/utils";

<div className={cn("px-4 py-2", isActive && "bg-primary text-primary-foreground", className)} />;
```

## Tokens and themes

Use semantic utilities such as `bg-primary`, `text-muted-foreground`, and `border-border` instead
of hard-coded surface colors. See [Themes](/docs/ui/themes) for preset application and custom token
overrides.
