This tutorial adds `@ryu/ui` to an app in the Ryu monorepo, loads its tokens, and renders a first
component.

<Callout type="warn">
`@ryu/ui` is a private workspace package (`"private": true` in `packages/ui/package.json`). It is
not published to npm, so you can use it only from an app inside the Ryu monorepo.
</Callout>

## Installation

Add the workspace dependency to the app that renders the components:

```json title="package.json"
{
  "dependencies": {
    "@ryu/ui": "workspace:*"
  }
}
```

## Load the tokens

Import the global stylesheet once at the root of the app:

```tsx title="app/layout.tsx"
import "@ryu/ui/globals.css";
```

The stylesheet provides semantic color tokens, typography, radius, animation keyframes, and the
Tailwind theme extensions used by the components.

If the app uses PostCSS, re-export the Ryu UI PostCSS config:

```js title="postcss.config.mjs"
export { default } from "@ryu/ui/postcss.config";
```

## Use a component

Each component imports from its own subpath, so an app bundles only the modules it uses. The
`exports` map in `packages/ui/package.json` resolves extensionless subpaths such as
`@ryu/ui/components/badge` to their source files, and workspace apps map `@ryu/ui/*` to
`packages/ui/src/*` in the `paths` of their `tsconfig.json` for type checking. For example:

```tsx
import { Badge } from "@ryu/ui/components/badge";
import { Button } from "@ryu/ui/components/button";

export function Example() {
  return (
    <div className="flex items-center gap-2">
      <Badge variant="secondary">Ready</Badge>
      <Button>Continue</Button>
    </div>
  );
}
```

Open the [component catalog](/docs/ui/components) for each module's live preview, variants,
settings, named exports, and import path. Read [Using Ryu UI primitives](/docs/ui/primitives) for
the layer ownership and composition rules.

## Merge classes

Use `cn()` when a component or surface needs conditional Tailwind classes:

```tsx
import { cn } from "@ryu/ui/lib/utils";

<div className={cn("px-4 py-2", isActive && "bg-primary text-primary-foreground", className)} />;
```

`@ryu/ui/lib/utils` re-exports `cn` from the [`cn`](https://github.com/shadcn-ui/cn) package. It
joins conditional classes and resolves Tailwind conflicts.

## Reuse a component's variants

Most components export their variant definitions next to the component. Use them to apply a
component's style to a different element:

```tsx
import { buttonVariants } from "@ryu/ui/components/button";

<a className={buttonVariants({ variant: "outline", size: "sm" })} href="/docs/ui">
  Read the docs
</a>;
```

## Tokens

All colors are CSS custom properties. Tailwind utilities such as `bg-primary`,
`text-muted-foreground`, and `border-border` map to these tokens. Use them instead of hard-coded
surface colors.

| Token | What it controls |
|---|---|
| `--background` / `--foreground` | Page background and text |
| `--card` / `--card-foreground` | Card surfaces |
| `--primary` / `--primary-foreground` | Primary action color |
| `--secondary` / `--secondary-foreground` | Secondary surfaces |
| `--muted` / `--muted-foreground` | Subdued text and surfaces |
| `--accent` / `--accent-foreground` | Accent highlights |
| `--destructive` | Error and danger actions |
| `--success` / `--warning` / `--info` | Status colors |
| `--border` / `--input` / `--ring` | Borders, inputs, and focus rings |
| `--radius` | Base border radius |
| `--sidebar-*` | Sidebar tokens |

## Dark mode

Dark mode is class-based. The `.dark` block in `globals.css` redefines the tokens, so set the
`dark` class on `<html>` as shown here.

```tsx
<html className={isDark ? "dark" : ""}>
```

See [Themes](/docs/ui/themes) for preset application, runtime switching, and custom token
overrides.
