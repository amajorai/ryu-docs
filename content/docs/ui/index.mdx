Ryu UI is the shared interface layer for Desktop, Web, extensions, and Companion apps. It provides
semantic tokens, accessible controls, agent-facing surfaces, data views, motion primitives, and the
host-aware shell blocks that keep each surface consistent.

## Package map

| Area | Import | Purpose |
|---|---|---|
| Components | `@ryu/ui/components/*` | Controls, layout, dialogs, menus, data views, agent UI, and motion |
| Hooks | `@ryu/ui/hooks/*` | Shared state, input, viewport, upload, and popup behavior |
| Themes | `@ryu/ui/theme/*` | Presets, token application, and persisted preferences |
| Utilities | `@ryu/ui/lib/*` | Class merging, motion values, formatting, and shared helpers |
| Tokens | `@ryu/ui/globals.css` | Semantic colors, typography, radius, and animation tokens |

## Surface integration

Use `@ryu/blocks/companion/app-ui` for fixed app roles and `@ryu/app-host` for host bridges. Keep
domain state in the app that owns it; use the shared UI package for presentation and interaction.

```tsx
import { RyuAppShell } from "@ryu/blocks/companion/app-ui";
import { Button } from "@ryu/ui/components/button";

export function App() {
  return (
    <RyuAppShell>
      <Button>Save</Button>
    </RyuAppShell>
  );
}
```
