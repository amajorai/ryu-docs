Ryu UI (`@ryu/ui`) is the shared interface layer for Desktop, Web, extensions, and Companion UIs.
It provides semantic tokens, accessible controls, agent UI components, data views, and motion
primitives.

## Package map

| Area | Import | Purpose |
|---|---|---|
| Components | `@ryu/ui/components/*` | Controls, layout, dialogs, menus, data views, agent UI, and motion |
| Hooks | `@ryu/ui/hooks/*` | Shared state, input, viewport, upload, and popup behavior |
| Themes | `@ryu/ui/theme/*` | Presets, token application, and persisted preferences |
| Utilities | `@ryu/ui/lib/*` | Class merging, motion values, formatting, and shared helpers |
| Tokens | `@ryu/ui/globals.css` | Semantic colors, typography, radius, and animation tokens |

## Companion UIs

Companion UI authors compose these primitives inside the fixed app roles from
`@ryu/blocks/companion/app-ui` and the host bridges from `@ryu/app-host`. See
[Choose the layer](/docs/ui/primitives#choose-the-layer) for what each package owns.
