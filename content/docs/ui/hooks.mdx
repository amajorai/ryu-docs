This reference lists the React hooks that `@ryu/ui` exports. Each hook imports from
`@ryu/ui/hooks/<name>`.

## State, data, and refs

| Hook | Import | Purpose |
|---|---|---|
| `useDataGrid` | `@ryu/ui/hooks/use-data-grid` | Table state, editing, selection, ordering, filtering, and clipboard paste |
| `useDataTable`, `useDataTableState` | `@ryu/ui/hooks/use-data-table` | TanStack Table state for sorting, filters, column visibility, pagination, and row selection |
| `useQuery` | `@ryu/ui/hooks/use-query` | Run an async `queryFn` keyed by `queryKey`, with optional `refetchInterval` polling and `refetch` |
| `useControllableState` | `@ryu/ui/hooks/use-controllable-state` | Controlled or uncontrolled state with an optional change callback |
| `useDebounce` | `@ryu/ui/hooks/use-debounce` | Debounced values |
| `useDebouncedCallback` | `@ryu/ui/hooks/use-debounced-callback` | Debounced callbacks that clean up on unmount |
| `useLazyRef` | `@ryu/ui/hooks/use-lazy-ref` | Lazily initialized refs |
| `useCallbackRef` | `@ryu/ui/hooks/use-callback-ref` | Stable callback refs |
| `useAsRef` | `@ryu/ui/hooks/use-as-ref` | Convert a value to a ref |
| `useViewClock` | `@ryu/ui/hooks/use-view-clock` | Wall-clock ticks for time displays; pauses while the view is hidden unless `runInBackground` is set |
| `useConfirmDialog` | `@ryu/ui/hooks/use-confirm-dialog` | Await a confirmation while the modal stays in the caller's React tree |

## Input, viewport, and drag

| Hook | Import | Purpose |
|---|---|---|
| `useProximityHover` | `@ryu/ui/hooks/use-proximity-hover` | Hover activation near an element |
| `useHoverCapable` | `@ryu/ui/hooks/use-hover-capable` | Detect hover-capable input devices |
| `useIsTouchDevice` | `@ryu/ui/hooks/use-is-touch-device` | Detect touch devices |
| `useIsMobile`, `useIsCompact`, `useMediaQuery` | `@ryu/ui/hooks/use-mobile` | `useIsMobile` is `true` below 768px and `useIsCompact` below 1024px. `useMediaQuery` matches any media query |
| `useBadgeOverflow` | `@ryu/ui/hooks/use-badge-overflow` | Detect clipped badge content |
| `useSlider` | `@ryu/ui/hooks/use-slider` | Shared value and input handling for the motion range sliders |
| `useReorderShift` | `@ryu/ui/hooks/use-reorder-shift` | Drag-reorder preview where neighbors slide apart instead of a drop line |
| `useDropNudge` | `@ryu/ui/hooks/use-drop-nudge` | Drop preview that eases the hovered element and its neighbor apart |
| `useUploadFile` | `@ryu/ui/hooks/use-upload-file` | Track file upload progress |
| `useContrastInk` | `@ryu/ui/hooks/use-contrast-ink` | Pick the theme color with the larger luminance gap on a themed surface such as `--primary` |
| `useMounted` | `@ryu/ui/hooks/use-mounted` | Detect the client mount after SSR |
| `useIsomorphicLayoutEffect` | `@ryu/ui/hooks/use-isomorphic-layout-effect` | Use layout effects in the browser and effects during SSR |

## Shared preferences

These hooks subscribe to a preference stored in `localStorage`, so every component in the same
document sees the same value. `useFriendlyMode` and `useBotTerminology` return `[enabled, setEnabled]`.
The two blur hooks return a boolean; change them with `setPopupOverlayBlur` and
`setDialogOverlayBlur` from the same modules.

| Hook | Import | Default | Purpose |
|---|---|---|---|
| `usePopupOverlayBlur` | `@ryu/ui/hooks/use-popup-overlay-blur` | Off | Backdrop behind anchored popup surfaces |
| `useDialogOverlayBlur` | `@ryu/ui/hooks/use-dialog-overlay-blur` | Off | Dimmed, blurred backdrop behind dialogs, sheets, and drawers |
| `useFriendlyMode` | `@ryu/ui/hooks/use-friendly-mode` | On | Replace technical vocabulary with plain language |
| `useBotTerminology` | `@ryu/ui/hooks/use-bot-terminology` | On | Show "bot" in place of "agent" in interface copy |

## Example

```tsx
import { useDebouncedCallback } from "@ryu/ui/hooks/use-debounced-callback";
import { useIsMobile } from "@ryu/ui/hooks/use-mobile";

export function SearchInput({ onSearch }: { onSearch: (value: string) => void }) {
  const isMobile = useIsMobile();
  const search = useDebouncedCallback(onSearch, 300);

  return (
    <input
      onChange={(event) => search(event.target.value)}
      placeholder={isMobile ? "Search" : "Search documentation"}
    />
  );
}
```

## Data grid cell memoization

`DataGridCell` re-renders when either compared row's `original` value is null or undefined, so the
memo comparison does not throw on a nullish row. It does not validate row data. Column accessors and
cell renderers must still handle nullish rows themselves.

See the [component catalog](/docs/ui/components) for `DataGrid`.
