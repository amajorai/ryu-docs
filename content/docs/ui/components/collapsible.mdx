## Trigger and content treatments

Use `appearance` on `CollapsibleTrigger` to match its purpose: `provider-group` for a provider or agent model group, `permission-group` for grouped permissions, `skill-targets` for supported agent choices, `voice-transcript` for text history, `mission-summary` for a turn summary, or `gateway-hook` for hook details. The existing `settings-detail` and `tools-server` treatments remain available. Omitting `appearance` retains the ordinary trigger treatment.

On `CollapsibleContent`, choose `spacing="provider-fields"`, `spacing="model-list"`, or `spacing="permission-list"` for those settings groups; use `spacing="mission-events"` for a turn's event stack and `spacing="gateway-detail"` for hook metadata. The existing `spacing="settings-detail"` remains available. Keep open state, labels, children, actions, and outer layout at the calling site.

For a compact disclosure, set `spacing="compact"` on `Collapsible` to stack its trigger and content with a small gap, `appearance="specimen"` on `CollapsibleTrigger` for a rounded, muted trigger, and `spacing="compact"` on `CollapsibleContent` for a compact vertical stack. Omitting `spacing` on the root keeps its ordinary unstyled layout.
