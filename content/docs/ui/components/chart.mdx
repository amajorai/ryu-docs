## Series label lookup

Series labels are resolved from the outer payload first, then a nested payload. Each configuration lookup uses the same text value it checked, so a changing getter cannot replace that value during that lookup. If no text label is available, or its key has no configured entry, the lookup falls back to the original series key. Other tooltip processing, including custom formatters, can read the payload independently.
