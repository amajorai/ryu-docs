## Library and signal slots

| Slot and option | Purpose |
| --- | --- |
| `Card` appearance `library` | Flush library card with a muted hover surface. |
| `CardHeader` layout `library-row` | Horizontal library heading and actions. |
| `CardContent` layout `library-body` | Compact vertical library details. |
| `CardContent` layout `signal-grid` | Compact grid of health signals. |

These options belong to the named slots. Use the library header with its existing metric spacing, and the signal grid with its existing flush top spacing. Supply content, actions, and keyboard behavior at the calling site.

## Onboarding, widgets, and body slots

Use `appearance="onboarding"` on `Card` for the framed onboarding card, `"onboarding-setup"` for the unframed setup card, `"onboarding-success"` for its success frame, or `"memory-source"` for the muted source card. Existing border tone, elevation, size, inset, layout, and appearances remain available; caller classes follow the selected presentation.

Use `appearance="dashboard-widget"` for widget chrome or `"database-row"` for a database row card. Set `interaction="drag"` or `"resize"` for widget gesture feedback; `motionEnabled={false}` suppresses the active widget gesture feedback while retaining its ordinary hover and transition treatment. Database-row drag interaction dims the row. Keep drag handlers, widget controls, titles, and business data at the calling site.

On `CardHeader`, `appearance="bot-entry"` provides the centered bot entry header; `"message-review"` provides the separated message header. On `CardContent`, `inset="widget"` provides the widget body inset, and `"bot-entry"` provides the centered bot entry body. Use `layout="reflection-summary"` or `"memory-actions"` for those body arrangements, `status="muted"` for muted body text, and `typography="body"` for explicit body text sizing. Existing inset, spacing, layout, and top-spacing choices remain available.

On `CardFooter`, `appearance="onboarding-step"` adds the step footer separator; `"bot-entry"` provides the bot entry action footer. Use `spacing="choices"` for choice action spacing. Keep action alignment and wrapping at the calling site.

## Publisher health and body rhythm

Use `appearance="publisher-health"` on `Card` for the muted publisher health surface. On `CardContent`, `verticalInset="comfortable"` or `"generous"` adds vertical padding to the body, and `separators="rows"` draws a border between its direct child rows. These options combine with the existing inset, spacing, and layout choices; omitting them preserves the ordinary body.
