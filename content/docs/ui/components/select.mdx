Dropdown select with a ghost trigger by default and an optional shared full-window backdrop; its background appears on hover and while open. `SelectValue` measures its rendered label, fades only when the value is clipped, and auto-scrolls with a full-value tooltip on hover/focus. Pass `variant="default"` for the filled trigger. The module is part of the `@ryu/ui` package and is available on every surface that includes the package.
