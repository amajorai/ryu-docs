## Loader and recording geometry

Without `levels`, Wave renders five loading bars with the shared `loading-ui-wave` animation. With `levels`, it buckets the history into five live bars by default; a custom `barCount` produces bars that share the available width. Use a nonnegative integer `barCount` and finite amplitude samples. Invalid array lengths retain the native array-construction exception.

Use the container's classes to set the wave's footprint and text color. Bar geometry and animation use ordinary component CSS rules. More specific unlayered caller rules can override them, and important caller rules retain precedence. The loading animation stylesheet is shared rather than inserted as a `style` sibling at each render; structural selectors should target the wave's status element rather than depend on that removed sibling.
