## Input purposes

Use `variant="island-settings"` for a compact settings input, or `variant="picker-search"` for a borderless picker search input. These are presentation variants, not new sizes; labels, values, validation, and handlers remain at the call site.

| Variant | Purpose |
| --- | --- |
| `blog-search` | Tall, muted search field with leading search-icon space. |
| `store-search` | Compact transparent search field without a visible focus ring. |
| `pricing-amount` | Compact amount field with heading typography and tabular digits. |

These variants retain the native default size. The blog search field retains the native medium-screen text sizing; the store search field retains the native default text sizing. Keep width constraints, amount alignment, icon placement, labels, and handlers at the calling site.

## Agent profile fields

Use `variant="agent-profile-name"` or `variant="agent-profile-description"` for transparent, borderless profile fields without the ordinary focus ring. These variants retain the native medium-screen text sizing. Supply labels, values, disabled state, validation, and change handlers at the calling site.

## Field purposes

Use `purpose="space-title"`, `"space-row-title"`, `"picker-filter"`, `"picker-code-value"`, `"model-filter"`, `"model-identifier"`, `"worktree-branch"`, or `"numeric-setting"` for those field presentations. Set `typography="caption"` for caption text and `tone="background"`, `"muted"`, or `"observability-foreground"` for the corresponding tone. `leadingAdornment="search-icon"` reserves space for a search icon. Existing size, variant, and compact adornment options remain available; caller classes follow the chosen defaults. Picker and model purposes preserve inherited line height.

Use `purpose="command-search"` for a borderless, transparent, unpadded command search field with base-size text and without the ordinary focus ring; give its surrounding container a visible focus treatment. Use `tone="card"` to give the field the card background color. Keep placeholders, values, results, and keyboard handling at the calling site.
