## Presentation slots

Set `spacing` on `PopoverContent`: `inset` adds a compact content inset, while `menu` and `dense-menu` provide the menu recipes. Set `variant="marketplace-add"` on `PopoverTrigger` for the compact marketplace add action. These props belong to the named slots, not `Popover` itself.

## Content spacing

On `PopoverContent`, use `spacing="small-inset"` for a lightly padded picker, `spacing="choice-grid"` for compact choices, or `spacing="form"` for compact groups of fields. These options belong to the content slot. Omitting `spacing` preserves its ordinary treatment; supply fields, labels, actions, and validation at the calling site.

## Message and composer slots

Use `variant="message-read-receipt"` on `PopoverTrigger` for the reading-state control, and `appearance="message-read-list"` on `PopoverContent` for its reader list. For a composer menu, combine `appearance="composer-menu"`, `spacing="dense-menu"`, and `corners="rounded"` on the content slot. These options belong to the named slots; supply labels, reader data, actions, open state, width, and placement at the calling site.

## Trigger presentation

PopoverTrigger supports sessions, system-status, and startup-wallpaper presentation variants. They apply their authored control styles while preserving the native Base UI trigger, including render, disabled state, accessibility attributes, open state, and event handlers. Caller classes follow the recipe and can override its utilities. A className callback receives the native trigger state and its returned classes follow the recipe.
