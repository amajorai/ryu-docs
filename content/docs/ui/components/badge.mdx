## Typography purposes

Use `typography="price"` for heading-font prices with tabular numerals, or `typography="normal"` for regular-weight tag labels. The default typography and existing numeric/code choices remain available. Use `appearance="ryu-reviewed-card"` for a review label on a card, or `appearance="ryu-reviewed-hero"` on a dark hero.

## Badge label purposes

Use `typography="caption"`, `"micro"`, `"code-micro"`, or `"tabular"` on `Badge` for those label purposes. Code micro combines the micro size with a monospace face; tabular preserves the existing face. Use `size="download-label"` for a compact download stamp and `spacing="relaxed"` for wider icon or channel label spacing. Existing regular-weight typography and capitalized casing remain available. Keep dynamic business colors and positioning at the calling site.

## Casing, corners, and status tones

Use `casing="uppercase"` for uppercase labels alongside the existing capitalized casing. `corner="preview"` gives the bottom-left corner the theme's large radius instead of the label's full rounding, for a release-stage label such as a preview tag. Omitting either prop keeps the ordinary label shape and casing.

Use `tone` for a tinted status fill. `"informational"` and `"expanded"` use the info color, `"success"` and `"warning"` use their status colors, `"streaming"` pairs a chart tint with foreground text, `"active"` uses a primary tint, `"muted"` uses the muted surface, and `"disabled"` dims the muted text further. `tone="destructive"` keeps its destructive border and text. Tones only color the label; keep the state they describe and any accessible status text at the calling site.
