9 variants (default/mono/outline/secondary/ghost/destructive/link/loading/progress), 8 sizes. Direct text children get a measured trailing-edge fade when constrained, then gently auto-scroll and show the full value in a tooltip on hover/focus; use the exported `ButtonLabel` for a custom composed label. `loading` disables the button and places a spinner at the top-right; `progress` renders a fill bar. The module is part of the `@ryu/ui` package and is available on every surface that includes the package.
