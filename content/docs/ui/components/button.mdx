Variants default/mono/outline/secondary/ghost/ghost-muted/destructive/link/loading/progress; sizes include default, xs, sm, lg, and the icon-only icon/icon-xs/icon-sm/icon-lg. Direct text children get a measured trailing-edge fade when constrained, then gently auto-scroll and show the full value in a tooltip on hover/focus; use the exported `ButtonLabel` for a custom composed label. `loading` disables the button and places a spinner at the top-right; `progress` renders a fill bar. The module is part of the `@ryu/ui` package and is available on every surface that includes the package.

Use `radius="small"` for the compact corner treatment. Omitting `radius` keeps the ordinary button shape.

```tsx
<Button appearance="academy-reset" variant="ghost">Reset filters</Button>
```

Pair the service purposes with `size="sm"` and `variant="ghost"` for the service control treatment; its ordinary small text and icon sizing remain available. Retry and update colors also apply on hover.

Use `size="sm"` with the question navigation, question submission, and collapse purposes. Question navigation and submission retain the ordinary small text and icon sizing; `collapse-toggle` uses its smaller label treatment. Keep surrounding placement, including an answer row's negative margin, at the calling site.

Pair the goal purposes with `size="icon"` and `variant="ghost"`. They provide compact dimensions and subdued foreground colors while retaining the caller's accessible label, explicit glyph size, and action.

Use `answer-now` with `variant="link"` and the default size. Use `banner-customize` with `size="sm"` and `variant="ghost"` over the banner.

Use the diagram purpose with `size="icon"` and `variant="ghost-muted"`, and the table purpose with `size="icon-xs"` and `variant="ghost-muted"`. Keep the explicit expansion-control size and table pointer-event behavior at the calling site.

Pair `workbench-status` with `size="xs"` and `variant="ghost-muted"` for status-bar controls. Use `workbench-tab-close` with `variant="ghost-muted"`; its containing tab uses `group/workbench-tab` for the hover reveal, and keyboard focus reveals the control itself. Pair `worktree-handoff` with `variant="outline"`; choose its surrounding width and placement at the call site.

Pair `queued-message-action` with `size="icon"` and `variant="ghost"`; use `queue-send-all` with `size="sm"` and `variant="ghost-muted"`. Use `clipboard-format-copy` with `variant="ghost"`, and `composer-suggestion` with `size="sm"` and `variant="outline"`. Pair `plan-approve` with `size="sm"` and the default variant. Use `island-consent-declined` with `size="xs"` and `variant="ghost"` for a selected decline choice.

These purposes control presentation. Supply the action, accessible name, and disabled state for the workflow.

## Compact labels

Use `typography="compact"` with `size="sm"` for a smaller label while retaining the small button’s height, padding, gap, and icon treatment. Omitting `typography`, or using `typography="default"`, preserves the selected size and appearance’s ordinary text treatment.

```tsx
<Button size="sm" typography="compact" variant="ghost">Details</Button>
```

Use `typography="caption"` for the shared caption text treatment. Use `size="tiny"` for a shorter compact button with small text, compact padding, and the small button’s icon treatment. Omitting these props keeps the ordinary size and typography.

```tsx
<Button size="tiny" variant="ghost">Inspect</Button>
```

Typography selects a text treatment; it does not change the action, accessible name, or disabled state. Keep those at the calling site.

## Download and composer presentation

Use `spacing="regular"` for the regular icon-label gap, `"standard"` for a slightly wider gap, or `"comfortable"` for the widest gap, and `edge="joined"` to remove the right border when joining adjacent controls. Both options are available on `Button` and `buttonVariants`; choose the surrounding layout at the calling site.

Use `appearance="download-primary"` or `"download-primary-transparent"` for the primary download action, and `"download-trigger"` or `"download-trigger-transparent"` for its adjacent trigger. The transparent choices use a transparent background, a subtle border, and a slight backdrop blur. Download trigger appearances retain their dedicated dimensions for `size="sm"`, the default size, and `"lg"`.

Choose `appearance="extension-quick-send"` for the compact rounded quick-send control, `"store-engine-update"` for an update action with a primary foreground, `"settings-back"` for a compact back action, or `"managed-shader"` to inherit the hover foreground. Use `"goal-verdict-success"` or `"goal-verdict-warning"` for circular verdict controls. Use `"attachment-remove-visible"` or `"attachment-remove-hidden"` for the corresponding attachment removal visibility.

Use `appearance="composer-mode"` or `"composer-mode-active"` for a compact mode control with a top-aligned label; the active choice adds an accent background. Use `"composer-settings"` for muted compact settings text or `"composer-settings-foreground"` for its foreground-text and muted-hover treatment. Existing size, variant, loading, progress, and caller class overrides remain available. Supply accessible labels, actions, and disabled state at the calling site.
