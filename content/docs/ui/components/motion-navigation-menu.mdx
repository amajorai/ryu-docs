## Marketing navigation slots

Use `viewportAppearance="marketing"` on `MotionNavigationMenu` to choose a background surface without the default viewport blur or shadow. The separately rendered `MotionNavigationMenuViewport` accepts `appearance="marketing"` for the same surface. On `MotionNavigationMenuTrigger`, choose `tone="muted"` for a muted background or `"accent"` for an accent foreground. On `MotionNavigationMenuLink`, choose `spacing="compact"` for compact vertical padding or `"horizontal"` for its horizontal inset.

These options belong to their named slots. Existing value control, viewport content, event handlers, and render elements remain available. Caller classes follow the slot treatments; a supplied link render element retains its own class names after the link classes. Keep navigation destinations and application state at the calling site.
