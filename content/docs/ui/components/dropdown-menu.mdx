Dropdown menu with checkbox/radio items and an optional shared full-window backdrop; trigger and submenu labels share the clipped-label fade, hover/focus auto-scroll, and full-value tooltip. The popup morphs from its trigger with a reduced-motion fallback, and its top/bottom scroll fades appear only on edges with more content; short menus stay unmasked. The module is part of the `@ryu/ui` package and is available on every surface that includes the package.

## Picker slots

Use `layout="detail-stack"` on `DropdownMenuItem` for a stacked option label and description, and set `active` on the item to highlight the current choice. `DropdownMenuSubTrigger` accepts `spacing="comfortable"` or `spacing="spacious"`, `density="compact"`, and `tone="muted"` or `tone="foreground"` for its presentation. These options belong to the named slots; keep menu state and actions at the calling site.

Set `spacing="tight"` on `DropdownMenuItem` for a smaller gap between its content. On `DropdownMenuLabel`, use `variant="worktree-heading"` for the worktree heading treatment and `layout="icon"` for a label with an inline icon. Omit these options to retain the ordinary item spacing and label treatment.

## Trigger and action presentation

DropdownMenuTrigger supports account-row, sidebar-options, rounded-control, dialog-control, blurred-control, toolkit-picker, conversation-options, and organization-picker presentation variants. The account-row variant can use selected to highlight the selected account.

DropdownMenuItem supports composer-model, app-version, interface-level, layer-action, provider-heading, and node-choice purposes, selected for the selected row, and destructive tone for destructive action text. DropdownMenuSubTrigger supports layer-selection purpose and active highlighting in both menu and mobile drawer views.

Trigger className callbacks receive the native Base UI state; caller classes follow the selected recipe and can override its utilities. These presentation controls are consumed by their owning components and preserve native menu events, disabled state, inset behavior, and submenu navigation. Destructive tone follows the purpose recipe so it retains its text color when combined with provider-heading; caller classes remain last.
