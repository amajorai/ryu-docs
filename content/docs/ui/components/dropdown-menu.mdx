Dropdown menu with checkbox/radio items and an optional shared full-window backdrop; trigger and submenu labels share the clipped-label fade, hover/focus auto-scroll, and full-value tooltip. The popup morphs from its trigger with a reduced-motion fallback, and its top/bottom scroll fades appear only on edges with more content; short menus stay unmasked. The module is part of the `@ryu/ui` package and is available on every surface that includes the package.
