## Size and motion

Supply a finite, nonnegative `size` in pixels and a finite, positive `speed` in seconds. The eight loader variants retain their native animation targets, timer progression, and reduced-motion behavior. Dot and bar geometry and ASCII font size now use ordinary component CSS rules instead of inline drawing properties.

More specific unlayered caller rules can override that geometry; important caller rules retain precedence. Invalid sizes are unsupported and follow native CSS fallback. The `spinner` still uses its native SVG geometry.
