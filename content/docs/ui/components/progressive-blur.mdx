## Drawing and overrides

`height` accepts a valid CSS height, including `calc()` and live theme variables. `blurAmount` accepts a nonnegative CSS length. The fade follows `--background` unless `backgroundColor` supplies a valid CSS color. Top and bottom positions each retain four graduated backdrop layers.

The height, fade, and filter use ordinary component CSS rules. More specific unlayered caller rules can override them; important caller rules retain precedence. Supply valid prop values for predictable results. Invalid CSS values use the browser's fallback and can differ from the fallback of the previous inline declarations. The component retains the caller's class string without newly resolving utility conflicts.
