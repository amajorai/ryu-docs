title: "Editor"

---

The editor modules live under `@ryu/ui/components/editor`. The package exposes the editor shell,
composition helpers, plugin kits, and the UI elements used by editor nodes and toolbars.

## Start with the editor shell

```tsx
import { PlateEditor } from "@ryu/ui/components/editor/plate-editor";
import { EditorKit } from "@ryu/ui/components/editor/editor-kit";

export function DocumentEditor() {
  return <PlateEditor />;
}
```

Use `EditorKit` when creating a PlateJS instance that needs the shared plugin configuration. The
editor UI modules are organized by role under `@ryu/ui/components/editor/ui`.

## Editor modules

| Area | Import | Use |
|---|---|---|
| Editor shell | `@ryu/ui/components/editor/plate-editor` | Mount the shared editor |
| Composer | `@ryu/ui/components/editor/composer-editor` | Chat and prompt composition |
| Editor kit | `@ryu/ui/components/editor/editor-kit` | Compose the shared plugin set |
| Base kit | `@ryu/ui/components/editor/editor-base-kit` | Start from the base plugin set |
| Editor UI | `@ryu/ui/components/editor/ui/*` | Node renderers, toolbars, dialogs, and controls |
| Plugin kits | `@ryu/ui/components/editor/plugins/*` | Add focused editing capabilities |

Editor plugin kits are source modules. Compose only the capabilities a surface needs and keep the
host bridge or persistence adapter in the app that owns the document.
