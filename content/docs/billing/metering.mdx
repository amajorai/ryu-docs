title: "Metering Rates"
description: "Exactly what each unit of usage costs: models, tool calls, image and video, speech, and sandbox compute."
---

Every credit Ryu Cloud spends is metered against one of the units below. This page is the
reference for what each one costs; [Credits & AI Pools](/docs/billing/credits) covers the wallet
itself: pools, top-ups, spend order and auto-recharge.

<Callout type="info">
These rates apply to **Ryu Cloud** (managed inference). Running your own node with your own
provider keys bills you directly from that provider and Ryu meters nothing.
</Callout>

## Models

Model tokens are metered **at cost**. Ryu applies no per-token markup. You pay what the upstream
provider charges, and the platform's margin is taken once at deposit instead (see
[deposit fees](/docs/billing/credits#deposit-fees)).

Model prices vary per model and change when providers change theirs, so they are not reproduced
here. The model picker shows the current rate for each entry, and every charge appears on your
usage statement with the model that produced it.

## Agent tool calls

| Unit | Rate |
|---|---|
| Tool execution | **$0.299 per 1,000 calls** |

Billed at cost; this is the integration provider's own rate, passed through. A "tool call" is one
executed action against a connected integration, not a step of the model's reasoning.

## Image and video generation

Image and video are **metered on the compute time the generation actually used**, which the
provider reports back when the job completes.

| Unit | Rate |
|---|---|
| Generation compute | **$0.000975 per second** ($3.51/hour) |

Time spent queued before a machine picks the job up is **not** billed. Only the run itself is.

This is why the same model can cost very different amounts per image: a fast 2-second render and a
slow 30-second one are charged for what they used, not averaged. A short clip costs a fraction of
a long one.

<Callout type="info">
If a provider returns no timing for a completed job, Ryu falls back to a flat per-call rate:
$0.00195 for an image, $0.0585 for a video. These are estimates of a typical render and only apply
when there is nothing measured to bill from.
</Callout>

## Speech

Speech has no per-second measurement available from the providers, so it is billed per call.

| Unit | Rate |
|---|---|
| Text-to-speech (per synthesis) | **$0.000975** |
| Transcription (per request) | **$0.000975** |

## Sandbox compute

A sandbox is a real machine running your agent's code. It is metered **per second, only while it
is running**. A stopped sandbox costs nothing.

Charges are the sum of every resource the sandbox holds, per second:

| Resource | Rate |
|---|---|
| vCPU | **$0.0655** per vCPU-hour |
| Memory | **$0.0211** per GiB-hour |
| Storage (above the free allowance) | **$0.10** per GiB-month |
| Windows surcharge | **+$0.1114** per vCPU-hour |

The first **5 GiB** of sandbox storage is free; only usage above that is billed.

### GPU sandboxes

| GPU | Rate |
|---|---|
| H200 | **$5.90** per GPU-hour |
| H100 | **$5.13** per GPU-hour |
| RTX PRO 6000 | **$3.94** per GPU-hour |
| RTX 5090 | **$1.68** per GPU-hour |
| RTX 4090 | **$1.29** per GPU-hour |

GPU time is charged in addition to the vCPU, memory and storage of the same sandbox.

<Callout type="warn">
A sandbox bills for **wall-clock time while running**, not CPU time. An idle sandbox left open
still costs money. Set a per-run budget cap under **Settings → Billing → Spend controls** so a
looping agent cannot drain the wallet, and stop sandboxes you are not using.
</Callout>

## Managed cloud nodes

A managed node is a monthly subscription rather than metered usage, so it does not draw on
credits at all. Pro, Max and Teams each include one free node; larger instances are priced per
month from the live catalog when you pick one.

## What is never billed

- **Local models** on your own machine or your own node
- **Queue time** before a generation job starts running
- **Stopped sandboxes** — storage is billed while it exists, compute only while running
- **Failed requests** that returned no result

## Seeing what you spent

Every charge is written to your organization's usage statement with the model or resource that
produced it, what it was for, and when. Open it from **Settings → Billing → Usage** in the desktop
app, or from the Credits page on the web dashboard.
