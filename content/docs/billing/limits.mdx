<Callout type="warn">
  During the waitlist beta the desktop caps are off: the `billing.desktop_trial` rollout flag is
  off by default, so there is no tab or remote node limit. The desktop caps below apply once it
  is turned on. Hosted storage, mail, and Box limits apply now.
</Callout>

Numeric caps apply on Ryu's managed free path. A fully self-hosted deployment does not inherit
these commercial caps: the operator owns the machine and may set its own safety limits.

## Numeric caps

| Limit | Free (managed) | Teams | Business | Enterprise |
|---|---:|---:|---:|---:|
| Open tabs | **3** | Org policy | Org policy | Contracted |
| Agents created in the app | Unlimited | Unlimited | Unlimited | Unlimited |
| Spaces | Unlimited | Unlimited | Unlimited | Unlimited |
| Concurrent background runs | Unlimited | Unlimited | Unlimited | Unlimited |
| Eval runs / month | Unlimited | Unlimited | Unlimited | Unlimited |
| Space storage | **1 GB** | **50 GB** | **50 GB** | Contracted |
| Remote nodes | **1** | Unlimited | Unlimited | Contracted |
| Included cloud computers | None | **1** always-on server | **1** always-on server | Contracted |
| Running Ryu Boxes | **1** | **10** | **20** | Contracted |

The cloud-computer row describes capacity, not purchase permission; see
[Who can buy or upgrade](/docs/billing/cloud-computers#who-can-buy-or-upgrade).

Agents, simultaneous runs, and Spaces have no plan-based caps, including on the free desktop.
Managed AI still requires its execution entitlement and available credits, and runtime safety
settings can still restrict concurrency.

## Individual plans

Pro and Max are public individual managed plans when the individual shelf is available.

| Plan | Space storage | Running Ryu Boxes |
|---|---:|---:|
| Pro | **10 GB** | **2** |
| Max | **50 GB** | **4** |
| Desktop license | **20 GB** | **1** |
| A Major Pass | **1 GB** (the free baseline) | **1** |

Separately issued private individual plans keep the same personal quota boundary, fixed by the
pricing version recorded at subscription time. Which plans include a cloud computer is on
[Cloud Computers](/docs/billing/cloud-computers).

## Running Ryu Boxes

The Running Ryu Boxes cap counts the Boxes an organization has running, starting, or stopping at
once, including conversation session Boxes. Stopped Boxes do not count.

- A paid plan in its free trial runs **1** Box until the trial converts.
- A create or resume over the limit is refused until another Box stops.

See [Ryu Box pricing](/docs/standalone/box#ryu-capacity-pricing).

## Free local desktop features

Prompt Studio, evals, GraphRAG, the Companion overlay, and Gateway governance UI are free.
They require no desktop license or active trial. Model calls use your configured local model or
provider; managed AI still requires paid access and available credits. Gateway authorization and operator safety policies still apply.

## Desktop upgrade at the tab limit

On the managed free desktop path, opening a fourth tab offers the desktop license while keeping
your existing tabs available. The license unlocks unlimited tabs; it does not include managed AI,
monthly credits, or hosting.

## Teams seats

A seat is an organization member who can use the shared workspace. Seats are separate from the
desktop agent count, and cloud computers provide runtime capacity rather than seats.

- Teams and Business have a five-seat minimum.
- The shared AI-credit pool grows with the number of billed seats. Prices and pool sizes are on
  [Plans and Pricing](/docs/billing/plans#teams) and [Business](/docs/billing/plans#business).
- Private negotiated seats increase member capacity only.
- Enterprise capacity is written into the organization's agreement.

See [Teams seats](/docs/billing/seats) for seat lifecycle enforcement.

## What the caps mean

| Cap | What it counts |
|---|---|
| Open tabs | Simultaneously open desktop chat tabs |
| Agents | Agents created in the app; conversations are not counted |
| Spaces | Collaborative workspaces with shared context |
| Concurrent background runs | Agents that may run at once in the background |
| Space storage | Files, images, and indexes stored in Spaces |
| Remote nodes | Remote nodes connected to the desktop app |
| Included cloud computers | Managed runtime computers the plan includes for the organization |

Marketplace apps, plugins, skills, MCP servers, workflows, monitors, meetings, and their catalog
prices are not plan quotas. Free and paid listings pass the same signed-package and
server-lifecycle checks; a paid listing also requires a purchase or a plan that includes it.

The free baseline has no included monthly pool, but owners and admins can still buy prepaid
credits without a managed plan. Those top-ups use the base deposit fee, and automatic top-up
still requires an active managed plan; see [Credits](/docs/billing/credits). Enterprise limits
are set by contract.
