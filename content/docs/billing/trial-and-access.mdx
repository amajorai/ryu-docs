<Callout type="warn" title="Free during the beta">
  While Ryu is in its waitlist beta, the desktop trial is switched off. Every desktop runs
  free with desktop license allowances: unlimited tabs and remote nodes, no trial countdown,
  and no upgrade prompt. Managed inference, credits, and cloud computers still need paid
  access. The trial and free-tier caps described below are behind the `billing.desktop_trial` rollout
  flag, which is off by default, and apply once the beta ends.
</Callout>

Every fresh install gets a **7-day local desktop trial** of desktop license allowances,
including unlimited tabs. After it ends, the signed-in free path returns to three tabs.
The upgrade prompt is dismissible; local desktop features remain available.

Prompt Studio, evals, GraphRAG, the Companion overlay, and Gateway governance UI are free,
with no license or trial requirement. Managed inference and hosted services retain separate
paid access and usage checks.

## The trial

- **Length** - 7 days from first launch
- **What you get** - desktop license allowances, including unlimited tabs
- **What it does not include** - managed inference, credits, and cloud computers. Those
  are billed monthly through an individual Pro/Max plan or a shared Teams,
  Business, or Enterprise agreement, never through this desktop trial.
- **No card needed** - the trial starts automatically on first launch
- **After expiry** - the paywall appears. You can dismiss it to continue with free local desktop features.

## Desktop onboarding offer

Eligible workspace owners preview the selected task before seeing a managed subscription offer.
A preview does not execute work or use credits. Connecting an app requests its access level first.
Ryu-managed activation requires subscription confirmation and a fresh entitlement check before
creating the task; an existing subscription can cover it.

**Choose my own model** opens an editable draft without automatically sending it. Local hardware
and your own provider remain subject to their normal configuration and usage costs. A desktop
license unlocks unlimited tabs, not managed inference or hosted computers.

## Access decision logic

The desktop app resolves access in this order:

1. **Active subscription** → Pro, Max, Teams, or Business unlocked, managed inference enabled
2. **Valid desktop license key** → desktop license allowances unlocked, no managed inference
3. **Free during beta** → desktop license allowances unlocked, no trial clock, no managed pool. This is on while the beta runs.
4. **Inside the 7-day local desktop trial** → desktop license allowances unlocked, no managed pool
5. **Offline + fresh cache** → ride the cached entitlement (offline grace window)
6. **Otherwise** → Upgrade prompt (free local desktop features stay usable)

## The paywall

The paywall is **soft**: it's a dismissible modal, not a hard block. Dismissing it keeps local/BYOK chat, agents, tool calling, MCP, skills, Prompt Studio, evals, GraphRAG, Companion, and Gateway governance UI usable. The managed free path applies the numeric starter caps documented in [Free-tier limits](/docs/billing/limits); a self-hosted deployment remains operator-controlled.

The paywall shows:

- Trial countdown (if still in trial)
- Current access state (subscription, license, trial, locked)
- Upgrade / manage actions

## Offline grace

When the control plane is unreachable (network down, server error), the app uses a **cached last-good entitlement** for up to **7 days**. This keeps a paying user from being locked out by a network outage.

The cache stores:

- `proUnlocked` - the resolved Pro state at cache time
- `managedInference` - whether managed inference was enabled
- `marketplaceApps` - whether the entitlement included Marketplace apps
- `plan` - the plan id (if any)
- `cachedAtMs` - when the cache was written

After 7 days offline, the cache expires and the app falls back to free local desktop access.

## Self-hosted Ryu Server

The commercial access model applies to Ryu's managed path. A self-hosted Ryu server
is the customer-operated Core + Gateway runtime and does not require a Ryu
account or Ryu-operated backend:

- **No Ryu commercial caps** - the operator controls local limits and policy.
- **Local/BYOK inference** - use local models or provider keys owned by the operator.
- **No managed inference** - Ryu's hosted provider fleet is not part of this path.
- **CLI/SDK access** - connect directly to the server without the account-backed product shell.

The ordinary Desktop build is an optional client (Bot, OS, and Agent) and currently starts
behind an account session. It therefore needs a compatible Better Auth/control
plane for a fresh Desktop login, even when the active server is self-hosted. A
Private/Full Ryu Deployment can provide that control plane; a backend-free
deployment should use the CLI/SDK until a local-only Desktop identity mode is
introduced.

## License key validation

Desktop license keys are validated via `POST /api/billing/license/validate`. The
key is stored locally and checked on app launch. Only a key the license provider
does not recognize is reported as invalid. If the provider cannot answer (an
outage or a network failure), the check reports that validation is unavailable
rather than that the key is invalid. A valid license:

- Lifts the desktop tab cap and other license-based numeric allowances
- Does **not** enable managed inference
- Does **not** add hosted mail; the account keeps the free [Agent Inboxes](/docs/billing/agent-inboxes) baseline
- Includes one year of app updates per lifetime purchase. A repeat purchase adds another year to
  the end of the current window
