## What it does

Rust language server (rust-analyzer) for the ryu agent: definitions, references, hover, symbols, implementations, call hierarchies and diagnostics after every edit. You install rust-analyzer; the plugin ships config.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | limited |
| cli | full |

## Permissions

**Grants:** `pi:extension`

Requires Ryu >=0.1.0.
