## What it does

`@ryu/functiongemma` downloads the pinned 270M [Google FunctionGemma](https://huggingface.co/google/functiongemma-270m-it)
checkpoint into a private plugin runtime (about 575 MB for the model and tokenizer,
plus the CPU inference dependencies). Inference runs on the node that runs Core, and the
sidecar supports Python 3.11 through 3.14 there.

The Hugging Face repository is gated. First accept Google's Gemma terms on Hugging Face,
then save a Hugging Face token in the **Hugging Face** card under **Integrations** in the
Gateway settings (open them from the node selector) before you enable the plugin. Ryu uses
that token only for Hugging Face metadata and file downloads. It does not accept the license on
your behalf or pass the token to the plugin sidecar.

Use [Marketplace](/docs/surfaces/desktop/user-guide/marketplace) to install and
enable the plugin and review its requested permissions.

After enabling, select **FunctionGemma · 270M** under **Settings → Plugins → Shadow →
Computer use → Local model plugin**. Text entry still uses Shadow's configured text model.

<Callout type="warn">
  FunctionGemma is an experimental base checkpoint, not a Shadow-specific fine-tune. It can choose
  only the supplied operation and target ids, and Shadow validates the decision and rechecks the
  live target before sending input. For reliability-critical tasks, prefer a planner validated for
  your workflow.
</Callout>
