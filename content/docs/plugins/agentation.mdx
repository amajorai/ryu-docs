## What it does

Visual feedback for coding agents. Agentation connects UI annotations from a running web app to an MCP server so agents can read, acknowledge, resolve, dismiss, and reply to feedback without copy-paste.

## What it exposes

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`agentation`** - Agentation - receive and act on UI annotations from the Agentation toolbar. Exposes tools to list sessions, read pending feedback, acknowledge or resolve annotations, reply to threads, and watch for new annotations. Launched via `npx -y agentation-mcp@1.2.0 server`; requires Node.js and an Agentation toolbar connected to the local server.
