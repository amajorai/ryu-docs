## What it does

[Agentation](https://www.agentation.com/) turns feedback on a running web page
into structured annotations containing the selected element, source location,
component context, styles, and the user's request. An agent can read and act on
that feedback without copy-paste.

## MCP server

Ryu installs and enables **`@ryu/agentation`** by default. Core starts the local
server lazily with:

```bash
npx -y agentation-mcp server
```

The tools are exposed under the `agentation__` namespace. Node.js is required;
the Agentation toolbar must be connected to the local server (port `4747`) for
sessions and annotations to be available.

## Permissions

**Grant:** `mcp:agentation`
