## What it does

Run a validated, bounded fan-out of clean-context delegates.

Inline delegates are prompt-only. A requested `tools` list is rejected because it
cannot create a real allowlisted tool loop; use a registered `agent_id` when a
delegate must execute tools.

## What it exposes

### Tools

### `workflow.run` - workflow.run

Run several independent delegate tasks concurrently and return their results.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `tasks` | array | yes | Independent delegate tasks to run. |
| `max_concurrent` | integer | no |  |
| `wall_time_secs` | integer | no |  |
| `max_tokens` | integer | no |  |

## Permissions

**Grants:** `tool:execute`, `hook:run-agent`
