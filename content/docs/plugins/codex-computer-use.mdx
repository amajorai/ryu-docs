## What it does

Drives OpenAI's signed Codex Computer Use engine, the one the ChatGPT macOS app installs, as an optional provider for Ryu's swappable `computer.control` layer. Actions go to one target app in the background, through its accessibility tree and screenshots, without moving your cursor. Ryu launches it through the pinned `codex-computer-use-mcp@0.5.2` stdio bridge.

<Callout type="warn">
  Experimental and unofficial. It requires macOS, Node.js 22+, and the ChatGPT app with Computer Use set up; Ryu does not install ChatGPT. A ChatGPT update can break it.
</Callout>

## What it exposes

### Capabilities

- **Computer** - capability `computer.control`
  - Target: local-machine
  - Verbs:
    - `computer.capture` -> `codex_cu.get_app_state`
    - `computer.click` -> `codex_cu.click`
    - `computer.type` -> `codex_cu.type_text`
    - `computer.key` -> `codex_cu.press_key`

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`codex_cu`** - Unofficial stdio bridge to the Codex Computer Use engine that the ChatGPT macOS app installs. It exposes the ten official methods as typed tools (list_apps, get_app_state, click, perform_secondary_action, set_value, select_text, scroll, drag, press_key, type_text) plus computer_use_status. It only runs OpenAI-signed binaries (Team ID 2DC432GLL2) and runs no model of its own. Requires macOS, Node.js 22+, and the ChatGPT app with Computer Use set up; Screen Recording and Accessibility permissions still apply.
