## What it does

Start a private temporary chat that stays in the current tab and leaves no conversation history, drafts, presence, or reactions behind. After the chat has messages, **Save chat** promotes the in-tab transcript into an ordinary saved conversation if you change your mind.

Temporary chats exclude personalized memory by default. When the Memory plugin is enabled, the
composer **+** menu exposes **Use memory in temporary chat**. Turning it on allows this temporary
chat to read existing personalized memories, auto-recall, and user personalization for its replies;
the chat and its new turns are still not saved to history or written back to memory.
