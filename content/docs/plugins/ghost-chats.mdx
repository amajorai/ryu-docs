## What it does

Temporary Chats adds a **Temporary chat** toggle to the composer’s **+** menu. A temporary chat
stays in the current tab and uses the host's non-persistent lifecycle: it does not create
conversation history, long-term memory, drafts, presence, or message reactions.

The composer is visibly marked while the privacy boundary is active. Turning the toggle off returns
to the normal chat lifecycle; it does not convert earlier temporary turns into a saved transcript.

## Important distinction

This plugin is `@ryu/ghost-chats`. It is separate from `@ryu/ghost`, the computer-control plugin.
Disabling Temporary Chats removes the temporary-chat toggle without changing computer control.
