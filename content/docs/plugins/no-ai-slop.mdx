## What it does

Bundles the `no-ai-slop` editing skill and runs it on every finished answer: a separate reviewer with a fresh context reads the reply, names the AI-slop patterns it finds, and the agent rewrites the answer to fix them. One pass by default, configurable up to twelve, or set to 0 and trigger it by hand from the composer '+' menu. A clean answer is left alone silently.

## Permissions

## UI it contributes

### Composer controls

- **No AI slop** - Check this turn's answer for AI-slop patterns, even when automatic passes are set to 0. (type: toggle)

### Settings tabs

- **No AI slop** (fields: Automatic review passes (number), What a review does (select))

### Turn hooks

- **no-ai-slop.review** (on: `post_assistant_turn`)
