## What it does

Independent web search via the Brave Search API (https://brave.com/search/api/), exposed as one declarative HTTP tool. Provides the swappable `web.search` layer, so selecting it in the layer picker re-points the stable `web__search` tool at Brave's own crawled index without changing what agents call. Brave is search-only: it deliberately declares neither `web.extract` nor `web.crawl`. Requires a BYOK Brave Search API key.

## What it exposes

### Tools

### `brave__search` - Brave Web Search

Web search over Brave's own independent index. Returns ranked results with titles, URLs, and description snippets. This is a GET endpoint, so every argument is sent as a query parameter. Requires RYU_BRAVE_API_KEY.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `q` | string | yes | The search query. Brave accepts at most 400 characters and 50 words. |
| `count` | integer | no | Results per page. Brave's own maximum is 20, which is also its default. |
| `offset` | integer | no | Zero-based page offset (Brave's maximum is 9). |
| `country` | string | no | Two-letter country code to target results at (Brave defaults to US). |
| `search_lang` | string | no | Language code to filter result content by (Brave defaults to en). |
| `safesearch` | string (one of: off, moderate, strict) | no | Adult-content filter (Brave defaults to moderate). |
| `freshness` | string | no | Restrict results by age: pd (past 24h), pw (past 7 days), pm (past 31 days), py (past year), or an explicit YYYY-MM-DDtoYYYY-MM-DD range. |
