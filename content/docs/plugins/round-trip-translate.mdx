## What it does

Rewrite text by translating it through a pivot language and back with Google Cloud Translation, after removing invisible Unicode characters. Requires your own Google Cloud Translation API key; the result can change meaning and should be reviewed.

## Using it

1. Create an API key for a Google Cloud project with the Cloud Translation API
   enabled, then add it under **Settings → Round-Trip Translate**. Google bills
   Cloud Translation usage to that project.
2. Ask an agent to round-trip some text, for example "round-trip this through
   Japanese and back". The skill removes invisible characters, translates the prose
   to each pivot language and back, and leaves code, URLs, and paths untouched.
3. Review the result. Translation can change meaning, tone, terminology, and
   formatting. The plugin does not claim any effect on AI-text detectors or
   watermark checks.

To strip hidden characters without translating, ask the agent to clean the text.
This uses only `round_trip.clean_text` and sends nothing to Google.

## What it exposes

### Tools

### `google_translate.translate` - Google Translate

Translate text with Google Cloud Translation (Basic, v2). Returns data.translations[].translatedText and, when source is omitted, detectedSourceLanguage. Requires a Google Cloud Translation API key in the plugin settings.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `q` | string | yes | The text to translate. |
| `target` | string | yes | Target language code, for example en, de, or ja. |
| `source` | string | no | Source language code. Omit to let Google detect it. |
| `format` | string (one of: text, html) | no | Input format. Defaults to text. |

### `round_trip.clean_text` - Clean Invisible Characters

Remove invisible Unicode characters (zero-width characters, byte-order marks, soft hyphens, bidirectional controls, tag characters) and replace unusual space characters with ordinary spaces. Returns the cleaned text and per-kind counts.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `text` | string | yes | The text to clean. |
| `keep_joiners` | boolean | no | Keep zero-width joiners and non-joiners, which emoji sequences and some scripts (Persian, Indic) need. Defaults to false. |
