## What it does

Auto-renames a chat as soon as the first reply lands, then again after every N completed assistant turns (default 5), using a side model - and keeps a Core-side history of the names it chose so you can see how a conversation drifted. Enablement, the first-turn rename, frequency, and the model to use are all settings.

## Manual titles and failed renames

- **Automatic naming** never replaces a title you set yourself. If the model cannot produce a
  title, the automatic pass skips that turn silently and tries again on a later one.
- **Rename with AI** replaces any title, including one you set yourself, and the new title is then
  treated as yours. If the model cannot produce a title, it reports the failure and leaves the
  current title unchanged.

Core saves a title and its title-history entry together. If either write fails, the previous title
and history stay unchanged. Retry the rename after the storage error is resolved.
