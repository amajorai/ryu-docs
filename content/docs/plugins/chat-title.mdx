## What it does

Auto-renames a chat after the first reply and after every N completed assistant turns, five by default, using a side model. Core keeps a history of the chosen names so you can see how a conversation changes. Enablement, the first-turn rename, frequency, and model are configurable settings.

## Permissions

**Grants:** `hook:side-model`, `conversation:set-title`, `preferences:read`, `hook:run-self`

## UI it contributes

### Settings tabs

- **Chat titles** (fields: Auto-rename chats (toggle), Rename after the first reply (toggle), Rename every N turns (number), Title model (model_picker))

### Context menu items

- **Rename with AI** (anchor: conversation, capability: `hooks.run`)

### Turn hooks

- **chat-title.rename** (on: `post_assistant_turn`)
