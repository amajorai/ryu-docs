## What it does

Side Chats contributes `/btw <question>`. The side model receives a bounded copy of the visible
main-chat transcript, including the latest in-flight text, so it can answer a focused question
without adding another turn to the main transcript.

The answer is a dismissible side chat tied to its parent conversation. Re-open it from the Context
rail or by expanding that conversation in the desktop sidebar. The sidebar keeps saved side chats in
a connected branch-style list with the question, a short answer preview, and relative age. The side
model has conversation context but no tools, so a side chat is useful for clarification, critique, or
a quick explanation rather than for changing the workspace. When the side chat is shown in a compact
desktop surface, it uses the same transcript, mention-token, directory-menu, and preview-rail
primitives as the main chat; the no-tools boundary is unchanged.

## Settings

Choose the side-question model and reasoning effort in Settings with `btw-model` and `btw-effort`.
The transcript sent to the side model is bounded by the host.
