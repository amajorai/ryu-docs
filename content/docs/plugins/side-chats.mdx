## What it does

Ask focused questions about the current conversation without adding another turn to the main transcript, then keep the answer as a recoverable side chat.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | limited |
| cli | full |

## UI it contributes

### chat features

- **/btw**

### selection actions

- **Ask in side chat**
- **Explain**

### Slash commands

- **/btw** - Ask a quick side question using the current main-chat context

## Engine requirement

Requires Ryu >=0.1.0.
