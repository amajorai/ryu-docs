## What it does

Side Chats lets you ask a quick question about the current chat without adding a turn to the main transcript. Successful answers can be reopened from the conversation's **Side chats** list.

## Ask a side question

- Type `/btw` followed by a question in the main composer. `/btw` by itself does not send a request.
- Or highlight text in a message. A small note box opens right away. Type a question or instruction if you want, then choose **Ask in side chat**, **Explain**, or **Fix grammar**. The note is optional.

A side question uses the active model. It includes the selected text, your note if you wrote one, and the main-chat context.

If a request is denied or fails, the side-question dialog shows the error. Ask again in its composer to retry explicitly.

## What context is sent

In Desktop, a side question includes the latest 30 nonempty user and assistant text messages currently loaded in the main chat. Tool-only messages do not count toward that limit. Context is captured when you ask, including the latest text of a reply that is still streaming.

**Fix grammar** sends only the selected passage to the active model, without the main-chat transcript. The correction appears in the side chat for review. The original message is not changed.

## Stop and dismiss

**Stop** cancels the pending request and keeps the question visible so you can ask again. **Dismiss** closes the dialog and cancels its pending request. A late result cannot reopen a dismissed dialog or replace a newer side question.

Changing the conversation, node, or node credentials discards the previous side question.

Client cancellation does not guarantee that a remote model stopped processing, or that the service did not already save an answer. Check the conversation's **Side chats** list for saved answers.
