## What it does

Web search and page fetch via the DeepSeek Search / Fetch API (https://api-docs.deepseek.com/guides/search), powered by DeepSeek's in-house search engine and exposed as two declarative HTTP tools. Provides the swappable `web.search` and `web.extract` layers, so selecting it in the layer picker re-points the stable `web.search` / `web.extract` tools at DeepSeek without changing what agents call. Billed per successful request; requires a BYOK DeepSeek API key.

## What it exposes

### Tools

### `deepseek.search` - DeepSeek Search

Web search on DeepSeek's own engine. Returns reranked results with a title, URL, short snippet, a longer model-readable summary, a 0-3 rerank_score, a 0-4 authority tier, and the publication date. The query accepts site:, -site:, "phrase", -term, lang:, after: and before: operators. Billed per successful request. Requires RYU_DEEPSEEK_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | yes | The search query, 1-128 characters. Supports site:, -site:, "exact phrase", -term, lang:zh,en, after:YYYY-MM-DD and before:YYYY-MM-DD operators. |
| `count` | integer | no | Number of results to return (default 10). |
| `ori_question` | string | no | The user's original question, 1-128 characters, used to improve ranking. |
| `need_content` | boolean | no | Also return each page's full content (default false, which leaves content empty). |

### `deepseek.fetch` - DeepSeek Fetch

Fetch one web page and return its title and content as markdown. Success depends on the target site's availability and access policy. Billed per successful request. Requires RYU_DEEPSEEK_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | The http(s) URL of the page to fetch, without embedded credentials (up to 8192 characters). |
