## What it exposes

### Capabilities

- **Computer** - capability `computer.control`
  - Target: local-machine
  - Verbs:
    - `computer.capture` -> `ghost.ghost_annotate`
    - `computer.click` -> `ghost.ghost_click`
    - `computer.type` -> `ghost.ghost_type`
    - `computer.key` -> `ghost.ghost_hotkey`
    - `computer.scroll` -> `ghost.ghost_scroll`
    - `computer.focus_app` -> `ghost.ghost_focus`

### MCP server

- **`ghost`** - Ghost - desktop automation (29 tools: screen perception + input control). Cross-platform (Windows, macOS, Linux); install the `ghost` sidecar to enable. Unavailable until installed.

### Visible computer-use actions

When Ghost is running with Ryu Island, pointer actions can show a click-through
cursor overlay at the exact target. The overlay eases a small monochrome pointer
into place, keeps the marker semi-transparent so it cannot be mistaken for the
user's pointer, emits a small click ripple, and floats a short intent label beside
it such as `Click “Send”` or `Clicking`. It fades after a brief idle period and is
torn down after longer silence, so it does not leave a second permanent pointer
on the desktop. The overlay never receives input and does not move the user's
physical cursor.
