## What it does

Desktop automation: 29 screen perception and input control tools. Cross-platform (Windows, macOS, Linux).

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | full |
| mobile | full |
| extension | full |
| web | full |
| cli | full |

## What it exposes

### Capabilities

- **Computer** - capability `computer.control`
  - Target: local-machine
  - Verbs:
    - `computer__capture` -> `ghost__ghost_annotate`
    - `computer__click` -> `ghost__ghost_click`
    - `computer__type` -> `ghost__ghost_type`
    - `computer__key` -> `ghost__ghost_hotkey`
    - `computer__scroll` -> `ghost__ghost_scroll`
    - `computer__focus_app` -> `ghost__ghost_focus`

### MCP server

- **`ghost`** - Ghost - desktop automation (29 tools: screen perception + input control). Cross-platform (Windows, macOS, Linux); install the `ghost` sidecar to enable. Unavailable until installed.

## Permissions

**Grants:** `mcp:ghost`

## Engine requirement

Requires Ryu >=0.1.0.
