## What it does

Fast local regular-expression search through ripgrep's `rg` binary, exposed as Ryu command tools. Respects .gitignore, skips hidden and binary files by default, and returns line-aware JSON Lines output. BYO install; no API key.

## What it exposes

### Tools

### `ripgrep.search` - ripgrep Search

Search a file or directory with ripgrep. The result is bounded by the command runner and returned as JSON Lines; exit_code 1 means no matches.

Backend: CLI command

| Parameter | Type | Required | Description |
|---|---|---|---|
| `pattern` | string | yes | Regular-expression pattern to search for. Use a literal pattern when exact text is enough. |
| `path` | string | yes | Existing file or directory inside the active Ryu workspace. Relative paths resolve from that workspace; absolute paths must still stay inside it. |

### `ripgrep.files` - ripgrep Files

List files visible to ripgrep under a file or directory, respecting the same ignore, hidden-file, and binary-file defaults.

Backend: CLI command

| Parameter | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | Existing file or directory inside the active Ryu workspace. Relative paths resolve from that workspace; absolute paths must still stay inside it. |
