## What it does

Keeps subscription agents usable for the whole rolling window. It can pace usage down with a fallback ladder, then spend remaining quota on stronger models or ACP fast mode as a reset approaches.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | full |
| cli | full |

## Permissions

**Grants:** `preferences:read`, `usage:read`

## UI it contributes

### Settings tabs

- **Usage pacing** (fields: Automatically pace and escalate models (toggle), Pacing mode (select), Agent and global ladders (textarea))

### Turn hooks

- **usage-pacer.select** (on: `pre_model_select`)

## Engine requirement

Requires Ryu >=0.1.0.
