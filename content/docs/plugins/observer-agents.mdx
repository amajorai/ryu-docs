## What it does

Observer Agents is an opt-in watchdog for long-running work. Enable **Observer** in the composer
and an independent side model receives a bounded digest of the latest agent activity after each
assistant turn.

The observer normally stays silent. When it spots drift, a missed constraint, or a shortcut that
could compound, it emits one concise advisory note. The observer cannot call tools, change files,
grant permissions, stop the worker, or act as user consent; it is a second set of eyes, not an
authoritative controller.

## Settings

Choose an optional **Observer model** in Settings → **Observer agents**. Because an enabled observer
may make one side-model call per assistant turn, it is best suited to high-risk or long-running
tasks.
