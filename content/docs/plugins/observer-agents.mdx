## What it does

Adds an opt-in background reviewer that watches the latest agent activity and sends concise advisory reports when it spots drift, missed constraints, or shortcuts.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | full |
| cli | full |

## Permissions

**Grants:** `hook:side-model`

## UI it contributes

### Composer controls

- **Observer** - Have a quiet reviewer watch the agent's latest activity. (type: toggle)

### Settings tabs

- **Observer agents** (fields: Observer model (model_picker))

### Turn hooks

- **observer-agents.review** (on: `post_assistant_turn`)
