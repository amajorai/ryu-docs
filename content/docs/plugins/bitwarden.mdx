## What it does

Pull API keys from Bitwarden Secrets Manager on demand instead of storing them in plaintext - one machine-account bootstrap token (BWS_ACCESS_TOKEN) replaces N provider keys, and rotating a credential is one change in the Bitwarden web app. Declarative `command` tools that shell out to the locally-installed `bws` CLI (BYO binary, no API key in the manifest).

## What it exposes

### Tools

### `bitwarden__status` - Bitwarden Status

Check that the Bitwarden Secrets Manager CLI (`bws`) is installed and report its version. Does not contact Bitwarden - no token needed. Use this FIRST to confirm the binary is present before calling the other bitwarden__ tools.

Backend: CLI command

_No parameters_ (empty schema).
### `bitwarden__projects` - Bitwarden Projects

List the Bitwarden Secrets Manager projects the machine account can read. Returns an array of &#123; id, name &#125;. Use the returned id as `project_id` for the bitwarden__list / bitwarden__get tools. Requires BWS_ACCESS_TOKEN in the environment.

Backend: CLI command

_No parameters_ (empty schema).
### `bitwarden__list` - Bitwarden List Secrets

List every secret in a Bitwarden Secrets Manager project. Returns an array of &#123; id, key, value, note, projectId &#125;. The secret `key` is the environment-variable name Bitwarden manages; the `value` is the credential itself. Use this to pull credentials on demand instead of storing them in config or env. Requires BWS_ACCESS_TOKEN in the environment.

Backend: CLI command

| Parameter | Type | Required | Description |
|---|---|---|---|
| `project_id` | string | yes | The project UUID to list secrets from - the `id` returned by bitwarden__projects. |

### `bitwarden__get` - Bitwarden Get Secret

Fetch a single secret by its Bitwarden id (the `id` from bitwarden__list). Returns &#123; id, key, value, note, projectId &#125;. Prefer bitwarden__list when you want several secrets or do not know the id.

Backend: CLI command

| Parameter | Type | Required | Description |
|---|---|---|---|
| `secret_id` | string | yes | The secret UUID - the `id` field returned by bitwarden__list. |

## Permissions

**Grants:** `tool:command:bws`

## Environment

| Variable | Meaning |
|---|---|
| `BWS_ACCESS_TOKEN` | The machine-account bootstrap token. The tool's `command_env` passes it through from Core's environment on every call, so it never needs to live in a manifest or config file. |
| `BWS_SERVER_URL` | Optional Bitwarden instance URL. Also plumbed through `command_env` when set. |
| `RYU_BWS_BIN` | Optional path to the `bws` binary. Defaults to `~/.ryu/bin/bws`, which Core seeds when it manages the sidecar. |

Values carried by `command_env` are excluded from scans and audits, matching the other command-tool
secrets.

## Engine requirement

Requires Ryu >=0.1.0.
