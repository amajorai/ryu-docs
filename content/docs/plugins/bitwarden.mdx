## What it does

Pull API keys from Bitwarden Secrets Manager on demand instead of storing them in plaintext. One machine-account bootstrap token (`BWS_ACCESS_TOKEN`) can replace multiple provider keys, and rotating a credential requires one change in the Bitwarden web app. Declarative `command` tools invoke the locally installed `bws` CLI, which you provide separately; the manifest contains no API key.

## What it exposes

### Tools

### `bitwarden.status` - Bitwarden Status

Check that the Bitwarden Secrets Manager CLI (`bws`) is installed and report its version. This does not contact Bitwarden, so no token is needed. Use it first to confirm the binary is present before calling the other Bitwarden tools.

Backend: CLI command

_No parameters_ (empty schema).
### `bitwarden.projects` - Bitwarden Projects

List the Bitwarden Secrets Manager projects the machine account can read. Returns an array of &#123; id, name &#125;. Use the returned id as `project_id` for the `bitwarden.list` and `bitwarden.get` tools. Requires `BWS_ACCESS_TOKEN` in the environment.

Backend: CLI command

_No parameters_ (empty schema).
### `bitwarden.list` - Bitwarden List Secrets

List every secret in a Bitwarden Secrets Manager project. Returns an array of &#123; id, key, value, note, projectId &#125;. The secret `key` is the environment-variable name Bitwarden manages; `value` is the credential itself. Use this to pull credentials on demand instead of storing them in config or the environment. Requires `BWS_ACCESS_TOKEN` in the environment.

Backend: CLI command

| Parameter | Type | Required | Description |
|---|---|---|---|
| `project_id` | string | yes | The project UUID to list secrets from, returned by `bitwarden.projects`. |

### `bitwarden.get` - Bitwarden Get Secret

Fetch a single secret by its Bitwarden id, returned by `bitwarden.list`. Returns &#123; id, key, value, note, projectId &#125;. Prefer `bitwarden.list` when you want several secrets or do not know the id.

Backend: CLI command

| Parameter | Type | Required | Description |
|---|---|---|---|
| `secret_id` | string | yes | The secret UUID, returned in the `id` field by `bitwarden.list`. |

## Permissions

**Grants:** `tool:command:bws`

## Environment

| Variable | Meaning |
|---|---|
| `BWS_ACCESS_TOKEN` | The machine-account bootstrap token. The tool's `command_env` passes it through from Core's environment on every call, so it never needs to live in a manifest or config file. |
| `BWS_SERVER_URL` | Optional Bitwarden instance URL. Also plumbed through `command_env` when set. |
| `RYU_BWS_BIN` | Optional path to the `bws` binary. Defaults to `~/.ryu/bin/bws`, which Core seeds when it manages the sidecar. |

Values carried by `command_env` are excluded from scans and audits, matching the other command-tool
secrets.

## Engine requirement

Requires Ryu >=0.1.0.
