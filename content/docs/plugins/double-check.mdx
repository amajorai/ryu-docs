## What it does

Sends every answer to a second model for review before you act on it, so mistakes get caught by a fresh set of eyes. Off until you flip the Double-check toggle in the composer; the reviewer model is configurable in settings.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | full |
| cli | full |

## Permissions

**Grants:** `hook:side-model`

## UI it contributes

### Composer controls

- **Double-check** - Have a second model review each answer. (type: toggle)

### Settings tabs

- **Double-check** (fields: Reviewer model (model_picker))

### Turn hooks

- **double-check.review** (on: `post_assistant_turn`)
