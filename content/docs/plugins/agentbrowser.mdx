## What it does

Browser automation via the `agent-browser` CLI's MCP server (https://agent-browser.dev). Provides the swappable `browser.control` layer, so selecting it re-points the stable `browser.*` tools at agent-browser without changing what agents call. Launched via `npx agent-browser mcp --tools all`; needs Node on PATH.

The desktop shell also follows Agent Browser's current session when its documented
localhost stream is enabled. The latest frame appears in the shared live-media card,
where **Open PiP** opens a native always-on-top Tauri window and **Expand** opens the
same morphing lightbox used by image attachments. Recording controls are available
through the full MCP profile (`record start`, `record stop`, and `record restart`)
and follow Agent Browser's [recording contract](https://agent-browser.dev/recording),
while live streaming remains session-scoped through its [streaming contract](https://agent-browser.dev/streaming).

## What it exposes

### Capabilities

- **Browser** - capability `browser.control`
  - Grant: `browser:control`
  - Target: local-machine
  - Verbs:
    - `browser.navigate` -> `agentbrowser.agent_browser_open`
    - `browser.tabs` -> `agentbrowser.agent_browser_tab_list`
    - `browser.click` -> `agentbrowser.agent_browser_click`
    - `browser.scroll` -> `agentbrowser.agent_browser_scroll`
    - `browser.type` -> `agentbrowser.agent_browser_type`
    - `browser.snapshot` -> `agentbrowser.agent_browser_snapshot`
    - `browser.screenshot` -> `agentbrowser.agent_browser_screenshot`

### MCP server

- **`agentbrowser`** - Agent Browser - browser automation and recording over MCP (navigate, snapshot, click, type, scroll, screenshot, tabs, record start/stop/restart). Launched via `npx -y agent-browser mcp --tools all`; unavailable until Node is installed and the package can be fetched.

### Live stream

Run `agent-browser stream enable` for the active session. Ryu reads
`agent-browser stream status --json`, connects to the returned localhost WebSocket,
and follows its JPEG frames. Switching to another browser tab changes the frame
source; the PiP and lightbox follow that source automatically.

## Permissions

**Grants:** `mcp:agentbrowser`, `tool:execute`

## Engine requirement

Requires Ryu >=0.1.0.
