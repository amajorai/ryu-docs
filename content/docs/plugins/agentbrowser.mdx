## What it does

Browser automation via the `agent-browser` CLI's MCP server (https://agent-browser.dev). Provides the swappable `browser.control` layer, recording tools, and the documented localhost live stream, so selecting it re-points the stable `browser.*` tools at agent-browser without changing what agents call. Launched from the audited `agent-browser@0.34.0` package; needs Node on PATH.

## What it exposes

### Capabilities

- **Browser** - capability `browser.control`
  - Grant: `browser:control`
  - Target: local-machine
  - Verbs:
    - `browser.navigate` -> `agentbrowser.agent_browser_open`
    - `browser.tabs` -> `agentbrowser.agent_browser_tab_list`
    - `browser.click` -> `agentbrowser.agent_browser_click`
    - `browser.scroll` -> `agentbrowser.agent_browser_scroll`
    - `browser.type` -> `agentbrowser.agent_browser_type`
    - `browser.snapshot` -> `agentbrowser.agent_browser_snapshot`
    - `browser.screenshot` -> `agentbrowser.agent_browser_screenshot`

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`agentbrowser`** - Agent Browser - browser automation, recording, and screenshot tools over MCP. Launched via `npx -y agent-browser@0.34.0 mcp --tools all`; unavailable until Node is installed and the pinned package can be fetched.

## Permissions

**Grants:** `mcp:agentbrowser`, `tool:execute`
