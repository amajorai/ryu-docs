## What it does

Browser automation via the `agent-browser` CLI's MCP server (https://agent-browser.dev). Provides the swappable `browser.control` layer, so selecting it re-points the stable `browser__*` tools at agent-browser without changing what agents call. Launched via `npx agent-browser mcp`; needs Node on PATH.

## What it exposes

### Capabilities

- **Browser** - capability `browser.control`
  - Grant: `browser:control`
  - Target: local-machine
  - Verbs:
    - `browser__navigate` -> `agentbrowser__agent_browser_open`
    - `browser__tabs` -> `agentbrowser__agent_browser_tab_list`
    - `browser__click` -> `agentbrowser__agent_browser_click`
    - `browser__scroll` -> `agentbrowser__agent_browser_scroll`
    - `browser__type` -> `agentbrowser__agent_browser_type`
    - `browser__snapshot` -> `agentbrowser__agent_browser_snapshot`
    - `browser__screenshot` -> `agentbrowser__agent_browser_screenshot`

### MCP server

- **`agentbrowser`** - Agent Browser - browser automation over MCP (navigate, snapshot, click, type, scroll, screenshot, tabs). Launched via `npx -y agent-browser mcp`; unavailable until Node is installed and the package can be fetched.

## Permissions

**Grants:** `mcp:agentbrowser`, `tool:execute`

## Engine requirement

Requires Ryu >=0.1.0.
