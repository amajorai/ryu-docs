## What it does

Read the latest completed Is Agentic (https://is-agentic.com) agent-readiness report for a public website: a 0-100 score split into essential, recommended and bonus checks, plus every failing check with its evidence and recommended fix. Read-only, keyless, and never starts a scan.

## What it exposes

### Tools

### `is_agentic.report` - Is Agentic Report

Get the latest completed Is Agentic agent-readiness report for a public website. Returns `score` (0-100), `score_label`, `score_breakdown` (essential / recommended / bonus), and `issues`, each with `tier`, `result`, `details` and `recommendation`. Start with failed essential issues. This tool never starts a scan: when no report exists the response is a 404 problem body (`code: report_not_found`) whose `resolution` names the https://is-agentic.com/scan/&lt;domain> page that starts one.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | Public website to look up, as a bare domain (vercel.com) or an HTTP or HTTPS URL. |
