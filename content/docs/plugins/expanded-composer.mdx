## What it does

Expanded Composer adds an **Expand composer** control to the chat toolbar. Select it to move the
current draft into a larger in-place dialog while keeping the same text, attachments, plugin
controls, voice actions, and send behavior.

Closing the dialog or pressing **Escape** returns to the normal composer without creating another
draft or another send path. The transition respects the system reduced-motion preference.

## Activation

The feature is contributed by `@ryu/expanded-composer` and is active by default when the plugin is
enabled. Disable the plugin to remove the control while leaving the base composer unchanged.

## Engine requirement

Requires Ryu >=0.1.0.
