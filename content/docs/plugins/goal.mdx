## What it does

Give the agent a goal with `/goal` or let an agent set one with `goal.set`; it keeps working until a judge model agrees the goal is actually met, re-prompting itself after every turn instead of stopping and waiting for you. `/goal clear` stops the loop; the judge model is configurable.

## What it exposes

### Tools

### `goal.set` - Set Conversation Goal

Set or replace the goal for the conversation you are currently working in. The conversation scope comes from the caller context, so the tool cannot target another chat. Use this when the user asks you to pursue a durable outcome; it resets goal progress and starts the judge loop from the next reply.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `goal` | string | yes | The concrete outcome to pursue. Keep it specific and testable. |
