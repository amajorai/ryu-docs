## What it does

Give the agent a goal with `/goal`, or let an allowlisted agent call `goal.set` for the
conversation it is currently working in. Ryu keeps working until a judge model agrees the goal is
actually met, re-prompting itself after every turn instead of stopping and waiting for you.
`/goal clear` stops the loop; the judge model is configurable.

## Permissions

**Grants:** `tool:execute`, `hook:side-model`, `storage:kv`

## UI it contributes

### Slash commands

- **/goal** - Pursue a goal until a judge model says it is met. Use '/goal clear' to stop.

### Agent tool

- **`goal.set`** - Set or replace the durable goal for the current conversation. The conversation
  comes from Core's caller context, not the tool arguments, so an agent cannot target another chat.
  Grant `goal.set` in the agent's tool allowlist when the agent should be able to choose its own
  completion condition.

### Settings tabs

- **Goals** (fields: Judge model (model_picker))

### Turn hooks

- **goal.loop** (on: `post_assistant_turn`)

When the judge marks the goal achieved, the desktop shows the matching circular-check icon,
elapsed duration, and completion time beside the ending assistant turn.

## Engine requirement

Requires Ryu >=0.1.0.
