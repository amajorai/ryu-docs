## What it does

Give the agent a goal with `/goal` and it keeps working until a judge model agrees the goal is actually met, re-prompting itself after every turn instead of stopping and waiting for you. `/goal clear` stops the loop; the judge model is configurable.

## Permissions

**Grants:** `hook:side-model`, `storage:kv`

## UI it contributes

### Slash commands

- **/goal** - Pursue a goal until a judge model says it is met. Use '/goal clear' to stop.

### Settings tabs

- **Goals** (fields: Judge model (model_picker))

### Turn hooks

- **goal.loop** (on: `post_assistant_turn`)

## Engine requirement

Requires Ryu >=0.1.0.
