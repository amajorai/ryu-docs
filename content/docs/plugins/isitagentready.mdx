## What it does

Scan a public website with Is Your Site Agent-Ready? (https://isitagentready.com): a live check of robots.txt and AI bot rules, sitemaps, Link headers, Markdown negotiation, MCP and A2A cards, Agent Skills, WebMCP, OAuth discovery and agent commerce protocols, scored as a readiness level from 0 (Not Ready) to 5 (Agent-Native). Keyless.

## What it exposes

### Tools

### `isitagentready.scan` - Agent-Ready Scan

Run a fresh agent-readiness scan of one public website (about 5-10 seconds). By default (`format: agent`) it returns a compact Markdown report: the readiness level (0-5) and every failing check with its fix and an implementation-guide link. Pass `format: json` for the full per-check result (`level`, `level_name`, `checks` grouped by category with pass / fail / neutral / unableToCheck status and evidence, and `next_level` requirements).

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | Public HTTP or HTTPS URL to scan, e.g. https://example.com. |
| `format` | string (one of: agent, json) | no | `agent` (default) for a compact Markdown fix list, `json` for every check with evidence. |
