## What it does

Adds bash_background / bash_output / bash_kill to the managed Pi agent, so a long-running command does not hold the turn open.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | limited |
| cli | full |

## UI it contributes

### Pi extensions

- **shell** - Background bash for the managed Pi agent.

Requires Ryu >=0.1.0.
