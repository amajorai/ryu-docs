## What it does

Kotlin language server for the ryu agent: definitions, references, hover, symbols, implementations, call hierarchies and diagnostics after every edit. You install kotlin-lsp; the plugin ships config.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | limited |
| cli | full |

## Permissions

**Grants:** `pi:extension`

Requires Ryu >=0.1.0.
