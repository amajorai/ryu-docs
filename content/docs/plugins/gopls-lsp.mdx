## What it does

Go language server (gopls) for the ryu agent: definitions, references, hover, symbols, implementations, call hierarchies and diagnostics after every edit. You install gopls; the plugin ships config.

## Surfaces

| mobile | limited |
| extension | limited |
| web | limited |
| cli | full |
