<Callout type="warn">
  AGENTS.md Tail is experimental and opt-in. It is not enabled on fresh installs.
</Callout>

## What it does

AGENTS.md Tail refreshes the active project-instructions block before every model turn. By
default, Ryu keeps the existing head injection and adds one current copy after the latest user
message. The hook removes its own older tail before appending the new one, so the model receives
only the earliest head injection and the latest tail injection.

The tail is outbound context, not a chat message. It is hidden from the chat UI and is not written
to the persisted conversation transcript. If the project instructions change, the next turn uses
the latest content.

## Default behavior

| Part | Behavior |
|---|---|
| Head injection | Kept, using Ryu's normal project-instructions behavior |
| Tail injection | Current project instructions after the latest user message |
| Older tails | Removed before the latest tail is added |
| Chat history | User and assistant messages remain unchanged |

## Remove the head injection

The **AGENTS.md Tail** settings tab contributes a node-scoped **Remove the head injection** toggle.
It is off by default. Turn it on when you want only the latest hidden copy at the end of each
turn; the original project-instructions block at the head is removed from the outbound context.

## Agent support and ACP trade-off

The hook supports Ryu's message-array model paths and ACP's flattened prompt path, including the
managed `ryu` Pi agent. On ACP, refreshing the hidden tail starts a fresh in-process agent session
for that turn so an older hidden tail cannot remain in the agent's private session history. Ryu
replays the persisted conversation transcript, so the visible conversation is retained, but warm
in-process session state is lost for that turn.

## When it does nothing

If no project instruction file is available, there is no block to refresh and the hook leaves the
turn unchanged. Safe Mode also suppresses project-instructions injection, so AGENTS.md Tail is a
no-op while Safe Mode is active.

## Plugin details

### Settings

- **Remove the head injection** (toggle, node scope)

### Turn hooks

- **agents-md-tail.context** (on: `context`)

### Permissions

**Grants:** `preferences:read`

| Surface | Support |
|---|---|
