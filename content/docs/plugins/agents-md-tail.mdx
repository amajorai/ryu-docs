## What it does

Experimental context hook that keeps the active AGENTS.md instructions at the head and repeats the latest copy at the tail of each model turn without adding either injection to chat history.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | full |
| cli | full |

## Permissions

**Grants:** `preferences:read`

## UI it contributes

### Settings tabs

- **AGENTS.md Tail** (fields: Remove the head injection (toggle))

### Turn hooks

- **agents-md-tail.context** (on: `context`)

## Engine requirement

Requires Ryu >=0.1.0.
