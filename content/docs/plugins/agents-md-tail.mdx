## What it does

Experimental context hook that repeats the active AGENTS.md instructions at the end of the latest message on each model turn, without editing the system prompt or chat history.

## How it changes the prompt

The hook appends the active project instructions to the latest user message only, wrapped in a
`<ryu-agents-md-tail>` block. It does nothing when there are no project instructions.

It never edits the system prompt or earlier turns. The cached prompt prefix stays reusable from
turn to turn, and ACP agents keep their warm session. Only the repeated block is new input on each
turn.
