## What it does

Security Scanner runs a multi-agent security review of your code. It maps the architecture, looks for vulnerabilities, has independent agents try to disprove each finding, reviews diffs, and drafts fixes. It never changes files. The slash commands are listed under [UI it contributes](/docs/plugins/security-scanner#ui-it-contributes).

## Clearing a report

`/security-clear` confirms clearing the conversation report only after storage accepts the deletion. If deletion fails, it reports the failure and you can retry. A failed clear never says the report is gone.

Scan, verification, and patch-proposal results are saved for follow-up commands. If saving is refused, the current result remains visible with a state warning, but `/security-verify` and `/security-fix` cannot rely on it. Fix the storage problem and run the original command again. Retrying is safe.

## Bundled skill availability

Enabling the installed plugin copies its bundled skills (`security-scan`, `security-diff-scan`, and `security-fix`) into the Skills home and activates them. Disabling the plugin deactivates them and keeps the files. Uninstalling removes only skill folders this plugin owns, so a same-name skill you installed yourself is kept. If storage fails during enable, fix the storage problem and enable the plugin again. See [Bundle a Skill with a plugin or app](/docs/extend/develop/extensions/agent-skills#bundle-a-skill-with-a-plugin-or-app) for the full lifecycle.

The workflow still needs the connected tools it uses and their permissions.

## UI it contributes

### Composer controls

- **Security review** - Review security-sensitive code in each completed answer with static signals and a configurable second model. (type: toggle)

### Settings tabs

- **Security Scanner** (fields: Scanner model (model_picker), Synthesis effort (select), Standard scan workers (number))

### Slash commands

- **/security-scan** - Run a model-agnostic multi-agent security scan. Add quick, deep, or diff plus an optional scope.
- **/security-verify** - Independently try to falsify the latest scan findings and update their status.
- **/security-fix** - Draft a minimal patch and validation plan for the latest finding. It never applies changes.
- **/security-clear** - Forget the latest scan, verification, and patch suggestion for this conversation.

### Turn hooks

- **security-scanner.command** (on: `pre_user_turn`)
- **security-scanner.auto-review** (on: `post_assistant_turn`)
