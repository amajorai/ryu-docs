## What it does

After each turn while armed, a local sub-agent scans the reply and the workspace for work that is genuinely unfinished and that another turn could complete; if it finds any, it injects a follow-up turn automatically, so a task never stalls waiting for you to type "continue". '/auto-continue off' stops it.

## Permissions

**Grants:** `hook:run-agent`, `storage:kv`

## UI it contributes

### Slash commands

- **/auto-continue** - Arm or disarm the auto-continue loop for this chat ('/auto-continue on' &#124; '/auto-continue off').

### Turn hooks

- **auto-continue.loop** (on: `post_assistant_turn`)

## Engine requirement
