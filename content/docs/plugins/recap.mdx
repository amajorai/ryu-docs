## What it does

Ends a long agent turn with a short recap of what it actually did - the work, the files and commands it named, what it could not finish, and the obvious next step - written by a side model so the main answer is left untouched. Long turns only by default (short answers recap themselves). `/recap` recaps the whole conversation on demand without spending a turn on the main model; `/recap off` mutes the automatic one for that chat.

## Permissions

**Grants:** `hook:side-model`, `storage:kv`, `preferences:read`

## UI it contributes

### Slash commands

- **/recap** - Recap the conversation so far - what was done, what changed, what is still open. `/recap off` mutes the automatic per-turn recap in this chat, `/recap on` restores it.

### Settings tabs

- **Recap** (fields: Recap long turns automatically (toggle), Recap turns longer than (characters) (number), Detail (select), Recap model (model_picker))

### Turn hooks

- **recap.turn** (on: `post_assistant_turn`)
- **recap.command** (on: `pre_user_turn`)
