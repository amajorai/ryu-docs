## What it does

Scrapling provides adaptive web-page extraction through its MCP server (https://scrapling.readthedocs.io), which you install locally. It is the third provider for the swappable `web.extract` layer alongside the local `spider` CLI and hosted BYOK services. Selecting it routes the stable `web.extract` tool to a fetcher that impersonates a real browser TLS fingerprint.

Scrapling needs no API key. Install it with `pip install "scrapling[ai]"` and keep the `scrapling` binary on `PATH`. If you select Scrapling before the binary works, `web.extract` is unavailable; Ryu does not retry another provider automatically. Install Scrapling or explicitly select a working provider. The plugin does not provide `web.crawl`: neither the MCP server nor the CLI follows links. Scrapling's Python `Spider` class can crawl, but it is not reachable over MCP.

## What it exposes

### Capabilities

- **Extract** - capability `web.extract`
  - Verbs:
    - `web.extract` -> `scrapling.get`

### MCP server

- **`scrapling`** - Scrapling - adaptive web scraping over MCP (get, bulk_get, fetch, stealthy_fetch, screenshot, browser sessions). Launched via `scrapling mcp`; unavailable until `pip install "scrapling[ai]"` has been run and `scrapling` is on PATH. The browser-backed tools additionally need `scrapling install` to download Chromium and Camoufox.

## Permissions

**Grants:** `mcp:scrapling`, `tool:execute`

## Engine requirement

Requires Ryu >=0.1.0.
