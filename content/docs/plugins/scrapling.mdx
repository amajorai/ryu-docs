## What it does

Adaptive web-page extraction via the Scrapling MCP server (https://scrapling.readthedocs.io), a BYO local install. Provides the swappable `web.extract` layer as a THIRD provider alongside the local `spider` CLI and the hosted BYOK services, so selecting it re-points the stable `web.extract` tool at a fetcher that impersonates a real browser TLS fingerprint. No API key. Requires `pip install "scrapling[ai]"` and the `scrapling` binary on PATH; until then the MCP server does not start and the layer falls back to whichever other provider you select. Deliberately provides NO `web.crawl`: neither the MCP server nor the CLI follows links - only Scrapling's Python `Spider` class crawls, and it is not reachable over MCP.

## What it exposes

### Capabilities

- **Extract** - capability `web.extract`
  - Verbs:
    - `web.extract` -> `scrapling.get`

### MCP server

- **`scrapling`** - Scrapling - adaptive web scraping over MCP (get, bulk_get, fetch, stealthy_fetch, screenshot, browser sessions). Launched via `scrapling mcp`; unavailable until `pip install "scrapling[ai]"` has been run and `scrapling` is on PATH. The browser-backed tools additionally need `scrapling install` to download Chromium and Camoufox.

## Permissions

**Grants:** `mcp:scrapling`, `tool:execute`

## Engine requirement

Requires Ryu >=0.1.0.
