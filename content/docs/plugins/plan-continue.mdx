## What it does

While plan mode is on and the plan has not been accepted, this injects a follow-up turn after each completed turn asking the agent to carry on planning - so a plan never stalls waiting for you to type "continue".

## Permissions

**Grants:** `storage:kv`

## UI it contributes

### Slash commands

- **/plan-continue** - Turn the plan-mode auto-continue off or on for this chat ('/plan-continue off' &#124; '/plan-continue on').

### Turn hooks

- **plan-continue.loop** (on: `post_assistant_turn`)

## Engine requirement

Requires Ryu >=0.1.0.

## Activation

Activates on: `*`
