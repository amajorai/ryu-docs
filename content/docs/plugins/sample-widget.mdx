## What it does

Reference third-party MCP widget plugin. A tiny local Node MCP server (server.mjs) exposes one render tool (sample_widget.render) that returns structured data AND serves a self-contained skybridge HTML resource (ui://widget/sample.html). The approved mcp:server grant lets a Community plugin register the server; contributes.widgets plus widget:render authorize promotion into an inline chat widget. Copy this directory as the starting point for your own widget plugin.

## What it exposes

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`sample_widget`** - Sample widget MCP server: one render tool + the ui://widget/sample.html resource.

## Permissions

**Grants:** `mcp:server`, `widget:render`
