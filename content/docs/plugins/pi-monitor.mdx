## What it does

Adds the monitor tool to the managed Pi agent, so it can watch a command or WebSocket in the background and react when events arrive.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | limited |
| cli | full |

## UI it contributes

### Pi extensions

- **monitor** - Background watches (commands and WebSockets) for the managed Pi agent.

## Engine requirement

Requires Ryu >=0.1.0.
