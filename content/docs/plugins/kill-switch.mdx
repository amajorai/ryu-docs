## What it does

Kill Switch adds **Stop all chats and bots** and **Resume chats and bots** to the
chat context menu. Install and enable the plugin through
[Marketplace](/docs/surfaces/desktop/user-guide/marketplace), then right-click a
chat in the sidebar or its tab to use either action.

See [chat session controls](/docs/surfaces/desktop/user-guide/chat-session-controls)
for actions on a single conversation and [Bot](/docs/surfaces/desktop/bot) for
channel-bot setup.

**Stop all chats and bots** acts on the selected node only:

- It cancels active agent turns and closes native model streams.
- It pauses new chat turns, channel-bot turns, and scheduled work.
- Interrupted bot turns return a paused response instead of a partial reply.
- Conversation history stays available, and other nodes are unaffected.

<Callout type="warn">
  Stop takes effect immediately, without a confirmation dialog. Cancellation cannot undo a message
  already sent or an external action already completed. Remote agents receive a cancellation
  request, and their provider controls how quickly they stop.
</Callout>

**Resume chats and bots** allows new work again. It does not replay interrupted
prompts. Scheduled work that is due can run again after you resume. The pause
lasts only for the current Core process, so restarting the node also clears it.

The plugin requires the `execution:control` grant. On a registered personal node,
only its owner can use it. On an organization node, an organization administrator
is required. Disabling the plugin does not resume execution, so resume first if
you want new work to run.
