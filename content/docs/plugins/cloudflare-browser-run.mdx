## What it does

Hosted Browser Run quick actions over Cloudflare's remote OAuth MCP server. Adds URL-scoped navigate, snapshot, and screenshot verbs to Ryu's swappable browser.control layer; the full Browser Run MCP tool set remains available under cloudflare.*.

## What it exposes

### Capabilities

- **Browser** - capability `browser.control`
  - Grant: `browser:control`
  - Target: remote-desktop
  - Verbs:
    - `browser.navigate` -> `cloudflare.get_url_snapshot`
    - `browser.snapshot` -> `cloudflare.get_url_snapshot`
    - `browser.screenshot` -> `cloudflare.get_url_screenshot`

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`cloudflare`** - Cloudflare Browser Run remote OAuth MCP server. Native tools include HTML, Markdown, PDF, snapshot, screenshot, JSON, links, crawl, and browser-session operations.

## Permissions

**Grants:** `mcp:server`, `identity.read`, `tool:execute`

## Engine requirement

Requires Ryu >=0.1.0.
