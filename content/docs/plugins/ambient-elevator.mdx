## What it does

Plays one low-volume elevator track while any Ryu agent is actively working, then stops when the last working run ends or needs input.

| web | none |
| cli | none |

## UI it contributes

### Settings tabs

- **Elevator music** (fields: Play while agents work (toggle), Volume (number))

### live activities

- **Agent ambient audio**

## Engine requirement

Requires Ryu >=0.1.0.
