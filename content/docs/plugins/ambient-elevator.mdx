## What it does

Ambient Elevator plays one quiet elevator track while at least one Ryu agent
run is actively working. It stops when the last working run finishes, fails, or
needs input. Multiple concurrent runs share the same player, so starting a
second agent never starts a second copy of the music.

The plugin is desktop-only and is enabled by default. Its implementation is
part of Ryu's desktop shell; the plugin contributes the audio source and the
configuration contract.

## Configure it

Open **App Settings → Plugins → Ambient Elevator**:

- **Play while agents work** turns ambient playback on or off.
- **Volume** sets the track from 0 to 100 percent. The default is 35 percent.

Settings are user-scoped and take effect without restarting Ryu.
