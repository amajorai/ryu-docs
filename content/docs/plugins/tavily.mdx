## What it does

Search-and-extract for agents via the Tavily API (https://tavily.com), exposed as two declarative HTTP tools. Provides the swappable `web.search` and `web.extract` layers, so selecting it in the layer picker re-points the stable `web.search` / `web.extract` tools at Tavily without changing what agents call. Requires a BYOK Tavily API key.

## What it exposes

### Tools

### `tavily.search` - Tavily Search

Web search tuned for agents. Returns ranked results with titles, URLs, and extracted content. Requires RYU_TAVILY_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | yes | The search query. |
| `max_results` | integer | no | Number of results to return (default 10). |
| `search_depth` | string (one of: basic, advanced) | no | How much work Tavily does per query. |

### `tavily.extract` - Tavily Extract

Extract the readable content of one or more URLs. Requires RYU_TAVILY_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `urls` | array | yes | URLs to extract content from. |

### Capabilities

- **Search** - capability `web.search`
  - Verbs:
    - `web.search` -> `tavily.search`
- **Extract** - capability `web.extract`
  - Verbs:
    - `web.extract` -> `tavily.extract`
