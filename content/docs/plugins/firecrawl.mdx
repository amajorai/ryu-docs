## What it does

Web search and page scraping via the Firecrawl v2 API (https://firecrawl.dev), exposed as two declarative HTTP tools. Provides the swappable `web.search` and `web.extract` layers, so selecting it in the layer picker re-points the stable `web__search` / `web__extract` tools at Firecrawl without changing what agents call. Requires a BYOK Firecrawl API key.

## What it exposes

### Tools

### `firecrawl__search` - Firecrawl Search

Web search via Firecrawl. Returns ranked web results with titles, URLs, and descriptions. Requires RYU_FIRECRAWL_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | yes | The search query. |
| `limit` | integer | no | Number of results to return (default 10). |

### `firecrawl__scrape` - Firecrawl Scrape

Scrape a single web page with Firecrawl and return its main content as markdown. Requires RYU_FIRECRAWL_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | The URL of the page to scrape. |

### `firecrawl__crawl_start` - Firecrawl Crawl (start)

Start a Firecrawl crawl job and return its id. Asynchronous: poll firecrawl__crawl_status with the returned id. Requires RYU_FIRECRAWL_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | The start URL to crawl from. |
| `limit` | integer | no | Maximum pages to fetch. |
| `maxDiscoveryDepth` | integer | no | Link-discovery hops to follow from the start URL. |

### `firecrawl__crawl_status` - Firecrawl Crawl (status)

Read the status and accumulated pages of a Firecrawl crawl job started by firecrawl__crawl_start. Requires RYU_FIRECRAWL_API_KEY.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | The crawl job id returned by firecrawl__crawl_start. |

### Capabilities

- **Search** - capability `web.search`
  - Verbs:
    - `web__search` -> `firecrawl__search`
- **Extract** - capability `web.extract`
  - Verbs:
    - `web__extract` -> `firecrawl__scrape`
- **Crawl** - capability `web.crawl`
  - Verbs:
    - `web__crawl` -> `firecrawl__crawl_start`
