## What it does

Adds the Task tool to the managed Pi agent, so it can delegate a bounded, context-isolated job to a child agent.

Each child appears as its own nested activity transaction from spawn through completion or failure. Parallel `Task` calls show every child independently, while the parent agent receives each result through the enclosing `Task` and continues the turn.

In the plugin's node settings, **Default subagent model** starts as **Let the main agent decide**. In that mode, the agent may choose a model for each delegated task; without a choice, the child inherits Pi's managed default. Choose a model in settings to force every child created by `Task` to use it; the agent cannot override that choice per call.
