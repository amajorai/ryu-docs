## What it does

Adds the Task tool to the managed Pi agent, so it can delegate a bounded, context-isolated job to a child agent.

|---|---|
| gateway | none |

| island | limited |
| mobile | limited |
| extension | limited |
| web | limited |
| cli | full |

## UI it contributes

### Pi extensions

- **subagent** - Sub-agent delegation (the Task tool) for the managed Pi agent.
