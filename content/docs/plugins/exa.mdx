## What it does

Neural and keyword web search via the Exa API (https://exa.ai), exposed as two declarative HTTP tools: search and find-similar. Requires a BYOK Exa API key.

## What it exposes

### Tools

### `exa.search` - Exa Neural Search

Neural and keyword web search via the Exa API. Returns relevant web pages with titles, URLs, published dates, and full page text. Requires RYU_EXA_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | yes | The search query. Supports natural-language and keyword queries. |
| `num_results` | integer | no | Number of results to return (default 10). |
| `use_autoprompt` | boolean | no | Let Exa rephrase the query for better neural search results (default true). |

### `exa.free_search` - Exa Search (no key)

Web search through Exa's PUBLIC MCP endpoint, which needs no API key. Rate-limited free tier, intended as the zero-setup fallback when RYU_EXA_API_KEY is unset; add a key to use the higher-limit exa.search instead. Speaks JSON-RPC: the caller supplies the whole `tools/call` envelope, and the reply is a text/event-stream frame, so the capability adapter parses it rather than a response map.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `Accept` | string | yes | Sent as the Accept header. The endpoint 406s unless it names BOTH application/json and text/event-stream. |
| `jsonrpc` | string | yes | JSON-RPC version, always "2.0". |
| `id` | integer | yes | JSON-RPC request id. |
| `method` | string | yes | JSON-RPC method, always "tools/call". |
| `params` | object | yes | `&#123;name, arguments&#125;` naming the Exa MCP tool to call and its arguments. |

### `exa.find_similar` - Exa Find Similar

Find pages similar to a given URL using Exa's neural search. Requires RYU_EXA_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | URL to find similar pages for. |
| `num_results` | integer | no | Number of similar results to return (default 10). |
