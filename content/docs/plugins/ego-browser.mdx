## What it does

Ego lite (https://github.com/citrolabs/ego-lite) as an optional provider for Ryu's swappable browser.control layer. One sealed dispatcher launches the installed ego-browser CLI in a conversation-scoped Ego Space, while small adapters keep agents on the stable browser.navigate, browser.tabs, browser.snapshot, browser.click, browser.type, browser.scroll, and browser.screenshot verbs. Requires the Ego lite macOS app and ego-browser on PATH; Ryu does not install Ego lite or copy browser login state.

## What it exposes

### Tools

### `ego_browser.dispatch` - Ego Browser Dispatch

Dispatch one validated browser operation to the conversation-scoped Ego lite Space.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `operation` | string (one of: tabs, navigate, snapshot, click, type, scroll, screenshot) | yes |  |
| `url` | string | no |  |
| `tab_id` | string | no |  |
| `ref` | string | no |  |
| `text` | string | no |  |
| `replace` | boolean | no |  |
| `submit` | boolean | no |  |
| `direction` | string (one of: up, down, left, right) | no |  |
| `amount` | integer | no |  |

### Capabilities

- **Browser** - capability `browser.control`
  - Grant: `browser:control`
  - Target: local-machine
  - Verbs:
    - `browser.tabs` -> `ego_browser.dispatch`
    - `browser.navigate` -> `ego_browser.dispatch`
    - `browser.snapshot` -> `ego_browser.dispatch`
    - `browser.click` -> `ego_browser.dispatch`
    - `browser.type` -> `ego_browser.dispatch`
    - `browser.scroll` -> `ego_browser.dispatch`
    - `browser.screenshot` -> `ego_browser.dispatch`
