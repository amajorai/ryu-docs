## What it does

Ego Browser connects Ryu's swappable `browser.control` layer to [Ego
lite](https://github.com/citrolabs/ego-lite). Agents keep the same `browser.*`
tool names while Ego supplies Chromium tabs, logged-in browser state, and an
isolated Space for each Ryu conversation.

Install Ego lite separately, complete its onboarding, and make the
`ego-browser` command available to Ryu. Then install and enable this plugin from
Marketplace and select **Ego Browser** for `browser.control`. Ego lite currently
supports macOS; check the upstream project for platform updates.

## What it exposes

### Tools

### `ego_browser.tabs` - Ego Browser Tabs

List the tabs in the calling agent's Ego Space.

Backend: inline_deno

_No parameters_ (empty schema).

### `ego_browser.navigate` - Ego Browser Navigate

Open or reuse a tab at a URL in the calling agent's Ego Space and wait for the
document to load.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | Absolute URL to open or reuse. |

### `ego_browser.snapshot` - Ego Browser Snapshot

Read the accessibility snapshot and stable element refs for the selected or
active Ego tab.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `tab_id` | string | no | Optional Ego target id. Omit to use the active tab in the calling agent's Space. |

### `ego_browser.click` - Ego Browser Click

Click a snapshot ref in the selected or active Ego tab.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `ref` | string | yes | Element ref from a recent browser.snapshot result. |
| `tab_id` | string | no | Optional Ego target id. Omit to use the active tab. |

### `ego_browser.type` - Ego Browser Type

Type literal text into a snapshot ref, appending by default or replacing when
requested; optionally press Enter.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `ref` | string | yes | Focusable element ref from a recent browser.snapshot result. |
| `text` | string | yes | Text to insert. |
| `replace` | boolean | no | Replace the field instead of appending at the caret. |
| `submit` | boolean | no | Press Enter after typing. |
| `tab_id` | string | no | Optional Ego target id. Omit to use the active tab. |

### `ego_browser.scroll` - Ego Browser Scroll

Scroll the selected or active Ego tab with a real mouse-wheel event.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `direction` | string (one of: up, down, left, right) | yes | Scroll direction. |
| `amount` | integer | no | Distance in CSS pixels. Defaults to approximately 80% of the viewport. |
| `tab_id` | string | no | Optional Ego target id. Omit to use the active tab. |

### `ego_browser.screenshot` - Ego Browser Screenshot

Capture a PNG screenshot of the selected or active Ego tab as base64 image data.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `tab_id` | string | no | Optional Ego target id. Omit to use the active tab. |

### Capabilities

- **Browser** - capability `browser.control`
  - Grant: `browser:control`
  - Target: local-machine
  - Verbs:
    - `browser.navigate` -> `ego_browser.navigate`
    - `browser.tabs` -> `ego_browser.tabs`
    - `browser.snapshot` -> `ego_browser.snapshot`
    - `browser.click` -> `ego_browser.click`
    - `browser.type` -> `ego_browser.type`
    - `browser.scroll` -> `ego_browser.scroll`
    - `browser.screenshot` -> `ego_browser.screenshot`

## Permissions

**Grants:** `browser:control`, `tool:execute`

The bridge has child-process permission so it can start the fixed
`ego-browser nodejs` command. It has no direct filesystem or network permission;
web traffic and authentication remain inside Ego lite.

## Limits

This provider covers the canonical browsing surface only. Agent Browser's
recording and live-stream extras are not exposed here. To switch back, choose
**Agent Browser** for `browser.control` or disable Ego Browser.

## Engine requirement

Requires Ryu >=0.1.0.
