## What it does

Local-first hybrid workspace search through zvec-grep's `zg` MCP bridge. Use semantic and ranked retrieval over an explicitly indexed workspace, with local models by default and source-linked results. Requires Node.js 22+; no Ryu API key.

## What it exposes

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`zvec_grep`** - zvec-grep's pinned stdio bootstrap bridge. It starts or reuses the local zvec-grep daemon and proxies the default indexed-search MCP toolset over stdin/stdout; Node.js 22+ is required.
