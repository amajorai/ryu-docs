## What it does

Consult a stronger reviewer model for a second opinion - as an auto-review turn hook (toggle / `/advisor`) and as the model-callable `advisor.consult` tool, a declarative HTTP tool routed through Core's `/api/advisor/consult` bridge.

## What it exposes

### Tools

### `advisor.consult` - Advisor Consult

Consult a stronger advisor model for a second opinion. Call this BEFORE substantive work (before committing to an approach), when you are stuck, or before declaring a task done. The advisor reviews the question and context you provide and returns concrete, actionable advice. Give its advice serious weight. Returns &#123; ok, model, advice &#125;.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `question` | string | yes | What you want advice on - your plan, the approach you are about to take, the bug you are stuck on, or the answer you are about to commit to. |
| `context` | string | no | Optional. The relevant details the advisor should review: your current plan, the code or answer in question, key constraints, and anything you have already tried. The advisor only sees what you put here, so include enough to judge. |
| `model` | string | no | Optional explicit advisor model id. Defaults to the configured 'advisor-model' preference, else the node default. |

## Permissions

**Grants:** `hook:side-model`, `tool:http-egress:127.0.0.1`

## UI it contributes

### Slash commands

- **/advisor** - Ask a stronger advisor model to review the whole conversation and advise. Add a focus, e.g. '/advisor is this the right approach?'.

- **advisor.review** (on: `post_assistant_turn`)
