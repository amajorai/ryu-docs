## What it does

Worked example for tools/toolsmith - a real, verified inline_deno tool. Not registered with Core and not shipped; it exists so the scaffold → verify pipeline has an end-to-end regression test.

## What it exposes

### Tools

### `text_chunk` - text_chunk

Split a string into fixed-size chunks with optional overlap, returning each chunk with its start offset.

Backend: inline_deno

| Parameter | Type | Required | Description |
|---|---|---|---|
| `text` | string | yes | The text to split. |
| `size` | integer | no | Characters per chunk. Defaults to 512. |
| `overlap` | integer | no | Characters each chunk re-reads from the previous one. Must be less than size. Defaults to 0. |

## Permissions

**Grants:** `tool:execute`
