## What it does

Pomodoro Timer puts a focus timer in your chat. Ask an agent something like "start a pomodoro for the release notes" or "25 minutes of focus, then a 5 minute break" and the reply shows a timer you control.

The timer cycles focus rounds and breaks. After a set number of completed focus rounds, a long break replaces the short one. It counts down locally, so it keeps working while the agent does other things.

## Using the timer

- **Start**, **Pause**, and **Resume** control the current phase.
- **Skip** (the skip-forward icon) moves to the next phase. A skipped focus round does not count as completed and leads to a short break.
- **Reset** (the circular arrow) returns to the first focus round.
- **Chime** (the speaker icon) turns the chime at each phase change on or off. Browsers allow sound only after you click inside the widget, so the chime is ready once you press **Start**.
- **Pop out** (the picture-in-picture icon) appears when your Ryu surface supports picture-in-picture. It moves the timer into a floating panel.

By default the timer waits for you to press **Start** at each new phase. Ask for automatic start ("auto-start the breaks") to have each phase begin as soon as the previous one ends.

Progress is saved with the chat. If you reload, a running timer resumes from its original end time.

## Settings the agent can pass

All settings are optional. If a value is outside its range, the agent gets an error naming the setting and no timer is shown. Values are never silently adjusted.

| Setting | Range | Default |
| --- | --- | --- |
| Task label | Up to 120 characters | None |
| Focus length | 1 to 180 minutes | 25 |
| Short break | 1 to 60 minutes | 5 |
| Long break | 1 to 120 minutes | 15 |
| Focus rounds before a long break | 1 to 12 | 4 |
| Start each phase automatically | On or off | Off |

## Privacy

The timer runs in Ryu's sandboxed widget frame. It makes no network requests, cannot call tools or send messages, and stores nothing outside the chat's widget state.

## Required grants

Pomodoro Timer requests two grants. `mcp:server` lets it run its small local MCP server, and `widget:render` lets the timer appear in chat. If the widget cannot render on a surface, the agent's reply still describes the session settings as text.

## What it exposes

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`pomodoro`** - Pomodoro MCP server: the start tool and the ui://widget/pomodoro.html timer resource.
