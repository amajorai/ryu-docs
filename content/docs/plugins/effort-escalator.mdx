## What it does

Detects stalled work with a cheap background judge and moves the next turn up a configured reasoning-effort or model ladder, per agent or globally.

## Permissions

**Grants:** `hook:side-model`, `storage:kv`, `preferences:read`

## UI it contributes

### Settings tabs

- **Effort escalation** (fields: Automatically escalate stuck tasks (toggle), Judge model (model_picker), Agent and global escalation ladders (textarea))

### Turn hooks

- **effort-escalator.judge** (on: `post_assistant_turn`)
- **effort-escalator.select** (on: `pre_model_select`)
