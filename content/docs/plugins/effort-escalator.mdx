## What it does

Effort Escalator is an opt-in recovery policy for long-running work. After the configured quiet
period, a cheap read-only side model checks the recent conversation. If it identifies looping,
repeated failures, or another clear stall, the **next** turn uses the next step in a model or
reasoning-effort ladder.

It never changes a request that is already running. Agent-specific rules override the global rule,
and `max_escalations` caps how many steps a conversation can take. The main agent's saved defaults
are not rewritten.

## Settings

- **Automatically escalate stuck tasks** - off by default.
- **Judge model** - optional inexpensive model for the read-only stall check.
- **Agent and global escalation ladders** - JSON rules with `after_minutes`, `max_escalations`, a
  `ladder` of `from`, `to`, and optional `effort` values, plus optional per-agent overrides.

The default delay is 30 minutes. Set a shorter or longer delay for the work pattern you expect, and
keep the ladder explicit so every escalation is predictable.

## Permissions and cost

The plugin uses a side-model hook, node key-value storage for per-conversation state, and read-only
preferences. Each check may make one side-model call; enabling the plugin does not automatically
enable the policy until its setting is turned on.
