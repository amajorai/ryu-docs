## What it does

Notices when you correct the agent, writes the lesson down as a one-line rule in a Space, and hands every later session that rule list before the first word is generated - so a mistake you have already fixed once stops coming back. Each rule is an ordinary Space document you can read, edit or delete, and `/mistakes` lists, adds and forgets them from the chat.

## Permissions

**Grants:** `hook:side-model`, `storage:kv`, `preferences:read`, `spaces:docs`

## UI it contributes

### Slash commands

- **/mistakes** - The rules learned from past corrections. `/mistakes add <rule>` writes one by hand, `/mistakes forget <number>` drops one, `/mistakes off` stops learning in this chat.

### Settings tabs

- **No More Mistakes** (fields: Learn from corrections (toggle), Brief the agent at the start of a chat (toggle), Space (text), Rules per briefing (number), Extraction model (model_picker))

### Turn hooks

- **no-more-mistakes.capture** (on: `pre_user_turn`)
- **no-more-mistakes.brief** (on: `session_start`)
- **no-more-mistakes.command** (on: `pre_user_turn`)
