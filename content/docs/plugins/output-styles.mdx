## What it does

The nine built-in output styles - ELI5, I have ADHD, Explanatory, Learning, Proactive, Plain text, No AI slop, Bro and Gen Z. A style is appended to (or replaces) the agent's base instructions for the turn, so it changes how the agent talks - role, tone, default response shape - and never what it knows, which tools it has, or which model runs. Pick one in the composer; browse them in the Store's Output Styles tab.
