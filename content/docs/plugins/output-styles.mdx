## What it does

The eleven built-in personality profiles - ELI5, I have ADHD, Explanatory, Learning, Proactive, Plain text, Plain Technical, No AI slop, No Hype, Bro and Gen Z. Assign a profile to each agent to shape how it talks - role, tone, default response shape - without changing what it knows, which tools it has, or which model runs. Browse profiles here and choose one in the agent editor.
