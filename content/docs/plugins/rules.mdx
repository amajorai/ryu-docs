## What it does

Discover Cursor- and Claude-style project rules and apply them to agent context, with per-agent controls for automatic injection, matching mode, and plan-turn budgets.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | full |
| cli | full |

## Permissions

**Grants:** `preferences:read`, `storage:kv`

## UI it contributes

### agent edit panels

- **Rules** - Configure project and agent rules, matching mode, automatic context injection, and turns per plan. (type: rules)

### Turn hooks

- **rules.context** (on: `context`)

## Engine requirement

Requires Ryu >=0.1.0.
