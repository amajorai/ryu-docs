## UI it contributes

### agent edit panels

- **Rules** - Configure project and agent rules, matching mode, automatic context injection, and turns per plan. (type: rules)

Changes in the Rules panel save to the active Core node as you edit them. If a save fails, the panel keeps your edits visible and shows an error. The next successful save clears the error. Reopening the agent restores the last saved settings. This panel has no separate Save or Cancel action.

### Turn hooks

- **rules.context** (on: `context`)
