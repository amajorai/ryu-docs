## What it does

Composio Connect gives Ryu a single remote [Model Context Protocol](https://modelcontextprotocol.io)
connection to Composio's connected third-party apps. It is the Ryu integration for Composio's
**For You** experience and does not require a Composio API key.

The direct Composio API integration remains available separately. Its actions use the
`composio.<action>` namespace; this plugin uses `composio_connect.<tool>` so the two paths can be
enabled together without colliding.

## Setup

Open **Marketplace → Connections**, choose an identity profile, and select **Connect** on
**Composio Connect**. Ryu opens Composio's browser authorization flow, then stores the provider
token in the node's encrypted identity storage. If the account needs to be connected later, a tool
call returns a connection link instead of sending an unauthenticated request.

## MCP server

- **`composio_connect`** - hosted Streamable HTTP MCP at `https://connect.composio.dev/mcp`.

## Permissions and Ryu Work mode

The plugin declares the `mcp:server` and `identity.read` grants needed for Core's OAuth broker.
Composio's own read/write/destructive permission groups remain upstream connector policy. Ryu also
keeps its local tool allowlist and approval policy around every `composio_connect.*` call.

Ryu Work chat mode's **Auto** choice is an agent permission preset. It does not change Composio's
upstream permission groups or bypass Ryu's approval boundary.
