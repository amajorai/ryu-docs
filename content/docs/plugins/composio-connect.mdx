## What it does

Connect Ryu to Composio's hosted For You MCP server with OAuth. The connection exposes Composio's connected-app tools without requiring a Composio API key; Ryu still applies its own tool allowlists and approval policy.

## What it exposes

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`composio_connect`** - Composio Connect - hosted MCP access to connected third-party apps. Authorize the account from Marketplace → Connections before using its tools.

## Permissions

**Grants:** `mcp:server`, `identity.read`

When an account is connected from Marketplace → Connections, Ryu asks for a separate
connection-access level. The default is **Risk-based (recommended)**: safe reads flow normally and
Ryu's smart approval policy asks before risky writes or deletes. **Read only** blocks all changes,
**Write access** blocks deletes, and **Full access, including delete** allows known delete actions
while keeping Ryu's destructive-action confirmation. This per-connection ceiling is enforced by
Core; it does not replace the provider's OAuth scopes, the agent tool allowlist, or the Gateway's
`identity.read` grant.

## Engine requirement

Requires Ryu >=0.1.0.
