## What it does

Message Reactions adds a reaction action to chat messages. Hover a message and choose the reaction
button for a quick emoji, or choose **+** in the popover to search the complete emoji picker.
Selecting an emoji applies it immediately; the picker then closes.

The desktop supplies the native picker and Core supplies persistence and realtime updates. A
temporary chat has no persisted message surface, so it does not accept or save reactions.

## Contribution

The `@ryu/reactions` plugin contributes the **Add reaction** message action. Disable it to remove
the reaction affordance and its active persistence path without affecting ordinary messages.

## Engine requirement
