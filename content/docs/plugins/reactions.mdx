## What it does

Adds emoji reactions to persisted chat messages through the shared message-action contribution surface.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | limited |
| mobile | limited |
| extension | limited |
| web | limited |
| cli | none |

## UI it contributes

### message actions

- **Add reaction** (capability: `reactions.toggle`)

Requires Ryu >=0.1.0.
