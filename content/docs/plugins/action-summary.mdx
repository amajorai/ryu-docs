## What it does

Explains streamed thinking blocks and tool calls in one plain-language line per action, using a configurable small side model.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | full |
| mobile | limited |
| extension | limited |
| web | full |
| cli | full |

## Permissions

**Grants:** `hook:side-model`, `preferences:read`

## UI it contributes

### Settings tabs

- **Action summaries** (fields: Explain thinking and tool actions (toggle), Detail (select), Summary model (model_picker))

### Turn hooks

- **action-summary.action** (on: `action`)

## Engine requirement

Requires Ryu >=0.1.0.

## Activation

Activates on: `*`
