## What it does

Verify work with visual evidence: `/receipt <goal>` makes the agent capture a screenshot or screen recording of the thing actually working, then an INDEPENDENT verifier agent opens that artifact and judges what it can SEE against the goal. Where `/proof` verifies by re-reading the workspace, this one requires a durable artifact a human can look at afterwards. Resubmitting an old capture does not count. `/receipt clear` stops the loop.

## Permissions

**Grants:** `hook:run-agent`, `storage:kv`, `preferences:read`

## UI it contributes

### Slash commands

- **/receipt** - Pursue a goal until the agent captures a screenshot or screen recording of it working AND an independent verifier agent confirms, from the artifact itself, that it shows the goal done. Use '/receipt clear' to stop.

### Settings tabs

- **Receipts** (fields: Required evidence (select), Maximum verification rounds (number))

### Turn hooks

- **receipts.loop** (on: `post_assistant_turn`)
