## What it does

Verify work with visual evidence. `/receipt <goal>` makes the agent capture a screenshot or screen recording of the working result, then an independent verifier agent opens that artifact and compares what it shows with the goal. `/proof` verifies by re-reading the workspace; Receipts requires a durable artifact that a human can inspect later. Resubmitting an old capture does not count. `/receipt clear` stops the loop.

## Permissions

**Grants:** `hook:run-agent`, `storage:kv`, `preferences:read`

## UI it contributes

### Slash commands

- **/receipt** - Pursue a goal until the agent captures a screenshot or screen recording of it working and an independent verifier confirms from the artifact itself that it shows the goal done. Use `/receipt clear` to stop.

### Settings tabs

- **Receipts** (fields: Required evidence (select), Maximum verification rounds (number))

### Turn hooks

- **receipts.loop** (on: `post_assistant_turn`)
