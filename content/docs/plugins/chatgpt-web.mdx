## What it does

Use a ChatGPT Web subscription through Ryu's signed-in Browser app as an OpenAI-compatible model provider.

## Surfaces

| Surface | Support |
|---|---|
| gateway | none |
| core | full |
| desktop | full |
| island | full |
| mobile | limited |
| extension | limited |
| web | full |
| cli | full |

## Permissions

**Grants:** `sidecar:process`, `browser:control`, `preferences:read`

## UI it contributes

### Settings tabs

- **ChatGPT Web** (fields: Enabled profiles (text))

## Dependencies

Requires these apps:
- `@ryu/browser` (min `0.1.15`)

Needs these grants: `browser:control`

## Engine requirement

Requires Ryu >=0.1.0.

## Sidecar

Runs an out-of-process sidecar: `bridge`.
