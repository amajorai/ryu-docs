---
title: Plugin and app Doctor
description: Validate an installed plugin or app through Core's loaded manifest and lifecycle state.
---

The marketplace Health score is a deterministic, read-only scan of the listing data published by an
app or plugin. It covers provenance, documentation, maintenance, disclosures, permissions, and
manifest signals before you install. A score is useful evidence, not a guarantee that code is safe.

After installation, validate the artifact Core actually loaded:

```bash
ryu plugin doctor
ryu plugin doctor com.example.my-plugin
ryu app doctor com.example.my-app       # alias for the same lifecycle surface
ryu plugin doctor --json                # CI-friendly output
```

The runtime Doctor checks the loaded manifest and lifecycle record through the same Core path used by
the Store and enable/disable routes. It reports:

- manifest identity, name, version, and runnable shape;
- installed-version and Safe Mode state drift;
- missing or disabled plugin dependencies;
- declared grants that do not match the approved lifecycle record; and
- duplicate contributions or other loader reconciliation problems.

The command is a lint profile. It is read-only, does not execute plugin code, start sidecars, call
remote provider endpoints, or change permissions. That boundary is deliberate: catalog browsing
must not execute untrusted code. A future deep developer probe can be opted into separately after
the developer has trusted the local checkout.

The Health tab links the two layers: the marketplace score tells you what the publisher and catalog
make observable, while `ryu plugin doctor` tells you whether the installed artifact is coherent in
your Core runtime. The catalog score identifies ruleset `marketplace-plugin-1`; the runtime report
identifies ruleset `plugin-runtime-1`. Findings include stable check IDs, severity, evidence, and a
recommended action; the process exits non-zero when an error is present.

<Callout type="warn">
  A passing score or Doctor run is not a sandbox and is not a security guarantee. Review requested
  permissions, publisher provenance, source, and network behavior before enabling an unfamiliar
  plugin. Sidecars and plugin code run with the permissions granted by the host.
</Callout>
