## What it does

Search everything Shadow has captured (screen text, audio transcripts, input) and summarize recent activity. Exposed as declarative HTTP tools that reach the device-local Shadow sidecar through Core's authenticated `/api/shadow/*` proxy (which injects Shadow's bearer token).

## What it exposes

### Tools

### `shadow.search` - Shadow Search

Full-text search over everything Shadow has captured (screen text, audio transcripts, input). Returns matching timeline entries. Shadow capture is cross-platform (Windows, macOS, Linux); when the sidecar is not running the tool reports itself unavailable.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `q` | string | yes | Text to search for across captured screen/audio/input history. |
| `limit` | integer | no | Max results to return (default 20). |

### `shadow.semantic_search` - Shadow Semantic Search

Semantic (vector) search over captured history. Use for fuzzy, meaning-based recall when exact keywords are unknown. Shadow capture is cross-platform (Windows, macOS, Linux); when the sidecar is not running the tool reports itself unavailable.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `q` | string | yes | Natural-language query matched semantically against captured history. |
| `limit` | integer | no | Max results to return (default 5). |

### `shadow.timeline` - Shadow Timeline

Fetch captured timeline entries within an explicit time range (microseconds since the Unix epoch). Shadow capture is cross-platform (Windows, macOS, Linux); when the sidecar is not running the tool reports itself unavailable.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `start` | integer | yes | Range start, microseconds since the Unix epoch. |
| `end` | integer | yes | Range end, microseconds since the Unix epoch. |

### `shadow.recent_context` - Shadow Recent Context

Summarize what the user has been doing in the last N minutes, drawn from captured history. Shadow capture is cross-platform (Windows, macOS, Linux); when the sidecar is not running the tool reports itself unavailable.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `q` | integer | no | How many minutes back to summarize (Shadow defaults the window when omitted; typically 10). |
