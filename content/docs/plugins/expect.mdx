## What it does

Browser-based QA for agent code. Expect reads the current changes, creates a test plan, and runs it in a real browser with Playwright to catch regressions in behavior, performance, security, and design.

## What it exposes

### MCP server

MCP (Model Context Protocol) is a standard way for an AI host to find and call tools. An MCP server provides those tools.

- **`expect`** - Expect - test the current agent changes in a real browser with Playwright. Launched via `npx -y expect-cli@0.1.3 mcp`; requires Node.js and downloads the pinned CLI on first use. Ask the agent to run the Expect workflow after making UI changes.
