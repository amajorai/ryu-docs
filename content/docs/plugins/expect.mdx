## What it does

[Expect](https://www.expect.dev/) reads the current changes, creates a test plan,
and runs it in a real browser with Playwright. It checks behavior, performance,
security, and design regressions so an agent can fix issues and re-run the plan.

## MCP server

Ryu installs and enables **`@ryu/expect`** by default. The server starts lazily
through the local Node.js toolchain:

```bash
npx -y expect-cli@latest mcp
```

The tools are exposed under the `expect__` namespace. Node.js and network access
for the first package download are required. Ask an agent to run the Expect
workflow after making browser-facing changes.

## Permissions

**Grant:** `mcp:expect`
