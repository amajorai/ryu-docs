## What it does

[Expect](https://www.expect.dev/) reads the current changes, creates a test plan,
and runs it in a real browser with Playwright. It checks behavior, performance,
security, and design regressions so an agent can fix issues and re-run the plan.

## MCP server

Ryu ships **`@ryu/expect`** as an official Core-tier plugin, but it is opt-in.
Install and enable it explicitly before the server starts through the local
Node.js toolchain:

```bash
npx -y expect-cli@latest mcp
```

The tools are exposed under the `expect.` namespace. Node.js and network access
for the package download are required. Because enabling it downloads third-party
code, it is not activated on a fresh install. Ask an agent to run the Expect
workflow after making browser-facing changes.

## Permissions

**Grant:** `mcp:expect`
