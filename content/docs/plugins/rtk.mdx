## What it does

Run a dev command through RTK (Rust Token Killer) and get a token-compressed version of its output (60-90% fewer tokens), exposed as a declarative `command` tool that shells out to the locally-installed `rtk` binary. BYO - no API key.

## What it exposes

### Tools

### `rtk__run` - RTK Run

Run a dev command through RTK (Rust Token Killer) and return a token-compressed version of its output (60-90% fewer tokens). Prefer this over running noisy commands (git status/log/diff, test runners, build tools, ls/find/grep) directly - you get the same information for a fraction of the context.

Backend: CLI command

| Parameter | Type | Required | Description |
|---|---|---|---|
| `command` | string | yes | The dev command to run through RTK, e.g. "git status", "cargo test", "ls -la". RTK runs it and returns a token-compressed version of its output. |
| `mode` | string (one of: wrap, proxy, test, err) | no | wrap (default): filter+compress the output. proxy: run raw with tracking (no filtering). test: keep only failures. err: keep only errors. |

## Permissions

**Grants:** `tool:command:rtk`
