## What it does

Google's own search results as JSON via the Serper API (https://serper.dev), plus single-page scraping, exposed as two declarative HTTP tools. Provides the swappable `web.search` and `web.extract` layers, so selecting it in the layer picker re-points the stable `web__search` / `web__extract` tools at Serper without changing what agents call. Serper is a paid, credit-metered API with a free allowance; requires a BYOK Serper API key.

## What it exposes

### Tools

### `serper__search` - Serper Google Search

Google web search, returned as structured JSON. The ranked organic results carry a title, link, and snippet. Costs 1 credit per query. Requires RYU_SERPER_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `q` | string | yes | The search query, exactly as it would be typed into Google. |
| `num` | integer | no | Number of results to request (default 10). Google decides the real page size, so fewer may come back. |
| `page` | integer | no | One-based results page (default 1). |
| `gl` | string | no | Two-letter country code to search from (default us). |
| `hl` | string | no | Two-letter interface language code (default en). |
| `autocorrect` | boolean | no | Let Google correct apparent typos in the query (default true). Set false to search the phrase verbatim. |

### `serper__scrape` - Serper Scrape

Fetch one web page and return its readable content as text, and as markdown when asked. Costs 2 credits for a typical page, up to 6 or 10 for a hard-to-scrape one. Requires RYU_SERPER_API_KEY.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | The URL of the page to scrape. |
| `includeMarkdown` | boolean | no | Also return the page as markdown alongside the plain text (default true here). |

### Capabilities

- **Search** - capability `web.search`
  - Verbs:
    - `web__search` -> `serper__search`
- **Extract** - capability `web.extract`
  - Verbs:
    - `web__extract` -> `serper__scrape`

## Permissions

**Grants:** `tool:http-egress:google.serper.dev`, `tool:http-egress:scrape.serper.dev`
