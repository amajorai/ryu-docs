## What it does

Agent-readiness scoring from ora (https://ora.ai): look up or run a 0-100 score and A-F grade for a domain or MCP server, re-run selected checks after a fix, browse the check catalog, discover agent-ready products by intent, and draft a domain's agent discovery files. Read-only and keyless.

## What it exposes

### Tools

### `ora.score` - ora Score

Get ora's cached agent-readiness score for a domain: `score` (0-100), `grade` (A-F), `analysisStatus`, and a layer-by-layer breakdown where each check has a status, details and recommendation. Always try this before `ora.scan`. A domain ora has never scanned answers 404 with `code: DOMAIN_NOT_SCANNED`; run `ora.scan` then. Pass `format: audit` for the documented, versioned audit shape.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `domain` | string | yes | Domain to look up, e.g. stripe.com. |
| `format` | string (one of: audit) | no | `audit` returns the versioned, allowlisted audit shape with internal fields dropped. |
| `include` | string | no | Comma-separated opt-in expansions, e.g. `essentials` or `siteType`. |
| `siteType` | string (one of: content, business, app, store) | no | Score the cached scan against this site type instead of the detected one. |
| `competitors` | string (one of: 1) | no | `1` adds the domain's category leaders and leaderboard neighbours. |

### `ora.scan` - ora Scan

Run a fresh ora agent-readiness scan of a public domain, MCP server URL or MCP App URL (ora documents about 30 seconds, which is also Core's HTTP tool timeout, so a slow scan can come back unavailable: check `ora.score` before retrying). Use only when `ora.score` has no cached result or the user asks for a rescan. Deep checks can finish later: while `analysisStatus` is not `complete`, poll `ora.score` for the same domain.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | Domain, MCP server URL or MCP App URL to scan, e.g. stripe.com. |
| `mcpUrl` | string | no | Optional explicit MCP server URL for the target. |

### `ora.run_checks` - ora Run Checks

Re-run selected ora checks against a URL and get per-check results without an aggregate score: the re-verify step after shipping a fix. Check ids come from `ora.checks` or a score's layer breakdown.

Backend: HTTP · Method: POST

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | Website, MCP server or API URL to check. A bare domain is accepted. |
| `checkIds` | array | yes | Check ids to run, e.g. ["llms-txt-exists", "ard-catalog"]. |
| `mcpUrl` | string | no | Optional explicit MCP server URL for the target. |

### `ora.checks` - ora Check Catalog

List ora's full check catalog: every check id with its layer, applicability, maturity and maximum score.

Backend: HTTP · Method: GET

_No parameters_ (empty schema).
### `ora.discover` - ora Discover

Find agent-ready products that match a need, e.g. `send transactional email`. Each match carries its ora score, grade, category and tags.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `intent` | string | yes | What the product should do, in plain language. |
| `limit` | integer | no | Maximum number of products to return. |

### `ora.agent_files` - ora Agent Files

Draft a domain's own agent discovery files (ard.json, ai-catalog.json, poppy.json) from what ora observed. Pass `include: all` to also draft llms.txt, a robots.txt edit, an API catalog and MCP server cards. Drafts only: review them before publishing.

Backend: HTTP · Method: GET

| Parameter | Type | Required | Description |
|---|---|---|---|
| `domain` | string | yes | Domain to draft files for, e.g. example.com. |
| `include` | string (one of: all) | no | `all` adds llms.txt, a robots.txt edit, an API catalog and MCP server cards. |
