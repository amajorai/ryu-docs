## What it does

Scans each answer for security vulnerabilities and has a second model review the code before you ship it. Off until you flip the Security review toggle in the composer, or run `/security` for a one-off review of the last answer; the reviewer model is configurable.

## Permissions

**Grants:** `hook:side-model`

## UI it contributes

### Composer controls

- **Security review** - Scan each answer for security vulnerabilities and review the code with a second model. (type: toggle)

### Settings tabs

- **Security review** (fields: Reviewer model (model_picker))

### Slash commands

- **/security** - Run a one-off security review of the last answer.

### Turn hooks

- **security-guidance.review** (on: `post_assistant_turn`)

## Engine requirement

Requires Ryu >=0.1.0.
