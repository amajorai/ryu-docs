## What it does

Read-only MCP access to the Ryu documentation on docs.ryuhq.com - search the docs and pull any page into context as Markdown, without leaving your agent. Backed by the same content /llms.txt serves, exposed as tools by the hosted docs MCP server at https://docs.ryuhq.com/mcp. Ships enabled by default.

## What it exposes

### MCP server

- **`docs`** - Ryu Docs - read-only search + page content over the Ryu documentation (docs.ryuhq.com). Tools: docs_search (search the docs), docs_get_page (fetch a page as Markdown), docs_index (list pages, optionally per section).

## Permissions

**Grants:** `mcp:docs`

## Engine requirement

Requires Ryu >=0.1.0.
