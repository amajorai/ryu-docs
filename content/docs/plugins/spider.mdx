## What it does

High-performance web crawling and content extraction via the Spider CLI (https://spider.cloud), exposed as a declarative `command` tool that shells out to the locally-installed `spider` binary. No API key.

## What it exposes

### Tools

### `spider.crawl` - Spider Crawl

Crawl a URL with the Spider web crawler and return the extracted page content. Use depth=0 for a single page; depth>0 follows links up to that many hops.

Backend: CLI command

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | string | yes | The URL to crawl and extract content from. |
| `depth` | integer | no | How many link hops to follow from the start URL (default 1 - single page only). |
| `limit` | integer | no | Maximum number of pages to crawl (default 10). |

### Capabilities

- **Extract** - capability `web.extract`
  - Verbs:
    - `web.extract` -> `spider.crawl`
- **Crawl** - capability `web.crawl`
  - Verbs:
    - `web.crawl` -> `spider.crawl`
