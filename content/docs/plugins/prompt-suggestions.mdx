## What it does

Fast next-prompt suggestions in the chat composer. Enabling this plugin lifecycle-gates Core's single suggestion endpoint; after an assistant turn, the desktop requests one best-effort background generation from recent chat context. The plugin does not run a duplicate post-turn hook.
