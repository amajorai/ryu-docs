## Highlights

### Agent Plugins v1 package loading

Users can now install an Agent Plugins v1 extension by placing its directory in `~/.ryu/plugins`. Core recognizes the standard `plugin.json`, `skills/<slug>/SKILL.md`, and `mcp.json` layout and translates it into a native manifest, so a package built for Cursor, VS Code, or another conformant client loads as-is.

The import runs in front of the normal loader, so the usual validation still applies: id validation, legacy-id canonicalization, semver, duplicate-id rejection, and code-file hydration all behave the same for an imported plugin.

Affected packages: `ryu-core`

### Agent Plugins v1 package export

Every Ryu app and plugin can now be exported as a conformant Agent Plugins v1 package, the vendor-neutral extension format used by Cursor and VS Code.

The export follows the spec's closed manifest schema, so only the allowed standard fields are written and Ryu-specific manifest fields are kept out of the portable package.

Affected packages:

- [`@ryu/activity`](https://github.com/amajorai/ryu-activity/releases/tag/v0.1.5)

### Managed node purchase end to end

Managed nodes can now be bought end to end from the website. The catalog shows real Hetzner monthly prices and marks per-location availability separately, so an out-of-stock type still displays its actual cost.

The add-node flow carries the selected instance through checkout, and a one-hour negative cache keeps a Hetzner outage from flapping the catalog to empty.

Affected packages: `Website (ryuhq.com)`, `@ryu/api`, `@ryu/db`

### Desktop onboarding without local Core

The desktop app no longer requires a local Ryu Core before it can do anything. Preflight no longer blocks the tree ahead of sign-in and onboarding can connect to an existing node instead of forcing the local-core path.

The choose step now offers three paths, none of which presume a local Core is running, and production no longer downloads core and gateway binaries at boot before the user has made a choice.

Affected packages: `Desktop app`, `@ryu/blocks`
