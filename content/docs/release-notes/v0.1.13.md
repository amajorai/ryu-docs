## Breaking changes

### Managed gateways now bill by default

A managed gateway that has an internal_secret now enables credits by default, so the previous behaviour of serving tokens, tool calls, media and sandbox work without debiting anything is gone.

With credits enabled, an unset rate on any of five metered surfaces — Composio tool calls, image, video, TTS and STT — is now a hard startup failure that names each offending surface, validated at boot rather than at first debit. Those rates previously defaulted to zero, charging the customer nothing while the provider still billed.

Affected packages: `ryu-gateway`

### Plan and deposit-fee repricing

The plan catalog changed: Pro is $39 with a $15 pool (was $20), Max is $99 with a $30 pool (was $200/$150) and is now single-seat, and Teams is $49 per seat with a $15 per-seat pool. Anything that displays or computes plan prices, pool sizes or seat rules has to be updated to match, and checkout now refuses multi-member orgs on Max because Max is single-seat.

Deposit fees are now 15% base, 13% Pro and 12% for Max and Teams, with a $1.50 floor, replacing the 10% base and 5% subscriber perk. INCLUDED_CREDIT_FRACTION_DEFAULT's blanket 50% rule is replaced by INCLUDED_CREDIT_FRACTION_MAX, a 40% cap that constrains every per-plan override; code or documentation referencing the removed default must move to the cap.

Production had zero active subscriptions when this landed, so nothing migrates. New plan-economics tests encode the 40% cap, per-plan monthly and yearly profitability, top-up profitability from $5 to $500, and a dominance test; two vouchers.test.ts cases asserting Max yearly loses money were replaced because the repricing made them false.

Affected packages: `@ryu/auth`

## Highlights

### Chat media and workspace navigation

Video generations now render in the chat with the same treatment images already had, including a poster frame, a duration and a playable element. Failed generations of either kind now offer a Retry action. The new video-generation component in @ryu/ui mirrors image-generation in shape, states and prop naming.

The sidebar's Projects and Spaces sections are now single pickers whose default option is the aggregate, with a new Appearance toggle restoring the original one-row-per-container layout. Date grouping moved into generic helpers in lib/sidebar/date-buckets.ts. An empty chat start page now shows a Launchpad of app icon tiles below the composer, each opening an enabled app with a full-page UI.

### Node time zones and deferred updates

Every managed node now carries its own time zone, defaulted to the zone the machine reports; the gateway reads TZ, then /etc/timezone, then /etc/localtime symlink, then UTC, and the control plane records detectedTimeZone. Operators can set or clear the override through the timezone endpoint, with clearing treated as a normal state, and a bad zone is refused at the API. GET /api/control-plane/nodes now emits serverId resolved through gatewayCredentialId, and Node carries orgId and serverId; the Quiet hour section is gated on node.managed plus both ids being present.

Core can schedule a deferred update through POST /api/update/schedule, which pins the asset the user was shown and computes the next 03:00 in the node's own zone. The existing scheduler tick performs the install, the deferred record is cleared before the install rather than after, and DST is resolved through chrono-tz. The desktop app can request the deferral for a remote node and names the node's zone as well as the time in the confirmation.

### Pricing calculator and self-hosted options

The pricing-page savings calculator now has a second, separately opt-in group of rows that count the work Ryu displaces rather than only the SaaS subscriptions it replaces. Buyers can add the people they would otherwise hire, such as an SDR, support agent, analyst or ops lead, along with reclaimed ops hours, tickets handled by hand, agencies and contractors, go-to-market tooling, data enrichment, and the API keys they would otherwise hold themselves. Every row in this group is off by default.

The pricing page now sells self-hosting through a segmented card control that acts as a deployment switch above the existing audience and billing controls. Choosing the self-hosted side hides the audience and billing pill rows and the savings calculator, and shows a shelf of two cards. The cards state the licence boundary: core, SDK and CLI are Apache-2.0, while gateway and gateway are AGPL-3.0.
