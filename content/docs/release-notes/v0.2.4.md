## Highlights

### Skill Distribution System

This release introduces a comprehensive skill distribution system, allowing users to export skills from the editor, store, and library, and install them to specific targets. It includes APIs for skill target management and automatic distribution of default skills to saved agents.

### Rooms and Web Agent Integration

Rooms hosting is enabled with LAN share origins, and active-node model rooms are added. Web agent surfaces are finalized for improved user interaction and accessibility.

### Tailcat Network Backend

A new network backend called Tailcat is introduced, enhancing the platform's networking capabilities for agents and communication across local and web environments.
