## Highlights

### Release artifacts for every satellite

Every satellite repository now ships real downloadables on its releases. Previously only the backend satellites attached binaries; the nine UI companions, browser, voice, and predict released source alone.

The workflow generator builds each app according to its kind: Rust binaries for backend and predict, a tarball of the prebuilt UI bundle, Electron installers for browser, and a Python wheel plus sdist for voice. Rolling canary and nightly releases come from the same job, so artifacts appear there as well.

### Porting satellite PRs

Contributors can now open a PR against a public satellite and pull the change into the monorepo with one script. port-pr.sh applies the PR's patch, remaps satellite paths to the monorepo layout, and keeps the contributor as co-author.

The script refuses to run on a dirty tree and checks the patch applies before touching anything. Satellite READMEs now present each repo as the home of its app rather than a read-only mirror, making the porting flow the supported way to contribute.
