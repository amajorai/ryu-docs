## Highlights

### Env sync file export/import

Ryu's environment sync can now export and import settings to a portable file, letting you transfer environment configuration between machines without a direct connection. The new --file flag defaults to ryu-env.bundle.b64 in the current directory.

Shortcuts env:export:file and env:import:file wrap the new behavior, and bundle files are gitignored so they are not accidentally committed.
