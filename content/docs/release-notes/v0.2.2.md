## Highlights

### App UIs and workspace mentions

Invoices gained a React interface, and Teams gained a group roundtable view backed by shared team data. The mobile drawer gained Store, Marketplace and Teams screens plus node connection controls.

Desktop chat gained workspace resource mentions and shared picker controls for mentions, agents and output styles. Island gained shared dictation and speech-processing contracts with matching IPC wiring.

Affected packages:

- [`@ryu/invoices`](https://github.com/amajorai/ryu-invoices/releases/tag/v0.2.2)
- [`@ryu/teams`](https://github.com/amajorai/ryu-teams/releases/tag/v0.2.2)
- `Mobile app`
- `Desktop app`
- `Island`

### Marketplace availability and subscription usage

Marketplace listings now declare their supported surfaces, with Desktop and mobile clients reading the same availability information. Billing, purchases, entitlements and marketplace membership handling were updated alongside them.

The Desktop Usage page gained a subscription account dashboard for connected ChatGPT, Claude and GitHub Copilot accounts. It reads provider-reported limits and reset windows through Core without switching the account used for the next chat.

Affected packages:

### Passkey follow-up verification

After email-and-password sign-in, accounts with enrolled passkeys now verify a passkey before other follow-up factors. If the passkey is unavailable, users can continue with 2FA; email verification is the last fallback when 2FA is not enabled.

The website sign-in flow uses the new login assurance logic in @ryu/auth. The authentication-and-pairing and account-security guides describe the same sequence.

Affected packages:

- `Documentation site (docs.ryuhq.com)`
- `Website (ryuhq.com)`
- `@ryu/auth`
- `@ryu/blocks`

### UI documentation and extension guides

The documentation site gained a dedicated UI realm covering components, hooks, themes and the editor. A platform map and integration guides were added to the docs and website.

Extension authors gained guidance for action adapters and the boundary between the action toolkit and Core. The call_action reference, SDK README and runtime documentation were updated together.

Affected packages:
