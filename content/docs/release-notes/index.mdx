## Reading the notes

- **Stable releases**, such as 0.5.0, have highlights and the changelog for every package
  that changed. The GitHub release links here because the full changelog can be longer than
  a GitHub release body can hold.
- **Canary builds**, such as 0.5.1-canary.20261101.136, are prereleases built from the latest
  eligible `main` change.
- **Nightly builds**, such as 0.5.1-nightly.20261101.264, are prerelease snapshots of `main`,
  taken every 3 hours when it has moved.

Canary and nightly pages keep the notes each build was published with, and they follow the
stable releases in each sidebar group. The next stable release lists every change.

These pages describe what changed for users and developers. Internal file paths,
configuration names, and operational details are left out, and a capability that is still
rolling out gradually is not announced here until it is generally available. See
[Release channels](/docs/start-here/release-channels) for what each channel means and how
to switch.
