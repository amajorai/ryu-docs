Released 2026-08-04 · [GitHub release](https://github.com/amajorai/ryu/releases/tag/v0.1.3)

## Highlights

### Quests progress, claims, and streaks

Quests now has a real backend, so users can track quest progress, claim rewards, and keep streaks instead of relying on a local-only UI. The front end was rebuilt and gained clipboard export for quest details. The quests manifest and core-client bindings were updated in the same pass to match the new data surface.

Affected packages:

- [`@ryu/quests`](https://github.com/amajorai/ryu-quests/releases/tag/v0.1.3)
- [`@ryuhq/core-client`](https://www.npmjs.com/package/@ryuhq/core-client/v/0.1.3)

### Parallel web.search plugin

Operators can now install the Parallel plugin to answer web.search queries through Parallel's REST API. The plugin package includes the adapter, manifest, tests, and README.

Affected packages:

- `plugin: parallel`

### Marketplace catalog categories and brand chrome

The marketplace catalog now shows categories, brand images, and dither chrome instead of a flat app grid. The store layout was reworked to support contributed-store sections, and catalog tests were updated for the new structure. The changes are visible in the desktop store and the shared marketplace package.

Affected packages: `@ryu/marketplace`

### Theme presets and friendly mode

The theme system was refactored around unified presets, friendly mode, and background customization, with dialog blur applied across the UI. Desktop users can choose a preset or a friendly mode from Appearance settings and customize the background. The shared UI package carries the presets and preference persistence, and the desktop app exposes them in Settings.

Affected packages: `@ryu/ui`, `Desktop app`
