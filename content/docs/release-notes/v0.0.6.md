## Highlights

### Banner colour picker and avatar uploads

Users can now customise the agent-edit banner with six preset colours, a custom hue picker, and four direction choices, and can upload avatars for organisations and teams.

Banner overrides are persisted to localStorage per agent, so they behave as a per-machine cosmetic preference while the deterministic hash default still applies when no override is set. Locked and built-in agents keep the banner hidden.

Uploaded avatars flow through the settings API and are cropped before persisting; when no image is available, dither-based fallbacks keep the UI intact.

Affected packages: `Desktop app`, `@ryu/api`, `@ryu/blocks`, `@ryu/settings`

### App-store shell and detail redesign

The marketplace now presents a full app-store shell with a redesigned app-detail panel, provider and ACP brand logos, and an inline dither-gradient hero banner.

Catalog metadata such as icon background, accent colour, developer, tagline, and category is carried from the git catalog source through the Rust catalog entry and into the TypeScript types, while store apps bundle their plugin runtime pieces.

The desktop store navigation, catalog cards, and detail views were reworked to match, and the accompanying core, blocks, marketplace, and docs surfaces were updated together.

Affected packages:

- [`@ryu/browser`](https://github.com/amajorai/ryu-browser/releases/tag/v0.0.6)
- `ryu-core`
- `Desktop app`
- `Documentation site (docs.ryuhq.com)`
- `Island`
- `ryu-cli (TUI)`
- `Website (ryuhq.com)`
- [`ryu-kernel-contracts`](https://crates.io/crates/ryu-kernel-contracts/0.0.6)

_2 more packages — see the changelog below._

### Organisation selector in portal header

Signed-in users on the web portal now get an organisation selector in the header, next to the logo and badge, that lists organisations and switches the active one directly.

Members and Teams have moved from standalone pages into dialogs opened from the switcher, reusing the original pages' data layer. The organisations index now redirects to /dashboard while deeper routes stay available.

The shared header block gained an optional organisation slot, so the signed-out marketing header renders unchanged.

Affected packages: `Website (ryuhq.com)`, `@ryu/blocks`

### Workflow webhook relay starts automatically

Workflow webhook triggers now start the Ryu relay automatically whenever any workflow uses a webhook trigger, not only Composio-based flows, and webhook secrets are backfilled on save with reveal and copy affordances.

The desktop host RPC now returns the server-resolved public URL instead of localhost, so hosts point at the real endpoint. The channel__send MCP tool routes through the shared gateway egress DLP gate and fails closed, with an environment-variable escape hatch when fallback is allowed.

Affected packages:

- [`@ryu/webhooks`](https://github.com/amajorai/ryu-webhooks/releases/tag/v0.0.6)
- [`@ryu/workflows`](https://github.com/amajorai/ryu-workflows/releases/tag/v0.0.6)
