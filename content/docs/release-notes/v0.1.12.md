Released 2026-08-13 · [GitHub release](https://github.com/amajorai/ryu/releases/tag/v0.1.12)

## Highlights

### Local on-device video subtitling

A new apps-store app, @ryu/subtitles, lets you pick a video, transcribe it locally, translate the transcript into the language you want, and write a timed .srt/.vtt file beside the original so VLC, Plex or Jellyfin pick the track up on their own.

Both model hops stay on the device: transcription goes through the extracted ryu-stt crate to local whisper.cpp, and translation uses the local gateway's bundled on-device model. A node with no provider keys can still subtitle a film.

Affected packages:

- [`@ryu/subtitles`](https://github.com/amajorai/ryu-subtitles/releases/tag/v0.1.12)
- `ryu-core`
- `Desktop app`
- [`ryu-kernel-contracts`](https://crates.io/crates/ryu-kernel-contracts/0.1.12)
- `@ryu/app-host`

### Deep Read app and no-more-mistakes plugin

Ryu ships a new Deep Read app (Recursive Language Models) with its own sidecar, a deep-read turn hook and a sandboxed UI companion, registered as a built-in and embedded in the core. A new no-more-mistakes plugin adds capture, brief and command hooks for catching mistakes before they land.

The desktop gains interface-level controls, a sidebar brand badge, a side-panel route store, folder-path and page-route helpers, and an rlm API client. Web and docs surfaces pick up new landing blocks and documentation for the new surfaces.

Affected packages:

- [`@ryu/rlm`](https://github.com/amajorai/ryu-rlm/releases/tag/v0.1.12)
- `ryu-core`
- `Desktop app`
- `plugin: no-more-mistakes`

### Agent-discoverable website and web marketplace

ryuhq.com is now discoverable by agents: it exposes an MCP server, markdown content negotiation at page URLs, WebMCP metadata, and updated OAuth discovery endpoints that fix an authorization-server issuer mismatch.

The marketplace also gains animated gradient banners, a ghost like control with persisted counts, per-channel install pickers with GitHub topic discovery, and a hero-loop on the landing page that rotates through four everyday jobs.

Affected packages: `Website (ryuhq.com)`, `@ryu/marketplace`, `@ryu/api`, `@ryu/db`, `@ryu/ui`

### Split view layout presets

You can now save the current pane layout as a named preset, apply a saved preset onto the current view, and lay out empty panes that you then fill through a pane chooser. An equalize action in the split view context menu evens out pane sizes without dragging each divider.

Affected packages: `Desktop app`
