## Highlights

### Mermaid diagrams in pitch deck

The pitch deck now shows four new slides, each built around a mermaid diagram rendered by a new Diagram component: why the pilot dies, the competitor field, the vertical-sale horizontal-core argument, and the land-expand-upsell funnel. The diagram import is lazy, and the drawings follow the deck's dark palette rather than the visitor's OS color scheme.

Heights are clamped with a custom property applied to the SVG itself, so the drawings stay inside the carousel's max-height scroll box. The closing slide's Cal booker also drops its surrounding card chrome by posting UI configuration over the iframe's postMessage channel, and the slide counter now reads the live carousel length rather than a hardcoded number.

Affected packages: `Website (ryuhq.com)`

### Pass shared as still or loop

The waitlist share dialog now exports the actual pass card instead of a flat side-by-side redraw, as either a PNG still or a ten-second looping MP4 at 9:16, 4:5, 3:4, 1:1 and 16:9. The picture is made by sampling the same warp shader and metal ring that print the live pass, so the export matches the card.

Recording now indexes frames and pushes them to a self-sampling capture track, so a slow machine degrades to a choppier clip rather than a broken loop, and the shader ping-pong uses a raised cosine so the reversal happens at zero velocity. The still tab holds the exported frame, making the preview identical to the file.

The metal ring has no seekable clock, so it runs live and cross-dissolves to a copy of its opening frame over the final 0.6 seconds, keeping it alive without breaking the loop. The footer carries the member's own referral link, and the pass mark blinks and drifts on loop time.

Affected packages: `Website (ryuhq.com)`, `@ryu/ui`

## Changelog

### `@ryu/settings`@0.1.7

#### Patch changes

- The settings tsconfig was updated to declare allowImportingTsExtensions and the noEmit it requires, clearing all 40 TS5097 errors that explicit .ts/.tsx import specifiers had produced. (`ff29367`)

### `@ryu/ui`@0.1.7

#### Minor changes

- The pass studio was changed to index recorded frames instead of pacing off the wall clock and to self-sample the capture stream; the shader ping-pong became a raised cosine, and the metal ring was made to cross-dissolve to its opening frame to loop. tabs.tsx gained pills-lg, plus fixes for the active pill's indicator and label color. (`19f6e35`)

#### Patch changes

- In record.ts, the recorder was changed to feed a self-sampling capture stream and to nudge it with requestFrame only where that method exists, so recordings complete on browsers that lack it. (`4974c17`)
- sileo.tsx was updated so asOptions merges the trailing options object over the title and every toast helper forwards it, which makes two-argument calls like toast.success('Saved', { description }) render their descriptions. (`de8e86f`)

### `@ryuhq/client`@0.1.7

[Published package](https://www.npmjs.com/package/@ryuhq/client/v/0.1.7)

#### Patch changes

- The client's tsconfig was updated to set skipLibCheck, stopping two colliding @types/node copies from producing duplicate-identifier errors, and the tests' installFetch helper now keeps the real preconnect while fetch stubs declare fetch's own parameter list; the package went from 177 type errors to zero. (`7e05e14`)

### `Website (ryuhq.com)`@0.1.7

#### Minor changes

- Four new mermaid-rendered slides were added to the pitch deck through a lazy-loaded Diagram component that pins the theme to the deck palette.
