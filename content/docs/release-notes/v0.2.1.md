## Highlights

### Provider, gateway, and managed node operations

Users can reach provider and marketplace surfaces from the CLI, desktop, mobile, and website. The desktop app manages provider accounts, switches accounts in the universal picker, configures providers through the gateway dialog and provider control center, and filters marketplace listings by stability; creators can run referral campaigns, view results from a creator dashboard, and admins get a creators section. Marketplace checkout carries creator attribution, and selected provider calls flow through the gateway, which serves provider API endpoints. Outpost social posts publish through Treg selected in social settings, the gateway loads Treg credentials from its provider vault, and Treg tool calls are billed against organisation credits; sidecar app tool calls report to organisation billing.

Operators can bind self-hosted gateway nodes to an organization and see node ownership in a managed fleet, with enrollment and credential issuance resolving through organization authorization. Managed gateways resolve governance layers, governance state is readable and manageable per gateway through a scoped contract, and requests to the core server are checked against required scopes. Operators can issue scoped capability grants, approve specific pairing requests, view canonical usage rollups with token and cost totals, and managed Gateway/Core deployments can send analytics through the Ryu relay. Ryu nodes can also be described in one structured JSON file loaded at startup and wired into deployment tooling.

### Desktop, chat, collaboration, and safety

Desktop users get four tab view modes switchable from common controls, with live tab content surviving switches, an infinite canvas for panes, a scrollable view for many live tabs, and persisted canvas geometry. Desktop settings dialogs open directly from keyboard shortcuts, the browser app picks up WebMCP tools, horizontal wheel/trackpad input scrolls overflowing content across Desktop, Island, website, documentation site, and browser extension, and the desktop skills library adds a relations graph with list/graph toggle. Desktop users can choose which shortcut sends a message, configure the composer shortcut from General settings, carry an explicit Ryu response mode per chat session, use slash commands and human mentions, and after agent edits files, edit cards offer Undo and Review.

Collaborative sessions stay connected across interruptions for Canvas, Whiteboard, Dashboards, Workflows, desktop Chat and Home, Space document and database editors, and the mobile AI screen. Conversation and document session state is tracked in database models, so participants reconnect and keep editing rather than losing their place. Plugins can register a notification bridge and address notifications to a specific target, with the approvals app first; apps and plugins can use toast surfaces they own, and Ryu registers the bridge from kernel contract to app host. Plans can be verified before they run: Safe Actions represents plans, policies, receipts, and reviews as kernel-checked data, with a sidecar UI and desktop policy panel.

### New app surfaces and Spaces workflows

Sites ships an in-app control surface for its public edge, so operators can inspect and manage how a published site is exposed without leaving Ryu; ryu-core registers the Sites UI after seeding, and the documentation site adds a Sites page. The Feedback Board app ships as a builtin plugin with an admin surface, public board, and Rust backend service, while visitors can browse and read submitted feedback publicly. A Help Center app and companion ship with inbox, ticket, knowledge, insights, and agent support workflows, and Academy learners can browse a catalog, open course pages, work through lessons with progress that persists, and see certifications and a learner dashboard.

Spaces retrieval now runs through GraphRAG end to end, from the core retrieval host to desktop UI and client SDKs, so users searching a space get graph-aware results. Users can import files and Composio data directly into a Space from the desktop app, and operators can create and track GraphRAG retrieval jobs. Space pages keep durable version history, with a desktop version history view, and Spaces can open and edit Word, PDF, PowerPoint, and spreadsheet files from the space file viewer, writing edits back through the spaces API and routing file types into dedicated editors.

### Marketplace membership and onboarding

Marketplace listings can now be gated by membership, and creators receive a revenue share on paid installs. Access is resolved against a membership before a plugin is loaded, with entitlement and license hooks surfacing membership state across marketplace, plugin, and preferences surfaces; operators can verify an organization and apply entitlement checks before a listing is served. New desktop users get a longer activation sequence covering acquisition source, an activation offer, recommendations, individual activation tasks, and a value step. Desktop and website user menus include Invite a friend to the referrals page, marketplace membership usage is persisted, billing grants the marketplace membership plan entitlement, and gateway operators can enable provider-level billing pass-through.
