Released 2026-08-05 · [GitHub release](https://github.com/amajorai/ryu/releases/tag/v0.1.4)

## Highlights

### Provider subscription sign-in

Users can now sign in to ChatGPT, Claude, or Copilot subscriptions directly from the provider cards in the desktop app. The previous Login button ran a placeholder method that reported success without authenticating anyone.

The app now bridges the OAuth flow through the managed Pi's pi-ai library. It opens the system browser, shows device codes and interactive prompts such as select menus, and merges the resulting credential into the provider configuration. Canceling or timing out frees the callback port so a later login can succeed.

Affected packages: `ryu-core`, `Desktop app`

### Desktop quick capture

Desktop users can now start a quick capture from the app. The capability is implemented as a new Tauri module with a settings panel.

The surface is covered by new e2e harness stories for tray clips and contributed sections. The release also includes tray and updater polish alongside the capture work.

Affected packages: `Desktop app`

### Release notes viewer

Desktop users can now read release notes from inside the app. The desktop app gains a release-notes viewer and app-version helpers to support it.

The viewer is part of the desktop surface added in this release, alongside the quick-capture module and new e2e harness stories. It gives users a way to see what changed in their installed version.

Affected packages: `Desktop app`

### Contributed store sections

The marketplace catalog can now render contributed sections for apps and skills. The catalog components and shared types in the marketplace package were updated to support them.

The desktop e2e harness includes a contributed-section story for the new surface. App and plugin manifests across apps-store and the plugin marketplace were refreshed as part of the contribution update.

Affected packages: `@ryu/marketplace`, `Desktop app`
