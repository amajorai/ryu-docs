Each stable release has one page with its highlights and the changelog for every package
that changed. The GitHub release links here because the full changelog can be longer than a
GitHub release body can hold.

Canary and nightly builds are prereleases from `main`, not stable releases. Each build's page
keeps the notes it was published with, and the sidebar groups every page under its minor
version, newest first.

These pages describe what changed for users and developers. Internal file paths,
configuration names, and operational details are left out, and a capability that is still
rolling out gradually is not announced here until it is generally available. See
[Release channels](/docs/start-here/release-channels) for what each channel means.
