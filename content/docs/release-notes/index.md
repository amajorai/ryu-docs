Each stable release has one page with its highlights and the changelog for every package
that changed. The GitHub release links here because the full changelog is longer than a
GitHub release body can hold. These pages describe what changed for users and developers;
internal file paths, configuration names, and operational details are left out, and a
capability that is still rolling out gradually is not announced here until it is generally
available. Nightly and canary builds are listed only on
[GitHub Releases](https://github.com/amajorai/ryu/releases).
