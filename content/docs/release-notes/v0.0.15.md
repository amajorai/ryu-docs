## Highlights

### BYOK API credit balances

Users who bring their own provider keys can now see the dollar balance remaining on each key without leaving the picker or the Gateway dialog. A provider row shows the balance as a badge, and the Usage & cost tab of the Gateway dialog lists it in an API credit balance card.

Balances come from a new Core endpoint that resolves the stored key and queries the provider. OpenRouter, DeepSeek and Moonshot are supported; providers with no read-only balance endpoint state why they cannot appear instead of implying that pasting a key would help.

Affected packages: `ryu-core`, `Desktop app`, [`ryu-usage`](https://crates.io/crates/ryu-usage/0.0.15)

### Scheduled subscription warm-up pings

The new optional Warmup app sends a short ping to each subscription agent at times you choose, so a rolling usage window is already open when work starts. It defaults to 05:00, 10:00, 15:00 and 20:00 local time.

Warmup is a configurator rather than a daemon: it writes scheduled jobs into Core's scheduler and exits, and the ordinary scheduler tick runs them. Jobs remember the app that created them, so disabling the app pauses them and uninstalling it removes them entirely.

### Usage badges on picker rows

The model picker now shows usage on every agent row, so headroom is visible before the choice is made rather than after. Each agent row carries the single most-consumed window as a percentage, with the full breakdown in a tooltip.

Ryu pool rows show the pool's remaining granted credit in dollars and wear an expiry style when the grant lapses. The badges share the existing usage query's cache, so opening the picker does not trigger a burst of provider calls.

Affected packages: `Desktop app`, `Website (ryuhq.com)`

### Banked Codex resets and new providers

The usage bar can now report figures a simple percentage cannot express: banked Codex rate-limit resets with their own expiries, flex credits as dollars and credits, and Spark weekly limits. Non-percentage figures render as their own typed meters.

Copilot, Grok and Z.ai GLM join Claude and Codex as readable subscription providers, each reusing a credential already on the machine. Claude's per-model weekly limits are read from the limits array, so newly added models need no code change.

Affected packages: `Desktop app`, [`ryu-usage`](https://crates.io/crates/ryu-usage/0.0.15)
