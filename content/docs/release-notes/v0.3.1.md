## Highlights

### Video Studio production and media workflows

Users can produce video in Video Studio with timeline edits, clips, preview, titles, transcript panels, generation panels, captions, translations, transcript search, and measured-word highlighting. They can apply editable effect stacks, generate local 3D stage worlds, animate camera paths, upscale media, export modified stages, and compose adjustable production recipes that generate montages. Canvas, Whiteboard, and Video Studio search Openverse and Unsplash in-app, and Video Studio imports stock media from Pixabay, Pexels when configured, NASA, and Wikimedia Commons with license/attribution metadata.

Editors can apply ripple, multicam, markers, range-delete, crossfade/zoom transitions, clip trimming, animated titles, directional entry transitions, and waveform rendering while preserving speech timing and transcript alignment. Video Studio imports and renders OBJ/glTF meshes with bounds, projects glTF animation onto the timeline, rigs avatars, and keyframes mesh stages. Agents can edit timelines through the sidecar, and exports support selected codecs, interchange formats, editable production packages, quality presets, audio post-processing, production budgets, readiness gates, and gateway receipt correlation.

### Chat engines, model providers, and agent lifecycle

Users can select FreeToken and llama-swap chat engines, run chat against a local Lemonade Server, and add a ChatGPT subscription as a provider via OAuth login, with usage analytics and branded engine logos. The desktop model picker groups ChatGPT models and shows engine artwork for supported engines such as Ollama, vLLM, llama.cpp, and MLX.

Users can build agents from the ryu-agent-creator skill, with ryu-creator and ryu-configurator shipping as builtins. Installed agents support on-demand health audits with scorecard results, gateway posture details, and configurable ghost avatars rendered in desktop conversation rows and agent chat, with animated expressions and state changes.

### Verification, formal evidence, improvement runs, and security monitoring

App and plugin authors can run Lean conformance checks against platform seams, back proofs with Lean formal evidence, and gate formal artifacts before they are treated as evidence. Operators can create and run agentic verification checks on the local node, then review runs and results. Developers can create, retrieve, list, and transition durable improvement runs through first-class core API endpoints.

Operators can enroll projects or fleets in Ryu Watch, which scans codebases, audits Node packages against a rule set, and reports findings to a dashboard. The Watch API exposes analysis, GitHub, and network monitoring, and managed cloud nodes now auto-enroll without manual steps.

### Local file conversion and encrypted S3 backup/recovery

Users can convert files between formats entirely on the machine with Convert, including local PDF page rendering, with no upload step. Convert appears in the app store once installed and is registered as a built-in plugin in Ryu core from first run.

Nodes, Spaces, and apps can be backed up to encrypted S3 storage and restored from those backups. The desktop Spaces view exposes backup and recovery flows, and hosted apps can invoke the same calls through the core client and SDK.
