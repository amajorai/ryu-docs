## Highlights

### Merge two accounts into one

You can now merge two Ryu accounts that use different email addresses into one. The session proves you hold the surviving account, an emailed token proves you hold the account being absorbed, and both sides must confirm before anything moves.

The direction is fixed: credit stays in its workspace, and trial or promo benefits on the free tier do not stack. The other address stops working as a sign-in after the merge.

Affected packages: `Website (ryuhq.com)`, `@ryu/api`, `@ryu/auth`, `@ryu/blocks`, `@ryu/db`, `@ryu/email`, `@ryu/settings`, `@ryu/step-up`

### Schema-driven CRM desktop panel

The Harbor CRM now has a native dock panel in the desktop app. You can browse any object's records in a schema-driven grid, switch to a board view, open a record timeline, and import records from CSV.

The panel renders off the schema the sidecar returns rather than a fixed set of screens, so objects you define yourself appear in the rail and in the views without code changes.

Affected packages:

- [`@ryu/crm`](https://github.com/amajorai/ryu-crm/releases/tag/v0.1.10)
- `Desktop app`

### Per-layer context breakdown panel

A new context breakdown panel shows how much of the chat's model context each system-prompt layer consumes. An in-input-bar meter gives a live glimpse of the same measurement.

Core records the size of each layer at its merge site and exposes the attribution read-only through a new endpoint; nothing in the probe changes what is sent to the model.

Affected packages: `ryu-core`, `Desktop app`, `storyboard`, `@ryu/blocks`, `@ryu/ui`

### No-ai-slop automatic editing

A bundled no-ai-slop editing skill now runs on every finished assistant turn. The post_assistant_turn hook hands the draft to a fresh agent context, and if the review comes back with findings the agent rewrites its own answer.

A clean answer produces nothing; the composer's plus toggle is a manual override for the automatic pass, not the arming switch.

Affected packages:

- `ryu-core`
- `plugin: no-ai-slop`
