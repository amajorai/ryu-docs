## Highlights

### Webhooks on the default ingress

Operators can now reach a per-workflow webhook over the default RyuRelay ingress, without standing up a separate tunnel or relay. The relay captures the raw request body and broadcasts it to the matching subscriber so Core can re-verify signatures over the exact bytes.

The desktop Webhooks page surfaces each endpoint's resolved public URL instead of localhost, along with secret presence and last-delivery status. Endpoint URLs can be copied to the clipboard from the UI.

Affected packages: `ryu-core`, `Desktop app`, `@ryu/api`

### Plugin tools, mesh peers, release channels

Plugins can now ship runnable tools defined inline in Deno or as HTTP proxies, with per-tool grants and egress governed by the Gateway firewall. SDK users call defineTool({ run }) to serialize tool bodies the same way turn hooks are serialized.

Desktop users get a mesh peer picker that supplies the selected peer's bearer token, so newly added nodes stop returning 401s. A release-channel picker covers canary, nightly, beta, and stable builds, with a channel-aware updater, a sidebar build badge, and a separate Ryu Dev GUI variant.

Affected packages: `ryu-core`, `Desktop app`, `Island`, [`@ryuhq/sdk`](https://www.npmjs.com/package/@ryuhq/sdk/v/0.0.3)

### Canvas and finetune as plugin apps

The built-in Canvas and fine-tuning experiences are now distributed as plugin apps instead of hardcoded desktop pages. The desktop shell loads them through the plugin contribution registry, and their built-in pages, contexts, and APIs were removed from core.

Workflows gain a channel-send node that can post to Telegram, Slack, Discord, or a webhook from a workflow graph. Marketplace and seller flows were migrated to Stripe Connect direct charges.

Affected packages: `ryu-core`, `Desktop app`, `ryu-gateway`, `API server (api.ryuhq.com)`, `Website (ryuhq.com)`, `index.d.ts`, `@ryu/api`, `@ryu/app-host`, and 5 more — see the changelog below.

### Multi-tenant hardening and profile isolation

Multi-tenant deployments now enforce per-resource ACLs across conversations, spaces, memory, and retrieval, with enforcement tied to the org boundary. MCP agent calls are gated on a server-derived tool principal rather than a client-supplied user id, and the auto-recall path no longer leaks chat content across tenants.

Cross-device sync now attributes replayed rows to the original author, and mesh peer discovery returns a real candidate bearer and reachable URL.

Affected packages: `cloud-bot`, `ryu-core`, `Desktop app`, `Documentation site (docs.ryuhq.com)`, `ryu-gateway`, `API server (api.ryuhq.com)`, `Website (ryuhq.com)`, `Web app (app.ryuhq.com)`, and 10 more — see the changelog below.
