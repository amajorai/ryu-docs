## Changelog

### `@ryu/blocks`@0.1.8

#### Patch changes

- Updated the desktop onboarding block so the setup copy no longer punctuates between the two places where a node might already be running. (`e876afe`)
- Updated the desktop onboarding block so the local pick no longer runs a second progress surface; the card now reports on the shared installing phase with a real progress bar. (`cd935a6`)
- Restyled the desktop onboarding block's choose step into borderless tiles and made the local card show live byte counts while the pick works, with the backend's message kept under the friendly failure line. (`3bac9ec`)

### `Desktop app`@0.1.8

#### Patch changes

- Replaced em dashes with cleaner punctuation in the onboarding page and the e2e harness copy; status lines now read "Downloading Ryu Core 35%" and "Still starting, the first launch takes a little longer". (`e876afe`)
- Changed install progress reporting in App.tsx and OnboardingPage.tsx to show each step's own percentage instead of a raw byte count, clamped at 100 and falling back to a raw size when there is no Content-Length; the harness story matches the new status lines. (`6cadcd6`)
- Consolidated the local pick onto the single installing phase: localProgress is removed, the card only owns failures it can handle, the rotating copy alternates with real states like "Downloading Ryu Core — 42 of 119 MB" and "Installing the local AI engine…", and install toasts now report both binaries by name. (`cd935a6`)
- Kept the local pick's progress copy alive through the boot wait: startLocalCore reports its own status, a terminal install phase no longer clears the line, the failure card describes what was actually observed when health never answers, and the managed fallback avoids the restart screen during local bring-up; the harness story adds a booting column. (`68fe58e`)
- Streamed the core and gateway downloads with per-megabyte progress, swapped the whole-request timeout for connect and read timeouts, surfaced installation errors on the failure card instead of swallowing them, and made the local pick install the model gateway; onboarding requests now carry AbortSignal.timeout and the choose step is restyled as borderless tiles with live byte counts. (`3bac9ec`)
