Introduced a state store for model rooms, enabling persistent storage and management of configurations. Also registered the model rooms app contract for integration into workflows.

### Schedule Run Status Timelines

Added detailed timelines for schedule run statuses, providing users with visibility into execution progress and history for better monitoring.

### WebMCP Checkout Tools

Implemented checkout tools in WebMCP to facilitate seamless web-based transactions and operations within the platform.
