## Highlights

### App, plugin, and desktop experience updates

Users now get explicit preview-state disclosure in the Clips, Help Center, ReelFarm, Slides, and Token Table apps, making preview content distinguishable from live data. The ReelFarm studio has been renamed across its manifest, plugin metadata, and UI entry points, with UI copy/state handling updates in ReelFarm's bridge and model layer and Token Table's table copy, plus tests such as export-state.test.ts, bridge.test.ts, model.test.ts, and table-copy.test.ts. Documentation and READMEs were updated, the Studio app appears under its renamed identity across the documentation site and desktop app icons, app documentation pages state their preview state, and the apps index and meta.json were updated.

The Spaces home screen in the desktop app now shows a Space's shared context as a dedicated landing page. Opening a Space brings its shared memory and knowledge sources onto one screen, assembled from the desktop Spaces components in @ryu/blocks, with block tests and a new end-to-end Playwright proof harness with Vite and Playwright configs. A storyboard entry records the redesigned screen, and Spaces RAG documentation was updated.

### Account access, gifts, and referral history

Accounts can now be approved for sign-in by scanning a QR code from a mobile device. The mobile app gains a login approval scanner, so an already-signed-in phone can approve a login instead of relying on a password or code entry alone. The mobile scanner sits alongside an updated account switcher, and the approval handshake is defined by a new login approval contract and client in @ryu/auth with contract tests.

The website now has a gifts area where a gift card can be purchased and a redemption page where a recipient can apply one. Gift purchases settle through the existing success page, which now includes a gift settlement step, and the user menu links into the new flow. The desktop app reflects the resulting credit balance on its credits page.
