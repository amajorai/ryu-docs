---

Ryu gives people building an agent business three ways to start: refer businesses to Ryu, operate agents for clients, or host client agents on Ryu Cloud. You own the customer relationship and the offer. Ryu provides the agent and governance stack underneath.

See the live [Ryu for Agent Operators page](https://ryuhq.com/for/agent-operators) for the current commercial path.

## Refer

Share Ryu with businesses that need agents and earn through the affiliate program.

- Sign up and get a tracked referral link.
- Earn commission on eligible referred subscriptions and Marketplace purchases.
- Complete Stripe Connect payout onboarding for self-serve payouts.
- View the referral dashboard from your Ryu account.

This is the lowest-friction path if you already have an audience, a client network, or a consulting practice.

## Operate

Sell a managed agent outcome to a business while you run the implementation.

- Configure an agent, workflow, tools, and Spaces for each client or workflow.
- Set Gateway budgets, firewall rules, and audit controls.
- Connect the channels the client already uses, such as Telegram or Slack.
- Charge for setup, a retainer, usage, or a packaged service.

Ryu's own public path describes this as an agency model. Clients buy the outcome from you. Ryu is the engine you operate underneath.

For the policy boundary, see [Gateway governance](/docs/gateway/governance) and [Gateway security](/docs/gateway/security).

## Host

Run client agents on Ryu Cloud when you want to productize hosting instead of managing each deployment yourself. Ryu's public operator offer describes the hosted path as early access with packaging conversations, so availability is not the same as the self-serve desktop path.

The hosted model is for operators who sell and support the service while Ryu hosts the node, sidecars, and uptime. Contact the team through the [agent operator page](https://ryuhq.com/for/agent-operators).

## Publish a reusable Agent Template

If you want to sell a reusable package instead of a client service, use the **Sell** tab in the [Ryu Marketplace](https://ryuhq.com/marketplace).

- Free listings do not need seller payout setup.
- Paid listings use organization payouts through Stripe Connect.
- The current seller flow supports organization-owned skills, plugins, and tools.
- GitHub publishing validates the package manifest and immutable release before submission. Buyers install through Ryu and do not need GitHub access.
- A platform commission is deducted per paid sale.

This publishing path is separate from the agent-operator service path. A published Agent Template runs
on the buyer's node with the buyer's models and connections. It does not transfer your API keys,
identities, Spaces, or chat history.

<Callout type="warn">
  The current operator offer is not a white-label rebrand of the Ryu app. You own the client relationship, scope of work, and service terms. Ryu supplies the stack you run.
</Callout>
