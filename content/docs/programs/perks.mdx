The Ryu Perks directory collects deals from products used to build and run agents. Product partners can list credits, free months, or another offer. Ryu reviews submissions before they appear, and selected offers receive featured placement.

Browse the live [Perks directory](https://ryuhq.com/perks) or [list your perk](https://ryuhq.com/perks/submit).

## For product partners

Listing is free. The directory is for products in and around the agent stack, including model providers, fine-tuning services, browsers, sandboxes, integrations, data tools, observability, and voice services.

Each account can submit one perk. Editing an existing submission sends it through review again before the updated offer returns to the directory.

## Submit a perk

1. Sign in and open [List your perk](https://ryuhq.com/perks/submit).
2. Add your product or company name, offer headline, description, and a valid HTTPS redemption link.
3. Choose a category and whether the offer is available to all signed-in users or paid Ryu Pro members.
4. Add any optional redemption code, instructions, logo, or website, then submit it for review.

## Submission fields

| Field | Required | Notes |
|---|---|---|
| Product or company | Yes | The name shown on the perk card |
| Offer headline | Yes | The short description of the deal |
| Description | Yes | What the product does and what the deal includes |
| Redemption link | Yes | Must use `https://` |
| Category | No | Used by the directory filters |
| Eligibility | No | All signed-in users or paid Ryu Pro members |
| Coupon code and instructions | No | Shown only in the eligible redemption flow |
| Logo and website | No | Used to identify and link the partner |

Available categories include Models & Inference, Fine-tuning & Training, Browser & Web Agents, Sandboxes & Compute, Tools & Integrations, Memory & Data, Observability, Voice & Audio, and Other.

## For Ryu users

Anyone can browse the public directory. Sign in to redeem an approved offer. A perk for all users is available to any signed-in Ryu user. A Pro perk requires the paid Ryu entitlement before redemption.

The directory shows approved offers first, with featured offers and recent submissions ranked by the directory. It does not publish a product's private redemption code on the public card.

<Callout type="info">
  Perk terms belong to the product partner. Check the partner's redemption page for expiry dates, usage limits, and any eligibility rules before you rely on an offer.
</Callout>
