The Ryu Partner Program lets an organization offer Ryu Desktop to its members as a perk. It is for incubators, accelerators, portfolios, and other founder communities that keep a resource or perks page.

To start, open the live [Partner Program page](https://ryuhq.com/partners) and choose **Become a partner**. The button opens an email to the Ryu team.

<Callout type="warn">
  Partner codes are redeemed through the Ryu for Startups application. That program opens in stages. While it is closed, the Partner Program page shows **Register interest** instead of **Become a partner**, and founders can redeem a code only after the startup program opens.
</Callout>

## How it works

1. Tell the Ryu team who your members are and how you want to offer Ryu.
2. Ryu issues a partner code for your community.
3. List Ryu and the code on your resource or perks page.
4. A founder enters the code in the [Ryu for Startups](/docs/programs/startups-and-students#startups) application and is approved instantly.

## What members get

A founder who enters a valid partner code gets a free 12-month Ryu Desktop licence: the desktop app with local models or the founder's own provider API keys. It does not include Ryu Cloud, managed inference, or included credits.

[Startups and Students](/docs/programs/startups-and-students) has the full eligibility rules and everything the licence includes and excludes.

## Partner code limits

A partner code can have:

- An expiry date.
- A maximum number of redemptions.
- Both limits. The code stops working when either limit is reached.

Ryu can also turn a code off and back on.

## Community partners and product partners

These are two different ways to work with Ryu.

| Partner type | What the partner brings | What members or users get |
|---|---|---|
| Community partner | A defined community of founders | A partner code for a free Ryu Desktop licence |
| Product partner | A deal on its own product | A listing that Ryu builders can redeem in [Perks](/docs/programs/perks) |

If you run a product that helps with inference, fine-tuning, browsers, sandboxes, or agent infrastructure, [list a product perk](https://ryuhq.com/perks/submit).

To sell agent work to individual businesses instead of offering Ryu to a community, see [Sell Your Own Agents](/docs/programs/sell-your-own-agents).
