The Ryu desktop app is the flagship client for Ryu Core. It opens in one of three realms:
[Bot](/docs/surfaces/desktop/bot) for managed everyday chat, [Agent](/docs/surfaces/desktop/agent)
for power users and admins, and [OS](/docs/surfaces/desktop/ryu-os) for an agent-first desktop
workspace. All three show the same conversations.

## Shell appearance

The sidebar floats over the window as a rounded card with a soft shadow by default. Choose
**Inset** in **Settings → Appearance** (or right-click the sidebar) to dock the sidebar flush and
pull the content area in as its own rounded card instead. **Chrome shadows** can be turned off in
the same place; a choice you saved earlier is kept.

Turn on **Project rail** in **Settings → Appearance** (or right-click the sidebar) for a column of
project icons down the left edge of the sidebar, like servers in Discord. Pick a project to show only
its chats and make it the folder new chats start in; pick **All projects** (the home icon) to see
everything again. A project with no custom icon shows its initials.

Seasonal titlebar effects are off by default. Turn them on in **Settings → Appearance**; the
effects follow the calendar or a season you pick, and stay off when animations or your system's
reduced-motion setting are off.

System notices such as **Node offline**, a reconnect retry, or Safe Mode appear as a single line
under the title bar, with at most one action such as **Retry** or **Leave**.

Press `Cmd/Ctrl-K` to open the command palette. The filter row shows up to four result types,
starting with **All**, and the other result types (such as **Marketplace** and app-contributed
sections) sit under **More**. **Search** and **Compose** switch inside the palette, and `Tab` toggles between them.

## What Desktop adds

Desktop owns the native workspace and local-machine features that do not fit a browser or terminal.

| Capability | Desktop behavior |
|---|---|
| OS workspace | Dock, live App windows, App Launcher (`Cmd/Ctrl-K`), and curated wallpapers |
| Native media picture-in-picture (PiP) | Open a live browser, desktop, or recording preview in an always-on-top media window |
| Multi-window workspace | Use split panes, tabs, separate windows, and Desktop-only window actions |
| Local machine integrations | Manage local engines, sidecars, files, Git workspaces, and the Virtual Desktop |
| Full host rendering | Render the complete shared app shell, rich views, widgets, and contributed panels |

Plugins should still check the host capability descriptor before offering a native effect. See
[Native bridges](/docs/extend/develop/extensions/native-bridges) for the cross-surface rules.
