---
title: Engines and Sidecars
description: How Core downloads, runs, and health-checks the engines and runtimes behind every agent.
---

Each runtime, provider, and tool process that Ryu runs for an agent is a **sidecar**. A sidecar is
a separate process that Core downloads, checksum-verifies, installs, starts, and health-checks
(`apps/core/src/sidecar/`). You do not need a terminal or a package manager.

<Figure name="engines" />

Every engine, model, and strategy is a default that you can replace. Core resolves it from
environment variables and, for the settings whose readers open it, `~/.ryu/state/registry.json`.
Model weights and embedding settings come from environment variables only. See
[Defaults](/docs/reference/defaults) for each default and its override.
