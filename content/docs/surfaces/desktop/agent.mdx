Agent is the power-user and admin realm of the Ryu desktop app. [OS](/docs/surfaces/desktop/ryu-os)
is the agent-first workspace view in the same desktop app.

Ryu also ships [Bot](/docs/surfaces/desktop/bot), the focused account-only mode in the same
desktop app. Bot is managed end to end and hides Agent's provider, model, node, and infrastructure
controls. On a Ryu-managed node, Agent is available only to organization members whose role
grants Gateway configuration (owners and admins by default, or a custom role). Self-hosted and
local nodes open directly in Agent. The server enforces the same permissions on every request.

Agent is the name of this workspace, not of an agent: **Ryu Agent**, the default agent you chat
with, is available in every interface.

Bot, Agent, and OS are the built-in [interfaces](/docs/surfaces/desktop/interfaces) of the desktop
app. The same switcher in the Ryu lockup also offers Channels, Feed, and 2D and 3D worlds, plus
interfaces installed from the Store. All of them show the same conversations.

## Choose the startup realm

The Desktop app opens new users in **Bot**. After you switch between Bot, Agent, and OS, the app
remembers the last realm you used and opens there on the next launch. Change this in
**Settings → General → On startup → Realm on startup**.

- **Last used** follows the most recent realm, with Bot as the fallback for a new install.
- **Bot**, **Agent**, or **OS** always open that realm when the Desktop app starts.

Agent remains subject to the active node's organization access. A user without access to Agent is
kept in Bot even if an older startup preference requested it.

If the startup preference cannot be saved and read back, Settings keeps your requested choice
visible with an error. Choose **Retry saving startup realm** to try the same choice again. Until the
error clears, the saved choice for the next launch is not confirmed.

After a switch, the native window title follows the active realm: **Ryu · Bot**, **Ryu · Agent**, or
**Ryu · OS**.

## Compare realms

All three realms run on the same Core, Gateway, Pi, sandbox, and device-access runtime. A realm
changes only the desktop shell: which pages, controls, and shortcuts are available.

| | Bot | Agent | OS |
|---|---|---|---|
| **Who can open it** | Everyone | On a Ryu-managed node, members whose role grants Gateway configuration (owners and admins by default). On a self-hosted or local node, anyone connected to it: there is no organization check, and Core still enforces the credential you connected with. | Everyone on a regular Desktop install |
| **Interface** | Simplified | Full | Full, in a dock-and-window workspace |
| **Pages** | Chat and the managed agent view only | Every page, as tabs | Every page, as windows on the OS desktop |
| **Sidebar** | Chats and **New chat**, plus the Bot pulse card | All sections, sidebar modes, live activities, and import | The OS menu bar and App Launcher |
| **Agent in the composer** | Always Ryu, with no agent, team, or model picker | Any agent or team | Any agent or team |
| **Gateway settings** | Not available | Available | Not available; switch to Agent |
| **Settings, Library, Home, and Timeline shortcuts** | Disabled | Available | Available |
| **Account menu: inbox, announcements, downloads, settings, and Create** | Hidden | Shown | Shown in the menu bar |
| **Command palette, support-access banner, and safe-mode banner** | Hidden | Shown | Hidden |
| **Assistant dock** | Hidden | Shown | Hidden |
| **Agent editor** | Simplified | Full | Full |

<Callout type="warn">
  OS is off by default and rolls out per account. Until it is on for your account, the switcher
  and **Realm on startup** offer only Bot and, if you have access, Agent. See
  [Interfaces](/docs/surfaces/desktop/interfaces#availability).
</Callout>

The standalone Ryu Bot app always opens in Bot, whatever realm is saved.

Every surface uses the **same Core contract**. Agent may run a local Core or connect to a
managed or self-hosted node; Bot uses the managed path. A chat can remain the same conversation
when you move between Agent, the CLI, the Island, or your phone.
