# Import from another agent

Ryu can bring work and setup in from the other AI coding agents you already use —
**Claude Code**, **Cursor**, and **Codex** — so switching is cheap instead of a
clean start.

There are two things to import:

- **Chats** — your past agent conversations (threads), restored as Ryu
  conversations filed under the project folder they ran in.
- **Setup** — the configuration that made that agent yours: project instructions,
  skills, MCP servers, plugins, project memories, subagents, and slash commands.

Importing never modifies the source files. Everything is read from your own
folders and copied into Ryu's stores; the originals are left untouched.

## Import past chats

Open **Import a past agent thread** from the Chats section of the sidebar, the
launchpad, or the command palette. Pick the agent (Claude Code or Codex), choose
the threads you want, and import them.

Each imported thread becomes a normal Ryu conversation. If you import the same
thread again after continuing it in Claude Code or Codex, Ryu adds only the new
messages to the existing conversation instead of creating a duplicate. Messages
you added to that conversation inside Ryu are preserved.

## Import agent setup

Open **Import agent setup** from the Chats section, the launchpad, or the command
palette. Point at a folder and Ryu scans it for anything it can import:

- **Instructions** — `AGENTS.md` / `CLAUDE.md` at the folder root. The folder is
  registered as a project so chats group under it in the sidebar, and the file is
  **injected into the agent's context** for every turn that runs in that folder —
  the same behavior Claude Code and Cursor get from their instruction files.
  Ryu reads the live file, so editing it (in the folder, or from the project
  settings dialog) applies to the next turn.
  Ryu also composes matching instruction files from the user's home directory
  through each parent folder, broadest first. For node-local personalization,
  use **Profile → About you** to set a nickname, occupation, and background.
- **Skills** — any Agent Skills (`SKILL.md`) directories found inside.
- **MCP servers** — servers declared in an `mcp.json`, a Cursor `.cursor/mcp.json`,
  a Codex `config.toml`, or a Claude `~/.claude.json`. Remote servers that need
  authentication keep their headers, so you may need to finish setup after import.
- **Plugins** — plugin bundles (`manifest.json`) found in the folder. Plugins are
  installed but stay **disabled** until you review their permissions and enable
  them, so nothing runs or spawns without your say-so.
- **Memories** — Claude Code project memories (`memory/*.md`), deduplicated so
  re-importing never creates duplicates.
- **Agents** — Codex subagents (`~/.codex/agents/*.md`), imported as Ryu agents
  with their description, model, and instructions.
- **Slash commands** — Codex prompt commands (`~/.codex/prompts/*.md`). Imported
  commands appear in the composer's `/` menu and expand to their prompt template
  when you pick them, like Cursor or Codex.

The dialog offers one-click scans of your `~/.claude`, `~/.cursor`, and `~/.codex`
folders, or you can choose any folder (for example, a project that vendors its own
`skills/` directory or plugin bundles).

### Keep setup in sync

Turn on **Auto-import agent setup** in **Settings → General → Chats** to
automatically keep imported instructions in sync with your Claude Code, Cursor,
and Codex folders. Ryu rescans on launch, on a timer, and when the window regains
focus. For safety, auto-sync imports **instructions only** — skills, MCP servers,
and plugins are always imported explicitly so you review them first.

## What to review after importing

- **MCP servers** — entries with custom authentication, headers, or environment
  variables may need you to sign in again. Imported servers are enabled, since
  they are your own configuration.
- **Plugins** — imported plugins are disabled until you review their grants and
  enable them.
- **Skills** — imported skills are activated so they are available to your agents;
  disable any you don't want.
- **Agents** — imported subagents appear in the Agents library like any agent you
  created; their tools may need an MCP server that isn't configured yet.
- **Slash commands** — imported commands show up in the composer's `/` menu and
  expand to a prompt template when picked (see
  [Slash command reference](/docs/surfaces/desktop/user-guide/slash-commands)).
