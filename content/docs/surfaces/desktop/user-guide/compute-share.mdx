title: "Compute and Share"
description: "Early-access Desktop surfaces for renting governed capacity and sharing idle Ryu nodes."

Ryu **Compute** and **Share** are the exchange surfaces around [Ryu Hire](/docs/standalone/hire).
Hire is for bringing in a specialist agent for one run. Compute is for choosing a bounded
workcell. Share is for offering an idle node or an approved agent on terms you control.

## The product split

| Surface | Use it for | Current Desktop behavior |
|---|---|---|
| **Ryu Hire** | Run a managed specialist for one task | Managed, pay-per-run service |
| **Ryu Compute** | Rent CPU or GPU capacity for a bounded job | Choose workload and lease length; live provider search is not enabled yet |
| **Ryu Share** | Offer a node or hosted agent while it is idle | Choose an offer and schedule; publishing is not enabled yet |

Open **Compute** or **Share** from the Console sidebar, or use the command palette. Both pages
show an **Early access** label while the exchange control plane is being connected.

## Compute

Compute lets you choose:

- **Workload** — any lane, CPU, or GPU;
- **Lease length** — 15 minutes, 1 hour, or 4 hours.

The intended lease is a short-lived Ryu workcell, not SSH, VNC, or a login to the provider's
machine. The host supplies capacity; the lease owner receives the job result and a receipt for
the measured work. The current page keeps **Find capacity** disabled when the provider network
is unavailable, so it cannot submit a job or imply a charge.

Your active node remains visible beside the finder. A local node is shown as private by default;
opening Compute does not change node selection or expose its token.

## Share

Share offers two provider modes:

- **Compute lane** — accept an approved bounded job on spare capacity;
- **Hosted agent** — run a signed, approved agent package on the node.

Choose **When idle** or **On a schedule**, then keep **Protect active work** enabled when the
node must refuse leases while you are using it. These controls are currently a local preview of
the provider policy. **Publish listing** remains disabled until provider enrollment, metering,
and payout controls are available.

## Security boundary

The exchange follows the same ownership split as the rest of Ryu:

- **Core** runs the workcell and owns node-local process, filesystem, and sandbox state.
- **Gateway** must enforce the lease's identity, capability grants, budget, audit, metering, and
  payout rules.
- A provider never gives a renter the node token, host files, private keys, or an unrestricted
  remote session. A future lease receives only the scoped workcell contract.

The current Share page shows configured safe origins without displaying the origin itself. A
loopback-only local node stays private until a provider explicitly configures a safe network
path. Ryu-managed nodes are shown as **Ryu-managed** and are not offered as personal providers.

<Callout type="info">
  The Desktop pages are available for product discovery and interaction design. This build has
  no public lease, provider-enrollment, or payout API, so no rental is live from these controls.
</Callout>
