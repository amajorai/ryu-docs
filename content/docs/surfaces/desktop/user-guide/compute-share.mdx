Ryu **Compute** and **Share** are the exchange surfaces around [Ryu Hire](/docs/standalone/hire).
Hire is planned for bringing in a specialist agent for one run. Compute is for choosing a bounded
workcell. Share is for offering an idle node or an approved agent on terms you control.

<Callout type="warn">
  All three surfaces are early access. This build has no public lease, provider-enrollment, or
  payout API, so no rental or listing is live from these controls. The Desktop pages show an
  **Early access** label until the exchange control plane is connected.
</Callout>

| Surface | Use it for | Current Desktop behavior |
|---|---|---|
| **Ryu Hire** | Run a managed specialist for one task | Specialist runs are not available yet |
| **Ryu Compute** | Rent CPU or GPU capacity for a bounded job | Choose workload and lease length; live provider search is not enabled yet |
| **Ryu Share** | Offer a node or hosted agent while it is idle | Choose an offer and schedule; publishing is not enabled yet |

Open **Compute** or **Share** from the sidebar in Agent or the command palette.

Compute and Share are off by default and rolled out gradually. Until they are turned on for your
account, the sidebar buttons and command-palette entries are hidden, and opening either page shows
that it is not available yet.

## Compute

Compute lets you choose:

- **Workload** - any lane, CPU, or GPU.
- **Lease length** - 15 minutes, 1 hour, or 4 hours.

A lease is planned as a short-lived Ryu workcell, not SSH, VNC, or a login to the provider's
machine. The host supplies capacity. The lease owner receives the job result and a receipt for the
measured work. **Find capacity** stays disabled while the provider network is unavailable, so the
page cannot submit a job or imply a charge.

Your active node stays visible beside the finder. A local node is shown as private by default.
Opening Compute does not change node selection or expose its token.

## Share

Share offers two provider modes:

- **Compute lane** - accept an approved bounded job on spare capacity.
- **Hosted agent** - run a signed, approved agent package on the node.

Choose **When idle** or **On a schedule**. Keep **Protect active work** on if the node must refuse
leases while you use it. These controls are a local preview of the provider policy. **Publish
listing** stays disabled until provider enrollment, metering, and payout controls are available.

## Security boundary

The exchange follows the same ownership split as the rest of Ryu:

- **Core** runs the workcell and owns node-local process, filesystem, and sandbox state.
- **Gateway** must enforce the lease's identity, capability grants, budget, audit, metering, and
  payout rules.
- A provider never gives a renter the node token, host files, private keys, or an unrestricted
  remote session. A future lease receives only the scoped workcell contract.

The Share page reports whether a safe origin is configured without showing the origin itself. A
loopback-only local node stays private until you configure a safe network origin. Ryu-managed nodes
show **Ryu-managed** and are not offered as personal providers.

See [Nodes, Presence & Private Networking](/docs/core/node-and-presence) for the node and mesh
boundary.
