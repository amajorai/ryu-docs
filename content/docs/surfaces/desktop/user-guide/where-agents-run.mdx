---
title: Where Your Agent Runs
description: The two kinds of cloud agent in Ryu, Agent in the cloud and Agent on your computer, where each one runs its model calls, files, and commands, and which sign-in to use with each
---

When Ryu runs an agent's work in the cloud, it does so in one of two ways. The difference is where the **agent loop** runs:
the part that calls the model, decides what to do next, and keeps the conversation.

- **Agent in the cloud.** The whole agent runs remotely. Either Claude Code, Codex, OpenCode, or
  Cursor runs inside a Ryu Box, or the provider runs the agent in its own cloud (`claude --cloud`
  or `codex cloud exec`). This is the same idea as a Claude Code or Codex cloud session.
- **Agent on your computer.** The Ryu agent stays in Ryu on your node: the agent loop, its model
  calls, and its memory stay there. Only the sandbox runs in isolation: the files, edits, and commands
  of the task, or a Box's screen and browser.

A third option is neither: a run on your own plan **on this node** runs Claude Code or Codex
directly on your node, in a separate worktree of your checkout, with no cloud sandbox.

<Callout type="warn">
  Claude and ChatGPT plans are meant for your own use. Providers such as Anthropic can detect plan
  traffic from datacenter and sandbox IPs and restrict or ban the account. If the agent runs
  in the cloud, use an API key, or let the provider run it in its own cloud. To use your plan
  with a cloud sandbox, keep the agent on your computer.
</Callout>

### Agent on your computer

With the **Ryu** agent, a cloud task keeps the model, tools, and memory on your node. Its command
and file tools run inside the isolated workspace instead of on your machine. See
[Cloud environments](/docs/surfaces/desktop/user-guide/cloud-environments).

A conversation without a cloud task can also get a **session Box** for computer use and the
browser. Those two run on the Box's screen; everything else stays on your node. See
[Ryu Boxes](/docs/core/boxes#session-boxes).

Today this mode works with the Ryu agent only. Claude Code or Codex signed in on your computer
cannot use a cloud sandbox for their files and commands; they run either on your node or, as an
agent in the cloud, inside the Box.

<Callout type="info">
  "On your computer" assumes Ryu Core runs on your own machine or a machine you host. On a node
  that Ryu hosts for you, Core runs in the cloud too, so model traffic from the Ryu agent and runs
  "on this node" come from a datacenter IP. For that reason, running on your Claude or ChatGPT
  plan from a node that Ryu hosts, on this node or in the provider's cloud, is not available yet.
</Callout>

### Agent in the cloud

When you pick **Claude Code**, **Codex**, **OpenCode**, or **Cursor** for a **Fresh cloud box**
environment, the agent's command-line tool runs inside the Box and calls the model from there.
Bind the agent's API key, for example `ANTHROPIC_API_KEY` or `OPENAI_API_KEY`, as an environment
variable.

When the provider runs the agent in its own cloud, through **Run on your own plan**, your plan
is used the way the provider offers it. See
[Cloud sessions on your own plan](/docs/surfaces/desktop/user-guide/cloud-sessions-on-your-plan).
