These settings live in the agent editor. For the rest of agent setup, see the
[Agents guide](/docs/surfaces/desktop/user-guide/agents).

## Choose an agent avatar

In the agent editor, choose **Upload**, **Icon**, **Emoji**, **DiceBear**, **Dither**, or
**Expressive** for the agent's avatar. When an installed plugin provides an avatar style, a
**Styles** tab also appears. Pick a style, change the seed or select **Randomize avatar** for a new
look, then adjust the color and each part. Expressive keeps Ryu's ghost body and gives its eyes named
moods such as **Happy**, **Laughing**, **Curious**, and **Sleepy**. Choose **Random** to let the
avatar cycle through moods while blinking and following the pointer, or choose a named expression to
keep one mood selected.

Choose a separate animation from **Idle**, **Thinking**, **Wink**,
**Wide eyes**, **Alert**, **Notification**, **Exclamation**, **Sleep**, **Egg**, **Hexagon**,
**Play**, **Orbit**, **Burst**, or **Comet**. **Random** runs the full sequence with the same
smooth cross-fade between states; a named animation stays deterministic for the saved avatar.
Ryu automatically uses **Orbit** for an expressive avatar in the live thinking/working status row.
The existing eyes-only logo remains a separate compact logo variant.

### Expressive ghost appearances

Open the agent editor and select its avatar, then choose **Expressive**. Ghost avatars support **3D ghost**, **Outline**, **Muted outline**, **Orb**, and **Halloween costume** appearances. Existing expressive avatars keep their saved mood and animation.

Choose **Choose expressions** to select any named expression or animation, including **Random** for automatic cycling. Customize the base and three accent colors, eye size, color-cycle duration, and whether the avatar animates. Outline styles use Accent 1; the 3D body can use a solid color or flowing orb colors. Save with **Use ghost avatar** and save the agent. These settings also travel with exported and published agents.

Choose **Follow conversation** for a face driven by conversation activity:

| Conversation activity | Avatar reaction |
| --- | --- |
| Waiting for a response or reasoning | Thinking expression and dots |
| Writing a reply | Attentive face |
| Running a tool | Working/thinking face |
| Waiting for input or approval | Attentive face and notification |
| Request failed | Concerned face and alert |
| Idle or no live conversation context | Neutral face |

Conversation-following avatars use current chat signals rather than a random mood. Sidebar avatars also reflect the conversation's saved run status; interrupted runs wait for attention instead of appearing to keep working. Outside a conversation, the avatar rests in its idle pose. Turning animation off or enabling reduced motion stops automatic movement while still allowing the face to show the current state.

### Dress an agent in a costume

Choose the **Halloween costume** appearance to dress the ghost. Pick a ready-made **Costume** such as
**Pumpkin king**, **Witch**, **Vampire**, **Mummy**, or **Black cat**, or set each part on its own:

| Part | Choices |
| --- | --- |
| Colour | Witchlight, Slime, Pumpkin, Moonbeam, Bone, Candy, Blood moon, Midnight |
| Finish | Smooth, Gradient, Plastic, Sheet fabric, 3D, Ectoplasm, Glass, Holographic |
| Eyes, brows, mouth | Faces such as Starry, Smitten, Wicked brows, Fangs, or a Lantern grin |
| Ears | Cat ears, Bat ears, Bunny ears, Devil horns, Neck bolts |
| Headwear | Witch hat, Pumpkin cap, Crown, Top hat, Halo, Party hat |
| Glasses | Round, Star, Heart, Monocle, Eye patch, 3D glasses, Shades |
| Accessory | Bow tie, Vampire cape, Scarf, Candy bucket, Wand, Lantern |
| Pattern | Mummy wraps, Skeleton, Stitches, Stripes, Polka dots, Cobweb |

Changing any part turns the costume into a **Custom mix**. A costumed avatar keeps the face you
dressed it with, so it does not follow conversation activity, and the base colors, eye size, and
color cycle do not apply. The costume is saved with the agent like other avatar settings.

Plugins from the Marketplace can add more costume parts. They appear under **From Marketplace** in
the matching part list. If you turn off or remove the plugin, the agent keeps your choice but shows
the built-in look for that part until the plugin is back. Plugin authors can read
[Avatar accessories and styles](/docs/extend/develop/extensions/avatar-contributions).

## Agent profile banners

In the agent editor, open **Advanced → Profile card** and choose **Customize** on the banner, then
**Browse Marketplace wallpapers** to select a Marketplace background. The wallpaper renders through
Ryu's built-in backdrop adapter and is added to this device's Wallpaper Library. Agent banner
choices are stored on the active node, so every device connected to that node uses the same banner.
Existing style and color controls remain available.
