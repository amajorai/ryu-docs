---
title: Forms
description: How to build a form in the Forms app, publish its respondent link, review and export responses, and the per-node limits
---

Forms lets you build a simple form, share a public link, and collect answers. Open Forms from the Apps shelf in Desktop. Its workspace holds your forms and their responses on the active Ryu node.

## Create and edit

Select **New form**, enter a title and link name, then choose a blank, contact, or feedback template. A link name uses 3 to 48 lowercase letters, numbers, and hyphens. `admin` and `status` are reserved for the app itself, so Forms rejects them. The editor is a document page. Edit the title, description, prompts, helper text, and choice labels in place while answer controls stay visible. Type a question and press **Enter** to add a short-answer block, or type **/** to open the question block picker.

Each question's controls appear when it is focused or hovered. Use them to change the answer type, mark the question required, move it, or remove it. Add and edit choice options inline. The submit button appears below the questions. Expand **Confirmation screen** below it to edit what respondents see after submitting. Select **Save changes** to keep the current edits.

## Publish and share

Select **Publish** after you add at least one question. The public respondent page uses the form's Ryu node link. When the active node has a reachable web origin, the app uses it. Otherwise it shows the route path for you to combine with the node address.

Anyone who can reach the link can submit a response without signing in. **Unpublish** stops new responses and keeps existing submissions. When you save edits to a published form, the existing link serves the updated questions.

## Review and export

Open **Responses** to review answers in submission order. Select **Load older responses** to move through additional pages. **Export CSV** downloads all responses for that form.

Deleting a form permanently deletes its responses from this node.

## Limits

| Limit | Value |
|---|---:|
| Forms per node | 100 |
| Questions per form | 40 |
| Responses per form | 1,000 |
| Responses across the node | 2,000 |
| Submissions per form per minute | 30 |
