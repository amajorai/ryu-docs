---
title: "Ryu OS"
description: "The agent-first desktop workspace with a dock, live app windows, Mission Control, and curated wallpapers."
---

Ryu OS is the workspace view inside the Ryu desktop app. It gives Ryu Apps a familiar home: a
dock for the surfaces you use often, live windows for active work, and Mission Control for finding
the next thing without losing the current one.

Ryu OS is a surface, not a second runtime. It uses the same Core sessions, Gateway policies,
permissions, and tab state as Ryu Console.

## Workspace model

### Dock

The dock starts with the first-party surfaces people reach for most often:

- Mission Control
- Chat
- Spaces
- Tools
- Skills
- Apps
- Review

Each item uses the same manifest-backed app-icon treatment as the Store and desktop sidebar,
including the declared glyph, raster art, dither/background, and logo inset. A shell surface that
has no manifest plate gets a deterministic seeded plate behind its glyph, while any declared
manifest presentation always wins. Selecting an App opens its existing Ryu route as a window in
the workspace. If that surface is already open, Ryu brings its live window forward instead of
starting the work again. Mission Control opens the workspace command dialog rather than a content
window.

The dock uses a pointer-aware magnification effect with a square hit area for every item, keeping
each icon centered as it grows. Its items are keyboard-focusable, so it remains usable with a
keyboard as well as a pointer.

## OS menu bar

The OS menu bar groups workspace actions into **Ryu OS**, **Window**, and **View** menus. Its chrome
stays transparent over the wallpaper; only an opened menu uses an elevated popover surface. The
Window menu lists open windows and includes Mission Control. The View menu contains the wallpaper
set choices and shuffle action.

### Live windows

Each open surface is backed by the desktop workspace's existing tab state. The window header uses
Ryu's own right-side minimize, maximize/restore, and close controls. Minimizing keeps the window in
Mission Control; closing closes its tab. Switching to another window keeps the underlying session
mounted so work can continue without a restart.

### Mission Control

Select the **Mission Control** icon in the dock, choose it from the **Ryu OS** or **Window** menu,
or press `Cmd/Ctrl-K`. The command dialog searches both available dock Apps and windows already
open. Choosing an App opens it; choosing an open window brings that window forward.

## Wallpaper

Ryu OS starts with a random image from its curated Unsplash wallpaper sets. Use **View → Wallpaper
sets** to choose a mood, then select **Shuffle wallpaper** to choose another image from that set.
The workspace keeps a dark readability gradient over the image, and the solid color underneath
keeps the surface usable when the image host is unavailable.

Wallpaper is presentation only. It does not send workspace content to the image host.

## Product boundaries

Ryu OS is for arranging and switching between work. Use [Ryu Bot](/docs/surfaces/desktop/bot) when
you want managed AI without configuration, or [Ryu Console](/docs/surfaces/desktop) when you need
to operate nodes, models, tools, permissions, and Apps.

[Ryu Gateway](/docs/gateway) remains the control point for governed model, tool, and Skill calls.
[Ryu Box](/docs/core/boxes) provides an isolated execution workspace, while [Ryu Hire](/products/hire)
is the one-off, credit-based path for recruiting a specialist without installing it.

## Availability

Ryu OS is a desktop workspace feature. Other clients may expose the same Apps or sessions, but
they do not inherit the desktop dock or window chrome unless their host supports those controls.
