---
title: "Raycast"
description: "Reference for the Ryu Raycast extension on macOS and Windows: its three commands, its preferences, and how it talks to Core."
---

The Raycast extension (`apps/raycast`) lets you ask Ryu questions, chat, and search past
conversations from Raycast on macOS and Windows. It calls Core directly. Raycast commands run in a
Node context with no browser `Origin` header, so Core's CORS rules do not apply.

## Commands

| Command | What it does |
|---|---|
| **Ask Ryu** | Answers a one-shot question, streamed into a Detail view |
| **Chat with Ryu** | Runs a multi-turn conversation in a List view |
| **Search Conversations** | Browses your past [conversations](/docs/core/conversations-sessions) |

## Preferences

| Preference | Default | Meaning |
|---|---|---|
| **Ryu Core URL** | `http://localhost:7980` | Base URL of the running Core |
| **API Token** | empty | Optional bearer token for a Core that requires one |
| **Default Agent** | empty | Agent id to chat with; empty uses Core's default |

<Callout type="warn">
  The extension is excluded from the Bun/Turbo workspace (`!apps/raycast`) and builds with Raycast's
  own `ray` toolchain. Its `bun run test` suite covers preference normalization and Core SSE
  parsing; `ray build` and the live extension need a local Raycast install.
</Callout>
