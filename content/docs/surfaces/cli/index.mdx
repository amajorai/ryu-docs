`ryu-cli` is Ryu's terminal client, built with Bun and OpenTUI. It is for people who want Ryu in a
terminal or in scripts. It connects to the same Core as Desktop over HTTP and Server-Sent Events
(SSE), so conversations, agents, apps, and node settings stay shared across clients.

```sh
ryu-cli
```

Run it with no arguments to open the interactive workspace, or as `ryu-cli <subcommand>` to run one
command and exit. Install Ryu with the [Getting Started guide](/docs/start-here/getting-started)
first. From a source checkout, run `bun run --filter cli dev`.

## What it includes

The workspace provides chat, agents, groups, tasks, a library, workflows, spaces, tools, and app
contributions. `Ctrl+K` opens the command palette, `Ctrl+N` switches nodes, and `Ctrl+T` opens a
chat tab. `Ctrl+Shift+M` switches between Bot, Agent, and OS; Agent appears only after the CLI
verifies owner or admin access for the active managed node. Rich editors, phone-only controls, and
operating-system window effects stay in their native surfaces.

Requests to a managed node use that node's delegated credentials, and switching nodes keeps each
request bound to its own node. Official binaries update themselves in the background when the
shared **Automatic updates** setting is on; see
[Automatic CLI updates](/docs/surfaces/cli/getting-started#automatic-cli-updates).
