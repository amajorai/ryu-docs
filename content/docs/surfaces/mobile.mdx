## Delegation

Open **Delegate** to run a focused task in a separate session. Enter the task and
choose **Research**, **Read code**, **Edit code**, or **Summarise** before selecting
**Run delegate**. The selected preset is exposed to assistive technology. If the
task cannot start, the screen keeps a readable error and connection/permission
guidance visible so you can correct the issue and try again.
