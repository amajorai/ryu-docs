---
title: "On-device models"
description: "Download and run curated GGUF models on a Ryu Mobile device."
---

The Models screen starts with two curated choices: SmolLM3 3B Q4_K_M and Qwen3 4B Q3_K_M. Weights
are never bundled or downloaded without the user selecting a model. Downloads are resumable,
support split GGUF files, write through a temporary file, and finish with an atomic move into
app-scoped storage.

The Mobile screen combines Core's universal DownloadCenter snapshot and SSE events with the native
handset-copy task using the same lifecycle states and progress fields. Core remains the authority
for node-side staging; the handset task is the final local copy leg.

`llama.rn` is compiled into a native development client or EAS build. Expo Go and the browser do
not load the native module. Browser-local AI remains a separate browser provider path.

## Model lifecycle

1. Select a curated model on the device.
2. Download the model into app-scoped storage.
3. Resume an interrupted or split-file download when possible.
4. Stage the model through Core when the run needs a node-side copy.
5. Run the model locally through the native `llama.rn` module.

The device does not download model weights in the background without the user's selection.
