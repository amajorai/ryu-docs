The same Ryu Mobile app adapts to the window it runs in. Layout follows rotation, iPad Split View
and Stage Manager, Android multi-window, foldable postures, and resized windows.

## Screen sizes

| Device or window | Layout |
| --- | --- |
| Phones and narrow windows | The swipe-in navigation drawer and full-width content. Phones in landscape keep the swipe-in drawer, because a pinned sidebar takes too much room on a short screen |
| iPad, Android tablets, and foldables | Content is centered in a readable column once the window is tablet-sized. In wide (landscape) windows the drawer stays pinned as a sidebar and the menu button is hidden. Connected app surfaces keep the full width, and bottom sheets such as Search stay centered |
| Dual-screen and foldable devices | Laid out by window size. A folded outer display uses the phone layout, an unfolded inner display uses the wide layout, and the layout switches as the window size changes |

Content stays clear of camera cutouts and status bars on every edge, including side insets in
landscape. In right-to-left languages the insets follow the reading direction.

## Other devices

- **Mac.** The dedicated [desktop app](/docs/surfaces/desktop) is the full Ryu experience on macOS.
  When the iPad app runs on an Apple silicon Mac, it uses the same sidebar layout and resizes with
  its window.
- **Chromebooks and Android desktop windowing.** The Android app runs as a resizable window with the
  same tablet and sidebar layouts.
- **Android TV.** Ryu is listed on the TV home screen. The sidebar stays pinned for remote-control
  navigation. Hardware the TV lacks, such as a camera, Bluetooth, or a touchscreen, is optional, so
  tools that need it report it as unavailable instead of blocking installation.
- **Apple Watch and Wear OS.** A Ryu watch app talks to your agents through the phone; see
  [Watch and car apps](/docs/mobile/watch-and-car).
- **Apple TV.** Ryu Mobile does not run on Apple TV. For chat on Apple TV, use the separate
  [Ryu Bot apps](/docs/mobile/bot).

## Liquid Glass on iOS 26

On iOS 26 and later, Ryu uses Apple's Liquid Glass design:

- The app icon is a layered Liquid Glass icon, so it follows the Home Screen's default, dark,
  clear, and tinted styles.
- The menu is a glass panel over the screen it opens across.
- On list screens, the header is a glass bar and rows scroll beneath it. On other screens, the
  navigation button is a glass control.
- The chat composer floats as glass, and the Ryu keyboard shows the system's glass keyboard
  background.

On earlier iOS versions and on Android, the same controls use solid surfaces. The system's
Reduce Transparency setting is respected.
