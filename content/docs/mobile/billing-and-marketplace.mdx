In the default iOS and Android builds, Ryu Mobile shows the signed-in account's existing plan,
credit balance, usage, licenses, and installed apps. It has no upgrade, checkout, or top-up controls.

Marketplace item pricing is optional listing metadata. For skills, MCP servers, and plugins, a price
does not gate browsing, installation, or use on Mobile, so paid and free rows install the same way.
Paid language packs are the exception (see below).

## Browse Mobile catalogs

The native Marketplace has four catalog tabs: **Skills**, **MCP**, **Plugins**, and **Languages**.
The tabs keep all four labels on one line at phone widths.

Enter a query and submit it with the keyboard or **Search** to filter the selected catalog:

- MCP server searches use the active node's catalog.
- Plugin searches match the catalog entry's name, description, source, kinds, tags, or id.

After an install or catalog reload, Mobile keeps the active query in the results and shows the
updated installed state. Skills can also be installed from a repository or URL entered in the
search field.

Language packs show whether they can be installed or enabled on the active node. A paid language
pack that is not installed opens its Marketplace page on the web instead of installing.

## What Mobile can show

| Area | Mobile behavior |
|---|---|
| Plan | Show the current plan and access state |
| Credits | Show the current balance and usage |
| Licenses | Show existing Marketplace licenses |
| Installed apps | Browse and use installed apps when the host supports them |
| Paid actions | Hide upgrade, checkout, and top-up controls |

On iOS and Android, pull down on **Credits** to reload the balance and recent usage
from the signed-in account.

## Change your plan or add credits

Use the device or browser where you bought Ryu:

| Where you bought Ryu | Where to manage it |
|---|---|
| Apple | Apple Account subscriptions |
| Google Play | Play Store subscriptions |
| Web | Ryu on the web |

The same account keeps using its existing plan on Mobile. Core confirms access.
