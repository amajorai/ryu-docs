---
title: "Plans & Marketplace"
description: "How account access, credits, licenses, and Marketplace purchases behave on Mobile."
---

Ryu Mobile is a consumption-only surface for account billing in the default iOS and Android
builds. It can show the signed-in account's existing plan, credit balance, usage, licenses, and
installed apps, but it does not show upgrade, checkout, or top-up controls.

Marketplace app and plugin prices do not gate catalog browsing, installation, or use on Mobile, so
paid and free rows keep the same install path.

If you need to change a plan or add credits, use the device or browser where you purchased Ryu.
Marketplace item pricing is optional commerce metadata. Apple purchases are managed in Apple Account
subscriptions, Google Play purchases in Play Store subscriptions, and web purchases in Ryu on the
web. The same account can continue using an existing entitlement on Mobile; Core remains the
authority that confirms access.

## What Mobile can show

Mobile can present the account state that already exists for the signed-in user:

| Area | Mobile behavior |
|---|---|
| Plan | Show the current plan and access state |
| Credits | Show the current balance and usage |
| Licenses | Show existing Marketplace licenses |
| Installed apps | Browse and use installed apps when the host supports them |
| Paid actions | Hide upgrade, checkout, and top-up controls |
