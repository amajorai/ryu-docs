Ryu Mobile lets you use Ryu on your phone. Choose a remote Ryu node and agent, or use a model
downloaded to the phone. Downloaded models use local GGUF files and `llama.rn`.

Mobile is a native wrapper of the shared Desktop shell contract. Marketplace apps and host-rendered
contributions can reuse the same navigation and UI vocabulary, while Mobile keeps its own bridge
and explicitly omits Desktop-only native effects. “Supported on Mobile” means the declared support
level for this host; it does not mean the package owns or replaces the Mobile shell.

## Shared chat actions

Mobile chat actions are native to the handset. They include rename, pin, archive, and delete, but
omit Desktop window, tray, updater, file-manager, editor-launch, and always-on-top window controls.
Shared UI blocks feature-detect the mobile host instead of inferring Desktop behavior from screen
size or user agent.

## Native capability checks

Check `host.capabilities` before showing a native action. The host may lack a capability because the
OS, build, foreground state, or permission does not support it. See [Native bridges](/docs/extend/develop/extensions/native-bridges)
for the cross-surface contract.
