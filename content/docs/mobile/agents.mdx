This page shows how to manage agents from Ryu Mobile. Changes are written to the active node, so
they also appear on Desktop when it uses the same node.

## Add or remove agents

Open **Agents** to add or remove an agent on the selected node. If a change fails, the agent row
shows the error and keeps its earlier state. Fix the connection or permission problem, then use
**Add agent** or **Remove agent** again. The list refreshes after the node confirms the change.

## Create or edit an agent

Create or edit agents from the Agents screen. Agent details include the prompt, tools, skills,
delegation setting, engine, and an optional model override. **Save agent** writes them to the
active node and refreshes the Agents list in the drawer. Built-in agents marked as locked cannot be
edited.

A new agent starts with **How should this agent work?**:

1. Choose **Acts as you**, **Its own identity**, or **Both**. The choices mean the same as on
   desktop; see [Create a new agent](/docs/surfaces/desktop/user-guide/create-agent).
2. Choose **Continue** to the details. **Change** on the details screen goes back to the choice.

When you edit an agent, its **Identity** section lets you change the choice. Before you save, Ryu
asks the node whether the agent's engine can start with that identity. If it cannot, the editor
shows the reason and **Save agent** stays disabled until you pick another engine or identity.

An agent whose engine is a remote A2A peer (`a2a:<peer>`) runs on that peer's node, with the
accounts set up there. Its **Identity** section shows **Runs on another node** instead of the
identity choice and account access.

## Choose which accounts an agent can use

When you edit a saved agent, **Account access** chooses which accounts it can use. The rules match
desktop; see
[Choose which accounts an agent can use](/docs/surfaces/desktop/user-guide/agent-account-access#choose-which-accounts-an-agent-can-use).

- With **Limit to selected accounts** off, the agent can use every account its identity allows,
  including accounts you connect later.
- Turn it on to choose. The list starts with every account switched on, so nothing changes until
  you switch an account off. Accounts you connect later are not added to a limited agent.
- Turning the limit off and on again before you save restores your last selection.

Accounts are grouped by identity:

| Identity | Accounts listed |
| --- | --- |
| **Acts as you**, **Both** | Your accounts: connected apps, model providers, MCP sign-ins, services that use your saved keys, and control of your desktop |
| **Its own identity**, **Both** | The agent's own accounts: website logins it created and apps connected to its own identity |
| Every agent | **Treg**, the metered tool service described in [Gateway tools](/docs/gateway/tools) |

The selection is saved with **Save agent**, and the engine check uses it. A new agent starts with no
limit; open it again after saving to limit it. Connecting new apps to an agent's own identity and
choosing Identity Vault profiles are available on desktop only.

## Delegate a task

Open **Delegate** to run a focused task in a separate session.

1. Enter the task.
2. Choose **Research**, **Read code**, **Edit code**, or **Summarise**.
3. Choose **Run delegate**.

If the task cannot start, the screen keeps the error and connection or permission guidance visible
so you can fix the problem and try again.
