The extension can show browser notifications when an agent replies, needs approval, or finishes a
run. Each notification uses the sending agent's avatar as its icon. For the other extension entry
points, see [Popup and New Tab](/docs/browser-extension/popup-and-new-tab).

## Turn notifications on

Notifications are an optional permission, so updating the extension does not add a new permission
warning. The dashboard asks for it during onboarding, or when you turn on
**Settings → Privacy → Device permissions → Notifications**. If you decline, turn it on again there
or from your browser's extension settings.

## When notifications arrive

While a Ryu tab is open, it raises every notification. When none is open, the extension's
background worker checks the connected node about every 30 seconds and notifies you when an agent
finishes a run. Clicking the notification opens that conversation.

This background check uses the `alarms` permission, which shows no install warning, and only runs
after you turn notifications on.
