The extension stays usable when the network or your Ryu node drops out, and the browser keeps the
extension itself up to date. Sign-in and account switching are covered in
[Accounts and Sign-In](/docs/browser-extension/accounts).

## Offline and node status

The popup and New Tab stay mounted when the browser reports that the device is offline or when the
selected node stops answering. A compact status toast shows the state:

| Toast | Meaning |
|---|---|
| **Offline mode** | The extension waits for browser connectivity |
| **Node offline** | The extension retries the selected node |
| **Connection restored** | Live access returned; the confirmation appears briefly |

The dashboard uses the same connection status as Desktop. Connection checks, page-context sharing,
and auto-save pause while the page is hidden.

If saved connection data is malformed, the extension falls back to the local connection. Add the
intended node again in Settings.

## Preferences

Browser feature preferences are stored in the extension's local storage. If a preference cannot be
saved, its control keeps the previous saved value.

## Extension updates

When installed from a browser's add-on store, the browser checks for and installs extension
releases. Ryu does not download or replace the extension package itself.

The **Ryu … is available** notice inside the extension refers to a release for the connected Core
node, not to the extension package. Unpacked development builds need to be rebuilt and reloaded by
the developer.
