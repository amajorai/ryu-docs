The extension gives you several ways to start a chat without leaving the browser. This page covers
the toolbar popup, New Tab, the `ryu` omnibox keyword, and the full-page dashboard. For the chat
panel inside a web page, see [In-page Copilot](/docs/browser-extension/copilot).

## Entry points

| Entry point | Where it appears |
|---|---|
| Popup | The browser toolbar button |
| New Tab | Every new tab, with the SmartBar |
| Dashboard | A full-page view of chat, services, and settings |
| `ryu` omnibox keyword | The address bar |
| In-page Copilot and Ask Ryu | On top of the page you are reading |

The extension can also save pages, and work with tabs, screenshots, and downloads.

## Toolbar popup

On a regular web page, the browser toolbar opens the popup. The popup has three parts.

- The header shows a status dot for your Ryu node, an **Open Ryu** button that opens the
  dashboard, and the account menu.
- Below it is the **Quick Chat** box with the browser-model picker. Quick Chat carries the text
  into an unsent chat draft so you can review it before sending.
- Under the composer, one list holds the page actions for the active tab (**Chat with this page**,
  **Find on page by meaning**, and **Save to Bookmarks** when the Bookmarks app is installed),
  followed by up to five recent chats. A recent chat opens in the dashboard.

The account menu holds **Settings**, **Services**, **Organizations**, the theme, the prompt-tools
and page-copilot toggles, and **Import browser bookmarks** when the Bookmarks app is installed.
The popup, New Tab, and the in-page tools follow your system's light or dark appearance until you
choose a theme in the account menu.

## Services

**Services** opens the extension's service manager.

- Each service shows a status dot and one action: start, install, update, or retry.
- **Stop** and **Restart** for a running service are in its **⋯** menu.
- **Start all** is in the header. **Stop all** and installing missing dependencies are in the
  header's **⋯** menu.
- When a dependency check fails, Services shows the error that Core reports. When Services cannot
  load, it says so and offers **Retry**.

## New Tab SmartBar

New Tab's SmartBar opens typed URLs and search destinations in the current tab.

- When a query has more than one destination, they appear under the bar.
- Press **Tab** to cycle from an AI question to its search fallback.
- Use a `!` bang to choose a search engine.
- Prompts routed to Ryu open as unsent drafts in the dashboard chat.

One picker under the bar chooses the agent and the browser model. A model that can answer but
cannot run page actions is marked **Chat only**. The picker's last item, **Add custom model…**,
adds a Hugging Face model by its `org/model` id.

The SmartBar and the `ryu` omnibox also show instant local matches. See
[Local and page search](/docs/browser-extension/search).

When you are signed in, the bar under the New Tab SmartBar shows your
[primary bot](/docs/core/primary-bot) on the active node. Pick a bot to make it your primary bot,
or choose **Clear primary** to return to the node's default. A filled star marks an available
primary bot. The choice is saved on the node for your account, so other clients connected to that
node read the same one.

## Companion apps in the dashboard

Apps that your node contributes appear in the dashboard sidebar, as they do in the desktop app.
Opening one mounts its companion in the tab. The dashboard mounts both JavaScript and single-file
HTML companions in isolated sandbox frames. Unless you turned off the default content policy for a
custom app, a companion cannot open network connections itself. It reaches Ryu only through the
host bridge, where an approved app can:

- call its own sidecar API;
- use speech synthesis;
- list and install engines.

Each call keeps the active node's signed-in member identity and needs the matching approved app
permission. Closing the app cancels its subscriptions and in-flight streams.

## Get other Ryu apps

The account menu in the extension popup and in the full-page dashboard has a **Get Ryu apps**
submenu. It opens the download page for the desktop app in a new tab. It never lists the browser
extension itself, and it lists the mobile app only when that app can be installed from an app store.
