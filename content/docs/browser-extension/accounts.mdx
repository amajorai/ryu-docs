The extension signs you in to a Ryu node and keeps your member identity separate from the node's
connection credential. This page covers what you see when access is gated and how account changes
behave.

## Access checks

The signed-in popup and New Tab follow the account's waitlist status. By default every active node
is gated, including local, self-hosted, and previously connected nodes. An account still on the
waitlist sees the waitlist state on a gated node. If the approval status cannot be checked, the
workspace stays locked unless the account has a cached approval.

An approved account also needs a passkey or an authenticator app. Until it has one, the popup and
New Tab show **Set up two-factor authentication**.

- **Open setup page** opens the website's setup page in a new tab.
- **Check again** opens the workspace once the factor is in place.

See [Required second factor](/docs/security/authentication-account#required-second-factor).

## Two-factor setup in Settings

When you turn on two-factor authentication in Settings, verify your authenticator code to finish
setup. The extension then shows your recovery codes. Save them so you can sign in if you lose
access to the authenticator.

## Expired sign-in

If a browser sign-in handoff expires, the dashboard explains that it could not finish sign-in.
Choose **Continue** to return to chat, then start browser sign-in again.

## Shared nodes and account switching

Requests to a shared node carry your current signed-in member identity separately from the node's
connection credential. Switching accounts or signing out discards the previous member identity,
including token exchanges that were already pending. While the new account's identity is being
resolved, the node may refuse a request. Sign in with the intended account and retry the action.

## Browser session linking

Page content sends browser-session linking requests to the extension's background worker. The
worker selects the active node and prepares fresh identity headers. Page scripts do not receive the
account credential. Ghost Mode skips session linking.

Browser tools that change a page or move data need your approval. See the
[approval boundary](/docs/browser-extension/browser-tools#approval-boundary).
