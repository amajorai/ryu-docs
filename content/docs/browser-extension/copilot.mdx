The in-page Copilot is a chat panel that opens on top of the web page you are reading. Use it to
ask about the page or a passage without switching tabs.

## Open the Copilot

- Right-click the page and choose **Chat with Ryu about this page**.
- To ask about a passage, select text and choose **Ask Ryu about "…"**. The menu item shows your
  selected text.

The Copilot uses the shared compact composer. **Enter** sends and **Shift+Enter** adds a line.
The Copilot controls and the toolbar on AI sites render inside a shadow root, so page styles do not
change them. They also work on pages that prohibit inline styles.

## Page text and selected text

The Copilot attaches the current page text and any text you select as separate context
attachments. Both are included when available, and you can exclude either before sending. Keyboard
users can expand a preview to read the page text or the complete selection. The captured selection
stays attached for the next turn until you select something else or clear the selection on the page.

The text is bounded and treated as untrusted page content. Read-only
[browser tools](/docs/browser-extension/browser-tools) can read the same page text and selection.

## Stop a reply

Stopping a reply in the Copilot, Dashboard chat, New Tab, or Ask Ryu stops it on your Ryu node as
well. Closing that view or its page while a reply is still streaming stops the reply the same way.
For local Browser models, see
[Switch between Browser and Core models](/docs/browser-extension/local-models#switch-between-browser-and-core-models).

## Prompt tools on AI sites

On supported AI chat sites, the extension shows its own toolbar on the page.

- **Enhance** rewrites the current draft and puts the result back in the site's composer for
  review. It does not submit the message.
- **Prompts** opens an extension-local library where you can search, create, edit, and delete
  templates. Templates can use `{{variable}}` fields. Choosing one opens a short form and inserts
  the completed text into the composer.

This library is stored by the extension and is separate from Prompt Studio in other Ryu clients.
