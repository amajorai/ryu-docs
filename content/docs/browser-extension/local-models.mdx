The browser extension can run a small language model inside the browser, with no Ryu node doing
the inference. Choose the **Browser** provider in an extension model picker to use it.

## Default model and runtime

The default is SmolLM2 135M Instruct (`onnx-community/SmolLM2-135M-Instruct-ONNX-MHA`), an
instruction-tuned ONNX export that includes its chat template. Curated models and compatible
Hugging Face model IDs load through Transformers.js in the extension worker or offscreen runtime.
The selection is remembered per agent and browser entry point. If an older base-model selection is
still saved, choose the SmolLM2 entry again to switch to the instruction-tuned default.

- The runtime uses WebGPU when the browser supports it. It falls back to WebAssembly (WASM) when
  WebGPU cannot load the model or returns an empty answer.
- The WASM runtime ships inside the installed extension. Model files download on first use and
  stay in the browser cache for later turns.
- The extension reports preparation progress before it starts a local turn. If preparation fails,
  **Retry** tries again with the same model, and **Settings** opens the model configuration.

Browser-local inference is separate from Mobile's `llama.rn` path ([Mobile models](/docs/mobile/models))
and from Core-hosted inference ([chat and model providers](/docs/providers/chat-and-models)).
The **Ask Ryu** widget on the public website uses the same browser model runtime; see
[Ask Ryu on the public site](/docs/surfaces/public-website#ask-ryu-on-the-public-site).

## What is sent to Core

After a local turn finishes with no pending approvals, the extension links it to the conversation
on your Ryu node. The link carries a length-limited copy of your message, the reply text, the model id,
the page title and URL, and a per-tool `ok` or `failed` summary. It does not upload the full page body, DOM index,
screenshot, or raw tool results. Ghost Mode skips the link.

## Switch between Browser and Core models

In New Tab, choosing a Browser model clears the Core agent selection. A saved local model is
restored when you reopen the page; reopening alone does not download weights. Its next request
uses the browser runtime and cached files.

Choosing a Core agent returns requests to that agent. Choose the Browser model again to return
to local generation.

In the in-page Copilot, **Stop** cancels a local request and drops its late answer, session link,
and later browser actions. The current decoding step finishes before the cancel takes effect. You
can then send a new request with the prepared model.

<Callout type="warn">
Stopping generation does not undo a browser action that was already dispatched.
</Callout>
