---
title: "Browser-local models"
description: "Run local inference in the browser extension with Transformers.js."
tags: ["browser", "models", "transformers"]
---

Choose the **Browser** provider in an extension model picker. The selection is remembered per agent
and browser entry point. Curated models and compatible Hugging Face model IDs load through
Transformers.js in the extension worker or offscreen runtime.

WebGPU is preferred when the browser supports it. The runtime falls back to WebAssembly (WASM) when
WebGPU cannot load the model. The model remains in the browser cache, and the extension reports
preparation progress before it starts a local turn.

Browser-local inference is separate from Mobile's `llama.rn` path and from Core-hosted inference.
The extension can send a bounded transcript and source metadata back to Core when you choose to link
the local turn, but it does not upload the full page body, DOM index, screenshot, or raw tool result.

## Ask Ryu on the public site

The public website uses the same reviewed browser model contract in its **Ask Ryu** widget. A
visitor can explicitly download the small ONNX model and ask documentation questions in the tab
without an account.

The widget also exposes a separate **My local node** mode: after the visitor enters a node address
and token, the browser calls that node directly and sends non-persistent chat turns through Core's
normal stream. The browser-local path never silently upgrades to the node path, and the node token
never goes through the Ryu control plane.
