The browser extension brings Ryu into the browser's toolbar, new-tab page, and active pages. It
shares the familiar chat and agent controls with the other Ryu clients, then adds browser-local
inference and permissioned browser tools.

It is a browser-hosted wrapper of the shared Desktop shell contract, with a browser-native bridge
for the capabilities Desktop cannot provide in a tab. Marketplace support marked **Browser
extension** therefore describes where a package can appear; it does not mean the package owns the
extension shell or receives Desktop-only native APIs.

## Entry points

The extension can expose the popup, dashboard, New Tab, Ask Ryu, in-page copilot, page saving,
tabs, screenshots, downloads, and the `ryu` omnibox keyword. Shared Ryu work can connect to Core
or Cloud for normal turns, agents, conversations, services, and settings.

## Connection-aware browser surfaces

The popup and New Tab stay mounted when the browser reports that the device is offline or when the
selected node stops answering. A compact status toast says **Offline mode** while it waits for
browser connectivity, or **Node offline** while it retries the selected node. The dashboard uses the
same shared shell status surface as Desktop, so Gateway, Settings, Spaces, databases, multiplayer,
and mounted apps keep the same behavior. A **Connection restored** confirmation appears briefly when
live access returns.

## Security boundary

The extension never exposes arbitrary JavaScript evaluation, cookies, hidden credentials, or
extension storage to browser tools. Page changes, navigation, downloads, uploads, clipboard access,
and page saving require the matching approval.
