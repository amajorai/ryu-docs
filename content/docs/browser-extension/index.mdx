---
title: "Browser Extension"
description: "Use Ryu chat and agents in the browser toolbar, the New Tab page, and the page you are reading, connected to your Ryu node."
tags: ["browser", "extension", "models", "tools"]
---

The Ryu browser extension puts Ryu in the browser toolbar, the New Tab page, and the page you are
reading. It is for people who want Ryu chat and agents next to their browsing. It uses the same
chat and agent controls as the other Ryu clients, and adds browser-local models and permissioned
browser tools.

The extension hosts the shared Desktop shell, with a browser-native bridge for the capabilities a
tab can provide. It connects to Core or Ryu Cloud for normal turns, agents, conversations,
services, and settings. A Marketplace package marked **Browser extension** can appear in the
extension; it does not own the extension shell or receive Desktop-only native APIs. The permissioned tools are listed in
[Browser Tools](/docs/browser-extension/browser-tools).

<Callout type="warn">
Automatic page saving and the Island page-context bridge are off by default. Turn them on
explicitly if you want them.
</Callout>
